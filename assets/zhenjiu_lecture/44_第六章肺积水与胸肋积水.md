# 第六章·肺积水与胸肋积水

是心脏。 首先， 先介绍心跟肺的关系。 心脏在这，肺在心脏的上面，心脏好像汽车的引擎，这肺好像水箱，两个水箱在平衡它的温度，所以人才有正常的体温。

一但肺积水，水太多了，就要想办法排掉，否则会把火熄灭掉，造成心肺衰竭的现象。 所以，五行里面心和肺彼此是火和金的关系，要想办法，让这两个脏之间达到平衡。 你把心脏治好，肺没有好，就是水箱没有修好， 汽车还是过热，还是不能开，这两个脏又称为上焦。

中间有横膈膜隔到，在膈膜以上是清气，大肠里面是燥矢浊气， 大肠都有所谓的浊气，浊气只能到横膈，所以横膈的一个功能就是分清浊，它一直在做分清浊的一个工作。

诸位现在有概念了，人得了肺积水，就是有水在肺里面的时候，肺是金，不可以有水，有水要下到肾脏去，若这水下不去，停在肺里面，病人就但坐不得卧，这是肺里面有积水的现象。

下针横膈，就下背后的膈俞。 第七椎， 至阳穴外开一寸半的膈俞。 正面下膻中，鸠尾穴及乳根，这几个都是近取穴。所以，积水一定要在这下方。 会重要，正常的情形，应该是像水蒸气一样。那针下去以后，就像把水倒下来。 要开沟疏通水道。 名字有沟，有谷，有溪，有海的，都是可以通利水道， 如小肠经的阳谷、后溪， 海如照海。 针灸穴道每个名称都有它的意义。 所以选择穴道不要死板板的，井荣俞经合、俞募治疗，都有它的意义，不能乱取。 这是远取穴， 主治是只能坐，不能卧，一卧就一直咳。

还有， 若胸肋积水，不管你是肺积水或胸肋积水，一般的西方医学，都是将管子插进去帮你抽水，但水抽出去后还会回来。 中医把水去掉，水就不会再回来。 胸肋积水，通常在左边， 甚为痛，那多数在左边， 也有在右边痛，那胸肋积水的辨证跟肺积水的辨证是不一样的。 肺积水不能躺，胸肋积水病人可以躺下去睡， 但是不能躺左边睡。 因为左边是血， 右边是气在管，那遇到这种情形， 因为是在胸肋之间， 也是阳维阴维脉所经过的地方， 可下外关， 临泣治疗。

要利水出来， 可用水分 、水道 、乳根。 近取穴有脾之大络大包可利水， 同时胸肋正好通到大包， 它在极泉穴下六寸， 可以通胸肋。 这是排水！ 告诉你如何治水。
