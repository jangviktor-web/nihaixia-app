# 第六章·针灸疗程与针后禁忌

针灸治病有疗程的。 这疗程，一般的病，都是隔日，一三五、二四六，去做疗程。 有的病一次就好了，有的要好几次， 扎一次，去掉了八成，那隔天就再扎。星期一下针，好甚多了，但还有一点， 星期三再下。 要让它完全去掉才能停止。 肝病，内科病也是一样。

那下针完了，还有禁忌，有几个禁忌： 第一个不要喝酒。 打麻将可以， 喝酒不行。辣椒不可以， 辛辣的东西不要吃。 还有，麻油，麻油不要用，不小心吃到，就再扎。 这些是下针后的禁忌。 下针以后，这三种东西会把效果减轻， 例如下针以后， 阳气在走， 你喝了酒， 会影响到阳气行走，辣椒也会影响到阳气行走。麻油也会， 它会让气比较乱。 扎完后，要告诉病人这三件事， 饮食上要注意。

做疗程的中间有这些禁忌，两天以上， 三天以后， 才可以再喝酒， 不能说当天完全好了， 马上就喝，还是要等个两天，最好是三天， 七十二小时后， 比较保险一点。 有些坏心的医生就不讲， 因为可以赚钱。

这就是选择穴道的方法。 同样的脾肿大， 怎么知道脾肿大？脸色发黄、 没有胃口 、肚子大 、少腹满 、肚子圆通通的， 而且脾主四肢，脾主肌肉，脾有问题的人， 身体会很沉重（身重）。 正常人因为气是往上升的， 阳气由脚底往上升的，所以人像个气球一样， 走路不会觉得重。 脾脏有问题时， 因脾主肌肉， 这个时候， 四肢就会很沉重。

肝病的人，肚子大，肌肉萎缩，是因为肝克到脾脏，脾脏肿大，所以肌肉会萎缩掉。
