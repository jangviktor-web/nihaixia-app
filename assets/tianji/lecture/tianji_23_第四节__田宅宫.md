# 第四节  田宅宫

田宅宫有几种意义；

第一种，过去东四命西四命，我们的房子怎么怎么做，这个都不需要那么复杂，紫微斗术的田宅有两个意义，第一个代表我们的祖业，祖产有多少，

第二个代表你自产吉与不吉，这个自产为什么会有吉凶? 比如说有的人火星落在田宅上，结果他买的房子一把火烧了， 第一个是因为他可能做人不好，或者是他自己就是粗枝大叶的人，常常自己点火，他忘了，这都是原因，还有人是小人星，看不到小人，什么叫看不到小人，我们后面介绍星座的时候会跟诸位介绍，那就是家里会遭窃，小偷都看不到，看到都是强盗了。这种人不要有自产，所以我们算命跟现在的法律也有关系，法律规定你的就是你的。还有房屋的坐象如何我们也是从田宅

宫看的。
