# 第二十四节  阳宅化解

阳宅上面东西南北，坤地，母在这里，父在这里，太太从先生住到先生的位置的时候，妻居西北， 而且要与夫同住在西，在一个房子里都算是成格，所以我老是怀疑上帝是女人，这个女人西南也可以住，西北也可以住，她住西南角的时候坤为地，在西北角的时候是地天泰，男人只能住西北角是乾为天，男人跑到这里就是天地否了。太太住到西北角的时候乾为天成格，这个住上去以后主的是夫妻感情非常好，因为先生是乾为天，太太是地天泰，这两个夫妻在一起的时候就是一种治世的状态之下，所以我们每次苦口婆心的跟他说，西北角去住，我怎么可能把64个卦讲一遍? 可是我在那边刚强的要求他住西北角，目的在这里。有的人有福，有的人没有福。举例，有一个客户，今天来找我，他们家这是卧房，这是一个和室，这是厕所，这是厨房，这是客厅。去年来的时候我就跟他说，这个房间不要，把这个做成主卧房，今天下午来找我，说帮我看看今年的流年，我说好，没有关系，八字命先拿出来，八字拿出来一看，今年是禄存，财星，对面是天马、太阴化忌，她说你看我先生今年怎么样?我说小姐，如果按照算命的话，你先生今年是禄存，财禄事业上很赚钱，但是天马化忌可能今年有车祸，但是你是住在天雷屋的位置，对不起，不是车祸，是官司是非纠纷，因为厕所在西北。他还执迷不悟住这里，你的名字是丈夫，你住到东宫上，天雷卦，妄卦，后面我会告诉你，一年前我叫他去住他没有听我的，等事情发生以后才来问我，问我还是官司是非，怎么化解? 还在问怎么化解? 又回到原来的。那我先生今年怎么样? 就在那边蒙。这是反渎，重复的讲话，你问我的问题重复的问就代表你没有收到。我说小姐，没有关系，今年你先生还要死，她的话题就转了。所以诸位要去蒙之道要学会。讲一次讲完了不要讲第二次。我常

常跟他说，先生运掌握在你手上，长幼有序，所以人要各安其位，各得其位，这就是礼，礼之后世界大同了，进入地天泰，治世就来了，但是治世来的时候，你一念一错，当场就有疾了，老天爷不客气了。所以泰卦的续卦就是否卦，我们的阳宅上和命在做加减的时候就在这个重点，如果他今年没有住东宫，住西南角，今年太阴化忌的话，不但要有官司，坐牢， 夫妻还要离婚。如果你无法训练，无法把你周围的人训练起来，听我们这套理论，那就不好意思了，你要介绍你的生意给我做，想办法说服他来找我。正名的问题，如果公司挂太太的名字的时候，太太在西南角，如果公司挂先生的名字的时候，先生在西北角，如果地天泰，太太在先生的位置的时候，可不可以挂太太的名字? 不行，还是得挂先生的。如果有一种状况，很简单， 我家很大，西南角又有房间，西北角有房间，我太太住这里，我住这里，也可以，随便，你只要有宫，为什么之前我讲不行，因为很多人这个有房间的时候，往往这里没有房间，是厨房，厕所、 餐厅，如果这里有房间，这里有房间换位置没有关系，太太在这里还是可以挂太太的名字。我看过所有的人，来这里的是阴阳调和的位置，阴要与夫同住，有的太太来住的时候，她的八字是杀，就会变成，她住进去可能是先生已经死掉了，或者是离异了，她独居以后， 就变成母代父职，妈妈就很辛苦了。这是孤星到老。所以这个位置一定要夫妻同时居住，最好的时机就是结婚了以后， 当天晚上住进去，开始住，如果吵架以后再去住，就是事后改，有没有效果? 有效，我曾经改过一个太太，很好玩的，我告诉太太去住，一般是3天到3个月，他们已经要离婚了，结果到70 几天的时候，太太打电话过来，今天早上我已经跟我先生签字离婚了，你说西北角有效，还是签离婚了，我说小姐，几天了? 她说70多天，我说还是10 几天，你再等一下，结果没有多久，有一个女的来找我，她说我今天也来找你算命，为什么? 我昨天下班看看一对夫妻牵手在马路边走，一看是我姐姐和姐夫，不可能，他们结婚十年吵架十年，我太清楚了，从来没有这种镜头，所以我今天来找你算。这是地天泰，这就是过去的案例，可以找到。
