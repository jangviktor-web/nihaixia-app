# 第六节 如何分辨君子与小人

所以在学之前这些都很重要的一个观念，社会上诸位出去看的时候，我们班来的程度，来的学生经过我筛选过的。各位都来自社会不同的行业，外面看到形统统不一样，你可能是办教育的，你可能从司法界。你可能做生意，外形统统不一样，没有一个人是同行的，神是一样的，所以说我们在讲的时候我们就在介绍天纪的时候，比如说什么叫君子，什么叫小人，它的定义是什么? 在汉朝有一个很有名的人叫做管辂，这个人是汉朝很有名的相学家，《管辂相法》就提到一句话，他在言语的相法里，为什么叫言语的相法呢? 就是听别人讲话的内容，就可以判定他是君子，君子和小人不会在脸上写着我是小人，我是君子的，你要听就知道了，为什么听呢?听有什么好处呢? 诸位有空到法院门口去看，在姜太公著的——部《阴符经》里面讲了两句话、八个字，他说“聋者善视，瞽者善听”，聋子的人就是耳朵听不到任何的，听说有人说，他说，你说，妈妈说，他听不到，因为听不到他只好用眼睛仔细的去看，瞽者善听，眼睛瞎的人叫做瞽者，他眼睛瞎了以后他看不到这个人美丑，上帝有规定说穿西装、打领带的人就不会骗人吗?有规定漂亮女孩讲的话都对吗? 没有规定，他眼睛看不到他只，好用耳朵仔细的听，所以这两者人都不会找上法院的，你看到法院被人家骗的，被别人搞的都是眼睛好的，耳朵好的，到底谁是残障人士? 残障的定义是什么?瞎子还好一点，不会被骗。所以我们在这边正名，耳朵听就知道了，不需要看他长什么样子。你看外面谁都不会额头上刺字， “我是小人”，但是他的动作是小人。君子呢? 和小人不太一样，诸们要了解我们的目的，君子言简刚中，说话很简单，一句话就到进去了，而且是很纲常直中，一句话通到底，小人的定义呢? 管洛就讲了，他说“谗言易入耳，邪言轻出口”，我举个例子给你听， 当年汉高祖在打天下的时候，有一个人，也是他的手下叫魏无忌，这个人说你要打天下，你要用陈

平这个人就可以了， 汉高祖一听很好，陈平你来报到，陈平来报道以后第二天又有两个人跑去跟汉高祖讲报告皇帝， 陈平这个人你怎么可以用? 听说、 有人说陈平在家乡跟他大嫂发生关系，这种人你可以用吗? 汉高祖一听马上就把魏无忌叫来，你这个魏无忌介绍这种人给我?你知道魏无忌怎么回答? 他说报告皇帝，我是介绍他的才能，我没有介绍他的品德，这就是言简刚中。结果天下打下来了， 陈平出了大功劳，可是簫何、 张良、 韩信就没看清楚他跟的汉高祖是小人， 所以开国三杰都被汉高祖给干掉了，所以容易听人家的谗言的这种人，讲人家谗言的这种人就是小人，所以当有人告诉你听说有人说，这个时候你不要听，其实就是他说的，我们三个是好朋友，我们好朋友们在一起，可是我很妒忌他，我很恨他，我就跑到你面前，这位小姐在背后怎么讲你你知道不知道?讲了一大堆，你脑筋清楚的话这些话就是他说的，就是我说的，其实我也很不喜欢你，很妒忌你，所以我就借用别人的名义说他的坏话，社会上这种人十之八九，那你一听就听进去，根本没有问他，法官办案子都要双方到面谈，什么叫真话，他说你说了这个话，我们三个人当面说这个话你敢不敢? 如果敢就是真的，如果你不敢你就是邪言轻出口，如果你把邪言听进去你也是小人，你讲人家你也是小人。所以我经常说大家平时没有事的时候下午茶的时候东家长李家短，大家不要浪费时间去做这种无谓的事情，你把智慧用在学习知识上面，学习以后再深思熟虑，明辨是非，一定要看清楚什么才是对的，这个才是我们要学的，所以我们今天为什么要讲这个东西，就是要以正视听，让大家都看的很清楚，所以我们国家现在感觉到教育不是很成功。所以希望能对大家有所帮助。
