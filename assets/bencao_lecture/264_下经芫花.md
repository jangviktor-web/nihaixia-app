# 下经·芫花

**【本经原文】** 一名去水。味辛，温，有小毒。治咳逆上气，喉鸣，喘，咽肿，短气，蛊毒，鬼疟，疝瘕，痈肿，杀虫、鱼。生川谷。

**【产地】** 产我国河南以及北地山谷中，庭园亦可种植，为约三四尺之落叶灌木，花入药。

**【性味】** 味辛（或作苦），性温，有毒（或作大毒）。

**【主治】** 芫花为行水祛痰要药，主水肿，水饮，痰癖，利血脉，治疮毒，参看甘遂大戟等条。[

1.去上焦水用芫花，去腹中水用大戟，去三焦水用甘遂。使用时一定要加大枣。]

**【别录】** 消胸中痰水喜唾，水肿，五水在五脏皮肤，及腰痛，下寒毒，肉毒，根疗疥疮，可用毒鱼。

**【甄权】** 治心腹胀满，去水气寒痰，涕唾如胶，通利血脉，治恶风痹湿，一切毒风，四肢挛急，

不能行步。

**【大明】** 疗咳嗽瘴疟。

**【药征】** 主逐水也，旁治咳掣痛。

**【用量】** 普通七分至二钱。

**【禁忌】** 时珍曰，饮有五，皆由内啜水浆。外受湿气，郁蓄而为留饮，芫花大戟甘遂，逐水泄热，能直达水饮巢囊隐癖之处，但可徐徐用之，取效甚捷，不可过剂，泄人元气，反甘草，能堕胎，孕妇忌用，醋制良，参看甘遂大戟条。

又来了一个非常凶的药，芫花。

芫花跟我们前面的甘遂、大戟。

大戟呢有的人叫红大戟，这个都是我们的大戟，没关系。

芫花质比较轻，质最轻，如果说我们要攻上焦的水，这都是涤水的要药，味辛，温，有毒。

如果这个人痰涎的壅塞很盛，胸腔里面痰涎很盛，脑部里面有积水，老师，芫花跟生半夏，哇你这个很凶啊，这俩个药对！非常的对症！这俩个药一下去痰水就排出来了。

所以芫花大部分是上焦，肺以上喉咙的痰水，峻剂，我讲峻剂就是你用一剂就够了，你不要叫病人吃一个礼拜来找你，这个都脱水了，脱了都成骷髅头，这个津液都没了嘛，因为肌肉里面水都被你发光了。

没有，吃一剂就好了，就是一副哦，那芫花的话，你在汤剂时用一钱，因为它是花类，很轻。

汤剂开的时候芫花一钱，甘遂两钱，红大戟两钱，如果说你芫花用两钱，甘遂用三钱，红大戟用三钱因为这俩个质比较重，因为这是根嘛，这是花类，根的质比较重，一般花都长在上面。

所以说攻上焦积水的时候一定要用它。

脏腑之间积水的时候会用到大戟，好，那涤水力量的时候，把水排出体外的时候，要甘遂。

所以三个药混合在一起，刚好，吃下去以后上吐，上面会吐的原因是有芫花在里面。

大便会清出来很多水在那边，为什么？我们比如说吃的十枣汤。

肺里面积水，一吃下去后上吐下泻，病人好了，为什么，大便排出来是水的时候，是把脏腑里面的水统统清掉，那是靠大戟，我们后面会有单用大戟的，别跟别的药混在一起，那甘遂呢？上焦中焦下焦它都走，芫花只走上焦，所以说你要把这三个药混在一起的时候，它就可以把肺里面的积水从大便给你排掉，全部清掉。

所以上面吐，就好像一个吸管，你放到水里面去，按到吸管拉起来的时候水在里面，上面一吐，上面一开开，下面水就出来。

排肺积水的时候不是小便，是从大便清出来，一吃它就上吐，大便它就排水，大便排出来，不是真的大便，水龙头打开，水出来的感觉，呼轰！就到马桶里面去是从肛门排出来的，很凶！这些药在使用的时候我们会加红枣，温胃，不要让肠胃里面的津液不足，不要让肠胃里面都干掉了，像这种峻药，你如果没有加红枣，里面没有胃液了嘛，整个黏的，胃壁会黏在一起，肠壁会黏在一起，黏在一起的感觉呢？病人吃不饱！吃东西吃下去，还是饿还是不饱。

为什么？因为它黏在一起，完全没有津液了，这时就要红枣。

万一你说忘掉了，吃下去了，被岳母打了一顿！人家岳母也扁你一顿，这时你拿红枣去煮，煮那个稀饭，黏答答的，给她吃下去，好来弥补它，所以说最后不要忘，怎么可以忘。

忘掉不会死啊，很痛苦啊，饿在那边吃不饱，所以你只要病人吃了，哎倪海厦为什么我吃了你学生的药，上吐下泻完，怎么饿肚子一直吃不饱，完啦！大枣没加！我心里就知道了，当然我会帮你圆回来，当然胳膊肘往内弯的啦哈。

这是排水的要药，诸位记得这个花类的一定在头上，头面的。

所以味辛，性温，有毒。

诸位不要怕这些毒，这些毒吃到身体里面最多3 个小时全跑出来了，不会停在身体里面，你身体会把它排掉，而我们治病就要个毒才有用，芫花主治你看，行水祛痰的要药，主水肿，水饮。

怎么那么多水肿，所以我跟你分开来了，慢慢可以看到了。

那《别录》呢，消胸中痰水喜唾，病人，有人问你奇怪我这个每天，老师为什么我的外婆哦一直在吐口水，没事在那边吐口水，肺里有水！——芫花！那这个常常唾，喜唾，水肿，五水在五脏皮肤之间，这个疗这个疥疮，还有芫花都可以拿来毒鱼。

鱼吃了后当场就毒昏过去了，就捞鱼哦！这个用芫花你看，如果你在山里面迷路了，你认得芫花，你把芫花采起来，然后到河里洗一洗，旁边的鱼通通浮起来，哈哈然后把它们捞起来！中医是这样子啊，然后那边摘的野果野菜丢到水里面，一看漂在水上面的通通没有毒，所以中医在山里面过去可以活的哦！西医就不行啊，没有盘尼西林、没有阿司匹林，没办法治病！好，我们休息一下。

我们继续介绍芫花，身上有水饮，诸位看这个芫花的禁忌，李时珍说饮有五，皆由内啜水浆、外受湿气，慢慢会留饮怎么样的。

芫花大戟甘遂，逐水。

因为李时珍啊他这个徐徐用之，取效甚捷，不可过剂，泄人元气怎样怎样，其实看他这样写就没有用过，他不会看病。

对呀，我们用过，像我甘遂丸也可以，他一定没有用过，我告诉诸位他刚刚讲那个留饮哦，它只是一种留饮，我们有最重要的会产生十枣汤证，产生这种，水会留在肺里面，有几个原因，不单单是留饮，他的意思就是比如说现在天气热，你在外面动，流很多汗，流汗的时候你又回到房间里面，你房间里面有冷气，你要在外面待一下，不要动，等汗停下来再进去，可是有时候忙啊，谁有时间在那待一下，马上就进去了，哎进去以后冷，那里面身体很热，外面很冷，冷空气刺激你的皮肤毛孔，皮肤毛孔缩起来啊，缩起来你的汗就排不出来，刚开始一般来说皮肤痒痒抓抓就过去了，那有时候留饮，慢慢慢慢日积月累下来，而你的工作就在冷冻库里面，你是屠夫啊，专门在里面，一下跑里面来一下跑外面来，就那种冷热变化很大，慢慢日积月累下来，你留饮，水回头停在肺的下方，实物上看的时候，有的人怎样？比如说我们就感冒发烧，那感冒发烧老外不知道什么发表的药啊，就吃抗生素，抗生素根本是鸡同鸭讲，根本没有用，我从来没有看过一个人感冒治好的，感冒还在吃抗生素，那人很笨啊！美国人很笨啊！明知道感冒是滤过性病毒，药物学说没有任何能杀滤过性病毒，你说他感冒还在吃抗生素图个安心嘛，所以说西药都是安慰剂。

吃了没有好，还有表症，中医认为说要发表，就是说你吃吃药流流汗就好了。

可是西洋人没有啊，或者是现在一般相信西医的中国人，他不晓得啊，在正在风寒在表的时候不小心吃坏肚子，吃坏肚子后产生下利，结果你伤寒在表的时候，是应该发表发掉，结果你停在表没办法入里是因为你里面很盛，你的肠胃系统很好，顶着它那个病不会传经，那个病就在表面上，因为你体内很好，那结果呢你误食，那个食物中毒，吃到不干净的食物产生下利，一下利肠胃里面的元气一虚掉，这个表邪呢一下往里面走，好了，累积在肺里面，也会造成胸腔里面有留饮，这也是十枣汤证！那我们吃这个十枣汤药绝对不是徐徐饮入哦，那个都是笨蛋，那个都是不会看病，所以我说把它列出来不是尊重他是告诉你他不会看病，十枣汤拿起来的时候，甘遂芫花大戟是生药粉，红枣十个去煮成红枣汤，俩碗水煮成一碗，把那个粉放在嘴巴里用红枣吞下去，是这样子吃的！不是这样慢慢，徐徐吞啊！不是！如果说，你把十个枣，甘遂芫花大戟煮成汤，三碗水煮成一碗，放红枣下去煮啊。
