# 中经·蠡实

**【本经原文】** 味苦，平，无毒。治皮肤寒热，胃中热气。风寒湿痹。坚筋骨，令人嗜食。久服轻身。花、叶，去白虫，喉痹。一名剧草。一名三坚。一名豕首。又名马蔺lìn 子。

**【产地】** 产我国陕西河南一带多有之，为山野自生之宿根草，实入药。

**【性味】** 味甘，性平，无毒。

**【主治】** 蠡实主治皮肤寒热，一切疮疖[jiē]，产后血晕，寒疝诸疾，利大小便。

**【别录】** 止心烦满，利大小便，长肌肤肥大。

**【苏敬】** 疗金疮血内流，痈肿有效。

**【大明】** 妇人血气烦闷，产后血晕，并经脉不止，崩中带下，消一切疮疖，止鼻衄吐血，通小肠，消酒毒，治黄病，杀蕈毒，傅蛇虫咬。

**【用量】** 普通一钱至三钱。

**【禁忌】** 不详。

那接着我们继续看下去，这第166 味这个药呢，这叫蠡实，现在我们人用得不多，有的是药房可能还没得卖。

现在有的人不认识了，一般这个药过去呢按照记载上都是伤科，受伤伤科的时候用，所以伤科啊像内伤啊内部出血啊，刀伤啊，都可以。

因为受伤了以后你人会有发烧的现像，因为伤口发炎嘛，有的时候忽冷忽热，所以它也治疗寒热。

那一般我们感冒的寒热不会用到蠡实，受伤的寒热我们会用会用到蠡实。
