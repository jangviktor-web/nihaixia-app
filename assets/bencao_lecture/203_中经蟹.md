# 中经·蟹

**【本经原文】** 味咸，寒，有毒。治胸中邪气，热结痛，喎僻，面肿，败漆。烧之致鼠。生池泽诸水中。

**【产地】** 处处有之，产陂泽中，八足两螯，有甲壳。

**【性味】** 味咸，性寒，有小毒。

**【主治】** 蟹主散血，解结，疏肝气，理经脉，利肢节，续筋骨，治热结痛，胸中邪气，面肿，

妇人经血不通。

**【别录】** 解结散血，愈漆创，养筋益气。

**【用量】** 普通为服食之品，入药无定量。

**【禁忌】** 能动风，有风疾人不可食，不可合柿及荆介食，发霍乱动风，孕妇忌之，中蟹毒，紫苏煎浓汁，冷服。

螃蟹，过去有典故，这个新婚的夫妻结婚以后呢，因为这个新婚，结婚以后新房都要整修，把房子都要整修一遍，涂了很多油漆啊，家具什么的都重漆过，新人住进去以后开始生病，然后全身发高热，然后也不会好，面是赤红的，看起来是中毒，但是又查不到原因，病人又没有死，也不是食物中毒，同样的大家都吃一样的食物，别人都没有中毒，他就是不能动，然后全身皮肤红肿，红赤，发痒，结果一个医生来一看，这个是中的漆毒，因为中国以前大陆上那些油漆啊，涂上去，那个漆的味道很重嘛，没有把那个油漆的味道消除掉，人在里面呼吸的很久，结果中的毒很深，那怎么处理呢。

螃蟹，你不要拿那个活生生的拿在肚子上啊，不是哦，螃蟹，蒸过，蒸过螃蟹以后，放在肚脐上，把身上那个漆的毒吸出来，人就恢复过来，所以过去，如果我们确定这个房子里面油漆的味道很重。

里面那个漆，专门讲那个漆，这个时候我们就会放很多螃蟹，蒸几个螃蟹，螃蟹就会把所有的毒吸走，专门解漆毒，专门控制它。

螃蟹呢，味道是咸的，寒凉的药，这个也是能够散结攻坚解结舒肝。

这里的螃蟹，不是指的是海蟹，指的是淡水的蟹，所以螯比较肥的淡水蟹，这个我们讲鱼类甲壳类的时候，几乎都是淡水。

那这个产地呢，都不用讲了，性味是味咸，性寒，有小毒，有一点点小毒。

螃蟹主治散血结舒肝气，利肢节，也就是中毒嘛，那如果说你吃螃蟹吃的太多了，螃蟹毒怎么办？我们都是苏叶，日本人就知道啊，所以日本人吃日本料理的时候都会放几片绿绿的叶子，那就是紫苏叶。

那我们中药拿苏叶来行气，所以喉咙很多问题的时候我们会用到紫苏叶。

那你在吃日本料理的时候，你可以拿那个紫苏叶包住生鱼片，直接粘了wasabi吃，那前阵子看到wasabi 都是假的，所以台湾吃东西很麻烦，汽水也是假的，对哦，wasabi 也是假的，这真的是，别说他们上当，连我都会上当，我精成这样子也会上当，你想想看，所以说很难，所以诸位知道中了螃蟹毒要吃紫苏叶，换句话说任何鱼虾的过敏，“老师，我对鱼虾过敏啊”，你用紫苏叶，到中药房买紫苏叶。

紫苏叶很轻，晒干的时候很轻，你一钱已经一大堆了，你一钱两钱已经很多了，紫苏叶熬汤或者紫苏叶做成粉就可以解螃蟹鱼虾，吃鱼，吃虾，尤其是吃虾子，甲壳类的东西呢，皮肤过敏发痒都可以使用。
