# 中经·大豆黄卷

**【本经原文】** 味甘，平，无毒。治湿痹，筋挛，膝痛。生大豆。平。涂痈肿，煮汁饮，杀鬼毒。

止痛。赤小豆，平。主下水，排痈肿脓血。生平泽。

**【产地】** 黑大豆所制成，处处有之。

**【性味】** 味甘，性平，无毒。

**【主治】** 大豆黄卷为清热开胃，推陈去积要药，主行水去湿，胃气结积，治湿痹筋挛膝痛。

**【别录】** 五脏不足，味气结积，益气止痛，去黑皯，润肌肤皮毛。

**【用量】** 普通钱半至三钱。

**【禁忌】** 恶海藻龙胆。

249，大豆黄卷，我们一般写豆卷，它是黑大豆做的，一般来说这是黑大豆，不是那个黑大头，要更正，黑大豆。

味甘性平，它是一般推陈出新，去肌的药物，能够开胃，所以一般在肠胃的地方会用得比较多。

经方里面，张仲景没有用这个药。

那你可以知道，可以开没有关系，那跟张仲景的药比起来，张仲景用肠胃的药，和豆卷不一样，豆卷好像是我们煮面，吃面啊，入味，弄豆卷吃吃啊，那是跟张仲景比起来。

张仲景如果说把经方根温病的药一拿起来，温病的药好像病人刷牙，漱口，洗脸，掏掏耳朵，漱漱眼，洗洗眼睛用，那个塞塞牙缝，经方到身体里面去，完全不一样。

它的几味药都是重点。

所以，豆卷煮煮菜也可以，没有关系。

行水去湿，豆可以滋润的啊。

二五〇、粟米

**【本经原文】** 味咸，微寒，无毒。主养肾气：去胃中脾中热，益气。陈粟，味苦，寒，无毒。

主胃熟，消渴，利小便。

250，就是粟米。

我们在北方的杂粮店里面，你如果去看，哇，一票，可能有五六十种，各种不同的，这个五谷杂粮类的东西哦，其中一个粟米黑色的，味咸，微寒，那个粟米的颜色很暗，咸味的药。

那一般来说，这种都是杂粮类的药，杂粮类的食物。

那你如果说，你吃不习惯这种五谷杂粮类的东西，吃完要拉肚子。

实际上这种东西最好。

现在改良过的白米并不好。

改良后的白米里面，植物纤维少很多，非常得不好。
