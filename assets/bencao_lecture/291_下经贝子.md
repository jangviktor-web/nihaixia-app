# 下经·贝子

**【本经原文】** 味咸，平，有毒。治目翳，鬼疰，腹痛，下血，五癃，利水道。生东海池泽。一名贝齿。又名大贝。

**【产地】** 产海滨，壳略似三角形，口作锯齿状，有白色紫色之花者。

**【性味】** 味咸，性平，有毒。

**【主治】** 贝齿主散结热，利水道，治目翳，狂热，鬼疰蛊毒，搜湿毒，通五癃。

**【别录】** 温病寒热，解肌，散结热。

**【甄权】** 伤寒狂热。

**【弘景】** 烧研点目去翳．

【李珣】下水气浮肿，小儿疳蚀，吐乳。

**【用量】** 普通二至三钱。

**【禁忌】** 蜜醋浸透，虾米酒淘入药，无湿热结滞者勿用。

342，贝子，就是海边一种贝壳，产在海边，壳成锯齿状，这个贝壳是这样子的（展示样本）。

一般来说圆的这是蛤蜊，那贝子呢不是这样子的，它下面另外一片长成这样子，刚好跟它是对着的，这就是贝子，蛤蜊呢口是圆的，这是圆形蛤蜊。

一般来说在海边的不管是海蛤、贝子，这些东西呢，味道都是咸的，你看主治：能够散结热，利水道。

一般来说，我们用到甲壳类的东西，大部分都是使用在淋巴结，淋巴肿瘤病患上面，才会使用它。

那这种药也可以点眼睛，你看它点眼睛去眼疾的。
