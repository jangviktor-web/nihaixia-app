# 上经·石龙刍

**【本经原文】** 味苦微寒，主心腹邪气，小便不利，淋闭，风湿，鬼注，恶毒，久服补虚羸，轻身，耳目聪明，延年。一名龙须草。

**【产地】** 生长泽地，产山西河南一带，茎以九节多珠者良。

**【性味】** 味苦性微寒，无毒。

**【主治】** 龙须草为泻心经之热，通利小肠膀胱要药，主治小便不通，小便带血；茎中热痛及淋闭。

**【别录】** 补内虚不足痞满，身无润泽。出汗。除茎中热痛，疗疣虫肿不消食。

**【用量】** 普通一钱至三钱。

**【禁忌】** 小便不通不因于热者勿用。

第82味药，是石龙刍，现在叫龙须草，这个龙须草是泄心经的药，泄心经心脏，这个心经的热，能够通利小肠，跟我们一些像黄柏啊，还有前面的利膀胱的利小便的药，通通可以，功能差不多，使用功能都差不多啊。

一般张仲景，他没有用到这个龙须草，徐长卿他都不会用，他都没有用到这些，像淋病，小便里面带血你们都看到，按照书上看就可以了，这都属于寒凉性的药。
