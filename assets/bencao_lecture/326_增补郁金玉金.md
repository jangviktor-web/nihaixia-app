# 增补·郁金（玉金）

**【产地】** 产四川广东及台湾琉球等地，为多年生之宿根草，根茎似芋，内暗褐色或黄色，其香能及远。

**【性味】** 味辛苦，性寒，无毒。

**【主治】** 郁金为凉血破瘀要药，功能开血中之郁，泄血中之热，治吐血。溺血，恶血留积，失心癫狂。

**【唐本】** 主血积下气，生肌止血，破恶血，血淋，尿血，金疮。

**【甄权】** 单用治女人宿血气心痛，冷气结聚，温醋摩傅之，亦治马胀。

**【丹溪】** 治吐衄，妇人倒经[1.益母草、郁金配伍治逆经。]，痘毒入心。

**【元素】** 凉心。

【东垣】治阳毒入胃，下血频痛。

**【用量】** 普通一钱至三钱。

**【禁忌】** 凡病属真阴虚极，阴分火炎，迫血妄行，溢出上窍，而非气分拂逆，肝气不平，以致伤肝吐血者，均忌。

那第21味药，郁金。郁金呢也有人写成这样的玉金，也有人写草体、繁体字，写的很繁，反正都是郁金，那这个郁金呢这个是味辛苦，性寒，是凉血破瘀的药，功能开血中的郁，里面小便带血，活血化瘀的药。

我在治肝病的时候，最喜欢使用郁金，因为郁金不单单是活血，最主要它还散郁，散这个郁气，恶阻，这个人很恶阻郁气，得到病哦很恶阻郁气，郁闷，结气可以散掉，所以郁金吃了人会很开心，心情会比较好一点，那你要心情好一点，好。

老师那我们前面学过合欢，合欢当然可以啊，合欢很好啊，合欢吃的人很开心嘛，那远志呢，远志也很好啊，远志除了可以强心以外，远志可以让一个人镇静不要焦虑，心情能够比较平和。

郁金，那剂量呢，你当然可以用三钱，严重的肝病的话用五钱，一般的肝炎的话用三钱，五钱、六钱、七钱都没有关系，因为你知道功能的时候，当你知道这个郁金可以开郁不要让一个人太恶阻压力不要那么闷，那你开三钱下去他还在那郁闷，你就开五钱、八钱，因为你知道这个药可以解郁，你就开重嘛，对不对，不然的话，你不晓得那个药的功能是什么，你不会去加重它，那可以加这些药进去。

那这个，你看它这个主治啊有没有，恶血留积，失心癫狂，我们都可以用郁金。

所以郁金是非常好使用的一个药。

那【甄权】呢单用治女人宿血气心痛，女人这个情绪比较这个，张仲景特别有一章妇科的讲到女人，因为足不出户嘛，比较郁闷，气会郁结在身体里面，就会心痛，郁金能够散郁。

那【丹溪】治吐衄，妇人倒经，痘毒入心。

这个倒经就是逆经从鼻子出来，我们前面有介绍一个叫益母草，对不对，益母草也是专门治疗女人逆经用的，那你可以配合郁金来使用，配合郁金，第27 嘛，第27味，哦28充蔚子，33页充蔚子，又名叫益母草，本经里面是叫充蔚子。
