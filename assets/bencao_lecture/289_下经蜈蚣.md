# 下经·蜈蚣

**【本经原文】** 味辛，温，有毒。治鬼疰，虫毒，啖诸蛇、虫、鱼毒，杀鬼物老精，温疟，去三虫。生川谷。

**【产地】** 处处有之，赤足者良。

**【性味】** 味辛，性温，有毒。

**【主治】** 蜈蚣为驱风散结要药，主小儿惊痫，风搐脐风，治寒热积聚，堕胎，去恶血，制蛇毒。

**【别录】** 疗心腹寒热积聚，堕胎，去恶血。

**【日华】** 治癥瘕。

**【用量】** 普通一至二钱。

**【禁忌】** 蜈蚣有毒，必风气暴烈，药病相当，乃可设，或过剂，以蚯蚓桑皮解之，畏蛞蝓，被蜈蚣螫伤，捣蛞蝓涂之即止痛。

蜈蚣，诸位看这个蜈蚣长的样子，这么大一只，蜈蚣，已经干了没有关系。

那蜈蚣呢列入《神农本草经》，在《神农本草经》里面，过去我们使用在肿瘤硬块的时候会用蜈蚣，因为蜈蚣很凶啊，它咬进去的力量很强，所以淋巴癌，淋巴肿块，肝癌肿块，都会使用到蜈蚣，但是诸位记得，动物性的药它本身攻坚的力量很强，但同时会伤血，一定会伤到。

所以说你要加一些补血的药，混合在一起，攻补、补泻兼顾，不要老是在那边攻。

诸位看这个蜈蚣味辛，辛辣的，性温，有毒，它是祛风散结的要药，小儿孩子的惊痫，这个癫痫我们会使用到，堕胎也可以用到，它能够控制治蛇毒也可以。

那【日华】的症瘕之症就是我们讲的硬块，剂量一般来说一钱两钱就够了，不会用到很多。

三四〇、水蛭

**【本经原文】** 味咸平，有毒。主逐恶血，瘀血，月闭，破血瘕，积聚，无子，利水道。生池泽。

一名至掌。

**【产地】** 产池泽中，处处有之，好吸附人畜肌肤而吮其血。

**【性味】** 味咸，性平，有毒。

**【主治】** 水蛭主逐恶血，破征积，治折伤坠扑，蓄血疼痛，堕胎通经，外治肿毒。

**【别录】** 堕胎。

**【药征】** 治女子月闭，欲成干血劳。

【藏器】痈肿毒肿。

【宗奭】治折伤坠蹼蓄血有功。

**【容川】** 锐而善入，又能允血，故主攻血积。

【灵胎】逐瘀破积。

**【用量】** 普通一至二钱。

**【禁忌】** 破血泄结之品，不可轻服，误吞水蛭，入腹难死，久则生子，食人肝血，腹痛难忍，

面目黄瘦，用田中泥一两，雄黄二钱为丸，分四服，开水下，即随大便而出，桂圆肉包烟油吞之，即下，此物畏石灰食盐。

现在讲的都是一些虫子类的药，很峻，都是毒药。

这个34，就是水蛭。

经方里面张仲景用水蛭跟牤虫配合在一起用，那这个水蛭必须要找吸血的水蛭，那水蛭很小，那你只好把脚放到水里面去看它吸到你的脚上的一只，那个就有用。

水蛭攻坚的力量非常的强，硬块，活血，化瘀，尤其是急性的，如果有人踢到睾丸，急性的伤，踢到睾丸会重伤，那时候淤血会大块，整个肿起来，小便排不出来，这会死人的，这个时候呢，我们用水蛭用虻虫。

那到市场上去挑水蛭的时候，越细小的力量越大。

很咸味的，味咸都能软坚，你看它逐恶血，淤血，处方的时候，我们过去经方里面有叫抵当汤，那水蛭和牤虫，在开这种药的时候峻剂，这种都属于峻剂，你可以一剂。

一剂给他，就清出来了，大便出来都是黑的，小便那边的淤血都会排出来。

一般来说的话，我们开的一钱两钱就够了，看严重性、体格大小。

水蛭到手上的时候是炮制过，所谓炮制过就是他当场抓到水蛭就在那烧红的瓦片上烧过，偏黄的烤黄了以后，跟牤虫一样烤黄了以后收起来，这样不会坏掉，风干了跟干掉了一样，只要没有水它就不会坏掉，那就不需要再做其他的炮制了。

**【药征】** 你看看，治女子月经，月经都不来了，月闭，干血在里面，你用很多活血化瘀的药清不出来的时候，诸位就要想到用动物性的药，一剂就够了，吃了月经就来了，那[别录]：堕胎，下胎，那宗奭呢治折伤，跌扑，再有讲的就是睾丸那边阴部那边。

这个诸位看禁忌有没有，如果说你误吞，这个不小心吞下去了，这个是很危险的，会爬到肝脏上面去，那你如何去解它呢，诸位看这个田里面的泥巴跟雄黄有没有，或者说这个桂圆包，桂圆的肉跟腌的油包在一起。

为什么会这样子，因为这种中医，比如说过去我们解毒，比如说阴阳水，什麼叫阴阳水，就是你到井里面去拿一碗水，到河里面去拿一碗水，井的水没有见过太阳，河的水每天太阳晒，反正都很脏吗，不同的脏混在一起，阴阳水解毒，一吃下去当场上吐下泻就解掉了嘛，泥巴水你说脏不脏，让你喝那个就是让你解毒，把那个吐掉的意思，吐下。

那这个水蛭，如果真的不小心吃进去，前面有症状，现在那还是会发生，有那个小朋友到那个山里面去河里面去游泳，那个水蛭跑到鼻子里面去，堵在里面啊，清除水蛭的方式，诸位看看这个。
