# 上经·茵陈

**【本经原文】** 味苦平，主风湿寒热，邪气热结黄疸 dǎn，久服轻身，益气耐老，面白悦。今名茵陈蒿。

**【产地】** 生于山野或河岸沙石之多年生草，其叶状似青蒿而背白，茎叶枯，则由陈茎再生，故名茵陈。

**【性味】** 味苦性平微寒，无毒。

**【主治】** 茵陈蒿为黄疸要药，功能除湿利尿，主治脾胃湿热，天行时热，周身发黄，以此为君。

**【别录】** 治通身发黄，小便不利，除头热，去伏瘕。

【藏器】通关节，去滞热，伤寒用之。

**【大明】** 石茵陈治天行时疾热狂，头痛头旋，风眼疼痛，瘴疟，女人症瘕，并闪损乏绝。

**【药征】** 主治发黄也。

**【用量】** 普通钱半至三四钱。

**【禁忌】** 蓄血发黄者忌用，伏卤砂忌火。

第77味药，茵陈。

也有称为茵陈蒿。

这个药呢，是经方里面的，治黄的重药要药，我们前面介绍过黄芪，老师你说过嘛黄芪可以退黄，没错，茵陈也可以退黄，但是黄芪退的黄是三焦的黄，会染色皮肤，那个汗，流汗出来会把衣服染色掉，茵陈的黄不是，茵陈是肝胆病的黄，肝病那个黄用茵陈。

还有一种黄是贫血的黄，血色的黄，那个是我们要补血的药把血补足，血虚的时候我们可以看到黄啊，那是血。

手掌拿起来一看整个手都暗黄、淡黄色，没有什么血色啊。

那茵陈是我们用的很广的一个药，一般的剂量看你的轻重，比如说像我这种体格的茵陈用3钱，2钱那，小孩子用1钱。

那茵陈这个药本身呢，性苦平微寒，它有一点点寒，味很苦，苦能泄下嘛，那我们经方里面很有名的茵陈蒿汤，就是以茵陈为主。

所有的湿热症，这热若它在中焦，病人恶心呕吐，中焦哦，还结黄疸，胆汁，胆堵到了，胆汁逆流，全身黄疸，都会用到茵陈。

小便出来黄的，全身黄的。

一般来说，在经方里面我们会用到，会区分两种，我们叫阴阳，阳黄，还有一种我们称之为阴黄，这两种。

茵陈蒿大部分用在阳黄。

那我们在治疗肝病的时候，有的遇到寒热，遇到错综，也有寒症也有热症的时候怎么处理呢，你就用茵陈，跟寒药热药用在一起没有关系，很正常的，治疗癌症的时候，肝硬化肝癌，到后来都会看到寒热并结，都是重症才会寒症热症都有，这个时候你寒药热药合在一个方子里面没有关系，就用，不要说忌讳，啊这个是寒药，我们热症才用寒症不用，不行，啊他这个有寒热并结的症我们茵陈就是要用。

它主要的功能去黄疸哦黄湿，去湿能够利尿，所有脾胃的湿热通通可以用，那这个小孩子生出来的黄疸我们通通可以用，《药征》他讲得很简单，主治发黄，任何的发黄都可以治，越简单的叙述越正确，所以发黄，黄你就想到茵陈，当然也不是说只开一味茵陈在里面哪，有个复方在里面，这个茵陈是其中一个去黄很重要的药物，所以可能你们遇到的是急性肝炎，B型肝炎或C肝，或者是肝硬化肝癌，或者是胆结石，凡是看到黄，通通可以使用茵陈，我们用的很多。
