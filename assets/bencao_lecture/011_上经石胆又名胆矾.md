# 上经·石胆（又名胆矾）

**【本经原文】** 味酸寒，主明目目痛金创，诸痫痉，女子阴蚀痛，石淋寒热，崩中下血，诸邪毒气，令人有子，炼饵服之不老，久服增寿神仙。能化铁为铜成金银。

神农酸小寒，扁鹊苦无毒，周礼疡医凡疗疡以五毒攻之，石胆丹砂雄黄矾石慈石其中烧之三日三夜，其烟上着以鸡羽扫取之，以注创恶肉破骨则尽出。

**【产地】** 产山中，为蓝色结晶。

**【性味】** 味酸辛，性寒，有小毒。

**【主治】** 胆矾为腐蚀催吐要药，功能蚀恶疮散症积，涌吐风痰，治咽喉口鼻疮毒及目患。

**【大明】** 治虫牙，鼻内息肉。

【苏颂】入吐风痰药最快。

**【用量】** 入煎剂一钱至二钱，研末服一分许。

**【禁忌】** 胃弱人不宜多服。

【吴克潜】胆矾有腐蚀性与收敛性，故能治恶疮，吐顽痰，喉痹欲死，研末醋调灌之，大吐胶痰而愈。治狐臭，胆矾枯矾各一钱，轻粉百药煎各五分，为细末敷之效，著名方剂有铁桶膏（铜绿胆矾五倍子白芷轻粉郁金麝香）治发背将溃时，根脚走散不收者，用以涂疮四周根上效。

**【炮制】** 拣去杂质即可。

石胆，就是我们所介绍的胆矾，是一样的东西，那它是产自铜坑，像这个石胆那，空青那，曾青，都是我们过去在产铜的那个矿区里，这地方产铜，里面附带就是这个石胆，所以商人去把铜拿去做成五金类的加工，他们挖铜矿时候，药商，就是采药的人，进去挖这个石胆跟空青，曾青。

石胆又名胆矾，它的味酸寒，主明目。

胆矾，空青，曾青，这些过去还有朱砂，过去我们的书法家，都拿来做颜料，我讲过，都是铜坑产生，颜色是蓝色的，就叫做石胆；颜色是青色的，就是空青。

那老师很难区分那，蓝色和青色的，石胆是天蓝色，蓝色的结晶，很透，空青，颜色比较深一点，中国大陆过去穿的蓝色衣服，就是蓝的。

石胆，除了内服以外，像我们外敷的，脓疡的，脓疡科里面，五毒来攻，我们皮肤化脓了，收不了口，像石胆丹砂雄黄矾石啊磁石，这样烧，烧过以后，取它的灰出来，这都是一些提炼的最早的一些化学方式。

提炼一些药出来，所以说中医，过去本来就有化学，只是不像西洋系统的整理，过去就有化学。

石胆，本身就是蓝色的结晶，味酸。

临床上使用的时候，可以用它来做催吐，还有外用的，整个恶疮不能收口，统统可以用。

因为它性味比较寒，药性比较寒凉，所以胃弱的人不能吃，少吃一点。

【吴克潜】，近代的经方家，他能够用胆矾来治疗狐臭，比较经验的案例。列出来给你看，一个你可以开刀治疗狐臭，还不然找个先生喜欢闻那个味道的，海畔有逐臭之夫嘛，有的人喜欢那个味道，很迷人，还有一种用这个方式，来治疗狐臭，就在这个地方。
