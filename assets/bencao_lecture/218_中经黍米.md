# 中经·黍米

**【本经原文】** 味甘，温，无毒。主益气补中。多热，令人烦。丹黍米，味苦，微温，无毒。主咳逆，霍乱，止泄，除热，止烦渴。

251，黍米，这个黍米我们叫丹黍米，红色，赤红色，黄色的都有，玉黍是一样的，味甘，温，这种是补中益气。

所以，五谷杂粮类的东西，在中医的过去的观念里面我们称为食补，如果说我们食补，我们在治疗肠胃科方面，或者内科方面，我们一开始治的时候，现在的医生跟过去的中医讲话都不一样。

过去的中医，张仲景也不知道现在有了白面，白饭，对不对，哦，以前都吃糙米的嘛，所以他没有这种问题。

我如果叫病人把这个白米白面停掉，因为白面很多都是精炼过，有些放了漂白的东西，把那个面弄得很白，实际上都不好。

我的药可以弄回去吃，糙米最多，让病人去煮糙米稀饭，放点红番薯啊，番薯稀饭促进消化，然后把那个白米白面通通停掉，这种东西下去的时候纤维很多，自然而然会帮助排便。

现在很多人便秘，本来就排不出来，再吃的米又没有纤维在里面，白米是很香，实在是很香，很好吃，可是那个东西对身体并不是很好，是改良过的东西。
