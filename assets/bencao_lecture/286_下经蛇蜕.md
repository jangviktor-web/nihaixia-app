# 下经·蛇蜕

**【本经原文】** 味咸，平，无毒。治小儿百二十种惊痫，瘈瘲，癫疾，寒热，肠痔，虫毒，蛇痫。

生川谷及田野。一名龙子衣，一名蛇符，一名龙子单衣，一名弓皮。

**【产地】** 处处有之，多蜕于石上及人家墙屋间，白色如银者入药。

**【性味】** 味咸甘，性平，无毒（或作小毒）。

**【主治】** 蛇蜕主瘈瘲癫疾，弄舌摇头，治皮肤疥癣疮疡，明目退翳。

**【别录】** 大人五邪，言语僻越，止呕逆，明目，烧之疗诸恶疮。

**【甄权】** 喉痹，百鬼魅。

**【日华】** 炙用辟恶，止小儿惊悸客热，煎汁傅疬疡，白瘢风，摧生。

【孟铣】安胎。

**【用量】** 普通五分至一钱。

**【禁忌】** 性走窜，凡小儿惊痫癫疾，非外邪客忤而由肝心虚者忌用，孕妇忌之，畏磁石及酒，

得火熬之良。

诸位看这个蛇蜕，就是蛇的皮嘛，这个蛇蜕呢，质非常的轻，风一吹就不见了，跑掉了。

蛇蜕，336，我们用来治疗皮肤病，常常跟蝉蜕在一起并用。

性味，味咸甘，性平无毒，你看主治，蛇蜕主瘛疭、癫疾、癫痫，小孩子弄舌头，摇头晃脑，现在不是Tourettr 证（抽动秽语综合征），摇头晃脑，像那个耸肩呐，就是晃来晃去，蛇蜕啊，还有，这个小朋友还有口吐脏话，没办法控制，就在那边讲，哦，蛇蜕，蛇蜕是专门用在小儿科方面的。

你看皮肤的疥疮，蛇蜕非常好用，但希望你在煮蛇蜕，下蛇蜕的时候，你让那个蛇蜕用棉布把它包起来，包起来并不是蛇蜕需要包，而是浮在表面上太可怕。

哎，怎么有蛇在里面？可能煮药煮到一半，蛇跑进去，所以还是用棉布把它包起来，不用给他看到，非常好用，我用了很多。

处方的时候，你不会重用1钱吧？5分，就已经很多了，3分、5分就可以了，小朋友的话，像小孩子的话，1分、2分就，因为很轻嘛，质非常的轻，所以，小朋友受到惊吓，包括甚至扁桃腺炎都有人用到蛇蜕哦，皮肤病、皮肤痒，癫痫、发癫都可以，眼睛的问题通通可以使用，因为蜕就是褪下来的皮，你看眼睛里面生眼翳，可以用蛇蜕退掉。

你看这个【别录】：大人五邪，言语僻越，就是讲话——什么脏话都骂出来了，平常不是那样子的人，你说老师那不是神经病吗，现在口秽症有没有，口秽症啊，西药厂很喜欢取这个名称，这样他才可以卖药，然后开的口秽症的药也是些镇静神经的药，那我们用蛇蜕。

禁忌呢，诸位看：性走窜，凡小儿惊痫癫疾，由肝脏引起的，肝心虚，肝脏引起的禁忌，妇女孕妇禁忌，那怎么知道是肝脏引起的，一般，如果说前面有发过黄，还有小朋友不能安眠，晚上睡不熟，睡不是很好，这都跟肝脏有关系，禁忌归禁忌，你还是可以用蛇蜕，你可以开一些疏肝的药在里面，比如说柴胡、川芎、白芍、郁金，都可以开在里面。

我常常开的是蛇蜕五分、蝉蜕五分，一对一起用。
