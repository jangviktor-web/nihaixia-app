# 上经·白石英

**【本经原文】** 味甘微温，主消渴，阴萎不足咳逆，膈间久寒益气除风湿痹，久服轻身延年。形如紫石英，选白泽长者二三寸。

**【产地】** 产深山中。

**【性味】** 味甘微温无毒。

**【主治】** 肺大肠枯燥，疗肺痿肺痈消渴。

**【甄权】** 治肺痈吐脓，咳逆上气，黄疸。

**【好古】** 实大肠。

**【用量】** 普通煎用二至三钱，火炙过用。

**【禁忌】** 不可久服，寇氏曰紫白二石英攻疾可暂煮汁，未闻久服之益，仲景只为咀嚼不为细末，
