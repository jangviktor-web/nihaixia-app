# 上经·白瓜子

**【本经原文】** 味甘平，主令人悦泽好颜色，益气不饥，久服轻身耐老。

**【产地】** 热带地区处处有之。今名冬瓜。其子为白瓜子。

**【性味】** 甘寒。

**【主治】** 泻寒热，甘益脾，利二便，消水肿，止消渴，散热毒痈肿。子能补肝明目。现药物中所用之瓜子，皆冬瓜子也。

一四一，现在我们这个白瓜子呢，并不是南瓜子，而是我们的冬瓜子。

你也可以说是冬瓜仁。

在孙思邈的【千金方】里面，我们在研究《伤寒》《金匮》的时候会发现到有些中间的处方删掉了，比如说很有连贯性的，张仲景非常的细腻，一贯接下来，你会发现非常的系统，哎，中间少了，如果病人刚好发生在这个地方，刚好在两个中间没有那个处方，这个时候我就会补个处方进去，补个处方进去可能是张仲景有条辩放在里面，因为汉朝到现在太久了嘛，徒弟太多了走路摔倒啊，或者不好摔伤了就漏掉了，或者是遗失掉，或者是火灾，或者是人为的，那我就补一些方子进去，补他的《伤寒》《金匮》的不足，我重新补进去的方子就是我们的苇茎汤，那苇茎汤就有冬瓜仁在里面，这个我实际上从千金药方里面来的，我这就拿名医写的东西把他补进去，以后介绍金匮的时候我会跟诸位讲。

那这个冬瓜仁是入肺的，止咳入肺的，能够去痰，令人悦泽好颜色，也没有毒啊，甘寒，能够，你看，泻寒热，能够味甘，利小便，消水肿。

现在你只要记得，我们药物通通在用冬瓜子，冬瓜仁的籽仁，冬瓜仁。

这个药很好用，平常我用的时候两钱三钱都没有关系，因为它味甘寒，所以我们遇到热家的，热病，热症的咳嗽的时候，肺炎的时候我在用它，啊肺炎，中间差了一段，所以后来我们补了进去，在治疗肺炎的时候会用到。

咳嗽，浓痰啊，嘴巴燥渴，甚至咳嗽带血我们用冬瓜仁，因为它是甘寒的药。
