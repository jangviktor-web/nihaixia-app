# 中经·秦椒

**【本经原文】** 味辛，温，有毒。治风邪气，温中，除寒痹，坚齿，长发，明目。久服轻身，好颜色，耐老，增年，通神。生川谷。

**【产地】** 椒之一种，产我国陕西甘肃，今处处有之。

**【性味】** 味辛，性温，有毒。

**【主治】** 秦椒主温中去寒，除风邪气，治风湿痹，喉痹吐逆，疝瘕老血。

**【别录】** 疗喉痹，吐逆，疝瘕，去老血，产后余疾，腹痛，出汗，利五脏。

**【甄权】** 治恶风遍身四肢，疗痹，口齿肿胀摇动，女人月闭不通，产后恶血痢，多年痢，疗腹中冷痛，生毛发，灭瘢。

**【用量】** 普通五分至钱半。

**【禁忌】** 用椒红，去目，恶栝楼防葵，畏雌黄，闭口者有毒勿用。参看蜀椒条。

213这叫秦椒，你用这个椒也可以，用这个椒。

213秦芄（椒），山椒的椒。

那这个味道是辛辣的，能够这个，也是滋补的药，味辛为温。

它除了温中散寒以外，这个秦椒呢，我们能够治疗背痛、关节骨骨髓、补筋骨、生毛发，皮肤上有斑。

过去一些那个皮肤上你开完刀以后，这个伤口怎么搞的，肿起来很大，像螃蟹脚一样很大，那这种用秦皮，内服都可以加秦皮。

皮类的药，我们用根苗花果，用它的皮有桑白皮、地骨皮啊、生姜皮啊、陈皮啊、五加皮啊，反正皮类的药，大部分我们可以入皮，我们有五皮饮，五种不同中药的皮。

那这种秦皮呢对皮肤上的斑，不好看的，都可以有帮助。

当我们外敷的也有，待会我们讲到外敷的这个斑。

补充：秦椒呢，就是开刀以后伤口长得很大，皮肤有红红的一条一条的鲜红色粉红色的，我们用秦椒。

那是内服，有外用的，但不是秦椒也不是秦皮，用僵蚕，我们外面用僵蚕，僵蚕收疤的时候，收得疤皮肤颜色很漂亮。

那秦椒秦皮呢我们可以做洗眼的药水用。
