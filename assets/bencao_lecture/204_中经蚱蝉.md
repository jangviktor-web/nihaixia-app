# 中经·蚱蝉

**【本经原文】** 味咸，寒，无毒。治小儿惊痫，夜啼，癫病，寒热。生杨柳上。

【灵胎】清火散风。即今日之蝉。蝉蜕，其实这个就是蝉，我们的知了。如果你当这个是吃的，你抓那个蝉来，把那个翅膀剪掉，脚剪掉，头打开来，里面的浆清一清，剪掉，眼睛的部分剪掉，然后裹点面粉丢到油里面去炸，很好吃啊，这个是当食物吃，治病的时候我们是用蝉蜕，就是那个壳。看过这个壳啦，以前我们小时候都可以采集得到蝉蜕，我们在用动物脱下来的壳的时候，就是脱皮嘛，所以用到皮肤病上的时候很多。所以我们在治疗重症，比如说那种疥藓或者皮肤湿疹很严重，我会开蝉蜕，蛇蜕，那种新的皮会换旧的皮。那这种蛇蜕，蝉蜕本身质很轻，所以你也不要开那个五钱，三钱，一大包，三分，五分就很多了，就是你去树上面，蝉那个壳，就那个东西，我们佛罗达最多的是蛇蜕，走到树林里面很多蛇蜕，因为蛇很多嘛，各种蛇都有，台湾人呢，蝉很多，所以你看当地嘛，当地蛇蜕多，我们治皮肤病放蛇蜕，当地蝉蜕多，我们放蝉。那清风散火，这个本身都没有毒的，所以诸位记得治皮肤病的时候使用，那这个我们不分他表里寒热，就是皮肤已经有湿疹或者是干藓，很严重的时候都会使用它，因为它的目的我刚刚讲过，你不用管它是寒热，就是你希望他新的皮去换旧的皮的时候就会想到蝉蜕。
