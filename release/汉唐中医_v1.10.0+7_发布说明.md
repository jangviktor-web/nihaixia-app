## 修复内容

### ① 方剂 ↔ 本草 关联断裂（问题 3）
- **根因**：`formulas.json` 用现代/炮制名（朱砂、栝蒌实、橘皮、红枣、炮附子…），`herbs.json` 用神农古名（丹砂、栝楼实、陈皮、大枣、附子…）；旧 `_aliasMap` 仅 17 条且**未用于**草药→方剂匹配（精确相等 `c.name == herb.name`）。
- **修复**：重写为 `_canonicalOf`（约 75 条，仅收录「本身不是药库条目」的异名，避免把已直接命中的药误指古名而断开其自身关联），新增 `HerbRepository.canonicalOf()` 并应用到 `getByName` / `search` / 草药详情页的「含此药的方剂」匹配。
- **成效**：组成药名可解析率由 **67% → 91%**（240/262），草药页查「含此药的方剂」与方剂页点按组成跳药详情**双向打通**。22 个残留多为辅料/食物/非神农药（白酒、猪膏、人尿、苦酒、五苓散等），无需处理。

### ② 本草介绍不详细（问题 2）
- **修复**：仅填空字段、不覆盖既有内容，从文档干净【主治】等结构化块反向回填：`ni_note` 33→35、`historical_notes` 83→151、`nature` 284→313、`action` 367→370（另补灵胎/吴克潜/唐容川 注）。
- **限制**：矿物/虫鱼类（曾青、空青等金石类）文档为口语讲解、无结构化【主治】块，薄条目无法全补，已如实标注，不伪造数据。

### ③ 本经正典缺载药（问题 1）
- **修复**：补建 8 味缺载本经药（440→448）：狗脊、玄参、磁石（慈石）、水苏、姑活、乌韭、析蓂子、肉苁蓉（肉松容）；均含 `original / nature / action / dosage / contraindication / nature_category / flavor / category`。
- **成效**：「全量神农本草经」名副其实，共 **448 味**。
