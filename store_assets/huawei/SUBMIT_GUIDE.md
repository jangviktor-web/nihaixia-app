# 华为 AppGallery 上架指南（汉唐中医 v1.11.31）

> 结论先说：**这是四家里门槛最高的一条，短期不可行**。卡点不在技术，而在四道前置手续，其中 APP 备案和软著无法绕过，且个人主体基本办不成备案。本文按「耗时从长到短」排序，你可以据此判断是否值得投入。

---

## 一、四道前置手续（按耗时排序，全部办完才能提交）

### 1. 软件著作权登记（20–40 个工作日）

华为应用市场要求提供《计算机软件著作权登记证书》或《APP 电子版权认证证书》。

| 方式 | 周期 | 说明 |
|---|---|---|
| 传统软著登记 | 20–40 工作日 | 需源代码前 30 页 + 后 30 页、用户手册、申请表 |
| **APP 电子版权认证** | 数天 | 更快，部分商店接受，建议优先选这条 |

> 建议：如果决定走华为，先办电子版权认证，能省一个多月。

### 2. APP 备案（7–20 个工作日）

依据《移动互联网应用程序信息服务管理规定》，所有在中国大陆分发的应用必须完成工信部 APP 备案。

**这是最大的硬门槛**：
- 备案主体须为企业，需要营业执照、法人信息
- 应用**名称和包名必须与备案信息完全一致**，否则华为直接驳回
- 本应用包名 `com.nihaisha.nihaisha_app`，备案时就填这个，之后不可再改
- 未备案的应用在 AGC 提交时会被**系统直接拦截**，进不了审核队列

> 个人开发者在这一步基本走不通，除非注册个体户/公司。

### 3. 华为开发者实名认证（1–2 个工作日）

- 入口：https://developer.huawei.com/
- 个人：身份证正反面 + 手持照
- 企业：营业执照 + 法人身份证 + DUNS 编号

### 4. 受邀名单（3–5 个工作日，2026 年新规）

2026 年起华为收紧了创建应用权限：新注册账号需先加入「应用创建受邀名单」。

申请方式：发邮件至 `agconnect@huawei.com`，提供你的 **Developer ID**，3–5 个工作日处理。

**建议在项目启动初期就发这封邮件**，别等材料备齐才想起来。

## 五、两个高风险点（必须正视）

### 风险 1：医疗类定位

华为对医疗健康类应用要求严格，2026 年现行口径是「医疗健康类需互联网药品信息服务许可证等资质」，且部分场景要求 NMPA 认证 + 应用内标注「非诊断工具」。

**规避思路**：把应用定位为「古籍学习与条文对照工具」，全程不出现「诊断」「治疗」「处方建议」等表述。你的 README 和 PRIVACY.md 已经写明「不提供医疗服务」，把这段前置到应用介绍开头会更好。

### 风险 2：命理模块（最可能被卡）

紫微斗数、四柱、六爻、易经占卜属于国内应用商店内容规范的灰区，实践中被驳回的概率不低。

**三个可选策略**：

| 策略 | 做法 | 代价 |
|---|---|---|
| A. 上架版隐藏命理模块 | 用编译期开关关掉对应 Tab | 功能缺失，但与开源版可区分 |
| B. 保留但重命名 | 改叫「传统文化 · 历法」等中性表述 | 可能仍被追问，不保证过 |
| C. 直接提交看反应 | 一次提交，等审核意见 | 最省力，可能白等一轮 |

我的判断：**先按 C 走一次**（反正备案和软著都要等，提交成本低），被驳再按 A 收窄。反过来先删功能、后又被要求补材料，会更被动。

## 六、执行顺序建议（最省时的排法）

```
第 1 天   ├─ 注册华为开发者账号，做实名认证
          ├─ 发邮件到 agconnect@huawei.com 申请受邀名单（附 Developer ID）
          └─ 启动 APP 电子版权认证申请
第 3–7 天 ├─ 同步办 APP 备案（需企业主体，这一步决定成败）
第 7 天    ├─ 受邀名单批复，实名通过
第 7–20 天 ├─ 备案下号
第 20 天后 └─ AGC 建应用 → 传包 → 填表 → 提交审核（1–3 工作日）
```

**关键判断**：如果你没有企业主体，这条线现在就可以关掉，不用再投入。

## 七、和 Android 版的关系

华为现在主推鸿蒙原生应用（HarmonyOS 5+，需要 `.app` 包和 DevEco Studio 签名）。但 AppGallery **仍然接受 Android APK**，本项目的 Flutter APK 可以直接上传，无需改造为鸿蒙原生应用。

华为要求手机 APK 必须是 64 位——`app-arm64-v8a-release.apk` 满足，通用包也满足。
