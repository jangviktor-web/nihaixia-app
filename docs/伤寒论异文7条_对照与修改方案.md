# 伤寒论「异文/疑似错讹」7 条 · 三方对照与修改方案

> 三方来源：①宋本 398 条编号版　②`D:/nhx/人纪-伤寒论-倪海厦.txt`（倪师讲稿）　③App `assets/shanghan/clause_*.md`
> 编制：2026-11-05

## 一、总体结论

**7 条全部不是转写错误。** App 逐字忠实于倪师讲稿；差异来自**讲稿版本与宋本不同**（倪师讲稿有自己的字词、语序取舍，个别处与宋本相反）。

因此定性为「**讲稿 ≠ 宋本**」，而非「App 抄错」。App 定位是「倪海厦讲稿阅读库」，以讲稿为准是合理的，不应按宋本强改原文。

| 宋本 | 差异点 | 宋本 | 倪师讲稿（行号） | App | 判定 |
|---|---|---|---|---|---|
| **176** | 表里寒热 | 表有**热**，里有**寒** | 表有**寒**，里有**热**（L2851） | 表有寒，里有热 | 从讲稿；**倪师自注存疑** |
| **374** | 承气汤大小 | 宜**小**承气汤 | 宜**大**承气汤（L4695） | 大承气汤 | 从讲稿 |
| **361** | 脉数/脉缓 | 下利**脉数**…**今**自愈 | 下利**脉缓**…**令**自愈（L4605） | 脉缓…令自愈 | 从讲稿 |
| **19** | 主语位置 | 凡**服桂枝汤吐者** | 凡**吐家，服桂枝汤**（L399） | 凡吐家，服桂枝汤 | 从讲稿 |

| **288** | 异体字 | 恶寒而**踡**卧 | 恶寒而**倦**卧（L3921） | 倦卧 | 从讲稿 |

### 两条需要特别注意

1. **176 条倪师自己也存疑**。讲稿原文：「…此表有寒，里有热，白虎汤主之。**这个若真的是表有寒，里有热，这里还没有很清楚**…」——倪师本人就指出此处讲不通（白虎汤证当为里热，称"里有热"合理，但"表有寒"与脉浮滑不符）。这是《伤寒论》176 条的著名争议条文，宋本作"表有热，里有寒"同样讲不通。**不宜单方面改动**。
2. **374 条在 App 里没有独立原文块**。它只是 `clause_368`（三八九·白头翁汤，实为宋本373）讲解段落中的一行裸文本（当前 L7），既无 `>` 引用块、也无标题。这属于结构缺陷，需要一并修。

## 二、修改方案（推荐：保留讲稿原文 + 加宋本异文注）

### 2.1 原则
- **不改正文原文**（忠于讲稿，也与卡内讲解一致）。
- 在 `> 原文` 块之后**追加一行 `> **宋本异文**：…`** 注，说明宋本异文并注明出处行号。
- 格式沿用模块既有 `> **xxx**：` 风格（与 `> **补录说明**` 一致）。

### 2.2 注文模板
```markdown
> **宋本异文**：宋本第<X>条作「<宋本原句>」；本库从倪师讲稿作「<讲稿原句>」。
```
倪师有自述存疑的，补一句引用。

### 2.3 逐条落地

| 卡片 | 插入位置 | 注文 |
|---|---|---|
| `clause_181`（176） | 现 L3 原文块之后 | `> **宋本异文**：宋本第176条作「此以表有热，里有寒」；本库从倪师讲稿作「此表有寒，里有热」。倪师原话：「这个若真的是表有寒，里有热，这里还没有很清楚」——此条历代存疑，两说均难通，存而不改。` |
| `clause_368`（374） | 见 §2.4 结构修复 | `> **宋本异文**：宋本第374条作「宜小承气汤」；本库从倪师讲稿作「宜大承气汤」。` |
| `clause_348`（361） | 现 L3 原文块之后 | `> **宋本异文**：宋本第361条作「下利脉数，有微热汗出，今自愈」；本库从倪师讲稿作「下利脉缓…令自愈」。` |
| `clause_022`（19） | 现 L3 原文块之后 | `> **宋本异文**：宋本第19条作「凡服桂枝汤吐者」；本库从倪师讲稿作「凡吐家，服桂枝汤」。` |
| `clause_105`（92） | 现 L3 原文块之后 | `> **宋本异文**：宋本第92条作「脉反沉，若不差，身体疼痛」；本库从倪师讲稿作「身体疼痛，若汗之不差，而脉反沉」，语序不同，义同。` |
| `clause_165`（160） | 现 L3 原文块之后 | `> **宋本异文**：宋本第160条作「伤寒吐下后，发汗…八九日心下痞硬」；本库从倪师讲稿作「伤寒八九日，吐下后…」，语序不同，义同。` |
| `clause_279`（288） | 现 L7 该条文块之后 | `> **宋本异文**：宋本第288条作「恶寒而踡卧」；本库从倪师讲稿作「倦卧」（异体）。` |

### 2.4 `clause_368`（374 条）结构修复

**现状**：374 条是 373 条（白头翁汤）讲解段落里的一行裸文本：
```
L1  #### 三八九：下利，欲饮水者，以有热故也，「白头翁汤」主之。
L3  > 下利，欲饮水者，以有热故也，「白头翁汤」主之。
L5  呢下利，欲饮水者，…（讲解）
L7  三九O：下利，谵语者，有燥矢也，宜「大承气汤」。   ← 裸行，无引用块
```

**建议**：把 374 条提升为独立引用块（同卡内第二条，符合本模块"并卡"既有做法，如 `clause_279` 就并列了多条 `>`）：
```
L7  > 三九〇：下利，谵语者，有燥矢也，宜「大承气汤」。
L9  > **宋本异文**：宋本第374条作「宜小承气汤」；本库从倪师讲稿作「宜大承气汤」。
```
> 不做成独立新卡，因为讲稿把它连在 373 条之后讲，且并卡在本模块已有先例（`clause_279`/`clause_301`）。若你希望独立成卡，说一声，按补录方案的 `clause_XXXa.md` 方式加。
