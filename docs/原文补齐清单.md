# 条文卡原文补齐清单（v1.11.30 后 · commit a0380f2）

## 为什么补

条文卡此前的结构是：**原文塞在标题里、正文只有讲解**。这带来三个问题：

1. 阅读时看不到完整原文语境——标题可能被截断或概括（尤其伤寒老卡的「条文N：某某汤（说明）」式标题是编者概括，**不是仲景原文**）；
2. 「原文只存在标题」导致讲解放进去后，正文从头到尾没有一句仲景原文可对照；
3. 部分卡（合并问答卡、原典补录卡、nhx 补引卡）正文甚至完全没有原文。

本次为 **519 张卡**补入原文引用块（`> 原文`），与讲解并存。所有引用来自：①卡标题本身（标题即原文的卡）②《人纪·伤寒论》讲稿单元标题（逐字核对）③子代理按方名/证候在讲稿全文定位（20 张跳号卡，逐张标注行号依据）。
