# 免费模型配置指南（问倪师AI）

> 「问倪师AI」需要你**自己配置一个 OpenAI 兼容的 API 端点**（接口地址 + API Key + 模型名）。
> 本指南推荐两个**免费、无需付费**的选择，按步骤照做即可，全程约 5 分钟。
>
> ⚠️ 两个平台均为**第三方服务**，注册流程、免费政策、可用性由其官方决定，可能变化；
> 本项目不内置任何 Key、不做中转、不分润。API Key 只保存在你手机本机，请勿分享给他人。

---

## 配置入口

打开 App → **设置 → AI 讲义问答**，需要填三样东西：

| 字段 | 含义 | 从哪里拿 |
|:---|:---|:---|
| 接口地址 | OpenAI 兼容的 base URL | 见下方三个方案 |
| API Key | 平台发给你的密钥 | 注册后在各平台后台创建 |
| 模型名 | 想用的模型 ID | 各方案给出；也可点「获取模型列表」自动拉取 |

填好后打开顶部的**启用开关**即可使用；关闭开关 = 不发出任何网络请求。

## 方案一：Agnes AI（暂时免费，推荐首选）

新加坡 Agnes AI 的 `agnes-3.0-flash` / `agnes-2.5-flash` 等模型**目前免费开放**（官方政策可能调整，以官网为准），注册即用。

### 第 1 步：注册账号

1. 访问官网 **<https://agnes-ai.cn/>**（或 <https://agnes-ai.com/>）
2. 点 **Sign Up**，用邮箱 + 验证码注册即可，无需邀请码

### 第 2 步：创建 API Key

1. 登录后进入 **API 平台**
2. 找到 **API 密钥** 一栏，点右侧 **「创建新的密钥」**
3. 复制生成的 Key（只显示一次，妥善保存）

### 第 3 步：在 App 里填三项

| 字段 | 填什么 |
|:---|:---|
| 接口地址 | `https://api.agnes-ai.cn/v1` |
| API Key | 你刚复制的 Key |
| 模型名 | `agnes-3.0-flash` 或 `agnes-2.5-flash` |

填完 Key 后也可以直接点**「获取模型列表」**，App 会自动拉取可用模型供选择。

### 第 4 步：验证

打开启用开关 → 进「问倪师AI」随便问一句（例如「桂枝汤证的辨证要点是什么」），
能收到回答并看到「参考 N 条本地讲义片段」即配置成功。

## 方案二：智谱 AI（免费模型多，国内直连快）

智谱开放平台提供了多个免费模型，国内访问无需代理，速度快。

### 第 1 步：注册账号

访问开放平台 **<https://www.bigmodel.cn/>**，手机号或微信注册。

### 第 2 步：创建 API Key

1. 进入 **API Keys 管理页**：<https://www.bigmodel.cn/usercenter/proj-mgmt/apikeys>
   （或控制台右上角用户图标 → API Keys）
2. 点 **「添加新的 API Key」**，名称随意填
3. 复制生成的 Key

### 第 3 步：在 App 里填三项

| 字段 | 填什么 |
|:---|:---|
| 接口地址 | `https://open.bigmodel.cn/api/paas/v4` |
| API Key | 你刚复制的 Key |
| 模型名 | `GLM-4.7-Flash` 或 `GLM-Z1-Flash`（均为免费）|

免费模型列表：<https://docs.bigmodel.cn/cn/guide/models/free/>
（点「获取模型列表」拉到的名字也可以直接用，注意选免费的）

### 第 4 步：验证

同方案一。智谱的 `GLM-Z1-Flash` 带深度思考（推理），响应会明显偏慢；日常问答建议用 `GLM-4.7-Flash`。

## 方案三：书生大模型 InternLM（国内直连，Token 有效期 6 个月）

上海人工智能实验室的书生大模型，OpenAI 兼容接口，注册即用。

### 第 1 步：注册并创建 Token

1. 访问 Token 管理页：<https://internlm.intern-ai.org.cn/api/tokens>
2. 邮箱或手机号注册登录
3. 控制台点 **「创建 API Token」**

> ⚠️ **两条必读**：
> - 完整 Token **只在创建时显示一次**，务必立即复制保存
> - Token **有效期 6 个月**，到期需重新创建——哪天突然 401，先来这里换 Token

### 第 2 步：在 App 里填三项

| 字段 | 填什么 |
|:---|:---|
| 接口地址 | `https://discovery-api.intern-ai.org.cn/v1` |
| API Key | 你刚创建的 Token |
| 模型名 | `Atria-Dawn`（纯文本对话，推荐）/ `Sage-A1.5` / `Agents-A1` |

### 第 3 步：验证

同前三个方案。书生是国内域名，无需代理。

> 免费模型一览：`Atria-Dawn`（纯文本 LLM，512K，问答推荐）、`intern-s2`、`Sage-A1.5`（多模态，512K）、`Agents-A1`（多模态，256K）。问倪师AI 以文本问答为主，选 `Atria-Dawn` 即可。

## 三个方案怎么选

| | Agnes AI | 智谱 AI | 书生 InternLM |
|:---|:---|:---|:---|
| 费用 | 暂时免费（政策可能调整） | 免费模型不限量（付费模型另计） | 免费 |
| 网络 | 新加坡，部分网络需代理 | 国内直连，速度快 | 国内直连 |
| 模型 | agnes-3.0-flash / agnes-2.5-flash | GLM-4.7-Flash / GLM-Z1-Flash | Atria-Dawn / intern-s2 / Sage-A1.5 / Agents-A1 |
| 适合 | 想要"注册即用、随便用" | 国内网络、想要更多模型选择 | 国内直连；Token 6 个月有效期 |

> **国内直连、长期挂着不想管** → 书生 InternLM（注意 6 个月后回来换 Token）。

三个方案同时配也不冲突——App 只用一个端点，切换时改设置里的三项即可（配置只保存在本机）。

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|:---|:---|:---|
| 连接超时 | 接口地址填错 / 网络不通 | 核对地址（注意 Agnes 要带 `/v1`、智谱是 `/api/paas/v4`）；Agnes 可能需要代理 |
| 401 Unauthorized | Key 错误或失效 | 重新生成 Key，检查复制是否完整、有无多余空格 |
| 模型不存在 / 返回空 | 模型名填错 | 点「获取模型列表」用拉到的名字，或对照官网文档 |
| 提示「该端点未返回模型列表」 | 该端点未开放 `/models` 接口 | 不影响使用，**手动填写模型名**即可 |
| 回答不靠谱 | 模型能力差异 | 换模型试试；回答仅供参考，用药务必核对讲义原文与执业医师意见 |

## 安全说明

- API Key **只保存在你手机本机**的 SQLite 数据库，不上传、不写入日志；卸载 App 即删除
- 提问时发送的内容 = 你的问题 + 本地检索出的讲义片段；**不会发送**诊断历史、收藏、命盘库等任何本地数据（详见 [PRIVACY.md](../PRIVACY.md)）
- 免费 API 的调用数据会经过对应平台（Agnes / 智谱），其数据处理政策以各平台为准
- 若你在意这一点，可以不启用该功能——不开启时 App 不发出任何网络请求
