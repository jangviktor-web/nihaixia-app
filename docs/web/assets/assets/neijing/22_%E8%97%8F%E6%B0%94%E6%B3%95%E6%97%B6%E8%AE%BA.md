# 第二十二篇 藏气法时论

### 第一节 五味之药性

黄帝问曰，合人形以法四时五行而治，何如而从，何如而逆。得失之意，愿闻其事。

黄帝问道，把人体内的构造机能与天地四时配合起来，用此为规矩，来实行治疗，应如何才能适应于天理，如何作会违反天理，其间的得失如何，请为详述。

歧伯对曰，五行者，金木水火土也。更贵更贱，以知死生，以决成败，而定五藏之气，问甚之时，死生之期也。

歧伯回答道，这就是五行木火土金水的道理，依此理来治疗则合于天理，五行间的盛衰，可以决断病人的生死，是否能调合它们是治病成败的关键，若其中一样呈亢盛状态，从此处可推知病人的生与死。

191页，《黄帝内经》第22篇，脏气法时论，黄帝问曰，合人形以法四时五行而治，何如而从，何如而逆。得失之意，愿闻其事。这个就是把人体，身体里面的构造和天地四时配合起来，然后如何做可以顺天，如何做可以逆天，逆反天理，得失如何？

岐伯说五行，木、火、土、金、水，更贵更贱，就是一样过亢，或者一样过弱，一样太过了，一样太弱了，都可以以知死生，以决成败。所以，而定五藏之气，问甚之时，死生之期也。后面就解释清楚了。

黄帝曰，愿卒闻之。

黄帝说，希望你能一一为明。

歧伯曰，肝主春，足厥阴少阳主治。其日甲乙。肝苦急，急食甘以缓之。心主夏手少阴太阳主治。其日丙丁。心苦缓，急食酸以收之。脾主长夏，足太阴阳明主治。其日戊己。脾苦湿，急食苦以燥之。肺主秋，手太阴阳明主治。其日庚辛。肺苦气上逆，急食苦以泄之。肾主冬，足少阴太阳主治。其日壬癸。肾苦燥，急食辛以润之。开腠理，致津液，通气也。

歧伯回答，肝与春日一样，是由足厥阴与足少阳经所主治，天干中属甲乙之日为木，与肝同，当肝病时，病人发生痉挛的痛苦时，立刻给予甘甜之物来缓和，这是肝病为木克土，食甘强土，使木不制土。

心臓与夏季同，治由手少阴与手太阳二经，天干中，丙丁日与其同性，心气无力且减缓时，立刻给予酸物来收敛它，这是酸生木，而木能生火使心脏强壮也。

脾与长夏通，治由足太阴与足阳明二经，其天干中与戊己日同属。脾必受难于湿盛，立刻给予苦味的药来干燥它。这是苦主心，心主火，火又生土而致此。

肺与秋季合，治由手太阴与手阳明二经。天干中庚辛之日与其同属性。气不下而反逆必伤肺，立刻给予苦味之药来降气向下，因为苦入心，心主火，火能制金也。

肾与冬季相合，治由足少阴与足太阳二经。天干中之壬癸日与其同属水。过燥之气必伤肾，立刻给予辛味之蘖来润养，如此水份充足，肌理必顺达，津液就可以自由出入不致生阻碍了。这是因为辛主肺属金，金生水，故可强肾。

192页，黄帝说你说明。当黄帝比较好，不要用脑筋。就开始讲细了。

歧伯曰，肝主春，足厥阴少阳主治。其日甲乙。甲乙就是什么？木。肝主春天，足厥阴、少阳是管春天的，它的日子是甲，遇到甲日跟乙日。每天都有日干跟日支，甲日跟乙日都是属于木。肝苦急，若肝急的时候，肝主筋，抽筋，急食甘以缓之。这第一段就替药味下了定义，甘能缓。所以，以后再介绍本草的时候，甘味的药能缓，这个缓的意思，非常妙，你只要记得，任何东西急，统统要缓，要缓它你就要挑甘味的药，甜味的药。有人说老师，“糖就可以了”，这么笨，糖不是那个……。药味里面，本草，前面一开始讲过，吃金石，彩色的云石，一些钟乳石，吃黄金，这种金石类的东西。

硫黄，这是金石类的药。到家提炼金石的药就是提炼成丹，他认为说黄金可以永远不坏，就吃黄金，金刚不坏。草药，本草的，木头、草木就是百年不坏，所以要吃本草，讲的味，通通是以本草为主。当然了，所有金石类的药比较强，味道更强。

心主夏，手少阴太阳主治。其日丙丁。心苦缓，急食酸以收之。就是说心脏不喜欢缓，它缓下来，心脏跳下来太慢了，这怎么办？好，急食酸以收之。所以以后在讲本草的时候，酸性的药，都是能收。那例如有一个人晚上睡觉梦游去了，甚多人梦游，大家都知道这个魂跑掉了，要收他，就要用酸的药来收他。还有人睡觉梦甚多，神不守，或者是睡觉的时候。人卧，血应该是归肝，结果血没有归肝，是失眠了，就是收。总之要收，记得，统统用酸味的药。那精子遗精了，滴漏不止或者怎么样，收。你只要记得，收的就用酸味的药，都是主收。会有甚多酸味的药，酸的比柠檬还酸。脾主长夏，足太阴阳明主治。其日戊己。足太阴，阳明主土了。脾不喜欢湿，湿太盛的时候会造成脾脏的压力，这个时候，苦以燥之。当选择苦味的药，目的是干？就是太湿了，是希望它能燥。湿太盛了，就让它燥一点，就好像湿气很盛，就放点干燥剂，有没有，这就是燥，苦味的药就是燥。

那肺主秋，手太阴阳明主治。其日庚辛。庚辛是金日，那个手阳明大肠经，庚都是金。肺？若气上逆，肺最受不了气上逆，气应该下降才是正常，气反逆，那及时苦以泄之。所以，苦味的药能燥、能泄，能泄气让气往下沉。

肾主冬，足少阴太阳主治。其日壬癸。肾不喜欢燥，因为肾水甚多，不喜欢燥呀。

那太燥了怎么办？急时辛以润之。辛味的药，辛能润燥。那后面他没有提出来，提出来告诉你，所有中药咸味的药，咸能软坚，坚就是坚硬的坚。所有的肿瘤、硬块，咸能软坚。所以，坚强的东西，这个东西不该长在这边又长在这边了，坚硬的东西，要用咸味的药去软它，来化解它。所以，有肿瘤的病人每次喝的药，“你的药怎么如此咸？”又没给你盐巴。说如此咸！药味本身就是咸的。慢慢进入，慢慢进入，们如何取舍。张仲景这里就很熟呀，太阳、少阴……他很熟，他对本草也很熟，于是就开出处方来了，就依据这个药性。那肾苦燥，及时以辛润之，当有坚硬的东西要食咸来软之，开腠理，致津液，通气也。开腠理，让津液通气。这就是的五种，酸、苦、甘、辛、咸，用药的目的，取药的性原因在这里。前面你们学过了，过辛、甘生阳，酸、苦涌泄为阴。所以，你把酸味的药和苦味的药，两个加在一起就是阴药，涌泄就是阴，生阴。那要生阳，则是辛、甘合在一起，就会生阳。那辛就是辣味的，你把这个药一抓起来，哎呀，好辣！就是辛。如此，慢慢带你们进入中医的领域。

### 第二节 病于四时之变化

病在肝，愈于夏。夏不愈，甚于秋。秋不死，持于冬。起于春。禁当风。肝病者愈在丙丁。丙丁不愈，加于庚辛。庚辛不死，持于壬癸。起于甲乙。肝病者，平旦慧，下晡甚，夜半静。肝欲散，急食辛以散之。用辛补之，酸写之。

若病生在肝，到了夏季会痊愈。若夏季不愈，到了秋天必更严重，能够在秋季不死，可延续到冬天，俟春季来时又会复发，此病最忌当风。同理肝病会在丙丁日愈，若丙丁日不愈，必严重在庚辛日；能够度过庚辛日不死，则不变于壬癸日，会在甲乙日来临时复发。

肝病之人在清晨时，症状会很明显，傍晚时会很严重，半夜时趋于平静。肝有病气郁不散时，应给予辛味之药物予以发散，所以治肝之法在用辛味物来散其郁结，用酸味物来收敛辅强肝脏。

193 页，这一段，讲的是病随事实的变化，相生的时季则愈，相克的时季则凶，很重要，常常在用的就是这个地方。若一个人病在肝，肝病，会在夏天痊愈，相生的季节痊愈。夏天若没有好，在秋天的时候会严重。为什么？因为金克木。到了秋天，若秋天没死，冬天的病情不会延伸，就停在那边。很好玩，可见中医好棒，的老祖宗实在是厉害，实在是很厉害！那起于春？因为肝病起于春呀，所以，肝病的人绝对不可以当风。若的仇人是肝病的，你拿个电风扇对着他吹（大笑），这个人就死得甚快，不可以这样做的。所以，治肝病的人要尽量少吹风，不能让他到海边去散步，带着女朋友去散步，不好，风吹到了不好，要安居于室内，不要被风吹。
