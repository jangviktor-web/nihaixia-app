# 第四十五篇 厥论

### 第一节 阴脉者

黄帝问曰，厥之寒热者，何也？

黄帝问，厥症有寒有热，这是歧伯对曰，阳气衰于下则为寒厥。阴气衰于下则为热厥。

歧伯回答，阳气若衰败在身体下部，就成寒厥。阴气若衰在身体下部，则成热厥。

现在看，厥论第四十五。这个厥论真正的意思就是逆。也就是像，这个足厥阴肝经就是极，极点，到顶了，到最底下了。所以若讲足厥阴肝经，就是人身体里面最里面那个脏，躲在最里面的那个脏就是肝，厥就是极限的意思，意思可以这么翻译。

黄帝说，厥之寒热者何也？有的是热厥，有的是寒厥。这就是阴阳的定义，人常态阴升，人体中膈肚脐，阴升阳降，阴往上升，阳往下降。这个人身上的阳，从胃里面五谷杂粮进入胃，一路到第二个脚趾头，足阳明胃经，一路下来到脚，所以阳气往下降的。膀胱经，穴起睛明，攒竹穴一路从背后下来到脚上至阴穴。胆经也是从头上往下走到脚上。胃经，也是从头上往下的。你注意看，胆在这边，胃在这边，胆在这边，膀胱的最下面，这些都在中膈下面的地方，这个腑的位置在下面，结果经的位置在上面往下走，阳气都是往下降的，阴气是往上升的，这是一常态。所以少阴经涌泉、然谷，一路上来。脾经，都从脚往上，肝经都是从脚上往上走，这是一个常态。现在如果阳气，下焦阳气衰了，下焦阳气衰的话，若一个人体，过没有空间的，当你阳气一衰掉以后，阴气就会补位，所以你有时看到表面上是这样子，实际上里面是反的，！阴气就补位，所以阳气一衰的时候，阴气就补的话，所以他这里就讲了，阳气衰于下则为寒，因为阴没有温度是冷冰的。阴气若衰于下，阳气太旺一直往下走，阴气不够，阳气一直往下走，过热，就为热厥。所以阴和阳一定要互相平衡，平衡。

说孤阴不深，独阳不长。你若孤阳没有阴这个人就走掉了，孤阴没有阳这个人也走掉了。所以不管你是热厥、寒厥，阴阳之间要平衡。所以当你，可见阴虚的时候，阴气衰的时候看到是热，有的人阳气衰的时候，看到是寒。

### 第二节 热厥

帝曰，热厥之为热也，必起于足下者何也？

黄帝问，热厥之热，必肇始于足下部，为什么如此？

歧伯曰，阳气起于足五指之表，阴脉者，集于足下而聚于足心。故阳气胜则足下热也。

歧伯回答，全身是阳，起于足部五趾之表面，阴脉则起于足底而汇合在足心，所以一旦阳气盛，必足下先热也。

黄帝问了，那热厥为什么一定从脚下开始？

你们学过针灸就很熟了。歧伯就下定义了。歧伯说。阳气起于足五指之表，脚的表面上面。阴脉从脚的下面，而聚于足心，足心就是涌泉的地方，所以阳气胜则足下热。

常人一再跟诸位讲，上面是表阳，阳中一定要有阴，所以你摸上面是阳，但是是冰的，里面是阳，这是常态。你摸到下面是热的，但是这是阴的，这是热的。所以脚掌和手掌，若这个手掌一手摸到这边，一手摸到这边的时候，掌心跟掌背做比较的时候，正常的人掌背应该是冷的，手掌面应该是热的，因为这是阴阳交接‘井穴’的地方。

那你现在很简单辨寒热啦，辨寒热就这样。一摸上去，“老师，这个人的热从手掌热到时手背？”因为热正常是到指尖为极限，那热过头了。一摸，这个人热，！

因为手背上面都热。有的人你一摸，冷！冷到手掌这边来，手掌整个冰的。因为定义是冷只能到手背这边，整个冰的到手掌下面，阴就盛了？有的人一摸上去前面手指是冰冷的，手掌是热的，手指前面还是冰冷的，这就有区别了。今天有个人来找可见病，开完处方以后，本来手掌整个是冰的，开完处方，吃个几天回来一摸，诶！手掌是热了，手指头还是冰的，再继续吃。吃的处方越来越冰，本来手指这是冰的，结果手掌变成寒冰更冷，这是不对的。那以这个做标准，所以这个阴阳的标准，代表这是人体的末梢最敏感，所以你一查的时候可以知道它病好了没有，瞬间一下一摸就知道了。所以在诊所临床的时候很简单，病人手抓起来看看，摸摸，已经看完了。病人还没讲话，还没告诉你，！其实已经看完了。真的若说在看病的时候，若病人知道是怎么样的医生，一个小时可以看60个病人，真的是这样子，处方就开完了。可是病人不知道，所以要很有耐心坐在那边听。这个没有办法。等到你《黄帝内经》很熟，诊断速度甚快。现在知道了，！定义从这边来。

帝曰，寒厥之为寒也，必从五指而上于膝者，何也？

黄帝问，寒厥之寒，为何从五趾向上到膝部？

歧伯曰，阴气起于五指之里，集于膝下而聚于膝上。故阴气胜，则从五指至膝上寒。其寒也不从外，皆从内也。

歧伯回答，阴气是起于足五趾之里，向下汇集膝下而相聚在膝上，一旦阴气盛，则必从足五指开始寒冷而延伸至膝上。此寒冷并非从外来，皆因内发始然也。

379页，黄帝问，寒厥之为寒，必从五指而上与膝者。为什么从脚的五个指头到膝盖？

歧伯说，阴气起于五指的里面，下面是阴经。那集于膝下而聚于膝盖上面，故阴气胜，阴气太胜的话，从脚一路到膝上，这段是冰冷的，因为他的寒不是从外面进来的，不是说你脚放在冰水里面，它是从里面发出来的。直到膝盖为止。“老师，这个寒冷很奇怪，从脚一直到膝盖为止就上不去了，为什么？”气街在上面，阳明气在上面挡到，所以冷只到膝盖为止，这个中医很厉害。

帝曰，寒厥何失而然也？

黄帝问，寒厥是由何而发的？

歧伯曰，前阴者，宗筋之所聚，太阴阳明之所合也。春夏则阳气多而阴气少，秋冬则阴气盛而阳气衰。此人者质壮，以秋冬夺于所用，下气上争，不能复。精气溢下，邪气因从之而上也。气因于中。阳气衰，不能渗营其经络。阳气日损，阴气独在，故手足为之寒也。

歧伯答道，人的前阴位，是宗筋所聚之处，足太阴与足阳明所聚合之处。在春、夏二季是阳气多而阴气少之时节，秋、冬二季则是阴气多而阳气少的时节。得寒厥病之人，必持其体素壮，在秋、冬时节，恣意消粍其阳热之精，造成下焦阳虚而阴盛向上，无法复元，此皆精气消耗在下，邪气因而入侵体内。阳气（免疫系统）本自胃、脾中而生，今阳气衰，无法滋养全身经络，阳气日渐耗损，阴气独盛，故手足皆为寒也。

### 第五节 热厥之因、阳气乱

帝曰，热厥何如而然也？

黄帝问，热厥又如何发生的？

歧伯曰，酒入于胃，则络脉满而经脉虚。脾主为胃行其津液者也。阴气虚，则阳气入。阳气入，则胃不和。胃不和，则精气竭。精气竭，则不营其四支也。此人必数醉若饱，以入房。气聚于脾中不得散，酒气与榖气相薄，热盛于中。故热遍于身，内热而溺赤也。夫酒气盛而慓悍，肾气有衰，阳气独盛，故手足为之热也。

歧伯答道，酒入胃以后，造成络脉满溢而经脉空虚，脾脏主要功能为替胃运行其津液，今脾之阴气虚弱，则阳气必反逆入于胃，一旦阳反入胃，必令胃不和，胃无法平和，饮食之精华必无法吸收而减少，此五谷之精减少，四肢就无法得到其充足的营养。此种热厥之患者，必时常喝醉且饱食山珍海味，再强力入房事，乃致酒气与食物之热气相聚于脾中无法发散，酒气加上五谷之热气相争，造成内热盛于中焦，以致全身发热，小便赤红。酒气之物乃气盛且慓悍，必伤肾脏，一旦肾气衰弱，阳热之气必独盛体内，终至手足皆发热矣。

381页，黄帝问，热厥如何发生的？一个是寒厥和热厥。

歧伯说，酒入于胃，则络脉满而经脉虚。因为酒气甚为彪悍，甚为悍力，一吃下去，马上到手脚边去了，马上就进入络脉了，速度甚快，因为发散。有甚多中药需要发散。就是说希望把这个药能够带到络脉去，带到四肢的末梢去，这个时候，你煮药的时候加一点酒下去。就利用它的酒彪悍的气直接把药送到四肢的末梢去，这时会要求病人放一点酒下去煮。以后读了《伤寒》《金匮》之后，张仲景先师，用酒去煮，放一点酒下去怎么样，都有原因的，就从这里，即可蛛丝马迹的看到。脾主为胃，脾本身的功能是胃行津液，那阴气虚则阳气入，这个脾阴不足的时候，阳气就会跟进来。阴阳是一正一反的，所以一虚阳气马上进来。那阳气本来胃就是阳气，现在阳再加进来，阳加上阳胃就不合了。这个时候，津液就衰竭。这个主要原因是什么？

因为喝酒不会说光喝酒，一定是吃甚多好的食物。所以又吃肥美的食物，又是烧烤，一大堆肉，又喝酒下去，这两个东西同时到胃里面去，这个蒸化在中间，热上加热。所以喝酒就喝酒，浅酌就好了，吃东西吃一点，不爱吃太饱。两个并在一起吃，酒足饭饱，喝太多了会造成没办法消化，胃没办法消化，造成的精气会衰竭，反而会衰竭，就没有办法去滋润，补充四肢的营养。

所以会有热厥的人，一定是常年以来，不是说一两天，你一两天没有关系，偶尔放纵一下自己没有关系。歧伯说一定是日积月累下来。那每天都喝的醉，吃的很饱，强行入房，行房事，然后这个酒热之气聚于脾中不得散，酒气和谷气，有没有！喝酒和食物统统相薄，热盛于中，造成太热，这个时候热偏全身。内热，当有内热的时候小便是红的，赤色的。所以常常问病人，你小便什么颜色？赤色的，红色的。例如肝病肝炎，小便马上变成茶色，甚快，内热。你说，“老师，为什么要知道内热？”当然要知道，知道热就给他开凉的药下去呀。中医讲热，西医讲炎。那用寒凉的药下去，北派也有用寒凉的药，当然也会用寒凉的药。不是说纯寒凉的药，可以用这个寒凉的药。所以酒气，本身酒甚为气盛彪悍，肾气有衰，阳气独胜。所以，如果说你胃中中焦太热的时候，跑到四肢上去了，造成里面太热，过热，身体里面过热，就会伤到阴，伤到阴的时候变成阳气独胜，这个就会造成热厥，这是热厥的来源。所以吃东西一定要简单，少喝酒。

帝曰，厥或令人腹满，或令人暴不知人，或至半日远至一日，乃知人者何也？

黄帝问，厥之病，有时令人腹满，有时突然不省人事而昏厥，有时半日即苏，有时要一日后方苏，这是歧伯曰，阴气盛于上则下虚，下虚则腹胀满。阳气盛于上，则下气重上，而斜气逆。逆则阳气乱，阳气乱则不知人也。

歧伯回答，若阴气盛于上，必令下焦虚，下焦虚则令人腹满。阳气若盛于上，则令人下焦隙气亦上逆，加重的阳气乃成邪气而上冲头面，一旦如此，阳气必逆乱而行，故会昏迷不醒人事。

382页，这个厥，黄帝问了，有时令人腹满，有人令人昏倒不认识人。造成一个人会腹满，肚子一胀满，就是中医所谓的阴虚。一个人突然不认识人，你是他的亲人，他都不认识你，阳气盛，太盛了，阳气乱，乱到人神志会不识人。有的时候半天，有的时候一天，过了以后才会慢慢恢复。黄帝问厥就是反逆。

歧伯就说，阴气若盛于上，则下虚，下虚则腹满。所以阴气若盛于上，下面就会阴虚，本来下面是阴，结果阴跑到上面去了，身上是这样子，肚子，这个横膈在中间。本来上面是阳，下面是阴，结果……肾在上面，下面就虚掉了。那在脉上面可以摸到，寸是阳，尺是阴。上盛的时候，寸脉会变得很大，就知道上盛。上盛则下虚，下虚则腹胀满。阳气若盛于上，则下气重上，当，若另外一个阳气在上面，加倍的上盛的时候，下焦的阳气再往上走，下焦的阳气来自的命门，来自们的小肠，下面是很热，再往上走，阳气再加上阳气，加重。重上，而斜气逆。逆则阳气乱，阳气乱则不知人。为什么称之为斜气？因为的阳气入头有一定的方向。

是正经，走旁边斜着进去，造成一个人的气乱。阳盛太过，造成人不识亲疏。那一般若不识人的时候自己回头，很好治的。有的人不识亲疏，不认识那个人的时候，神亡的时候，那个时候人的命就没有的，那是很危险的。

### 第六节 六经脉之厥状

帝曰，善。愿闻六经脉之厥状病能也。

黄帝说，答得好，希望能说明三阳三阴经脉厥病症状情形。

歧伯曰，巨阳之厥，则肿首头重，足不能行，发为眴【xuàn】仆【pū】。旸明之厥，则癫疾欲走呼，腹满不得卧，面赤而热，妄见而妄言。少阳之厥，则暴聋颊肿而热，胁痛，骺【héng】不可以运。

歧伯回答，太阳之厥，会有头肿且沉重状，足无法行走，发作时眼目昏眩而仆倒不知人事。阳明之厥，令人如癫疯状，想奔走呼叫，腹部胀满无法入眠，面红赤且热，胡言乱语且不识人状。少阳之厥，令人耳聋雨颊肿胀且热，两胁疼痛，足膝无法正常走路。

383页，那刚刚讲的是上下阴阳的厥逆。黄帝现在问，想听听看六个经脉，厥症的症状。所谓六经脉就是太阳、少阳、阳明、太阴、少阴、厥阴，他不把它分成12经络来讲。

歧伯就说了，巨阳之厥，三阳的厥，足太阳在厥逆的时候，脸会肿起来，头会重，脚不能行。一发作的时候，人就眴仆，人会目摇昏倒，眼睛会发昏。诸位就可以了解，因为你学过针灸，膀胱经的经是从后面走到前面，！一直络到眼睛里面去，所以发昏眼睛会昏眩。膀胱经络一直到背后，从背后到脚上，脚就不能行，因为阳气厥逆。所谓阳气厥逆，就是须知道在介绍针灸的时候，膀胱经的气本来就是从头一直往下走，现在逆着走的意思，就这样子。那人就会有昏眩、昏倒，脚不能走的现象。

阳明之厥，则癫疾欲走呼，腹满不得卧，面赤而热，妄见而妄言。这就是阳明经的经气本来是往下走，头维、下关、颊车、承泣、四白、巨髎，现在阳明经往回逆。当然这里讲的阳明经包括它的手阳明大肠经跟足阳明胃经在里面，阳气应该往下走，现在回逆的。阳气会回逆的原因，多数都是下面有挡道，胃气就是讲食物，食物的消化系统。

下面大肠里面堵到了，这个沼气，气会回逆。本来这个沼气只能到胸膈为止，膈就是把它分隔开来，沼气上升就是这样。当然这就写道，腹满不得卧，就好像遛鸟、弃衣而行、登高而歌，就是这样子。

少阳之厥？若少阳经，包括手少阳还有足少阳，胆经一样，会造成人耳朵会聋，耳聋耳鸣听不到，颊肿而热，胁痛，两胁痛。诸位记得，以后病人只要告诉你，这两个胸胁这里胀满胀痛，少阳，已经讲完了。在《伤寒杂病论》讲的很详细，胸胁苦满，两胁胀满，少阳的位置。䯒不可以运，䯒就是脚的胫骨那边，足阳明胃经，胃经跟脾经中间，你摸下去那个骨头突起来，有没有！在你胫骨上边，那个就是䯒骨，会影响到，走路就比较不顺。

太阴之厥，则腹满䐜胀，后不利，不欲食。食则呕，不得卧。少阴之厥，则口干溺赤，腹满心痛。厥阴之厥，则少腹肿痛，腹胀泾溲不利卧，屈膝阴缩肿，骺内热。盛则写之，虚则补之，不盛不虚，以经取之。

太阴之厥，令人腹胀满，大便不顺，没味口，一吃东西就呕吐，无法安卧。少阴之厥，令人口干小便黄赤，小腹胀满而胸口痛。厥阴之厥，使人小腹肿胀且痛，腹胀如鼓小便不顺畅，嗜眠，屈膝时阴部会收缩且有肿胀感，大腿内恻有灼热感。凡厥症太盛则施泻法，太虚则施补法，平常不虚不盛时，只取病经上的穴道即可。

太阴，就包括肺经，手太阴肺经跟足太阴脾经，因为脾主少腹，肚子里面脾脏在管，则腹满䐜胀，后不利，大便就不通利了。前就是小便，后就是大便，不想吃东西，脾脏出问题的时候，都是胃口不好，肚子会胀满，大便不是很顺。一吃则呕，因为脾脏肿大在那边，里边累计甚多的湿，所以不好躺下去。所以常常，为什么须知道这个？有一个人胃口不好了，那他原因，可能西医讲甚多原因，你不管他。胃口不好的时候，你一查他腹胀满胀满的，大便也不是很好，知道脾，它太湿了，脾阳不够，因为阴太盛了，阳不够，就开一些健脾的药，把脾阳健起来，胃口就开了。

少阴之厥，足少阴肾经，手少阴心经，！手少阴心经跟足少阴肾经，这两个都属于少阴，因为两个甚为紧密，甚为紧密。这个少阴之厥，则口干溺赤，腹满心痛，因为你口干，舌头下面的金津、玉液，嘴巴里面的唾液源头是来自于肾脏，！现在有津液反逆，精气反走，造成口干小便赤，腹满心痛。

那厥阴？就讲的足厥阴肝经跟手厥阴心胞经，！少腹肿痛，腹胀，泾溲不利，小便不顺利，好卧，屈膝阴缩肿，膝盖那个肝经有问题的时候，膝盖喜欢弯着睡。阴缩，阴缩会肿胀，阴会缩起来。䯒内热，就是脚的胫骨里面，胫骨里面有那个脾经跟肾经还有肝经都在里面，靠在䯒的内侧也是肾经的位置。盛则泻之，虚则补之，不盛不虚，以经取之，这是一个治病的法则。因为你知道它是在肝经上面，就是虚则补，实则泻，平常以该经的‘经穴’来取它。

太阴厥逆，骺急挛，心痛引腹。治主病者。少阴厥逆，虚满呕变，下泄清。治主病者。厥阴厥逆，挛，腰痛虚满，前闭谵言。治主病者。三阴俱逆，不得前后，使人手足寒，三日死。

太阴厥逆时，会腿内侧抽筋，且心痛牵引腹痛。治法取病经上之穴道。少阴之厥逆，令人腹虚胀满且呕吐，下利清榖。治在其病经上的穴道。厥阴之厥逆，四肢抽筋，腰部疼痛，腹部虚满，小便不通且胡言乱语。治在其病经上的穴道。一旦三阴同时厥逆，大小便不通，令人手足冰冷，则三日内必死。

太阴的厥逆，现在讲厥逆了，就比较严重了，刚刚只是讲厥，厥就是反逆一点。

厥逆的话就是很严重了，严重的时候怎么办？，脚胫骨甚为绷紧，抽筋一样。心痛引腹，这是厥逆比刚刚厥来的严重，那心痛引到腹部，治怎么治？治主病者。所治主病者就是治他生病的那个经，知道他的位置，看这个是䯒急挛，心痛引腹。

一看到心痛只要引到少腹，知道是脾经，！足太阴，病发生在少腹都是属于太阴，这时候治太阴。太阴是脾，那治症上面有一个很好玩的，因为现在看治主病者，知道是脾以后，脾本身主少腹，少腹小肠？所以中医在治脾的时候，常常同时要去治什么？小肠。因为小肠受盛之官在少腹这边，湿甚多，甚多太太小姐说要减肥，看起来一点都不胖减什么胖？“不是，肚子很大。”看着不大，束腰绑住，女人希望肚子很平，希望很平，希望上面很高下面很平，原因是什么不了解，不是女人。少腹这边整个是脾湿把太阴堵到，要去湿，要治她的小肠。

所以治脾，一定会兼治到小肠，这个是治主病者，这是主病，脾和小肠。

那少阴厥逆，虚满呕变，下泄清，大便出来是清谷，清就是你吃的菠菜排出来菠菜，空心菜就是空心菜。少阴有厥逆的时候，就逆症比较严重，厥逆的时候。虚满呕变，因为胃是肾之关，前面跟诸位介绍过了。肾有问题的时候，一定可以看到胃的症状——呕吐，所以肾脏在衰竭之前的时候，病人一定很极度的晕眩，还有强烈的呕吐，吐出来甚多津液，这是肾要衰竭了，会出现呕吐的现象。原因再跟诸位说一下，肾在这边，肾是主水，水现在太多了，因为肾没有办法排水了，胃受不了，顶到胃，当然会吐。

那它有一个极限，超过这个极限胃开始吐的时候，已经到了中焦了，那个肾脏都快没了。

刚开始的时候水是从下面开始，一直到脚肿起来，都没有治好，严重到那个阶段。到了人体极限的时候，功能就没了。也治主病者，治肾的时候，常常会治他的胃。

厥阴厥逆，有痉挛抽筋的现象。腰痛虚满，前闭谵言，治主病者。这个肝病，肝脏跟大肠，所以肝有病的时候什么叫做治主病者？肝有病的时候同时要清理大肠，你光治肝病不会好的，一定要通大肠。所以在治肝病的时候，一定要保持病人大便排的很好。病人若大小便一路通，堵到了，来不及了。所以说好的医生，并不是说下手的时候要到病人最末梢。而是说一开始遇到肝病的时候就要知道，已经在通他大便了。你只要保持金和木之间的平衡，在治肝的时候，一直在疏干一直在清理他大肠保持他大便很通畅。

当然你说老师，保持他大便通畅，把攻下的药开的很重，那你太过了。你只要保持他随时都有大便，肝病自然而然会好起来，因为金会去制木，有金在这边制木，肝也很可怜，上面夹了一个肺在制它，下边一个经在制它，所以肝就好像爸爸，肺好像妈妈，下面大肠是儿子，爸爸一点地位都没有。（笑）有办法反过来，会教你们。就是因为两个经在制它，一个阳一个阴在制它，所以肝木很乖呀，很乖在中间，这是常态。

哪天生病出问题，这两个下手，都来不及了。所以要随时保持这两个很好，所以你说肺伤到会影响到肝，是对的。所以西方医学说抽烟对肝不好。对，中医同意呀。但是要清理大肠，你忘了说便秘对肝不好。所以常常保持大便通畅。你说，“老师，大便不好。”没关系，赶快去把它通一下，趁身体有微样，少许改变的时候赶快去治它，治主病者。那前闭，前闭不单单是讲小便，大小便都不通，病人会有谵言，神昏发语，这个就比较麻烦。因为厥而且逆，逆的很严重。

### 第七节 太阴太阳之厥、巨阳少阴之厥、气汇腹中
