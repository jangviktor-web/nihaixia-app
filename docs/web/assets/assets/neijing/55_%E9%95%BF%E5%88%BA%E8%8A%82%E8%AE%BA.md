# 第五十五篇 长刺节论

### 第一节 导腹中气、疝气病于筋筋痹

刺家不诊，听病者言。在头头疾痛，为藏针之。刺至骨病已，上无伤骨肉及皮。

皮者道也。阴刺入一傍四处，治寒热。深专者，刺大藏。迫藏刺背，背俞也。刺之迫藏藏会。腹中寒热去而止。与刺之要，发针而浅出血。

治腐肿者，刺腐上。视痈小大深浅刺。刺大者多血，小者深之。必端内针为故止。

病在少腹有积，刺皮腯【tú】以下，至少腹而止。刺侠脊两傍四椎间。刺两髂【qià】髎【liáo】季胁肋间，导腹中气。热下已。

病在少腹，腹痛不得大小便，病名曰疝。得之寒。刺少腹两股间，刺腰髁【kē】骨间，刺而多之。尽炅病已。

针家如不依靠脉诊，完全以问病情方式来作诊断，此时须注意，针头病之患者，下针须深骨边病方能除，针不可刺入骨中或在皮肉间穿刺，皮部是针必经之道，迅速通过不可滞留其间。针刺寒热病时，主针下后，必须在上下左右各加一针方可尽除病邪。若遇病邪深入脏者，则须剩脏，背部五脏之俞穴乃是与外界交流气机之所在，针刺背俞可强迫内脏之病邪外出，俟腹中寒热现象停止而出针，其无论何种刺法，都采浅刺且出针时泻血。

治疗脓肿疮家者，直接刺肿部放出脓，深浅及针孔大小全视其脓肿状况而定，刺大脓则多出血，刺小脓肿则下针要深，直到皮表回复原状则停止治疗。

如病在少腹中有积时，则下针在脐下有脂肪的穴位，至少腹积病位而止，再加刺华陀夹脊笫四椎位与膏肓穴，并在居髎与季肋中取穴位下针，如此则能导出腹中积气，俟热退后即止针。

病在少腹，引起腹痛无法大、小便时，此病名曰“疝”。是由中寒而来的，可针刺少腹及两股间与腰骨间之穴位，必有历痛点，待其感觉热时，病就好了。

现在开始讲长刺节论，《黄帝内经》第五十五篇，它一开始，可见这里就没有什么黄帝问岐伯曰，没有了，开始讲针灸的原则。

刺家不诊，针灸，下针的人不诊脉，不要摸脉，这下你们听得很爽，你说老师不用摸脉很好，其实告诉你，真正的中医摸脉只是确定，confirm给的。在望闻问已经很足够了，摸脉若摸到脉跟望闻问得出来不同的答案，舍脉取症，医家历代张仲景通通是这样做的，刺家不诊，听病者言，你要注意听病人讲话，病人头痛，那你为藏针之，就是埋针，刺到骨边，病就好了。

上无伤骨肉及皮。皮者道也。阴刺入一傍四处，治寒热。这个扎头部呢就是扎皮骨中间，若病人出现有寒热的症状，这个寒热跟刚刚头痛不一样，例如项强，全身发冷，全身发热，遇到这种情形的时候，一针下去，旁边再加四针，上下左右加，这一针扎到这边，这个穴道扎到上面、下面上下左右各扎一针，这个专门针寒热的。什么叫针寒热？“老师，现这个病人在怕冷。”你问他，你这个怕冷是从哪里，从里面冷还是从外面皮肤冷？皮表冷，病人会知道。你去问，你不需要摸脉。当然一摸脉是浮脉就知道是皮表冷，那肺主皮毛，皮毛合肺，你就在肺，第三椎是身柱，下一针身柱，上下左右各再下一针，上下左右各一寸，这个时候寒就会散到，那若还是寒，你问他你这个寒从哪里来？“是从骨头里面冷出来。”肾主骨，病人会很清楚，他会告诉你的，这时候你就挑，所以没有一定的穴道，但是都是在主症的穴道旁边上下左右各加下一针。

深专者，刺大藏。迫藏刺背，背俞也。这个呢就是若这个病情很深，深到骨头旁边，这个刺的道理，若说这个病情呢是在背上，的背上有所有的内脏的心俞、肺俞、肝俞、脾俞、肾俞通通有，也有腑，胆、小肠、胃、大肠、膀胱通通有。那若说这个病从脏里面发出来，知道这个是脏病，要下针在背的俞穴上面。比如说胃就扎胃，肾扎肾，三焦就扎三焦，诸如此类的。若刺他的脏腑的俞穴的时候，腹中的寒热就会自然而然会停止，与刺之要，发针而浅出血，在针灸上面来说的话，一般而言在背上膀胱经上面，记得，膀胱经在针灸上面和《黄帝内经》上面一再强调它是少气多血的经，所以你若治脏病，现在讲的是完全是针灸，包括治你气喘、胃癌、肾脏癌都是一样，不管里面的病，专门治脏病的时候，你扎在当经俞穴上，可以放血，皮肤放点血出来，当你放点血出来的时候，一定是当病人还有正气的时候。病人若元气大虚，你再给他放他会更虚，邪会更深入，所以当你知道病人还可以跟病在抗争的时候，你把血放掉，这个病邪会往外走。

若治腐肿者，就是你化脓了，有痈肿里面化脓了，就直接扎在脓肿上面，那看它的痈的大小深浅来刺。若痈很深，即可刺得很深；浅，刺得很浅。那你如何知道它深浅，很简单，你把它捏起来一摸就知道有多深，捏一下好大针一只下不进去，有时针扎到脓里面，空的，里面都空的，都化脓了，那针就往下，碰到底了就停住，那一般扎脓的话针都很粗，你拿那个32号那个没有用，那个好象刷牙漱口那个没有用，那个剃牙签一样治不到位的，拿粗一点的针把针孔摇大一点，让它脓化出来，那脓还不出来，你再火罐上把它吸出来。遇到有脓，只要是皮肤开口有脓的，通通要把脓放出来。这个你不用管阴阳表里虚实寒热，为什么，因为已经化脓了，代表是病在里面把脓抽掉，那恢复会快甚多。刺大者多血，小者深之，一定要内针，扎到好的皮肤为止。

若这里开始，病在少腹有积块，有硬块在下面，刺皮腯以下，腯就是脂肪，直接穿刺脂肪到下面，一直到少腹而止，这意思是针到那个痹块为止。诸位若看临床会发现那个病人那个妇人肚子有硬块的时候你一摸就摸到了，很大一块硬硬的。那有的妇人她站那没有感觉，一躺就摸到了，所以都是躺那扎针，摸到那个硬块。摸到那个硬块的时候针即可直接扎到硬块上面，不要穿到硬块里面去，扎到硬块上面，至少腹而止。扎完以后你留下针，背面呢可以刺挟脊两旁四椎间，就是华佗夹脊，从督脉第一椎大椎开始算第四椎开始，两旁各两针，还有膏肓穴扎针。还有刺两髂（腰骨）季胁肋间，这个讲的是什么，导腹中气。热下已。热排出来就好了。

记不记得诸位在讲一个经外奇穴的时候，这是病人的臀部，这个是第十四椎，这一椎是第十四椎，就是的命门，命门穴，命门往上一截，外开三寸半，这个地方特别一个名称，叫做痞根。在针灸的观念里面，所有的外的病都是百病风之始，是从外面进到身体里面，进到皮肤表面没好从孙络就跑到主经上去了，那主经上没好就跑到内脏去了，这个才会病越来越深，白病风之始。那若说你扎了硬块，再扎背后的夹脊两旁第四椎下，夹脊是督脉外开五分，这个是督脉，外开五分在这边，外开一寸半才是膀胱经，外开五分这边是夹脊，你针直着下去没关系，不要拿一寸半，一寸针下去就好了，扎到夹脊上面。后面讲的那个髂股那个季胁肋间就是讲的这个穴道，第十三椎外开三寸半，痞根穴，这样子来导腹中的气，热往下走，少腹就会开始热，并不是说热从阴部排出来下走，而是说这个时候上焦的热就会直接进入少腹，肚子会热起来，热起来以后肿瘤、硬块通通会消掉，这是扎硬块。所有的积块全部是来自寒，所以你要热到了才行。

当然你灸关元甚佳，怎么会不好。

那你说平常没事也可以灸，你没事灸从来没有人说灸关元死掉，那和尚每天在打坐，那你灸关元你根本就没有病，所以灸关元会长命百岁。那病在少腹，腹痛不得大小便，病名曰疝，疝气，得之寒，所有的疝通通是寒，当然有好几种疝，到时候在经过那种寒疝很强的时候，病人的白经都吐出来，那个肚子很痛，一味药就好了。越重的症药会越来越少，到时候会教诸位，这个不难。那若说《黄帝内经》不讲药，讲针灸。若说刺，刺少腹两股间，刺腰的髁股的之间，刺而多之，尽热而病已，这个少腹呢两个骨头按照正面，寒散的时候腹痛很强，肚子会痛得很强，这个髋骨这边你去压，痛在这里，哪边痛就扎哪边，痛点，叫阿是穴最准，针扎到这个上面，这就是少腹两股之间，还有腰后面的腰骨之间。你的后面腰骨这边也可以找到压痛点，第十四椎周围找到压痛点，按照压痛点来下针是最标准，因为你寒的位置这边这边这边有时候不一样，有时会上下，所以压痛点会稍微转移一点，所以诸位现在得到了，这个疝气针灸也可以治得好。所以可见两种病都是疝，都是寒，所以说一定要保持下焦是热的。

病在筋，筋挛节痛，不可以行，名曰筋痹。刺筋上为故，刺分肉间，不可中骨也。病起筋炅【jiǒng】病已止。

病在肌肤，肌肤尽痛，名曰肌痹。伤于寒湿。刺大分小分，多发针而深之。以热为故。无伤筋骨。伤筋骨，痈发若变。诸分尽热，病已止。

病在骨，骨重不可举，骨髓酸痛，寒气至，名曰骨痹。深者刺无伤脉肉为故。其道大分小分，骨热病已止。

病在诸阳脉，且寒且热，诸分且寒且热，名曰狂。刺之虚脉。视分尽热病已止。

病初发，岁一发，不治月一发。不治月四五发，名曰癫病。刺诸分诸脉。其无寒者，以针调之，病止。

病风且寒且热，炅汗出，一日数过，先刺诸分理络脉。汗出且寒且热，三日一刺百日而已。

病大风，骨节重，发眉堕，名曰大风。刺肌肉为故，汗出百日，刺骨髓汗出百日，凡二百日须眉生而止针。

病生在筋，令人抽筋关节痛，无法行动，此名“筋痹”。可针刺痛部，针入筋与肉间，不可刺中骨，直俟筋热起时出针病愈。

病在肌肤间，会令肌肤疼病，名为“肌痹”，针刺在大小肌肉间，下针多且采深刺，此为伤于寒与湿气，得觉针头热时就出针，不可刺伤筋骨，一旦伤及筋骨，日后会生痈肿或引起其它病变。

病在骨时，会使人觉得骨重无法抬举重物，骨中髓部酸痛，阵阵寒意由内而生，此名“骨痹”。针刺必深，但通过肌肉血脉时，不可误伤。针从大小肌肉间下，直达骨边，俟觉得骨部发热，表示病愈，则可止而出针。

病生在阳经时，呈现出忽冷忽热，分肉间亦有忽冷忽热的现象，此名曰“狂”。

可刺盛大的阳经脉，使之虚弱下来，俟全身觉得发热则停止，病必愈。又有病始发时一年一次，不治好，则成每月一发，再失治则成每月发四、五次，此名“癫病”。宜刺各分肉间，及各经脉之穴位，如遇只发热不恶寒之病人，则只宜针刺调和，发作停止则针亦停止。

若因风邪致病，且忽冷忽热，一日出数次的热汗，此时可先刺肌肉分肉间及络脉位。多汗且忽冷忽热者，探用三日一刺，须满百日方愈。

受大风而病之人，其症是骨部沉重，须及眉皆落，此名“大风”（痳疯），针法在肌肉中即可，使之汗出，满百曰后，待脱落之须眉再生出时，即可停止刺法。
