虚就是没有，里面什么都没有长，就叫虚脉。摸到实脉比较不好，所以摸到实脉的话，就是实脉，阳实或者阴实。

若虚脉的话代表里面没有长东西，所以若病人摸，摸他的脉本来是实脉，本来是重病的，结果你把一个病人从实脉治成虚脉，甚佳。病人在从生病回到正常之前，都是纯虚症，纯虚症。

这是过去，不管是理论上《黄帝内经》讲的，在临症上面看的时候，都会呈现到虚症的现象。这个时候也就是说，人体就这样子，你把病去掉以后，人是很虚的，这个时候你给他滋补一下就好了。这是很正常的现象，就好像你车子原来不好，你把它故障修好了，！修好以后，车子还不会跑，因为汽油还没加，机油还没灌，！水箱还没加水，然后给它滋补一下就开始动了。所以人体，就按照阴阳平衡的道理来走，跟的那个奇恒跟揆度是一样的，专门讲的天地的阴阳平衡，完全是要相合相通的。这是这个章节讲的东西。
