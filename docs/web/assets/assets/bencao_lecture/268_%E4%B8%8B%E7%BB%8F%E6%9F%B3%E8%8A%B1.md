# 下经·柳花

**【本经原文】** 味苦，寒，无毒。治风水，黄疸，面热黑。叶，治马疥，痂疮。实，主溃痈，逐脓血。生川泽。一名柳絮。

**【产地】** 江南一带，生湖畔河堤处。

**【性味】** 柳絮，柳枝，柳叶，柳根皆味苦，性寒。

**【主治】** 柳絮为祛湿，解热，止痛药，治黄疸，湿痹，金疮及脚气。柳叶可疗疥，洗漆疮，解热毒，止痛。柳枝及根白皮能解热，止痛，消肿。

**【别录】** 主痂疥，恶疮，金疮，实主溃脓，逐脓血，子汁疗渴。

**【甄权】** 主止血，治湿痹，四肢挛急膝痛。

**【日华】** 煎膏续筋骨长肉止痛，主服金石人大发热闷，汤火疮毒入腹闷热，及疔毒。

**【苏敬】** 柳枝与根主治痰热淋疾，可为浴汤，洗风肿疮疡，煮酒漱齿痛。

**【时珍】** 煎服治黄疸，白浊，酒煮熨诸肿痛，去风，止痛，消肿。

【附方】金疮出血——柳絮封之即止。脚多汗湿——柳絮着鞋袜内穿之。眉毛脱落——柳叶阴干为末，以姜汁在铁器内调膏，夜夜抹之。黄疸初起——柳枝煮浓汁半升，顿服。乳痈妒乳——初起坚紫，众疗不愈，柳根皮熟捣，火温棉裹慰之，冷更易，一宿消。

**【用量】** 一般一钱至三钱。

**【禁忌】** 寒症忌用。

这个316 就是柳花，他叫柳花，实际上我们看到的江南一带河边都有种柳树，我们台湾也很多种柳树，你到公园里面就可以看到种的柳树，台中也有，台中公园也有柳树，公园水旁边都有柳树，这个柳树非常好，全身是药。

当然你不要让上面的寄生虫拿来当药。

我们讲的全身是药，你看它的柳絮、柳条、柳叶、柳枝、柳树的根通通可以用，所以你看它处在江南一带，柳絮、柳条、柳枝、柳叶和柳根都可以使用。

你要知道一些这个柳树的东西，经方张仲景没有用这个药，但是你有机会用到。

因为这一棵树有那么多功能在里面，尤其你到江南一带的时候，都可以使用。

它能够祛湿解热，止痛，因为柳絮就是柳花嘛，能祛湿止痛，治黄疸，湿痹都可以，柳树的叶子，那个长条形的叶子，好像蒸叶洗疥疮，身上的疮，解热毒。

柳枝和根白皮呢，那树根的白皮，消肿止痛，使用上面非常好用，你看附方，这个都是经验的，好的东西我给你列进来给你看。

你看金疮出血，柳絮，这个脚多汗，汗太多，怎样呢？诸位自己看就可以了。

第五个，胸部的、乳房的硬块，你如果是乳房的、乳癌的初期，有硬块在里面，颜色是坚紫、硬非常的硬，而且颜色是紫色的，这个时候刚开始，没有切片，什么都没有，你可以用柳根，效果很好。

用不用无所谓，只是一般你去药房里面买柳根，没有。
