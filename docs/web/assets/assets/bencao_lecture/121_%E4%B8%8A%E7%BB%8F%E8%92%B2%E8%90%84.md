# 上经·蒲萄

**【本经原文】** 味甘平，主筋骨湿痹：益气倍力，强志，令人肥健耐饥，忍风寒，久服轻身，不老延年，可作酒。

**【产地】** 处处有之，多种植园区山地之间，美法诸国盛产之。

**【性味】** 味甘涩，性平，无毒。

**【主治】** 蒲萄主补身益气养血，治筋骨湿痹，作酒用良。

**【别录】** 逐水，利小便。

**【甄权】** 除肠间水，调中治淋。

【苏颂】时气痘疮不出，食之或研酒饮之效。

【灵胎】补益筋骨，滋养肌肉。

**【用量】** 普通做食品，入药无定量。

**【禁忌】** 多食令人卒烦闷眼暗，东南商人食之多病热，西北人食之无恙。

那蒲萄呢，就是我们的葡萄，那葡萄呢，水果类的，我们常常可以食用的是葡萄。

所以诸位你看他都没把凤梨写进来，西瓜、凤梨，莲雾，葡萄他有他的道理，所以没事就吃吃葡萄。

这个《神农本草经》里面果类的东西，果实类的东西，大枣啊，葡萄。

我平常在诊所看病的时候我就吃个葡萄，吃葡萄的时候你们最好买那个比较原始的葡萄，有皮啊有籽的，连皮带籽一起通通吃下去，这个葡萄不但可以保养牙齿对身体也很好，同时呢筋骨湿痹：益气倍力，可以常吃的。

葡萄补身益气养血。

那你养血的葡萄，绝对不是，我们有青色的跟黑色的暗色的葡萄，你要养血一定要找红色的黑色的才有，找那个青色的它不养血。

但是你可以看它的颜色，葡萄是滋补身体的，青色的一定入肝，红色的一定入心，黑色的一定入肾，你这样子想就好了，用意，可以以意得之。

能够排水，利小便。

这是我平常就在吃的，那徐灵胎说能够补益筋骨，滋养肌肉。

所以我没事在诊所里放的就是蔗糖，一块一块的，我丢在嘴巴里来吃，想吃点蔗糖，站太久了脚筋骨有点抽筋，就丢个蔗糖，平常就吃个葡萄，多补啊，你不要没事就在那边吃多种维他命，吃完这个还要吃ABCD什么的，实在害死人，花钱买祸，葡萄非常好。

那禁忌呢，多食令人烦闷，怎么样，东南商人吃之多病热，西北人吃了没有关系。

这个我不了解，实际上葡萄你吃多会有这种情形，我想是因为这个他吃太过量了，太过量了有这种反应，实际上我不太认为是这样子。
