# 上经·络石

**【本经原文】** 味苦温，主风热死肌痈伤，口干舌焦，痈肿不消，喉舌肿，水浆不下，久服轻身明目，润泽好颜色，不老延年。

又名耐冬，云花，为野生常绿藤本，茎有气根，藉以攀缘于他物上。此药以石上生者为最佳，故又名石龙藤。

**【产地】** 产山谷阴湿之地，为自生常绿之草，茎入药。

**【性味】** 味苦性微寒，无毒。

**【主治】** 络石主利筋骨关节，治风热痈肿，能凉血退热，舒筋活络。

**【别录】** 大惊入腹除邪气，养肾主腰髋痛，坚筋利关节，久服明目润泽。

【藏器】主一切风，变白宜老。

**【苏敬】** 蝮蛇疮毒心闷，服汁并洗之，刀斧伤疮，敷之愈。

**【用量】** 普通一钱至三钱。

**【禁忌】** 阴脏人畏寒易泄者忌服，恶铁落，畏贝母菖蒲。

【附方】喉痹肿塞、喘息不通须臾欲绝，用络石草一两，水煎一大碗，细细吞下，少顷即通。第五十六，原名是络石，实际上现在是络石藤。以前称为络石，那是因为，它是藤状的东西，就生在那个大石头，山林里面的大石头，上面就长很多青苔嘛，然后去看，哎，怎么树藤那样把整个石头包住，绑得紧紧的，那就是络石藤。那这个药呢，味是苦，性微寒，主风热死肌痈伤，所有的发炎的炎症，统统可以使用络石藤，那因为络石藤刚好是在把整个石头绑住，这样包住的感觉，你把它石头想成骨头的话，它对利筋骨关节非常的好，能够舒筋活血。还有，喉咙肿，水浆不下，那过去呢，我们经方也有，我们有药，可以打开喉咙，本草经，你可以用络石藤一味药，单味药，你用 1 两，用三碗水去煮，煮成一碗，然后煮成一碗的时候很浓稠，让病人慢慢慢慢喝下去。遇到喉癌，或者是你那个扁桃腺发炎，里面可能是喉癌，舌癌，口腔癌，或者是扁桃腺发炎之类，反正舌头不能吞东西了，你不能吞东西很危险，因为病人死不是癌症死，也不是扁桃腺发炎死，而是饿死的，因为吃不下东西嘛。那过去呢就用络石藤，把它弄了煮浓汤，然后叫病人慢慢啜，喉咙就打开来了，这是一种方法。那前面介绍的硝石，是不是也是这个功能啊？哦，硝石更凶啊，“老师，络石藤打不开”，硝石就丢下去把它炸开来，硝石无毒，可以吃的啊，就是不要去点火啊，你不能说，“老师，硝石丢下去，我在他舌头上灸”，你点火，你不是想整人？那个老师他寒嘛，寒症的时候我们要灸，然后再放硝石在里面，哇，你很可怕，心很好但是有点白目嘛。这个硝石很强，一下去就打开来，那打不开来，就已经无救了嘛，我们药到这种程度，那经方呢，我们有半夏苦酒汤，也是很凶的药，收敛的力量很强，所谓收敛就是把肿瘤统统收敛，结果管道就会打开来，我们的半夏苦酒汤，有很多种方法来开喉咙，络石藤是一种方法。书中呢，你看像我们这个蝮蛇、疮毒，都可以，用络石藤来外洗。这个药呢，因为它把石头整个是包住的，所以它入三焦，按照藤状的东西，它入三焦，所以说，像胸部乳房，乳房是不是一大堆乳糜把乳房包住，所以我们在乳癌，通乳上面的时候，硬块上面，我们也会开到络石藤，能够让它疏通，但是一定要用在热证，病人有三焦燥火，热证的时候用。
