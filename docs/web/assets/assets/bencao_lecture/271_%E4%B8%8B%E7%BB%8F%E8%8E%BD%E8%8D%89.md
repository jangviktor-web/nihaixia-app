# 下经·莽草

**【本经原文】** 味辛，温，有毒。治风头，痈肿，乳痈，疝瘕，除结气，疥瘙，杀虫、鱼。生山谷。

**【产地】** 处处有之。

**【性味】** 味辛性温有毒。

**【主治】** 消肿，杀虫要药，治痈肿，瘰疬，疥癣，白秃，头风痛及皮肤麻痹。

**【别录】** 疗喉痹不通，乳难，头风痒，可用沐，勿内服。

**【甄权】** 治风疽疝气肿坠，凝血，治瘰疬，除风湿，不入汤服，主头疮白秃，杀虫，与白蔹，

赤小豆为末，鸡子白调之如糊，敷毒肿，干更易之。

**【用量】** 无定量。

**【禁忌】** 只可做沐汤及外敷药，不可内服。

319 莽草，这个莽草呢，一般来说，我们都不内服，只做外敷，煮汤啊洗身体，这个外用的。

一般药房里面买不到莽草，诸位看看就可以了。

那以我的看法，因为这个药，现在这个人会用得不多，我们到阳明山上看很多芒草，那个芒是这个“芒”，芒草哦，很像芦苇，尾巴这样长起来。

我个人的想法就那个东西，山上到处都有。

因为现在人很少使用它了，所以药房也抓不到。

那反正是外用的，诸位可以买来，自己采回来使用没关系，这个，对身体、皮肤一定会很好的。

诸位记得，你看那个花类的东西，像那个，它种子在传播的时候，会有枊（ang)，长枊，风一吹的时候到处飘，你看它性那么轻，那么轻的浮在表面上，浮在空中，可以散到很远的地方，它可以到皮肤表面上。

所以说外洗一定可以使用，绝对不会有问题的，是杀虫的药，身上的疥廯呐、皮肤痒呐什么都可以使用。

三二〇、雷丸

**【本经原文】** 一名雷矢。味苦，寒，有小毒。主杀三虫，逐毒气，胃中热，利丈夫，不利女子。

作膏摩，除小儿百病。生山谷土中。

**【产地】** 产我国河南陕西湖北等地，生土中，为竹之余气所结，故亦曰竹苓。

**【性味】** 味苦（或作咸），性寒，有小毒（或作无毒）。

**【主治】** 雷丸为消积杀虫要药，主除皮中热结，逐毒气，杀诸虫，作摩膏治小儿百病。

**【别录】** 作摩膏除小儿百病，逐邪气恶风汗出，除皮中热结，积虫毒，白虫寸白，自出不止，

久服令人阴痿。

**【甄权】** 逐风，主痫狂走。

**【用量】** 普通一至二钱。

**【禁忌】** 不利女子，多服令人阴痿。

那，这里没有雷丸哦，因为雷丸是很普遍的药，药房就有这个雷丸。

32雷丸，这个雷丸中药房都有得卖。

雷丸，一般来说，小儿科的时候使用，小孩子，儿科，一般来说雷丸可以做膏，做成药膏，涂在身体、皮肤上面。

那你看雷丸的性味，味苦、咸，性寒有小毒，一般来说就是小孩子杀虫，像那个那个食物消化不好，用雷丸，杀虫，使用最多的就是蛔虫，现在这个雷丸呢，我手边没有。
