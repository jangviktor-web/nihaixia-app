# 中经·地榆

**【本经原文】** 味苦，微寒，无毒。治妇人乳痉痛、七伤、带下十二病，止痛，除恶肉，止汗气。

消酒，明目，治金疮。生山谷。

**【产地】** 生山间向阳之地，今处处平原川泽亦有之，根直而柔，入药。

**【性味】** 味苦（或作苦甘酸），性微寒，无毒。

**【主治】** 地榆为止血收敛要药，功能止吐血下血久痢，妇人崩带。

**【别录】** 止脓血诸瘘恶疮热疮．补绝伤，产后内塞，可作金疮膏，消酒除渴，明目。

**【开宝】** 止冷热痢，疳痢极效。

**【大明】** 止吐血鼻衄，伤风，月经不止，血崩，产前后诸血疾，并水泻。

**【容川】** 地榆首之气味厚，故行血更有力，尾之药味薄，故行血之力轻。

**【用量】** 普通二钱至三至四钱。

**【禁忌】** 性寒下行，脾胃虚寒作泄，白痢久而胃弱，胎产虚寒泄泻，血崩脾虚作泄，均忌，恶麦冬，丹砂，硫黄，雄黄。

191味药，地榆。

你们传阅看看。

地榆这个药呢，主要的使用时机是我们用来止血、收敛。

老师我大便之前血都飙出来的，但都不痛，这是内痔。

地榆一下就止掉了，这是内痔。

我们大便带血先不要紧张，你要先问他，请问你是看到黑血还是鲜血，鲜血都没有事。

鲜血是近血，所谓近血就是靠近肛门的血呀。

我的大便是黑的，一冲的时候看到暗红的血，这是远血。

远血就可能来至胃呀，胃里面的出血。

所以胃溃疡、胃癌里面出血大便是黑的。

那你老师我大便出来是鲜血，鲜血是近血，靠近肛门都没有关系。

这个内痔、外痔嘛，或者大肠炎。

外痔就是大便都很好，肛门外面胀的很痛呀，都没有血。

结束的时候一擦纸巾上有血，这是外痔。

内痔不是呀，内痔是先血后便，哇——，先排一大堆血出来，最后才排大便出来，这是内痔。

大肠炎呢，colitis，血跟大便是混在一起的，那一天下利三、四十次呀，这个没事就在跑厕所——大肠炎。

那如果看到是你情敌，太好了，不要治。

如是非情敌，我们用禹粮石、赤石脂呀，桃花汤呀，都是治了大肠出血的。

它是治血收敛的药，功能吐血，下血，久痢，妇人崩带。

我们中医讲血无止法，如果你把身体机能调理回来，血自然停止。

那有的时候，他虚的很厉害，需要止血的时候，就考虑使用地榆。

前面介绍的阿胶，它也有止血的效果。

但阿胶比较偏重于这个女人的月经。

地榆呢比较偏重于肠胃、大肠、肛门这边，还有吐血用地榆。

外用也可以，做成膏状，打粉敷在伤口上也能止血。

鼻子出血加在汤剂里面都可以使用。

唐容川就讲了，地榆首之气味厚，故行血更有力，但地榆的尾巴呢，药味比较淡，行血的力量比较轻。

所以地榆首跟地榆尾稍微一点不同。

那因为它药性是稍微寒凉的，里面寒症的时候使用就要小心了，一般都是热症的时候我们在使用。

一般像内痔的大量的出血，一般都是热症。

湿热下注呀，肛门都是粘粘的，也就是那个滴漏不止，很可怜呀！已经病成这样了，西医给他说先生我告诉你只有开刀会好，好，病人趴在那儿给你开刀，开完刀后呢，还是一样。

（笑）我就从来没有听说过一个人开刀好过。

开完刀还更坏，还造成一个瘘管。

从此男人还戴着一个（卫生巾），很可怕。

（笑）很难过的呀！我们如果说开处方，地榆是止血的。

那你说，老师我没有流血呀，有那个湿湿粘粘的津液排出来呀，你可以用些去湿的，赤小豆，白术呀，这个知母呀也可以去湿，来处理这个排湿的。

所以血跟湿你给他排开来。

那你在使用的时候，唐容川说头跟尾不一样。

你去写个地榆头，药房不会抓给你的，你就写地榆好了。

不要写个地榆头呀地榆尾的。

好，上堂课我们介绍到一百九十一，地榆，这个地榆主呢，止吐，呕吐，吐血，最主要是止血，最常用的地方就是痔疮的出血，痔疮，还有吐血，嘴巴的吐血，那，可能里面的内症，里面的病呢，可能是肝硬化以后，好了，肝硬化呢，又影响了门静脉破裂，门静脉破裂病人吐血，或者胃癌，吐血，那大便出血，最常用的就是，几乎想到那个痔疮的出血，我们就会使用到地榆。
