# 下经·水斳（芹菜）

**【本经原文】** 一名水英。味甘，平，无毒。治女子赤沃，止血，养精，保血脉，益气，令人肥健，嗜食。生南海，池泽。又名芹菜。

**【产地】** 处处有之。

**【性味】** 味甘性平，有特殊的香味。

**【主治】** 解热止血，健胃药，治女子血崩赤带，小儿暴热，大人酒后热。

**【本经】** 主女子赤沃，止血养精，保血脉，益气，令人肥健，嗜食。

【藏器】饮汁去小儿暴热，大人酒后热，鼻塞身热，去头中风热，利口齿，利大小肠。

**【大明】** 治烦渴、崩中，带下，五种黄病。

【圣惠】捣汁日服六七合，治小便出血。356是水靳。我们有陆上的靳就是我们现在吃的芹菜，还有一种靳菜是生在水里面的。现在水里面的靳菜的叶子跟陆上的靳菜叶子不同，陆上的靳菜叶子比较大，生在水里面的比较长，细长象竹叶一样那是水靳，那水靳呢，这种解热止血健胃的药，止血的功能很好，味甘性平，药性是比较平和的，会用到水靳的在食物里面用，比如一些解酒啊，小孩子发高烧啊，统统可以，小便出血，这是食物类的东西，这个可以常常吃没有关系。
