# 中经·紫苑

**【本经原文】** 味苦，温，无毒。治咳逆上气，胸中寒热结气，去蛊毒，痿厥，安五脏．一名青菀。

**【产地】** 为山野多年生草本，产我国中部，庭园亦可栽植，其花美丽，根状似细辛，其质柔轫，

入药。

**【性味】** 味苦辛，性温，无毒。

**【主治】** 紫苑为祛痰止咳要药，主治咳逆，痰涎，吐脓血，益肺气。

**【别录】** 疗咳唾脓血，止喘悸，五劳体虚，补不足，小儿惊痫。

**【甄权】** 治尸疰，补虚下气，劳气虚热，百邪鬼魅。

**【大明】** 调中消痰，止渴润肌肤，添骨髓。

**【好古】** 益肺气，主息贲。

**【用量】** 普通七分至钱半。

**【禁忌】** 肺病咳逆喘嗽，皆阴虚肺热也，忌独用多用，即用亦须与二冬百部桑皮等苦寒药参用，

方无害以其性温也。

一七九味药，叫做紫苑，我们这个药，祛痰。

我们治疗咳嗽的时候用得非常多，张仲景呢，也用得很多，那它的主要的性味呢，味苦辛，又有辛辣的味道，又苦，能够泻，辛是散苦是泻，所以呢我们如果说肺里面有水，它是一定可以的，因为它是辛辣的，可以散，那苦又可以泻下，肺里面有积水。

痰，也可以，当然可以祛痰啦，所以很多的咳嗽，里面除了，本身我们要治疗咳嗽的话，要把痰去掉，或者要把痰要把水也去掉，那紫苑是很好使用的一个药。

那最主要是用在这个祛痰止咳，病人呢，如果有肺家病比较严重的时候，咳出脓血来，或者是肺气不足，呼吸很短都可以考虑使用紫苑。

由于紫苑的性是温的，所以寒家的咳嗽，寒咳，我们可以加上紫苑。

那肺癌，肺结核，名称不管，病名不管，要出现肺寒证的人，咳血，咳嗽，都可以使用紫苑。

那剂量呢，诸位看看紫苑长这个样子，它很轻，你可以用一钱哪两钱，严重的三钱都没有关系。

一八O、紫草

**【本经原文】** 味苦，寒，无毒。治心腹邪气，五疸，补中益气，利九窍，通水道。一名紫丹。

一名紫芙。

**【产地】** 为山野自生之宿根草，园圃亦可栽种，产于寒地野生之根为良。

**【性味】** 紫草味甘咸，性寒，无毒。

**【主治】** 紫草为痧痘要药，功能凉血，活血，透发解毒，治恶疮天花，麻疹及小儿疮疖与面皻。

**【别录】** 通水道，疗肿胀满痛，以合膏疗小儿疮及面皻。

**【甄权】** 治疮癣。

【灵胎】淸血除邪。

**【用量】** 普通二钱至三钱，大剂一两。

**【禁忌】** 痘已出而红活及白陷，脾胃肠虚寒大便溏者忌服。

第一八〇味，我们称为紫草。

这个紫草诸位看，就是紫色的，长这个样子。

因为它药性是寒的，我们专门是治疗热证时使用。

这个味道是苦味的，使用的时机呢，我们治疗痧痘，出疹子，德国麻疹，痘疹，水痘的时候我们都可以使用紫草，因为它的味，除了它有甘味，有点咸味，有甘有咸，那药性是寒凉的，所以热证的时候都可以使用。

过去呢，我们发恶疮，天花，麻疹，小孩子得麻疹通通都可以使用紫草。

你也可以说它的根效果最好，所以我们也可以叫紫根。

现在如果你处方的话，你写紫根三钱，可能药房更了解，你写紫草他还搞错，因为紫草，我们是以根部药效果最好，同一株的嘛。

那这个除了痘疹以外，恶疮天花，我们要想到这个紫根。

那《别录》呢，说通水道，能够疗肿胀。

如果说痘子，水痘或者是天花这种出来，这个颜色很鲜红的，或者是白色凹陷下去的，还有肠胃虚寒的都不可以用，都不要用这个紫草。
