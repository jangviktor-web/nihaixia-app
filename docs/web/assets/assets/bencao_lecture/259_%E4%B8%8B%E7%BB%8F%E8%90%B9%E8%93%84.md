# 下经·萹蓄

**【本经原文】** 味苦，平，无毒．治浸淫，疥瘙，疽，痔，杀三虫。生山谷。一名萹竹。

**【产地】** 处处有之，多繁殖路旁，叶细绿。

**【性味】** 味苦，性平，无毒。

**【主治】** 萹蓄草为杀虫疥，利小便要药，治湿疮浸淫，热淋涩痛，热疾黄疸。

**【别录】** 疗女子阴蚀。

**【甄权】** 煮汁饮小儿，疗蛔虫有验。

**【用量】** 普通一钱至三钱。

**【禁忌】** 无湿热者勿用。

二九六，这是萹蓄，诸位看萹蓄长成这样子。

这个药呢，也是杀虫，还有皮肤病的时候使用，内服也可以，外敷，洗用也可以。

主治洗身上的疥虫，这个皮肤很痒，这个也可以内服。

这个很轻，你们看，它质地非常的轻，所以排、皮肤病或者去虫的时候，1 钱的量就已经很多了，2钱，那就是肚子里面你确定他虫很多的时候。

这种打虫药一吃下去，大多数都是从大便排出来，吃完以后会拉肚子。

一到厕所，哇！一票虫排出来，所以要赶快冲掉，会吓死人的。

那小朋友呢，肚子里面有虫，我们检查的方式很多，第一个你看如果有虫的话，肚子会很大，挺起来，硬梆梆的；第二个你把他下唇拉起来一看，哦，牙齿下方的牙龈的地方，你会看到很多白色的虫卵一样的，一粒粒的，白色的，它就长在那边，眼白里边有蓝点，都是肚子里边有虫。
