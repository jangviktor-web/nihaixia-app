# 下经·杏核仁（杏仁）

**【本经原文】** 味甘，温，有毒。治咳逆上气，肠中雷鸣，喉痹，下气，产乳，金疮，寒心，奔豚。生川谷。今名杏仁。

**【产地】** 杏树处处有之，有多种，以产山西河南山东一带者为胜，仁入药。

**【性味】** 味甘苦，性温，有小毒。

**【主治】** 杏仁为咳逆痰气要药，主咳嗽气急，能下气平喘，治风寒痰滞，能宣肺解肌，除风散寒，润燥消积，利胸膈气滞。通大肠气闭。

**【别录】** 惊痫，心下烦热，风气往来，时行头痛，解肌，消心下急满痛，杀狗毒。

**【甄权】** 治腹痹不通，发汗主温病角气，咳嗽上气，喘促，入天门冬煎润心肺，和酪作汤润声气。

**【元素】** 除肺热，治上焦风燥，利胸膈气逆，润大肠气秘。

**【容川】** 杏仁有油，但得苦味，无辛烈之气，故降而不及。色白属金，降气行痰，气降则血降，

故凡吐血必咳痰，痰为气分，因气逆而血升，故引出其血也。

**【药征】** 主治胸间停水也，故治喘咳，而旁治短气结胸，心痛，形体浮肿。

**【用量】** 普通钱半至三钱。

**【禁忌】** 凡杏子性皆热，小儿多食致疮痈膈热，多食动宿疾，产妇尤忌，杏仁双仁者有毒能杀人，阴虚咳嗽，肺家有虚热痰者均忌，恶黄耆葛根。

杏仁，在本草上面有这个杏仁，杏核仁，他说有一点小毒，所以就因为有小毒，现在南派的中医生连杏仁都不敢用，你跟他说用三钱，哎呀杏仁有毒你怎么用三钱，我请问你我们常人吃那个杏仁豆腐，你什么时候听到过吃杏仁死掉啦，那没听说过，杏仁很好吃呀！杏仁还有故事在后面：过去东北，我们抗日战争在东北打的时候，结果很多人得到TB就是肺结核，那当时没什么药怎么办，当时就有个老先生跟个年轻人讲，那年轻人肺结核，一直在咳血，这样子，他说你去花点钱去买那个杏，丹东东北产的那个杏，杏跟桃子很像但杏的皮是光亮的，美国有产的。

然后你吃那个杏里面的仁—新鲜的仁，然后你去专门去吃那个仁，对年轻人说这样你就会好。

那年轻人说我无所谓啊，每天咳嗽每天咳血，就拿钱买很多杏，跟小朋友，你们大家来帮我吃杏但条件是核要给我。

小朋友很乐啊就吃吧，核就给他，吃那新鲜的杏。

结果吃了两三个月，咳嗽也好了也不吐血咳血，都好啦，结果故事就传出去了。

传出去以后这日本人呢那时占领东三省，心想这个家伙好了，把他拿来化验看看这个人到底是怎么回事，找个理由抓起来，抓起来把他剖开来，一看他肺里面所有的肺泡结的地方都有杏把它结住，功能完全恢复，只是那个杏把肺泡破损的地方统统结起来了，结痂，那个里面的经结统统都被杏包住。

所以这个杏仁有那么好的效果，这个二次世界大战记录我看到一些，里面刚好看到这个记录，正好验证中药是对的。

那这个性温呢，是药性比较温和，比较温性的药味甘苦，杏仁呢，咳利痰气的要药，张仲景用杏仁用得很多，包括宣肺去痰，肺气不开，宣肺，它能够去痰。

这个杏仁去的痰呢都是浊痰，黄浊的痰，对肺的功能很好，那我们不管治疗百日咳，不管它的名称是什么，不管是TB或者肺结核，或者是肺气肿或者气喘或者只是一般性的咳嗽都没有关系，只要看到有痰，肺气没有办法宣泄，短气，统统可以加杏仁上去。

黄痰黄粘稠的焦痰，口渴一般来说应该是热症，我们可以用杏仁，那这个主治呢，你看它能宣肺解肌除风散寒，润燥消饥。

诸位看，这个刘元素除肺热治上焦风燥，润大肠细腻，吃了杏仁就会有通润大便的功能。

那唐容川呢，讲杏仁跟桃仁都有油，但是杏仁得到苦味没有辛烈没有辣的味道所以降而不及，所以它色白，杏仁颜色是白色的，属于金，所以凡吐血咳痰都会使用到这个杏仁。

诸位看，这是杏仁粉，杏仁很好吃啊，闻起来就是杏仁味道，台湾的杏仁豆腐。

这个杏仁粉，我们在药房里面做生药的时候，杏仁拿出来丢到煎汤剂里面的时候，会把它打碎，这样子比较好煮，不然的话一片好像煮不熟象煮花生一样的不容易煮开，我们一般把它打碎，打碎给它，敲一下捏住把它打得很碎，药力比较容易出来。

所以说那个吐血一定会有咳痰，痰是气分，因为气逆有血生所以引起出血，这个时候痰呢，就是有痰你没有好，痰一直咳出来以后血就跟着出来，唐容川就是这个意思。

你会看到血是因为之前有痰出来，所以说杏仁能够去痰所以它能够止血，最主要是它把痰去掉所以血就归位，最主要原因在这里面。

那这个禁忌，杏子比较热，跟桃仁杏仁都一样，吃了容易长痘痘，但是你如果做成了杏仁豆腐不一样了，那豆腐本来就是去热毒的，所以我们中医，过去的豆腐，比如说慈禧太后她吃那个珍珠，因为珍珠可以美颜嘛，但珍珠有毒啊那个怎么吃，她用珍珠，下面一层豆腐做底把珍珠放上去，当然你不会那么傻把珍珠撒上去，一定用布，用棉布把珍珠撒上去一收好收啊，不然的话煮完了后到哪里去找珍珠，那里面一堆乱豆腐你到里面去捞对不对，那么傻对不对，珍珠很小颗没办法，用棉布，把珍珠放在棉布上，下面是豆腐，然后上面再放一层棉布把珍珠盖在棉布中间再放一层豆腐蒸。

豆腐很奇怪，豆类的东西可以去热毒，所以你如果是杏仁用豆腐炮制过的话反而可以去痘痘，那个热性反而没有，所以你吃杏仁豆腐到没有关系。
