# 中经·槀本

**【本经原文】** 一名地新。味辛，温，无毒。治妇人疝瘕，阴中寒肿痛，腹中急，除风头痛，长肌肤，悦颜色。生山谷。名鬼卿。

**【产地】** 野生草本。

**【性味】** 味苦辛，性温。

**【主治】** 鬼卿为祛风寒镇痛要药，治大寒犯脑头痛齿亦痛，女人阴寒肿痛，体肤风湿。

【东垣】头面身体皮肤风湿。

**【大明】** 治皮肤疵皯，酒皻，粉刺，癫疾。

**【元素】** 治太阳头痛，巅顶痛，大寒犯脑，痛连齿颊。

**【用量】** 普通一钱至三钱。

**【禁忌】** 热病头痛，血虚头痛，均忌服。

【附方】头屑干洗—槀本，白芷等份共末，夜擦旦梳，垢自去。第22第一百八十五，诸位看这个槀本，它又有一个名称叫做鬼卿。那这个药呢，在皮肤病上面，我们为了让女子美容养颜，使用得很多。还有呢，它之劳妇人的疝气、徵瘕，阴中寒，阴部那边的寒痛，妇科上用得很多。这个味苦味、辛味，槀字原来是“藁”这样子，在本草经上面就变成这样子写的，原来那个正楷字，这个古体字，查这个字就查到了，槀本。它主要的功能呢，因为它是苦味的，辛味的，所以苦味能够泄，辛味能够散，所以能够驱风、祛风寒，能够镇痛。那头痛啊、牙齿痛啊、女人的阴部痛啊。使用的时机，我们常常用在脸上的，不管是脸上的斑，红斑哪，还有些黑，雀斑啊，一些条啊，还有酒糟鼻啊都可以使用，那这个复方，你有头屑，老师头皮太多了，你用槀本跟那个白芷混在一起用，都是一般性的经验方，诸位可以看看，可以使用没有关系。
