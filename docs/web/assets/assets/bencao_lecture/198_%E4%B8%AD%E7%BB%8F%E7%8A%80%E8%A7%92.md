# 中经·犀角

**【本经原文】** 味苦，寒，无毒。治百毒，蛊疰，邪鬼，瘴气，杀钩吻，鸩羽，蛇毒，除邪，不迷惑，魇寐，外服轻身。生山谷。

**【产地】** 产我国云南贵州四川等地，生山谷中，角入药。

**【性味】** 味苦酸咸，性寒，无毒。

**【主治】** 犀角为散邪清热凉血解毒要药，主伤寒时疫，发黄发斑，风毒中恶，狂言妄语，治胃中大热，痘疮黑陷，吐血下血，蓄血谵语，能消痈化脓，解毒定惊。

**【别录】** 伤寒瘟疫头痛寒热诸毒气，令人骏健。

**【药性】** 辟中恶毒气，镇心神，解大热，散风毒，治发背痈疽疮肿，化脓作水，疗时疾热如火，

烦毒入心，狂言妄语。

【灵胎】养心开窍，解毒除邪。

**【用量】** 普通三分至一钱。

**【禁忌】** 恶乌头，忌盐，能消胎气，孕妇忌服，痘疮气虚无大热，伤寒阴症发躁，脉沉细，足冷，渴而饮不多，且复吐出者均忌。

228犀角就是犀牛角，现在这个药呢，已经禁用了。

国际都列为国际保护动物，但是在我的抽屈里还有犀角哦，为什么？动物园的园丁送给我的，因为他在动物园是专门负责清理东西的，他腰痛都找我治，他说你要犀角很简单呀，我们那个犀角没事就在树上挂，因为角很粗啊，它要常常去刮嘛，一刮就一片一片的刮下来了，掉在那边，你要的话我捡些给你。

那很好啊，反正他不要了，犀牛也不会说你怎么可以拿我的犀角，对不对，就把它捡扫起来统统给我，放在抽屈里好多犀角。

他说这个是黑的，这个是白的，都给我讲，动物里面有。

动物园里面那个园丁你跟他好好地相处，他会拿犀角给你，但是放心，他不是杀犀牛。

这个专门治百毒，犀牛在森林里面呢是个救火队员，它看到那边失火，它的欲望就是要灭火，他非要把那个火踩灭掉，所以一物克一物，所以它寒，非常地寒哦，那过去呢因为他是性寒的，所以它能够善清邪热，过去南派遇到壮热，高热病的时候就开犀角一钱。

那现在犀角禁用了，所以南派的不会治高热了，看到你高热，就叫他去打点滴。

打什么点滴呀，不要打点滴，我们用石膏啊，很多很多去热的药，一剂就把那个热退掉了，不需要用到犀牛角。

张仲景在1800年前，他也没有用到犀牛角呀，解大热的话我们有很多的药可以解大热，能消痈化脓，解毒定惊的药也有很多，黄连也解毒甘草也解毒。

那黄连和甘草有什么不一样，很简单呀我们前面讲过，甘草解百草的毒，黄连苦味的入心，任何东西能够达到心脏里面，能够造成心脏毒害，用黄连就可以解呀。

尿毒实际上并不是在洗肾呀，是心肺透析，把心脏的血拿出来把里面的尿毒洗掉，再把它放回心脏里面。

所以黄连是解尿毒用的，那你说哎老师用甘草解尿毒行不行？这两个不对症。

所以诸位只要想它的药性，苦味的入心，任何能毒害心脏的就是黄连可以解，食物中毒是用甘草。

以前道士用犀角画符用，所以用途也很多，现在我们不用了。
