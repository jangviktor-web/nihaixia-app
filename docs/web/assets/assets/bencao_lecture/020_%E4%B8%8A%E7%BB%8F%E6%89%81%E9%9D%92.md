# 上经·扁青

**【本经原文】** 味甘平，主目痛明目，折跌痈肿，金创不疗，破积聚解毒气，利精神，久服轻身不老。神农雷公小寒无毒，治丈夫内绝令人有子。去寒热风痹，及丈夫茎中百病益精。

**【别录】** 吐风痰，癫痫，平肝。

【灵胎】养肝明目。扁青，治症非常多，我们空青、曾青很多都是治疗眼科的病，诸位看到没有，都是眼科的疾病，目痛、目瞑都是在这个白青、扁青上面。养肝明目，我们一般最常用的眼科的药都是曾青，空青，扁青，白青，都是从这里面出来的，金石类的药很多，当然我们草木类的要也有，像贝母，我们用在眼科上面非常好。我们甚至于贝母都可以泡水，我们会介绍，这里不讲，等讲到贝母再说。象金石类的药，如果炮制过，提炼过以后，你放水下去，然后无论是提炼还是锻过，烧过烧红，打碎磨的很细，然后让它溶解到水里面让它飘，就是水飞，停在那边，然后沉底，沉底的不要，溶化在水里面的就可以作眼科的药来涂，像曾青、白青、扁青都可以作眼科的药水来涂，眼睛痛痒都可以止痛。象我前面讲的，我们用炉甘石都可以。
