# 中经·水苏

**【本经原文】** 味辛，微温，无毒。主下气，杀谷，除饮食，辟口臭，去毒。辟恶气。久服通神明，轻身，耐老。生池泽。一名芥蒩。

那后面呢，252，253，254，这个蓼实啊，葱实，水苏。

水苏这种现在都已经很少使用。

那像这个葱实呢，我们又有个名称叫薤白，薤白我们后面会介绍，它的味道像大蒜一样。

那这个葱实，这个相当于茎。

光是一根葱，有葱尾、葱白和葱叶，那这个葱尾（根部）的部分切下来，那个尾（根部）的须须，刺激一下乳头，然后旁边这一片切下来这个切面的地方有辣味，刺激一下那个乳头，奶水就排出来了。

这个葱白的地方可以入汤剂，能够通脉，通血络，活脉。

葱茎呢，就是这个葱叶，葱叶这个地方，我们没有那个橡皮的导尿管，那个橡皮的导尿管是给敌人用的，因为那个很痛嘛，中医过去导尿管就是葱叶。

叶子找那个比较（长，粗的），不一定是三芯葱嘛，有二芯葱也可以，叶子长这个样子，把它（的叶尖）切掉，这个头里面有津液嘛，里面辣的津液很多，（示意）这个是葱叶，中间是空的，当把它伸到尿道里面去以后，它那个辛辣的会刺激它，一下子就排出来了。

中医过去是用葱叶来导尿，哦，用途很多。

这个后面的几味，蔬菜类的，谷类的，都是属于食补，真正治病的话，力量还是不够的，但是食补很重要，我们饮食上的调理非常的重要。

本经下药一百二十五种为佐使，主治病以应地，多毒不可久服，欲除寒热邪气，破积聚愈疾者，本下经。
现在，今天我们开始介绍，《神农本草经》下卷的药，哦，诸位看，125种，为佐为使，治病以多毒，大部分还是已治病为主的，药性很毒，哦，所以不可以长期的服用，你要欲除寒热的邪气，破积聚肿瘤的，都是要靠本草经的下经。
所以，这个下经张仲景用的非常得多。
