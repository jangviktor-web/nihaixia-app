# 上经·天名精

**【本经原文】** 味甘寒，主瘀血，血瘕欲死，下血止血，利小便，久服轻身耐老。

**【产地】** 产平原川泽，处处有之，纲目属湿草类。（西充有）

**【性味】** 味甘苦性平无毒。

**【主治】** 天名精主治瘀血症瘕，诸毒疔肿，破血生肌杀虫，内外皆可用。

**【别录】** 除小虫去痹，除胸中结热，止烦渴，逐水，大吐下。

**【唐本】** 破血生肌，止鼻衄，杀三虫，除诸毒肿疔疮瘘痔金疮内射，身痒瘾疹不止者，皆之立已。

【注】血瘕，留着肠胃之外及少腹间，下有积气，坚牢如石，女子多因经行未尽，饮食过度，血留经络而得之，治法不一。

**【用量】** 普通一二钱。

**【禁忌】** 时珍曰有小毒，生汁吐人。

第66味药，天名精，天名精这个药呢，也是很普遍，到处都有，便宜的药，他是味甘，而且有点苦，这个性都是没有毒的，上经都是没有什么毒，那一样，主治的症状呢，很多都重复了，象有些虫毒，虫咬伤啊，瘀血啊，和活血化瘀的，诸位记得只要是苦味的药，药有是苦味的，它有燥，燥就是能够收敛伤口，它有个泻，就是活血化瘀的，这个还有去烧的，都可以用。

那中间有个“注”，有个“注”这很重要，血瘕，这个定义就是留在肠胃之外，少腹之间，下，这个坚牢很硬的，有的是女孩子月经没有排完，有的是男人是伤科，踢伤，内伤，出血，硬块在肚子上边的，血留经络而得到，都可以用，诸位要在肿瘤，身上的癌症、肿瘤跟一般的瘀血、我们这个良性的瘤怎么区分，最简单的方式你用触摸的时候，摸上去只要是肿瘤，硬，他是恶性的，摸他表面非常的硬，而且，表面上非常的粗糙，一般大多数病人不疼的，那你摸到表面很平滑的，它会动的，而且会疼的，这是良性的。

当然不一定，但绝大多数，你们可以按照这个经验法则去看，这是天名精。

那这种药呢都是你们可以加进去，附加的，我们处方不会以这为主，这个可以说是小药，不是大药，刚刚的续断就是大药。
