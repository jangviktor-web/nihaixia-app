# 中经·蟅虫

**【本经原文】** 味咸，寒，有毒。治心腹寒热洒洒，血积，症瘕，破坚，下血闭，生子大良。生川泽及沙中、人家墙壁下土中湿处。一名地鳖。

**【产地】** 处处有之，多生墙壁下土中湿处，形扁小，六足，似鳖而无甲。

**【性味】** 味咸，性寒，有毒。

**【主治】** 蟅虫为破症瘕下血积要药，主心腹寒热，留血积聚，治乳脉不通，妇人经闭，产后血积，折伤瘀血。

**【药征】** 主治干血，故兼治少腹满痛，及妇人经水不利。

**【用量】** 普通一钱至三钱。

**【禁忌】** 用皂荚菖蒲，无瘀血停留者忌，孕妇慎用。

二百四十六，蟅虫，大家看，这是蟅虫。

拿起没关系，已经烤焦了。

不会跑出来咬你的。

蟅虫呢，我们叫地鳖虫。

你如果乡下老灶，那个锅子，你那个铁锅子一打开来，当然里面有伏龙肝，就是我们灶心土。

你还会看到里面有大蜈蚣，蜈蚣很喜欢躲在里面，地鳖虫在里面，地鳖虫跑出来，六只脚，那个背后一条一条的，地鳖虫。

就是这里讲的蟅虫。

我们前面跟大家讲大黄蟅虫丸里面的蟅虫。

这个246呢，这个蟅虫。

这个245我们讲蜚蠊。

这个蜚蠊就是蟑螂。

蟅虫又名地鳖虫，它的味咸有毒，那一般来说，活血化瘀，尤其是攻妇女的，子宫里面瘀血的时候都会使用。

那为什么说下血闭，生子大良。

就是说你如果一个妇女子宫里面完全没有瘀血，因为你的组织非常的健康嘛，当然会生小孩，生的很正常，对不对。

这到处都有，味咸的，咸味的统统可以软坚。

那你如果使用，你说“老师，子宫里面有硬块呀，肿瘤呀，有那个肌瘤呀或什么，脂肪瘤”，没有关系。

都可以使用。

那蟅虫呢，是破症瘕下血积要药，有时候我们血瘀在里面排不出来，我前面讲过，会让人发狂的，我们可以用蟅虫，像留血积聚，乳脉不通，妇人经闭，因为女人的月经跟奶水是相通的。

那【药征】，主治干血，这个干血，我们有个特别名称叫做痨证，干血痨。

这个血干在里面，清出来不好清，太久了，陈血，陈年的血，会让一个人非常的疲劳，我们叫干血痨。

工作一下就会很疲劳，痨证。

那我们要用些昆虫甲虫类的药来清它。

我讲干血你怎么知道呀，很简单，小腿的地方肌肤甲错，那是主要的症状。

诸位看这个虻虫，呢，你如果开的时候，虻虫是一钱两钱就够了，就很强了，不用开太多。

这个蟅虫呢，你可以开几只，比如一钱两钱，或者十只都没有关系，你开几只就可以。
