# 下经·桃核仁

**【本经原文】** 味苦，平，无毒。治瘀血，血闭瘕，邪气，杀小虫。今名桃仁。

桃花——杀疰恶鬼，令人好颜色。

桃枭——在树不落，微温，主杀百鬼精物。

桃毛——平，主下血瘕，寒热积聚，无子。

桃蠹——杀鬼，辟邪恶不祥。生川谷。

**【产地】** 处处有之，以产河南陕西者为良，仁入药。

**【性味】** 味苦甘，性平，无毒。

**【主治】** 桃仁为破血润燥要药，主行瘀血，消心下坚硬，治血晕血痞血积血痢，血热燥痒，蓄血发狂，通月经。[桃仁吃多了很上火。]

**【别录】** 止咳逆上气，消心下坚硬，除卒暴击血，通月血，止心腹痛。

**【元素】** 治血结血秘血燥，通润大便。破蓄血。

【孟铣】杀三虫，又每夜嚼一枚和蜜涂乎面良。

**【容川】** 桃花红而仁味苦，皆得地火之性，仁在核中，又象人心，味苦有生气，是正入心中，

故桃仁能破血，亦能生血。气属阳，血属阴，瘀血阻气，则阳不入阴，蒸热汗出，宜破其血，使气得入于血中，则不壅热，桃仁主之。

【灵胎】逐瘀血，除邪气。

【倪注】痘家勿用，因仁有生气，可令痘长。

**【药征】** 主治瘀血，少腹满痛，兼治肠痈及妇人经水不利。

**【用量】** 普通一钱至二至三钱。

**【禁忌】** 生桃实多食，令人膨胀及生疮疽，与鳖同食患心痛，服术人忌之，作脯食，益颜色，

肺病宜之。桃仁散而不收，泻而无补，过用或不当，能使血下不止，损伤真阴，故凡经闭由于血枯，产后腹痛由于血虚，大便闭涩由于津液不足者均忌，双仁者有毒，不可食。

桃核仁，简称桃仁，顾名思义，就是桃子里面的核，核打破里面的仁，桃仁。

这个桃仁我们使用非常多，专门活血化瘀，治淤血。

比如说咳嗽咳久，痰里面带血，或肺里面有血，很多肺气管破裂里面有血，我们会用桃仁，妇女来经期痛或者下血块下来肚子痛，每次来了痛经我们也可以加桃仁，那一般来说都是加三钱，三钱起跳，那力量才有，举凡任何的淤血我们需要活血化瘀的时候都会使用到桃仁，但我们不会说管他淤血在哪个部位，在肺里面、在子宫里面、大肠里面、胃里面、肌肉上面，统统可以使用桃仁，脑部里面也可以使用桃仁，至于后面哪个什么桃毛啊什么东西那个不重要了，谁会去刮那个桃子的毛？没那么挑剔，产地以河南陕西最好，桃仁，仁来入药，味是甘苦的，所以诸位只要记得我们中医讲的“仁”剂，只要有“仁”就代表有油脂，油就代表可以利大便，就会利大便。

这个利大便当然不能跟大黄比了，大黄叫川军啊，川象征四川人已经很辣了，加上大将军，川军更凶悍啊，那它当然没有像大黄利得那么厉害，但是它有通便的功能，诸位晓得桃仁有活血化瘀的效果，有通便的功能的话，我们一般治疗肝病的，肝硬化，肝癌，我们都会，肝是血脏，心脏的问题我们会使用到桃仁，肝脏的问题我们也会使用到桃仁，为什么？实际上癌症或者硬化，讲穿了，治疗就是活血化瘀，所以唐荣川写的《血证论》写得很好，专门讲这个血症，久病必有淤，这个必有淤的状态之下，我们为什么要用攻坚，很多南派的温病派的中医不敢攻坚，怕人越攻越虚，其实经方家认为，以通为补，因为有淤血在那边，你不攻掉它，气血不通，不通反而补不进去，要以通为补，通才能补得到它，所以我们常常用攻坚的药，比如说大便不通，我们开处方把大便清出来，那这个不能用啊，这个清了人会虚掉，它就是你已经十天都排不出来了，你再不把它攻出来，它那个（产生）沼气以后，你这病人真的会死掉，那个沼气会回头啊，所以该攻的时候去攻不要怕。

所以你看主治，桃仁会破血，润燥，因为它里面有“仁”剂，所以可以润燥，主行淤血，消心下坚硬，治血瘀血闭血积血痢，蓄血发狂，我们的蓄血发狂很多人认为内伤，常见的就是踢到阴部，用功夫或者打拳打到踢到阴部以后，血排不出来小便排不出来，这种人真的是会发狂这种现象。

月经不通它可以通月经，所以这个【别录】呢：止咳逆上气，象在《千金方》里面，孙思邈出一个方子，叫千金苇茎汤，里面就有桃仁，久咳，肺里面的热，吐的黄痰，我们用苇茎、冬瓜仁和丹皮、桃仁，活血化瘀，所以它对咳嗽，肺里面有痰可以使用。

刘元素说，血结血利血燥，因为淤血造成的秘结，统统可以使用，那淤血造成的秘结，大便是黑的，你冲到那个马桶里面一冲的时候，便可以看到血，可以看到血的颜色。

那【孟宪】呢：杀三虫，用这个桃仁杀虫，晚上嚼一嚼，然后和蜜涂在脸上，这个女人，中国有些女人，现在是兰蔻，那个CD，倩碧，对不对，女人的化妆品那么多，女孩子还是爱美的，虽然没有还是爱美的，拿桃仁因为“仁”剂的可以敷脸，这个太阳晒太多，要保湿补水，都可以用。

那【唐容川】呢，他说桃花红认为苦，地火，因为红花，就像芍药一样，红的又叫地火之性，那说仁象心脏，正入心中，所以桃仁破血也能生血。

诸位记得，中医的观念里面就是，这个我们常常在补血，然后老是补血的话，南派温病用的四物汤很正常的补血，可是你越是补，有的人吃四物汤，一吃嘴巴也破裂了，嘴角也干裂了，晚上也变的很燥渴很焦躁，脉变的很数，嘴巴很燥渴，需要喝冰水，为什么同样吃四物汤，他不会有事他有事。

就代表他补不进去，所以如果说不了解如何补血，只知道开补血的药，而不知道如何把血补足，你没有办法治好贫血。

很多的贫血实际上是阳不入阴，怎么讲阳不入阴？比如说他身上有血，淤血堵到了，在这血管里面淤血，那阳气呢？真的血里面的阳，就是血里面的动能，这个阳之气也可以讲我们血里面的氧气，在血里面停有很多的氧，进不去因为有淤血堵到，这个时候你开活血化瘀的药，把淤血一去掉的时候，阳可以入阴，那血液循环就开始动，血就开始生产制造。

所以中医过去在治疗贫血的时候，你看肝藏血，脾统血，心生血，所以你要这三个脏器同时能顾虑到的话，就会把造血的功能恢复，那西医到现在贫血没办法，无治，没有办法治贫血，所以大概两个月给你打一个多种维他命，B12 注射一剂或者怎么样，然后看看红血球太低了打红血球，血红素太低了打点血红素，铁太少了给你输铁片，那你如果按照西医的做法，铁片吃完堵在肝脏里面，肝里面都是铁，吃完铁片以后第一个后遗症就是便秘，你不相信你吃吃看，吃铁不会补铁，西医认为补铁，你吃了铁剂还不如吃点那个叫什么菠菜啊，搞不好补起铁来比你那个更好，所以西医不晓得如何治贫血，象我们开一些活血化瘀的药，再开一些入肝，入心，入脾脏的药，血就会补起来，这个我在后面注解一点就是，一般临床医生没有注意到这一点。

如果说看这个小姐是你的情敌，那小姐那么漂亮，她月经痛，桃仁你多加一点，她就跟你说吃了这个你开的药，月经不痛了很好，可为什么痘痘那么多，脸上长满痘痘，所以年轻小姐不要吃太多桃仁，或者你用别的药取代。

这个用一钱就可以了，我们加其它别的药，活血化瘀的药很多嘛，桃仁只是其中一种，桃仁会上火，那女孩子会长痘痘，男人也会长痘痘，所以你看如果不顺眼加点桃仁下去就好了，很灵光的，因为我在临床多年，我稍微加减一下我就知道，很多年轻小姐来找我来治那个痘痘，那个痘痘很大，我就用火罐去吸呀，对不对，你不可能用嘴去吸啊，那么大恶心死了，拿火罐去吸，左面拿10个罐子右面拿10个罐子，每一个罐子里面的血有七分饱，整个粘稠稠的，青春痘大到那种程度，那你弄完后你开处方给她，我们开些白芷、黄连啊清热解毒的药，你要开个桃仁下去她长得更多，对不对？所以一定要知道。

以后会有青春痘小姐来找你看病，那你给你岳母千万不要吃太多我六十几岁还长痘痘，吃了你的药居然长痘痘长青春痘，错就是桃仁，我每次桃仁一拿掉痘子就没了，一加进去痘子就来了，所以我心里很清楚。

肠痈的时候里面有淤血，我们要活血化淤，会用到桃仁，肠子破裂了里面有出血，那桃仁里面有仁剂，可以润肠同时又可以把血攻出来，非常好用，那后面的生桃实吃多了头上生疮这个自已去看一下，这个到无所谓，至于说双仁有毒什么的这个倒不用太在乎，以前的禁忌，诸位真正在用处方药的时候不要受禁忌的影响，需要用就用，不要被禁岂绑到手脚。
