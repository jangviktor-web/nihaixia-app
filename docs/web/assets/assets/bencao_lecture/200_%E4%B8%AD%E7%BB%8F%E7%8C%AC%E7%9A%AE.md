# 中经·猬皮

**【本经原文】** 味苦，平，无毒。治五痔，阴蚀，下血赤白，五色血汁不止，阴肿痛引腰背。酒者杀之。生川谷、田野。

**【产地】** 山地多有之。

**【性味】** 味苦，性平。

**【主治】** 猬皮治五痔，泻血，阴肿痛及反胃，炙为末或烧灰服。

**【别录】** 疗腹痛疝积，烧灰酒服。

【毅明】治反胃吐食。

**【用量】** 一般一钱至三钱。

**【禁忌】** 禁生用。

231味，这猬皮就是刺猬皮，就是你看它那个身上的毛就是刺猬。

我们会用到刺猬皮最多的地方是用在痔疮。

那你说老师痔疮不是地榆吗？老师怎样治疗痔疮？那赤小豆去湿，地榆止血，刺猬呢来活血化瘀。

长痔疮的时候，里面瘘管会很多，刺猬可以到所有的地方去，用刺猬皮来收敛，赤小豆去湿，地榆止血，这样就会配合得很好。

治疗痔疮的手法很多，你看猬皮治五痔，我们在治疗痔疮的时候，你不要听分很多菊花痔啦，樱花痔呀分很多，你看针灸里面有四十九种痔疮的名称，你不要真正的去背，不要去背。

痔疮我们分内痔跟外痔就讲完了，名称不一样用药是一样，你不要管那么多名称，尽量减化。

刺猬皮呢止流血不止、痔中痛，如果配合针灸，那效果更快。

那如果是外痔，发起来的肿块硬在那边很痛，你用针刺放血，放血的时候他痛就消了很多，你再加些内服的药。

针灸针下孔最，承山。

把刺猬烤干磨成灰，跟着酒一起吃，不要生用哦，动物的皮生用不得了要把刺猬皮弄干净，把它刷洗干净烧烤以后再去弄。

刺猬皮一定要制过后用，不能生用。

刺猬皮治疗痔疮，我们最主要的主力是使用在痔疮，疝气，因为刺猬钻的力量非常的强，一定要制过用。
