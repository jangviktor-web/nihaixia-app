# 增补·鸡矢白

**【产地】** 处处有之。为鸡食砂岩后排出之大便中，色白者。

**【性味】** 味苦，性微寒，无毒。

**【主治】** 主行水消积，治鼓胀，疗转筋入腹，破石淋，利二便，下气破血，治伤寒寒热中风贼风风痹白虎风，贴风痛头痛，止遗溺，灭瘢痕，小儿客忤惊啼，解金银毒，酒服疗乳妒乳痈乳头破裂，外敷秃疮耳疮瘰疬。

【素问】治臌胀。

**【用量】** 普通一钱至三钱。

**【禁忌】** 酒服最佳。

第十一呢鸡矢白，这个鸡矢白呢方子在《黄帝内经》里面有介绍，就是我们讲鸡呢山鸡啊放山鸡，吃的那个砂岩石灰岩以后排出来的大便，颜色白的我们把它收起来，这个主行水消积专门治鼓胀，这个不是说拿起来就给他吃下去啊，不是，这个鸡矢白拿出来炮炙过炙过烤过烤过以后味道没有啦，跟酒撒酒上去混在一起吃下去才有效，不是光喝，这个呢它鸡矢白能解金银毒，酒服疗乳房的癌啊，乳房硬块啊，乳房化脓啊，乳头破裂啊，都可以使用这个鸡矢白，那解金银毒，我们如果说有金中毒或者银中毒这种东西，发生的时候五金的中毒，铜啊金银铜铁锡，你不要去记鸡矢白解金银毒那铜毒啊什么东西你不要，硫磺解五金毒，所以我们真的五金中毒的时候我们使用硫磺一律用硫磺，硫磺解毒一下统统清出来，这个是用硫磺来解金属的毒最好速度最快，所以有金属中毒的时候大家记得用石硫磺，不要忘了我们介绍本草经的时候前面有土硫磺，市面上有土硫磺跟石硫磺，土硫磺不入药不入内服的药啊，只入外敷的伤科才用的，【素问】呢你看22页，素问讲这个鸡矢白记录就是腹胀肚子胀，所以诸位现在学到了，一味药来治疗腹胀就是鸡矢白，那普通一钱到三钱酒服用酒来吞服最好。
