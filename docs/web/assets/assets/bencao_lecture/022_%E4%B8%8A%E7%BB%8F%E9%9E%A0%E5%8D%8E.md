# 上经·鞠华

**【本经原文】** 味苦平，主风，头眩肿痛，目欲脱泪出，皮肤死肌，恶风湿痹，久服利气血，轻身耐老延年，生川野及田野。今之菊花。

**【产地】** 处处有之，种类很多，黄白二种入药，味苦，家庭玩赏之菊不入药，今杭州出产多，

号称杭菊。

**【性味】** 味苦甘平无毒。

**【主治】** 菊花为清风热明目解毒要药，主诸风头眩肿痛，目痛翳膜，利血脉，治疔疮。

**【甄权】** 治头目风热，风眩倒地，脑骨疼痛，身上一切游风令消散，利血脉，调四肢。

**【大明】** 作枕明目，叶亦明目，生熟都可食。

**【元素】** 养目血，去翳膜。

**【容川】** 菊叶为治疮之要药，因其性散，能去肌肉中之风邪也。

【灵胎】平肝熄风。

**【用量】** 普通一钱至三钱。

**【禁忌】** 味苦辣者，陈久者，不堪用，其甘者亦名甘菊，可饮可食亦入药。

【吴克潜】近世用为平肝良药，头痛目疼多因肝经风热上乘所致，菊花入肝，兼行周身，血脉不利而死肌，得菊花之利血脉皆效，特长于解毒，外科方剂用之治疔毒发背者，沈金鳌曰菊花并茎叶打汁饮，外涂内服皆可。时医用之因防邪热过久而酝酿化毒；平淡多奇功。

【附加菊叶】菊叶解毒之功胜于花，以鲜者良，捣汁敷一切肿毒，亦可内服。

**【炮制】** 拣去杂质及梗叶，拍去灰尘即得。

第二十味药，叫菊花，鞠华，原文是鞠华，实际上就是菊花。

菊花和菊叶的功能非常多。

这个一般讲的是杭菊，杭州的菊花，杭州的菊花都很小，一颗颗的，黄色的白色的最好入药。

你不要菜市场买个很大大的菊花，老师我这个菊花最大的买这么大一朵，没用，那个只能观赏用，不能吃的。

小朵菊花，你看，菊花是这个样子的，杭菊，黄白，黄色白色，这个是石菖蒲，你可以传传去看。

菊花，常常到中药行去，他就用菊花来泡茶，菊花茶，就是这个杭菊。

叶子，菊花不是有叶子么，我们生用，我们咬咬碎，嘴巴咬咬碎，敷在伤口，脓疮和伤口都可以收敛伤口，可以解毒，那这个菊花很好用。

所以一般，因为这个是滋补润喉的药，所以一般，中药行都会用菊花来招待客人，你坐在那边等着包药的时候，他就给你个菊花茶。

那这个菊花味是苦平，苦味的药能够泻，能够燥，能够坚，你只要记得苦味出现了能够燥，能够坚，能够泻，苦味的药本身的药性就有这三个，焦燥的燥，能够坚能够泻。

这个产地，我刚才讲了，黄白杭菊。

**【性味】** 苦甘平无毒。

菊花主治，《神农本草经》里面主治是：清风热，明目解毒的要药。

任何的头痛、昏眩。

这个风也就是说，外感，一般，没有什么其他问题就是头痛，风寒吹到，吹冷气或者吹风吹太多都可以用到菊花，还有生眼翳，这种都可以用，因为菊花它本身苦平。

唐【容川】，他认为菊叶是疗疮的要药，能够疗皮肤生疮。

**【禁忌】** 的，一般来说菊花陈年太久了不好用，几乎大部分的中药越陈越好，陈皮，我们针灸的艾叶，孟子说，治三年之病，七年之艾，怎么的，都是越陈越好，中药是越陈越好，那个是，菊花并不是越陈越好。

等下我们要讲陈皮嘛，陈就是陈年，那个橘子的皮越陈越好。

现代我们一般的医生，【吴克潜】近世我们用为平肝良药，大部分是治疗肝病的时候常常会开些菊花，因为头，眼泪过多，头痛，风热肝经，风热上乘，因为菊花本身它入肝嘛，常常会加进菊花在里面，而且特长是解毒，这些功能大家可以看一下。

用到菊叶的话以新鲜的最好，如果在这边没有杭菊，杭菊实际上自己可以种植的，那你用新鲜的叶子，外用，把他揉碎，把它搅碎解毒直接涂到伤口上就可以了，但是要新鲜的。
