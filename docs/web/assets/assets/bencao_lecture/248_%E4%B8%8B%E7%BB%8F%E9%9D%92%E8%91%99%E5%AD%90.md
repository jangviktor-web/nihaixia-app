# 下经·青葙子

**【本经原文】** 味苦，微寒，无毒。治邪气，皮肤中热，风瘙身痒，杀三虫，子，名草决明，治唇口青，生平谷道旁。一名草蒿，一名萎蒿。

**【产地】** 产我国南方暖地田野，为草本植物，茎直立，叶作披针形，花作淡红色，茎叶皆入药，

名草决明，子名青葙子，别有一种名决明子，与此名似而物殊。

**【性味】** 味苦，性微寒，无毒。

**【主治】** 青葙子为眼科要药，主镇肝明目，治赤障青盲翳膜。

**【甄权】** 治肝脏热毒充眼，赤障青盲翳肿，恶疮疥疮。

**【大明】** 治五脏邪气，益脑髓，镇肝，明耳目，坚筋骨，去风寒湿痹。

**【用量】** 普通一钱至二、三钱。

**【禁忌】** 虚寒之人，火衰目病者不宜。

284，青葙子，它又名草决明，诸位读过，决明子就是草决明。

跟决明子很类似。

这个呢，味苦，性微寒。

诸位看看这个青葙子长这样子。

处方的时候也是两钱、三钱，都可以使用，这个青葙子是治疗眼科的，和决明子一样，眼科的药。

诸位，如果你说我什么都不要看，我就专门看眼科，你从这边开始往回头，把眼科的药物通通找出来分寒热，然后在放到柴胡汤，小柴胡汤里面，几乎眼科的病都治，很快，很简单，因为我讲过，你只要有经方做基础，基础方由经方做导使，把药物带到那个位置上，再加药进去就好了，这是最好的方子。

那，味苦，性微寒，无毒，他是正肝明目的，治疗赤障，青盲，眼翳膜，各类的翳膜都可以，因为他能把这个热度清掉，他是寒性的药，那个治肝脏热毒，肝开窍在眼睛，所以我们眼睛的问题，眼翳的问题，我们通通使用，在肝经上面来判断，决明子呢很好吃，你炒熟以后，麦一样，当茶喝，炒决明子是放在汤剂里面使用的，你平时泡炒决明子很难吃啊，决明子很好吃，决明子真的特像麦茶一样，在放点蔗糖更好。

今天介绍到这里，我们休息。

这个是青葙子，这个青葙子呢就是上次介绍的草决明，我们用那个石决明，是眼科的要药。
