# 中经·款冬花

**【本经原文】** 一名颗东。一名虎须。一名菟奚。味辛，温，无毒。治咳逆上气，善喘，喉痹，

诸惊痫，寒热邪气。生山谷及水傍，一名橐吾。

**【产地】** 产我国陕西山河西北诸地，为山野多年生草，庭园亦可栽植，百草中惟此不顾冰雪，

至冬即生芽而花，故名。

**【性味】** 味辛甘，性温，无毒。

**【主治】** 款冬花为润肺祛痰止嗽要药，主治咳逆上气，肺痿肺痈，寒热邪气。

**【别录】** 消渴，喘息呼吸。

**【甄权】** 疗肺气心促，急热劳咳，连连不绝，涕唾稠粘，肺痿肺痈吐脓血。

**【大明】** 润心肺，益五脏，除烦消痰，洗肝明目，及中风等疾。

**【用量】** 普通钱半至三钱。

**【禁忌】** 咳逆消渴喘急，皆火炎气逆之病，款冬隆冬独秀，辛散而润，甘缓而和，故虚实寒热皆可用，无禁忌。

**【容川】** 此药生于冬月冰雪之中，而花又在根下，乃坎中之阳象，故能引肺中阳气下行，而为利痰止咳之要药。

195叫做，款冬花。

当你处方的时候你写款冬花，写冬花，药房都看得懂。

冬花呢长这样子，质非常的轻，可以看看这个镇，止咳化痰的一个很重要的药，颜色带点粉红，很好看，在开处方的时候2 钱，因为它的质很轻嘛，你开两钱就很多了，冬花，那它的味道是辛甘。

辛味和甘味，辛甘为阳，阳性的药，能够化水，能够利水出来，【药性】是温性的药，【主治】呢，款冬花是润肺去痰，止嗽的重要的药，会（治）肺痿和肺痈。

因为它是温性的药，所以说你要治疗寒性的肺的问题最好。

比如说病人寒咳，躺下去，人就咳，那嘴巴也不口渴，常常喉咙里面有水的声音，肺里面的有积水的声音，都可以使用它。

**【甄权】** 呢，你看，肺的，肺气心促，咳嗽不绝啦，都可以使用。

那一般来说，因为它药性是温度的，并不是说很强的，很热的药，是中，平温的，并不是很热的药，所以【禁忌】里面说，一般来说冬花，款冬花为什么叫冬花，冬天的时候它开花。

它的药性是辛散，润，能够润燥，甘缓而和，所以有的时候你看到咳嗽，不清楚虚实寒热，你都用冬花都没有关系。

没有那么强烈的，说一定要寒证的才使用，热证也可以使用。

它没有什么大的禁忌。

【唐容川】，他说药生于冬月冰雪中，花又在根的下面，这花开不在上面，在下面的。是坎中阳，所以能引肺的气，阳气下行，是利痰止咳的药。引肺气下行的时候，前面还有个磁石。金石类的药里面呢，就是磁石，可以引肺气下行。所以我们治疗气喘，咳嗽，呼吸短气的时候，肾脏病，我们都可以使用磁石。那这里是植物性的药，花类的药，冬花很好用。那临证上面，处方里面，张仲景使用冬花，紫苑啊，经方里面会看到这味药。所以诸位要记得，引肺气下行的，能够止咳，又能够定喘，冬花非常好用。
