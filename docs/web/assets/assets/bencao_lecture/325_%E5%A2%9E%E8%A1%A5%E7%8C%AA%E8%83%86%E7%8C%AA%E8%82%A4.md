# 增补·猪胆、猪肤

**【产地】** 处处有之。

**【性味】** 猪胆汁味苦性寒，无毒。

**【主治】** 主清心明目，凉肝胆，治目赤目翳，小儿疳瘦，著名方剂有猪胆汁方。（用猪胆汁和醋少许，灌入谷道中，少顷大便出宿垢），治阳明热结于下，大便不通者。

**【用量】** 一次一枚。

**【禁忌】** 寒实者禁忌。 [猪肤煮米粉，治喉咙化脓长疮。]

第20是猪胆、猪肤，猪胆汁味苦性寒没有毒，主要主清心明目，凉肝胆，那老师那猪胆汁真拿起来喝啊，不是哦，张仲景猪胆汁不是拿起来喝。

你的胆汁已经很苦了，还找猪的胆汁来喝，我们知道那熊胆，南派的，拿去治疗肝病，那我治肝病从来不用熊胆，不用，不需用熊胆汁，那我们那个猪胆汁呢是润肠用的，有时候病人体很虚，汤剂攻不下去，他不能喝了，这个时候我们把那个胆汁啊，猪的胆汁，从灌肠从肛门那面灌进去，灌到大肠里面，大肠有那个胆汁来滋润的话，哇！大下，对不对，所以你不要那么笨，对着肛门，那大下的时候全部喷到你身上，很快的哦，老师那时没有针管你怎么去灌，中国以前用竹管、竹筒、竹子哦抽起来打进去，那现在有那个大的针管，你不要拿针头嘛，圆筒，你不要那么笨嘛，那个针头刺进去一定刺到大肠，你拿个圆筒嘛，比较把猪胆汁吸起来打进去，这时候你用猪胆汁，那你说老师甘油锭，那当然不要用。

猪胆，外用的，无所谓，那甘油不要用，我用蜜蜂，有没有，蜜煎导法，圆锥状塞到肛门里去，都可以哦，这是我们外用的通大便的。

象猪肤，我们用猪皮，拿来煮米粉，也是张仲景使用到的，喉咙痛啊，喉咙里头长疮啊，喉咙里头长阴实，化脓都可以使用。
