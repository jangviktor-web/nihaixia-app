# 中经·鹿茸

**【本经原文】** 味甘，温，无毒。治漏下，恶血，寒热，惊痫，益气，强志，生齿，不老。角，

温，无毒。治恶疮，痈肿，逐邪恶气，留血在阴中。

**【产地】** 鹿产山林中，处处有之，我国西北及东三省为多，其茸及角入药。

**【性味】** 味甘咸，性温，无毒。

**【主治】** 鹿茸为大补真阳要药，主养血益阳，强筋健骨，生精充髓，治男子虚劳，老人精衰，

腰膝无力，滑精，眩晕，妇人崩瘘带下。

**【别录】** 疗虚劳洒洒如疟，羸瘦，四肢酸痛，腰脊痛，小便数利，泄经溺血，破瘀血在腹，散石淋，痈肿，骨中热，举疽痒，安胎下气，杀鬼精物，久服耐老，不可近丈夫阴令萎。

**【日华】** 补男子腰肾虚冷，脚膝无力，夜梦鬼交，精溢自出，女人崩中瘘血，赤白带下，炙末空心酒服方寸匕，壮筋骨。

**【容川】** 其宿以头顾尾，能通督脉，督者肾脉，坎中一阳之主脉也，鹿生北方，得坎中一阳之气也，故其督脉极旺，而脊与脑髓极足，因而上发而生角，每年一换，初生为鹿茸，茸之精气极足，为补髓强精壮阳益血之圣药。但其性上行，凡是血逆火逆者不宜用。惟血虚火弱，阳不举，气不上者，乃为合宜。

【灵胎】补阳益血。

**【用量】** 普通七分至钱半。

**【禁忌】** 壮年慎用，阴虚火旺者忌之，麻勃为使，畏大黄，不可嗅，有虫恐入鼻颡，药不能治，

男子阴茎近入易于痿弱。

鹿胎—浑然元气所在，归下焦而不上行，为种子益肾补胞宫之要药。

这里拿片鹿茸你看看鹿茸长这个样子，这个鹿茸跟我们前面讲的117 白胶呢，那个是鹿角胶。

这里讲鹿茸，性味差不多，那鹿茸是大补真阳的药，能够生精充髓，味甘咸。

这一段呢，我把唐容川的原文写在这里，唐容川认为鹿睡觉是头尾相连的，所以通督脉。

据我判断他这里有点误解，羚羊生在大草原，羚羊角一圈圈，螺旋，直直的向上，睡觉时是头尾相连。

鹿角是叉开来的，生在山林，树枝比较多，它头伸进去睡觉，羚羊角两根直的没办法架在上面睡觉的。

最近你在青藏铁路上看那个藏羚羊，在高原上一大片都没有树的，蒙古大草原也没有树的，不管怎么样这个鹿角是补督脉的药，我们真正补督脉最强动物性的药就是鹿角，鹿角是补得最强的，补精。

如果以任脉来说的话是败龟板，败龟板最好，督脉来说的话是鹿茸。

所以老人精衰腰膝无力，我们用延年益寿，滋补的药这种药都很好。

那这类型的药补身体的时候跟多种维他命不一样，中医是以物像来补，比如你吃骨髓补骨髓，吃肝补肝，以物像来补绝对是有他的道理存在，你如果精炼过的多重维他命营养剂，那个是因为精炼过的体积会变得很小，你吃下去等于喂食这个癌症，喂食这个疾病。

天然的东西，像动物身上的鹿茸啊什么的，它的体积比较大，你吃下去同类，同气相求，所以它滋补到你的身体里面，而且不会滋补到坏的东西，那我们常常治疗脑瘤呀治疗督脉督阳不够，我们用鹿角啊，鹿茸，斑龙丸这种东西，我们下去把督脉补起来的时候，新的东西会进入脑部，脑部会把陈旧的东西推出来，加快新陈代谢，所以我们在候，阳不足需要补阳益血的时候，比如脑瘤啊，血癌啊，督脉有问题的时候都可以使用到鹿茸，像脊椎骨扭伤呀受伤，或MS，像脊椎骨变得S型的哦，就脊椎骨不直嘛，你知道变成S 型怎么来的？这个病本来是不存在的哦，就是打B肝疫苗造成的后遗症就是MS，督脉本来的直的嘛，现在扭曲变成S形，就是打B肝疫苗造成的，所以我一直很反对打疫苗，打了还照样得肝癌，还不是照死。
