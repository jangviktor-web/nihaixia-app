# 上经·车前子

**【本经原文】** 味甘寒，无毒，主气癃，止痛，利水道小便，除湿痹，久服轻身耐老。因喜在牛迹中生，故又名当道也。

**【产地】** 产泽野及路旁，处处有之，自地下生叶，从叶中抽茎，长数寸，多子。

**【性味】** 味甘，性寒，无毒。

**【主治】** 车前子为行水泄热要药，主利小便，通淋沥，清肺肝风热，渗膀胱湿热，强阴益精明目。

**【别录】** 男子伤中，女子淋沥不欲食，养肺，强阴益精，令人有子，明目疗赤痛。

**【甄权】** 去风毒，肝中风热，毒风冲眼，赤痛障翳，脑痛泪出，压丹石毒，去心胸烦热。

【灵胎】专利小便。

**【用量】** 普通钱半至三钱。

**【禁忌】** 内伤劳倦，阳气下陷者忌，肾气虚脱者忌与淡渗药同用。

【吴克潜】曰车前子能利水道而不走真气，与茯苓同功，治暑湿暴下，则泌别清浊，使小便利而泄泻自止，治五淋则渗泄湿热，使从小便下而淋自止，且以通为补，车前尤能强肾益精，如五子衍宗丸等。

**【附录】** 车前叶──凉血除热，止吐衄，消症瘕，与车前子同功。

第三十四，车前子。

**【主治】** ，车前子是行水泄热的要药，主利小便，通淋沥。

所以湿热症的时候我们会用到，病人有湿、热，湿热性的小便不利，我们可以用车前子，如果是病人本身是虚的人，车前子就不可以用了，了解。

它本身能够强阴，这个对眼睛也很好。

因为它是寒凉的药，所以里面有虚寒，虚寒的人，车前子不要用，比如说这个人你小便出来，他说我小便频尿，一天二三十次，每次小便都有刺痛，小便黄个颜色很黄，然后味道很重，车前子，车前子。

我小便一天二三十次，小便淡淡一点点，也不痛，小便淡白的，每次小完都感觉小便没有排尽的感觉，没有排完的感觉，这种膀胱没有利，里面是虚寒的，这个时候你用车前子是不对的，你说老师他小便不利车前子，你刚好用在你岳父身上，你就毁了，所以说我们以后一般要用在湿热上面，你为什么知道病人会有湿热，一看就晓得，听就晓得，应该不会错。

这个【徐灵胎】说，专利小便，所以要听清楚，不能不是小便不利就可以用的，一般是有热结在里面，有实热或湿热结在里面才用。

你看这个【吴克潜】，也是我们近代的经方家，他说任何你如果只要对症，小便不利，你把用车前子下去，把个湿热排掉以后，小便变利正常了，以通为补。

所以车前子也能够强肾、益精，所以我们南派的，这个五子衍宗丸这种一般的过去的医生制造出来的，当然可以用，没有关系，它因为子类的东西，我们讲过子类的东西通通能够补精。

子类我们覆盆子，菟丝子都能够补精，至于壮阳是另外一回事情，精不足的话我们可以用它来补精。
