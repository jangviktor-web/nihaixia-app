# 中经·瞿麦

**【本经原文】** 味苦，寒，无毒。治关格，诸癃结，小便不通。出刺，决痈肿，去翳，破胎堕子，

下闭血。一名巨句麦。

**【产地】** 为山野河边自生之宿根草，子黑色扁平，入药。

**【性味】** 味苦，性寒，无毒。

**【主治】** 瞿麦为利水破血要药，主五淋，治小便癃闭，月经不通，降心火，利小肠。

**【别录】** 养肾气，逐膀胱邪逆，止霍乱，长毛发。

**【大明】** 主五淋，月经不通，破血块排脓。

**【用量】** 普通一钱至三钱。

**【禁忌】** 瞿麦性猛利，善下逐，凡肾气虚，小肠无大热，胎前产后一切虚人患小水不利，及水肿鼓胀脾虚者均忌，能堕胎孕妇忌用，恶螵蛸，伏丹砂。

王执中曰五淋大抵皆属湿热，热淋用八正散（瞿麦萹蓄车前滑石甘草山栀仁木通大黄），血淋宜小蓟牛膝膏，肾虚淋宜补肾，不可独泻，老人气虚者。宜参术加木通山栀，亦有痰滞中焦作淋，宜行痰兼通利药，最忌发汗，汗之必便血。

第167 味，瞿麦，诸位看看这个，这东西呢，到处都有，山野河边生的草，草根我们来入药，还有籽也可以。

那这个呢是一个利尿利小便的药，也可以破胎堕胎用，主下胎。

诸位记得苦寒的药，苦主泻下，苦能够坚能够又主泻下。

它是寒性的药，所以说这个药呢，最终我们使用在利血利水。

我们主要使用在利水利尿剂，还有呢，活血化瘀的。

就是破血，你有血块在里面我们可以破血，破血的药。

因为它药性是寒的，所以说如果遇到热性的病，是对症的，诸位可以使用它。

比如说我小便痛，小便颜色赤红，已经讲完了他就是热嘛，我们就要用寒的药，这都可以用，那寒症的话药就不能用，比如说小便是淡白的也不痛，虚寒的人，你再用寒药的话他人会更虚。

所以一般这个瞿麦呢我们是只用在实症，虚症的时候我们都不用。

剂量1钱到3钱，看实际上状况需要使用多少，王执中后面最后一句话很重要。王执中他说，最后一句话他说所有这种最忌发汗汗之便血。

这讲的是什么，淋病。

我们所谓五淋，有石淋沙淋呀，这个淋病，小便有问题的时候，所有的热症，这个绝对忌讳发汗。

因为中医的观念呢，你发汗他的话小便就会带血。

中医的观念里面认为说，汗血是同源，来自相同的地方。

所以你要发汗的时候，如果发汗太多我们赶快要去止汗。

为什么，啊，血会虚掉，这个人会虚脱掉。

所以汗血是同源的，如果说，这个病人有热症，结果你用汗剂的时候，我们用麻黄桂枝，这种都是汗剂，吃下去就是说病人流汗流很多，汗一多的时候小便变得浓浊了嘛，更浓了以后小便里面的那个那个石头呀一些沙淋呀不容易排出来，这个因为血，水太浓了，太浓以后排出来以后它经过那个尿道的时候，那个沙淋石淋会把尿道划开来会划伤口，所以排出来血很多，所以一般淋病我们绝对忌汗，一汗的话小便就会出血，这是我们可以看到的，这个要重点要注意一下。

那诸位什么时候是使用瞿麦的时机呢，很简单，热症的淋病统统可以使用，这种是属于利尿剂，所以当你在分药的时候，啊老师这是利尿剂，这是破血的药，活血化瘀的药，同时可以利尿。

比如说有的时候这个病人呢膀胱有踢伤，有踢伤有瘀血，有的利尿剂呢它就是利水而已它不活血化瘀的哦，不破血，像这种同时可以利水同时又可以破血，破瘀血。

这个功能就跟其它像猪苓啊茯苓啊泽泻不太一样。

这样子什么时候使用大家就很清楚了。
