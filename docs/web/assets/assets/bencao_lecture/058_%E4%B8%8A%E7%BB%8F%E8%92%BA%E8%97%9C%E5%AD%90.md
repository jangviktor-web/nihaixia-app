# 上经·蒺藜子

**【本经原文】** 味苦温，主恶血，破症结积聚，喉痹乳难，久服长肌肉，明目轻身。又名刺疾藜。

**【产地】** 到处皆有。

**【性味】** 味苦性温。

**【别录】** 主身体风痿，头痛，咳逆伤肺，肺痿，止烦下气，小儿头疮，痈肿阴溃，可做磨粉。

**【大明】** 主身益精，疗水脏冷，小便多，止遗沥泄精，溺血肿痛。

【毅民】白疾藜治睛球凹陷，及睛生障翳，视物模糊。

**【容川】** 利湿，此以金行水也。

【时方】腰脊引痛——捣末为蜜丸，胡豆大，酒服二丸日三。年久失明——阴干捣散，食后水服方寸匕。（外台）第57味药蒺藜子。蒺藜子这个药呢？是眼科的要药，尤其呢蒺藜子里面有一种，是白蒺藜，白蒺藜打粉，老师，这个病人一个眼球都萎缩掉了，凹下去了，怎么办啊？蒺藜，蒺藜它能够金生水，金能够生水，那个眼珠里面本来就很多水在里面，金生水。用白色的最好，白色是金嘛，蒺藜有一种黑的和白的，那本身蒺藜味是苦，而且性是温的，一般来说，这个蒺藜很普遍，到处都有，那一般来说身体的这个风痒啊，肺家的病里面会用，还有眼科用。你看那个【毅民】，毅民就是崔毅民，也是一个经方家，那白蒺藜治睛球凹陷，睛生障翳，视物模糊。过去崔毅民是蛮有名的中医的眼科。那【唐容川】说，它能够利湿，为什么？此以金行水。那后面呢，诸位看，他说年久失明，现在时方，眼睛长年失明的，你把蒺藜阴干捣散吃，都可以。那我临床上面开处方的时候，诸位看，本经的原文：蒺藜之它恶血，破症，那个症结积聚，喉箅还有乳难。我在临床上的时候，乳房有硬块，还有哺乳，里面有硬块，那个奶水没有办法完全排完，还有呢，这个妇科的，子宫里面的肌瘤，都可以使用到蒺藜。而眼科的时候是蒺藜里面的白蒺藜，专门是治疗眼科的，这个药用的很多。
