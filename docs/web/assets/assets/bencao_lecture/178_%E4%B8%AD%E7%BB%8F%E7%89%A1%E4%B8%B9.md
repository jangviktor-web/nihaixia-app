# 中经·牡丹

**【本经原文】** 一名鼠姑。味辛，寒，无毒。治寒热，中风，瘛疭，痉，惊痫，邪气，除症坚，

瘀血留舍肠胃，安五脏，疗痈疮。生山谷，一名鹿韭，今名丹皮。

**【产地】** 牡丹处处皆有，庭院亦多种植之，花开美丽而大，为群花之王，色有红白紫等。其根部之皮入药。

**【性味】** 味辛苦，性微寒（或作性温），无毒。

**【主治】** 丹皮为理血要药，功能清伏火，凉血热，通月经，排瘀血。主治胎前产后，冷热气血之病，为女科良剂。

**【别录】** 除时气头痛客热，五劳劳气，腰痛，风噤癫疾。

**【甄权】** 治冷气，散诸痛，女子经脉不通，血沥腰痛。

**【大明】** 通关腠血脉，排脓，消扑损瘀血，续筋骨，除风痹，治胎下胞，产后一切冷热血气。

**【元素】** 治神智不足无汗之骨蒸，衄血吐血。

**【容川】** 其色味如红花，而根性主下达，与花不同，故主内及泄中下焦之血。气属阳，血属阴，

瘀血阻气，则阳不入阴，蒸热汗出，宜破其血，使气得入于血中，则不壅热，丹皮主之。气通则热不蒸，此为治热之变法也。色赤味苦，泻火，即能泻血。

【灵胎】疏肝气，通经脉。

**【用量】** 普通一钱至三钱。

**【禁忌】** 入血凉血能行血，凡女子血崩，及经血过期不尽，均忌与行血药同用。忌蒜及芫荽铁器。

196呢牡丹，我刚刚在跟诸位讲，花类的东西质很轻，所以你用2钱，1钱就很多了。

重症你用3钱，都可以，一般用2钱就够了。

牡丹皮呢，当然你写个丹皮也可以，一般我们就写丹皮，你要想表示文字很好，写牡丹皮也可以。

这个牡丹皮用得很凶，就是牡丹花的根，那牡丹花很漂亮啦，你去找个最漂亮的花，牡丹，最大一朵的花，他这个本经的原文，说，它能够治疗中风，能够除症坚，硬块，血块，瘀血，留在身体里面的瘀血，藏于身体中间的瘀血，都可以使用，那丹皮，非常多，到处都有，不是很难采集的药，这个牡丹皮呢，味是辛苦，辛辣，有一点辛辣，苦味的药，丹皮我们用得非常的广，十个里面有八个我们都在开丹皮。

那药性是微寒，一点点寒，【主治】呢，丹皮是理血的，反正有血症，我们都会使用丹皮。

它能够通月经，排瘀血。

所以常常女孩子，月经不順，月经痛，我们都会使用丹皮，你现在知道了，老师，一个丹皮，活血化淤，一个白芍，能够止女孩子的腹痛，对啊，这个都是妇科的药。

杜仲，当归，川芎，都是。

**【大明】** ，它能治胎下胞，产后一切，就有时候那个生完小孩后紫河车，胎盘排不出来，都可以使用丹皮。

【刘元素】那边他说神智不足无汗的骨蒸，那个不是山谷的谷哦，我们要更正，是骨头的骨。骨里面发热。一般来说，虚，久病必有淤。

【唐容川】呢，他认为，久病之人哪，必有淤。所以说他会出血症论就是活血化淤，这是他的法则。那一般，我们治疗癌症，治疗硬块肿瘤的时候，就是活血化淤，讲穿了就是活血化淤。你光是活血化淤没有用哦，它只是一个部分。一般伤科里面淤血我们可以治疗。你要把阴，就是要用热药下去，把阴实的门打开来，然后才有办法把病去除掉。但是你如果说，把那个热的药下去啊，把实，堵塞得到的硬块，同时加入活血化淤的药，就是我们很好的，治癌的妙药。那丹皮呢，是活血化淤的理血的药剂。唐容川呢，你看，他说，其色味如红花，它颜色看起来象红花一样，而根，本生的任何的根，根的性都是往下走的，都是主下达。所以你要用植物的根的时候都是往下走的。花都是往上走的，所以我们鼻子，病很多是用取花的。淤血，气，阻气都在腹部，那这种阳不入阴，因为正常的人呢，阳要在阴里面，这个脏才会有功能，才会有活动。乳房，那个子宫哦，你说奶水要排出来，奶水是阴，可是如果你没有阳的话，奶水没有动能，排不出来的，所以阳就是动能，阳要进入阴阴才能够活动。如果说你里面淤血阻到的时候，这个有淤血在里面，阳气就没有办法入阴，阴就会堵塞在里面。所以说，这个我们会用到丹皮来活血化淤，把这个淤血一排掉以后，阴阳气就顺畅了。那这个【徐灵胎】呢，说丹皮可以舒肝气。我在治肝病的时候，用丹皮，川芎，白芍，用得很多，非常的多。当然象我们前面讲的白鲜皮，那急性黄疸的时候，急性肝炎的时候可以用。你慢性的时候用，效果并不是很好。急性，本来是这一分钟都没有发黄，下一分钟，瞬间突然发的鲜黄，用白鲜皮很好。

**【禁忌】** ，你看，丹皮呢，因为它入血，凉血，它能够行血，所以凡是女子血崩，

已经在出血了，月经过期一直没有停，本来应该上个礼拜就停的，结果月经到现在滴滴答答还在来，还在出血，这个时候呢，你不能和排血，行血的药一起吃，吃下去的话，越吃呢，血量就越多，在失血的时候，辛辣的东西不能吃，最后一个是一个重点。

蒜啦，辛辣的，不要，你病人现在出血，刚失完血，现在伤口正在收口，你说医生啊，什么东西我不能吃？你跟他说辛辣的不要吃。

辛辣的主发散，你越吃血就流得越多，就不要吃辛辣的东西。

因为辛味的主散，发散。

当然啦，是你的敌人，你给他多吃点大蒜辣椒，让他一直出血，就不会好，这个就是丹皮，丹皮长这样子，非常普遍的药，我一直在讲，我用得非常的多，牡丹皮。
