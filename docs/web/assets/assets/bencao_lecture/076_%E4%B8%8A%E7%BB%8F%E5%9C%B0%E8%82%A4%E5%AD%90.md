# 上经·地肤子

**【本经原文】** 味苦寒，主膀胱热，利小便，补中益精气，久服耳聪目明，轻身耐老。

**【产地】** 生田野间，处处有之，子落则老茎可以为少帚，故又名落帚。（西充叫铁扫把）

**【性味】** 味苦性寒。无毒。

**【主治】** 地肤子为利小便要药，主膀胱热，通利五淋，强阴益精，治下焦虚而有热良。

**【别录】** 主皮肤中热气，使人润泽，散恶疮疝瘕，强阴。

**【甄权】** 治阴卵颓疾；去风热，可做汤沐浴，与阳起石同服，主丈夫阴痿不起，补气益力。

**【日华】** 治客热丹肿。

**【用量】** 普通一钱至二三钱。

**【禁忌】** 老人小便短而频数，是膀胱气化不足，小肠火偏弱也，法当补小肠火；如乌药艾叶，

不可独用地肤子。

**【附录】** 地肤子煎——煎水洗目，去热暗雀盲涩痛，煎水服利小便诸淋，解恶疮。

第75味药，地肤子，它又名叫做落帚，就我们扫帚啊，扫把，他那个枝掉光了以后啊，老的茎我们可以收集起来做成扫把，可以扫地用，这个味道是苦寒的，苦寒的药，它味是苦寒，那寒呢能够去热，比如说小便发炎哪，小便刺痛哪，都可以用，苦味呢能够泻，所以说它是非常好…膀胱…比如说小便刺痛哦，都可以用哦。

那是利小便的药，但是这个利小便一定是炎症，膀胱里边发炎刺痛了，有尿道炎哪，我们使用的，膀胱结石啊，也可以使用。

那个甄权呢，如果说，你如果阴囊，睾丸呢有比较肿大，就可以用这个地肤子，也可以做汤来洗也可以内服，和阳起石同用，用来治，专门治疗阳痿。

象那个禁忌，是我给他补进去的。

那有的老年人频尿，你不要给他吃这个地肤子，因为地肤子本身寒凉的嘛，一吃这个频尿越频，那小肠火偏弱，老人呢这个频尿是因为里寒，这个时候像我们常常用到乌药、艾叶，艾草的艾叶哦都可以，去里寒小肠的寒，这个时候你不要用地肤子。

那地肤子呢可以煮汤水，我们有好几位中药可以煮汤水来洗眼睛，专门治疗眼科的发炎，这个很好，效果很好。
