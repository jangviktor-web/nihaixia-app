# 上经·飞廉

**【本经原文】** 味苦平，主骨节热，胫重酸疼，久服令人身轻。

**【产地】** 陶弘景曰处处有之，极似苦芙，叶多缺刻，叶下茎多有皮起。

**【性味】** 飞廉根及花味苦，性平。

**【主治】** 飞廉花根为去风湿止痛活血药，能下乳汁及杀虫。

**【别录】** 头眩顶重，皮间邪气，如蜂螫针剌，鱼子细起，热疮，痈疽，痔，湿痹，止风邪咳嗽，

下乳汁，可煮、可干用。

**【苏敬】** 主留血，疗疳蚀，杀虫。

【萧炳】小儿疳痢，为散水服，大效。

**【用量】** 普通一钱至三钱。

**【禁忌】** 里有寒，又兼下痢者禁用。

第70味药，飞廉。

那这种药呢，张仲景都没有用过，我们呢，不是说他不用是不好，现在也很少人去用这些东西，一般来说，飞廉的外皮呢，我们使用在这个皮肤上的问题，哦，被蜜蜂咬到了哦，很多的地方可以利用飞廉，这种地方这个药很多，很便宜的，能够主治的是能够去风湿止痛，下乳汁及杀虫啊，最主要是被蜜蜂咬的，皮肤的咬伤，那任何的药，大家只要记得，当你做外敷的时候，外用的时候，一个是你可以用新鲜的汁，比如说你用新鲜药材用汁挤出来，那个汁，就好像生姜有汁在里面，还有呢，你把它烘焙，烘干后打粉备用，都可以用，那这个药，我本人用得不多。
