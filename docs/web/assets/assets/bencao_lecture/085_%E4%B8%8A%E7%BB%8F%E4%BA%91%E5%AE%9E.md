# 上经·云实

**【本经原文】** 味辛温，主泄利，肠澼，杀虫蛊毒，去邪恶结气，止痛除热，主见鬼精物，多食令人狂走，久服轻身通神明。

**【产地】** 处处有之。

**【性味】** 味辛微苦，性温。

**【主治】** 云实为止泻，截疟，杀虫要药。

【苏颂】治疟多用。

**【用量】** 普通一钱至三钱。

**【禁忌】** 寒利者禁忌。

第84味药，云实。

中药里面呢，我们有几种，这个药专门治疗疟疾的。

一个是常山苗，我们称为蜀漆，常山。

一个是云实，这种都是治疟，疟疾，往来寒热下利这种。

这种天行时，就是瘟疫，长江黄河以前沿岸一带，过去二次大战的时候在大陆上开战的时候，他们用奎宁来治，实际上真正，他们后来看到中医用常山，用这个云实，他们去拿去化验的时候发现它治疟的效果，里面它的药效比那个奎宁大100 倍，所以中医还是厉害的。

那这个常山我们后面会介绍。

这个云实呢，肠病就是下利，下利不止，杀虫杀毒，就是肠瘟疫嘛，杀里面的瘟疫，下利不止，那这个味辛有一点苦味，性温，那是止利、下利不止非常好用的药，杀虫，肚子里面有虫哦，都可以用。

那一般来说你只要看到病人是疟疾，往来寒热，下利不止，呕涨吐下泻，吃什么都吐，然后拉肚子，拉的人都虚掉了，很多人腹泻，这个会死掉很多人，像秘鲁，国家死的，很多人死在腹泻上面，就这个拉肚子，拉拉肚子死掉真的很难听，实际可以不死的，但他们不会治嘛，实际上像我们的常山、云实，我们有很多的药，真的中药到后来，我们用药治疟，不管他是不是疟，我们都按照症来辨的，如果没有好我们利小便，这个都可以把利止掉，这是云实。

所以大家只要以后看到这个药，看到这个疟疾呀，肚子里面长虫哦，寄生虫，都可以用。
