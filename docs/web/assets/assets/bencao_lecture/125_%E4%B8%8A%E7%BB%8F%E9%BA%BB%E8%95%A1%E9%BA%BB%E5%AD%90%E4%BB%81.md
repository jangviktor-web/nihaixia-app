# 上经·麻蕡（麻子仁）

**【本经原文】** 味辛平，主五劳七伤，利五脏，下血寒气，多食令人见鬼狂走，久服通神明轻身。

今名麻勃（花粉)，火麻仁（果仁）。

**【产地】** 大麻处处有之，种者尤多，生圆形坚果，中含扁平之仁，即为麻子仁，入药，其花粉即麻勃。

**【性味】** 麻仁味甘，性平。麻勃味辛，性温。

**【主治】** 麻仁为滑润，行血，除风，强壮药，治大便燥，乳汁少，热淋经闭。麻勃为除风，通经，健脑药。

**【别录】** 麻仁治中风汗出，逐水气，利小便，破积血，复血脉，乳妇产后余疾，沐发长润。

**【开宝】** 主补虚劳，润五脏，疏风气，治大肠风热结涩，利大小便。

【孟铣】取汁煮粥去五脏风，润肺，治关节不通，发落，产后余疾。

**【士良】** 主润五脏，利大肠风热燥结及热淋。

**【日华】** 补虚劳，逐一切风气；长肌肉，益毛发，通乳汁，止消渴，催生难产。

**【用量】** 普通钱半至三钱。

**【禁忌】** 大便溏者禁忌麻仁，患疔肿者忌麻勃，见之致死，用胡麻针砂烛尽为末，醋合敷之，

可解。

麻勃药性——主一百二十种恶风，黑色遍身苦痒，逐诸风恶血，治女人经侯不通。

【附方】产后秘塞——老人虚秘，麻仁，紫苏子等分，淘净研细，再以水研滤取汁，煮粥饮之。（本事）月经不通——二三月或半年者，麻仁，桃仁等分，研匀，老酒浸一宿后，日饮一升．（普济）发落不生——麻仁研汁煮粥频食之。（圣济总录）大风癞疾——大麻浸酒，研取白汁，滤去渣，纳瓶中，煮数沸，每饮一杯。（圣惠）健忘——麻勃一升，人参二两，为末，蒸令气遍，每卧服一刀圭。（范汪）

**【容川】** 麻仁油滑，而无辛烈之性，故但能润降，不能速下。

一三七，这叫做麻蕡。

原文呢是麻蕡，实际上就是麻子仁。

这个字念蕡（fen）。

就是我们现在使用的麻子仁。

诸位只要看到有仁，都代表会有油脂，都是能够利尿利大便的，都是吃多了会下利。

柏子仁、杏仁，只要有仁的都有，都会利大便。

这个麻子仁呢，辛辣，味辛平，有甘饴的味道在里面，可以久吃，长期吃没有关系，象女人有习惯性的便秘，你可以吃这个麻仁。

主治呢滑润，行血除风，强壮药，大便很干燥呢都可以治疗。

那麻子仁呢平常不用开太多，一钱半，有时便秘很严重可以开到三钱，大便就排出来了。

吃了这个麻子仁一般都会下利，你吃了大便没有排出来的话，就很重，因为麻子仁它会产生油脂在肠子里面，润肠的功能很好，都能下。

那西洋人呢，只知道用蓖麻子，就是我刚刚讲的蓖麻子油来通大便，他不知道我们中药麻子仁，柏子仁，酸枣仁很多仁都可以通大便，个个的功能都不一样，象以后会介绍经方里面脾约麻仁丸，专门用麻子仁治疗脾约，什么叫脾约我们这里不讲，讲到经方，讲到伤寒的时候再谈。

那这个麻子仁呢，你看看【士良】，它能润五脏，利大肠风热燥结及热淋。

所以除了你便秘大肠太干燥我们用麻子仁下去滋润它以外，小便刺痛，红赤，颜色很深都可以使用麻仁。

那禁忌呢，它本来就有通利大便的功能，大便已经在泻的就不要用麻仁了。

这个诸位看后面的【附方】：发落不生，麻仁研汁煮粥也可以让头发再生，所以我们要长头发的药很多，诸位可以参酌的使用，一般有效的我会把它收录在我们的本草经里面。

象你看产后的秘塞大便，老人啊，我们麻子仁和大黄，我们攻坚的时候有大黄，当然我们还没有介绍到我们暂时不讲，因为治病的时候要用大黄。

你平常的时候，老年人的虚秘，人是因为虚排不出来的，你用大黄下去人更虚啊，太强了，你用麻仁下点下去，滋润它让他出来，他大便排出来人也不会虚，所以麻子仁是功能清润，能够润肠的的药，能够通大便的药，但把它放到本草的上经，意思就是你平常也可以吃的，就算你下利也不会虚到什么程度。

那大黄、芒硝是很凶的，不要乱来，要把它放到别的经。

所以有他的目的，老人平常的，年龄大的都可以使用。

记得，每天一定要有大便，我们一天24个小时是一个大周天，子丑寅卯，辰巳午未，申酉戌亥，12个时辰是一个大周天，所以你循环过来的时候，到了早晨5 点到7点的时候大肠的卯时，大肠开卯时一定要去上厕所，吃下去的东西24小时要排掉，排不出来呆在身体里面超过24小时以后它就开始产生变化了，所以这个时候你就要小心了。

如果你没有大便，我们要想尽办法在你还没有生其他病的时候赶快让你通大便，不要等他，老师我便秘十天了你才讲话，两天三天就要讲了嘛，十天两个礼拜不出来才讲，那要赶快讲。

小病，便秘都要讲，免得以后发生很多问题。

唐容川在讲到麻仁，他说，油滑，而无辛烈之性，所以他能够润降，滋润，它能慢慢出来，才不会速下。

我们有的时候需要速下，比如这个人两个礼拜不大便吓死了，赶快要把它清出来，那有的人呢还是没有commonsense，你有的时候问她，21岁22岁的小姐，你大便好不好？大便很好啊。

你怎么个好？一个礼拜一次，她问我很好啊，一个礼拜一次很爽啊，不要常常上厕所多难过啊，这种笨蛋也有，这是白目中的白目啊，怎么讲呢，她还认为她正常，居然还认为她正常，这个所以你们要问人家，她跟你说正常，你要问清楚你的正常是什么意思啊，每天一次不是一个礼拜一次，所以临床的时候一定要小心，人家跟你说正常，没有讲完，还没讲完，这要特别特别注意。
