# 中经·石龙子

**【本经原文】** 味咸，寒，有小毒。治五癃，邪结气，破石淋，下血，利小便水道。生川谷及山石间。一名蜥蜴。

**【产地】** 今之蜥蜴。处处有之

**【性味】** 味咸性寒，有小毒。

**【主治】** 有利尿通淋下血之效，妊妇不得服用。

**【别录】** 主治五癃结气，利小便水道，破石淋，下血。

**【用量】** 一般一条至两条，烧灰研粉酒服。

**【禁忌】** 有寒利者禁忌。

242石龙子就是我们的蜥蜴。

味是咸的，寒的，有小毒。

专门治五癃，小便不通。

蜥蜴味咸性寒。

咸味的，它也是寒凉的，讲白话寒的药，药性是寒的是消炎的啦，所以一个人说小便不通，刺痛，滴滴沥沥黄加很红加刺痛这是热症，脸是红的脉是瘦的这是热症，用寒药，消炎嘛。

同样一个老先生跑来，脸色苍白没有力气，小便滴滴答答他是摄护腺肥大，里面是虚寒的，这个时候你不要给他吃石龙子，越吃小便越不出来，因为它是寒凉的药，这要大热的药下去才行。

所以寒热要分的清楚。有的时候小便不出来不单单是膀胱结石啊，有的是踢足球不小心被踢到，踢到那边。

很痛。

过去中医有桃核承气汤可以使用，抵挡汤。

这个石龙子也可以下血，膀胱被踢到阴部里面有出血，淤血堵到啦小便不出来。

小便不出来很痛苦的，这时候吃什么都吃下去，你相信我哦，你一天不小便，我告诉你这个可以利小便出来，保证你要吃下去，只要利小便出来就好了。

这个时候很痛苦的，小便排不出来很危险。

石龙子蜥蜴很小，你不要抓那个马来西亚很大的蜥蜴，那个那个比鳄鱼还大，你说“老师那个最好”。

很小一只，药房里就有的卖，拿出来壁虎一样小小一只。

有利尿通淋下血的功能。

孕妇不要吃，因为它性很寒。

孕妇在怀孕中间的时候和怀孕之前，我们要让容易怀孕的时候我们都要让她热。

子宫太冷不容易受孕。

反过来说寒凉的药是可以避孕的，热性的药是可以助孕的。

这样分开来就可以了。

当然我们避孕的效果绝对不如西医，我讲过你要找什么东西毁坏，西医最厉害。

要找什么建立，一定要找中医。

毁坏你要找西医，他们一级棒，他毁坏他还不承认。

就好像小孩子玻璃打破了，杯子打破了他还不承认。

你说小孩坏不坏？我都看到了还不承认。

很坏哦。

它能通淋下血。

那一般来说你开处方一条两条，不会说一钱两钱。

哪有一条长的刚好一钱。

一条两条。

一般来说做成灰。

这是石龙子。
