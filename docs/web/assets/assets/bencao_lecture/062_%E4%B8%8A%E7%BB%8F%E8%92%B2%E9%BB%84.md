# 上经·蒲黄

**【本经原文】** 味甘平，主心腹膀胱寒热，利小便，止血消瘀血，久服轻身，益气力延年神仙。

**【产地】** 香蒲为生于池沼之宿根草，处处有之，蒲黄乃蒲花之花粉，入药。

**【性味】** 味甘辛，性平，无毒。

**【主治】** 蒲黄为凉血活血散结除热要药，生用消瘀通经，疗扑打损伤，炒黑用止血止崩，止带止遗。

**【甄权】** 治痢血鼻衄，吐血，尿血，泻血，利水道，通经络，止女子崩中。

**【大明】** 妇人带下，月侯不匀，血气心腹痛，妊妇下血，坠眙，血运，血症，儿枕气痛，颠扑血闷，排脓，疮疖，游风肿毒，下乳汁，止泄精。

**【用量】** 普通七分至二钱。

**【禁忌】** 一切劳伤发热，阴虚内热，无瘀血者忌。

蒲黄配合五灵脂，治产后腹痛，产后血晕，不省人事，亦治妇人痛经，单用炒黑，止一切血均效。

第六十一味，蒲黄。

这个防风诸位看一下，切片以后，长这样子。

这个蒲黄呢，你们可以传阅一下，这个蒲黄我们内外都用，内科外科都在用。

蒲黄本来呢我们用的是蒲黄花的花粉，花粉，你拿到那个就是花粉，来入药，那一般来说，我们有生用跟炒过的，你看主治，蒲黄呢味道是味甘，辛，有辛辣的味道，也有甘饴的味道，是活血化瘀的凉血活血除热，生用呢，消瘀通经，所以我们活血化瘀的药里面会用到蒲黄，那这个跌打损伤的，如果你炒过了，把这花粉炒黑了，可以用来止血，血崩，可以用外敷外涂也可以，内服也可以，两种都可以用。

那病人呢，这个尤其象我们常常看，《大明》上面说哦，妇人妇科的排脓啊，疮疖，游风肿毒，下乳汁，比如我们知道是乳癌的时候，我们放蒲黄粉下去，比如说一钱，它是花粉，一钱就很多了嘛，内服的，外面用蒲黄粉，用炒过的，黑的，炒熟以后外敷，我们外敷的药，炒熟最好，因为怕有些不干净的东西嘛，灰尘啊什么不干净的东西，你炒熟以后就没有关系，外敷，那止血的效果非常的好。

所以以前我们那个部队打战的时候，军人身上带点蒲黄粉，止血嘛，刀砍伤怎么样，撒上去，止血。
