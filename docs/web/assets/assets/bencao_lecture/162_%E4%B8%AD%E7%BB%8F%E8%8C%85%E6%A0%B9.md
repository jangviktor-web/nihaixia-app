# 中经·茅根

**【本经原文】** 味甘，寒，无毒。治劳伤、虚羸，补中益气，除瘀血、血闭、寒热，利小便。其苗，主下水。一名兰根。一名茹根。

**【产地】** 生于原野路傍之宿根草，产楚地，今处处皆有。

**【性味】** 味甘，性寒，无毒。

**【主治】** 白茅根为止血利尿要药，功能止吐血行瘀血，治消渴水肿，不伤胃气。

**【别录】** 下五淋，客热在肠胃，止渴，坚筋，妇人崩中。

**【大明】** 主妇人月经不匀，通血脉，淋沥。

**【用量】** 普通钱半至三钱。

**【禁忌】** 不宜遇铁。胃寒脾湿者忌之。

那后面呢，这味药也是很重要的，第一七八，白茅根，你也可以叫茅根，它也叫做白茅根。

这药在这边，诸位参考一下，就长这个样子，很像以前那个竹扫把，你不要把扫把剪了拿来给人家，白茅根。

它原名叫茅根，后来我们叫白茅根，因为它的颜色比较白嘛。

一般呢，白茅根是利尿剂，那利水，所以水肿的时候可以使用。

它除了利尿剂以外，最重要的还有止血的功能。

如果说有一个人，他是同时身体里面有出血，同时又兼有水肿，我们就可以想到用白茅根，因为它一个药是两种功能同时具备在身上。

比如说现在有一个人肝病，肝癌，西医很喜欢做栓塞。

千万不要栓塞，因为你一栓塞以后呢，等到我要把它拿掉，拿不出来啦，所以只有一次机会。

你一做栓塞以后造成身体里面会出血，淤血，血会逆流，这个我们来治，我们来动手的时候很麻烦，除了排水药，还要去那个淤血，有时候还要帮你止血，那病人要服用白茅根了。

那如果说你没有做栓塞，身体循环还是很好，我们只要活血化瘀，然后再一直清利你的大肠，保持你的肠胃系统很好，那你根本就不会水肿，你不要等到肚子很大再去弄，那比较慢，一开始我们就下手。

所以我一再跟病人说，不要去做栓塞，做完栓塞有几个人活到呢。

那西医很恶劣，做完栓塞以后，闯了祸他又不去擦屁股，等于说这个动作是一个治不好病的医生在前面，把病人的生路断绝了，这种动作，就是栓塞。

他没有机会了。

所以你哪天得了肝病，你不想活了，你去做栓塞，保证你活不了。

好，待会我们再继续讲这个白茅根，我们休息下。

OK，我们继续下来，这个茅根，就是现在所谓的白茅根，诸位看这个本经的原文，它说补中益气，能够除淤血，利小便，它的苗呢主下水，白茅根的苗能够利水，臌胀，身体上积水的话都可以使用白茅根。

味甘，甘味的药，是甘淡渗利的药，所以你看他后面讲主治了，它是止血利尿的主药，很重要的药，功能止血，治吐血，能够行淤血，有淤血堵到，都可以。

那专门治消渴，水肿我们可以考虑到白茅根，又不伤胃气，同时呢，妇人的月经，因为它能够行血嘛，能够活血化瘀。

在张仲景的经方里面，他治症的时候呢，他没有挑白茅根。

那这个白茅根，你可以在经方里面加白茅根下去，比如说，现在一个妇女，她肚子痛，那肚子痛的时候，她每次月经来的时候小腹鼓胀的很硬，月经走了以后肚子就消了，那你在活血化瘀的同时呢，鼓胀的很厉害，里面水又堵到，同时加些白茅根把肚子里的水一起利掉，就可以做加减使用。

它本身药性是稍微寒的，所以说，胃寒脾湿的不能用。

所谓胃寒的人呢，很简单，胃口很小，吃一点点，鸡蛋嘛，吃个半个，饭吃几口就饱了，这种就是胃寒，或者就不喜欢吃饭，这种都是胃寒。

寒症的时候如果你使用寒凉的药，就会寒上加寒。

但是到寒极的时候，到极限的时候又会转寒为热。
