# 上经·防风

**【本经原文】** 味甘温无毒，主大风头眩痛，恶风，风邪，目盲无所见，风行周身，骨节疼痹烦满，久服轻身。

**【产地】** 产蒙古及山西河南等地，根黄白色，入药。

**【性味】** 味甘辛，性温，无毒。

**【主治】** 防风为伤风头痛要药，功能散表发汗，主诸般风，周身痛，搜肝泻肺，散风胜湿。

**【别录】** 烦满胁痛，风头面去来，四肢挛急，字乳，金疮内痉。

**【大明】** 治三十六般风，男子一切劳劣，补中益神，风赤眼，止冷泪，及瘫痪，通利五脏关脉，

五劳七伤，羸损盗汗，心烦体重，能安神定志匀气脉。

**【元素】** 治上焦风邪，泻肺实，散头目中滞气，经络中留湿，主上部见血。

【吴克潜】防风善表散，故用以解毒，如砒毒，乌头毒。芫花毒，野菌毒，诸毒药，又防风本制黄耆（黄芪），黄耆得防风而功最大，治风邪久留不去，表虚自汗不止。徐之才曰得葱白行周身，得泽泻橐本疗风，得归芍阳起石禹余粮治妇人子脏风，元素曰治风去湿之仙药也。

**【容川】** 防风辛而味甘入肌，气香而温，故入脾。散肌肉之风寒。

【灵胎】专治风邪。

**【用量】** 普通一钱至三钱。

**【禁忌】** 似中风，产后血虚发痉，诸病血虚痉急，头痛不因风寒，溏泻不因寒湿，二便秘涩，

小儿慢惊，阴虚盗汗，阳虚自汗，均忌。

第六十味药，防风，防风在经方里面也是很有名的药，经方里面治疗风湿关节炎的时候，会用到防风，防风能够去风，它呢，味是辛甘，辛甘发散为阳药，它是主发散，所以四肢关节疼痛，辛甘发散，因为它同时兼具两味药，甘，两种味道，又有甜味又有辣味，两个混在一齐，辛甘能够发散，那风湿关节炎就是风湿堵在关节上面啊，散不了啊，气血过不去啊，产生疼痛，我们用防风，它都是没有毒的，大风头痛，恶风，风邪，眼睛看不到，风行全身，骨节烦疼，通通可以用，所以治头痛的必要的药，如果我们确定这个头痛是血，瘀血堵到头痛，瘀血不是看舌头吗，皮肤是比较粗，是瘀血。

那个风痛的话我们就会用到防风，头痛嘛，头痛用到防风。

它功能发表散寒，那《大明》呢，治疗三十六种不同的风，那这个风症一个标准的一个症状就是它游走性，不会固定在哪里。

整颗头都痛，有时在后面，它的痛常常变化，有时候整个头，有时候偏，有时候偏这边，有时候后脑勺，这是风痛，如果是一个地方痛，我就是痛那一点，都不动，就很危险了，恐怕是脑瘤或者是那个血管堵到了，那就是川芎。

防风也是解毒的药，因为防风呢散，它的功能善于散表，散，发散的东西，所以用于解毒，任何性发散的都可以解毒，所以像砒霜的毒，乌头的毒，芫花的毒，野菌的毒，吃那个香菇，跑到山区里面随便采，那香菇好漂亮哦，五颜六色又厚，采完煮了吃，结果吃完中毒，那怎么办？吃防风。

黄芪跟防风是两个互相制衡的药，黄芪呢，得到防风，力量更强，所以你如果说，老师这个防风不是去风，风都在表上面的，那黄芪是走表，能够散寒，散风寒，能够去水，如果防风和黄芪加在一齐，DOUBLE，有一个人跑来跟你说，哎呀我全身水肿，怎么全身肿成这样子哦，关节肌肉都痛，黄芪跟防风，它们放在一起，互相制衡，为什么会制衡？因为你光是一个黄芪，黄芪走表速度很快，那防风呢，配在里面的时候能够制衡，黄芪不要太快，所以陈年的老病，有时候痛了很久的，全身肌肉痛痛了很久，太久了病很深，你用黄芪，单味黄芪走得很快嘛，你用防风把它收一下，不要太快，病还没有出去，你就跑掉了。

那你说，老师，再加一点玉竹好不好，当然很好啦，玉竹不是去肌肉的痛吗？去里面肌肉的湿，所以方子就这样来的。
