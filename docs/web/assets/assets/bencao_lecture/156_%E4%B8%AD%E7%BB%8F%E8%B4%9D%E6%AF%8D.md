# 中经·贝母

**【本经原文】** 味辛，平，无毒。治伤寒烦热，淋沥邪气，疝瘕。喉痹，乳难，金疮，风痉。一名空草。

**【产地】** 产四川山西等地，为圆球形之根。色白入药，今浙江亦有之，称浙贝母，功用稍异。

**【性味】** 味辛苦，性平无毒。

**【主治】** 贝母为袪痰治咳要药，功能散结泄热，润肺清火，治烦热疮疡。

**【别录】** 疗腹中结实，心下满，洗洗恶恶，风目眩项直，咳嗽上气，止烦热渴，出汗。

**【大明】** 消痰润心肺。末和沙糖丸含之，止嗽，烧灰油调，传人畜恶疮，敛疮口。

**【容川】** 色白性平，利胸肺之痰气。

**【药征】** 主治胸膈郁结痰饮。

**【用量】** 普通钱半至三钱。

**【禁忌】** 寒湿痰食痰嗽，湿痰在胃，恶心欲吐，痰饮作寒热，脾胃湿痰作眩，及痰厥头痛，中恶呕吐，胃寒作泄，法宜用辛温燥热者，均忌贝母。

第172，这个是贝母，在介绍贝母之前呢，我先跟各位讲，贝母这个东西哦，当我们一直把它打成细粉，越打细粉，你用那个很细的目哦，就是滤网，你一直过滤，一直过滤，把那个纤维拿掉，变成很细的贝母粉，非常细的，那个时候你可以看到一点淡黄色，那个细到什么程度，丢到水里面就融化掉了，就是水飞嘛，丢到水里融化掉，所以如果一小罐，你可以，差不多30：1 的比例，贝母粉倒点在蒸馏水里面然后你摇晃以后，可以做点眼睛的药，因为他能够去热，去眼翳。

所以过去很多人用贝母，我们有很多点眼睛的药，贝母是其中一种，你看『大明』
