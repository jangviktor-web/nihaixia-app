# 下经·天雄

**【本经原文】** 味辛，温，有大毒。治大风，寒湿痹，历节痛，拘挛缓急，破积聚、邪气，金疮，

强筋骨，轻身，健行。生山谷。

**【产地】** 如乌头。

**【性味】** 味甘辛，性温热，有毒。

**【主治】** 天雄与附子之功用略同，惟一般对下元虚寒性机能衰退者及风痰症都多用天雄。

**【别录】** 疗头面风，去来疼痛，心腹结聚，关节重，不能步行，除骨间痛，长阴气，强心，令人勇武力作不倦。

**【用量】** 一般一钱至三钱

**【禁忌】** 热症之人忌用二百六十六，天雄，为什么叫天雄，因为吃了以后变得雄壮威武啊，就是很补的意思，很凶，天雄是长这样子，那你说老师，这天雄长得跟乌头和附子都很像喔，就是很像，是同一株的，这天雄我放这给你们看，你们不要偷吃掉，我话还没讲完，这天雄呢，前面最初的时候最小颗的乌头，那附着乌头生的就是大附子，就是我们的附子，天雄实际上就是附子五年以后采收，我们同一株，农民去种啊，第三年采收下来是大附子，四年采收的是乌头，第五年去采收的根茎那就是天雄。

它在土里面很久啊，很久以后它的性能就很强很凶，最毒的是乌头，其次才是天雄附子，那天雄呢我们中医过去是拿来做补剂是拿来治痨症使用。

有时这个痨，病人呢，这个痨字设计得很好，因为等你写完你也痨了，也很累，写这字很麻烦。

那痨症时候补不到啊，老师你看他是虚热，我开四物汤给她吃，她上火，我开四君子汤给她吃，她还上火，我开十全大补汤给她便秘，老吃六味地黄丸也不行，怎么吃都补不到，痨症它很讨厌，那就是痨，脉大为痨，血脉很大啊，那我们怎么去补？

经方的张仲景，天雄嘛，天雄这个药跟乌头附子是同一株，你看本经，《神农本草经》原文说，味辛，温，有大毒。

治大风，寒湿痹，历节痛，关节炎，拘挛啊，强筋骨，轻身，主治呢天雄跟附子功用略同，但一般对下元虚寒，大部分用天雄来补他的虚，如果你这个人阳没有问题，阳举没有问题的时候，诸位记得了，我们现在还没有进入《伤寒》《金匮》经方，你阳举没有问题的时候，你开一些滋阴的药补阴就可以了，不要去开壮阳的药，负负会得正，阳举没有问题你给他开壮阳的药，不要说给他开壮阳的药，你拿鹿茸鹿角往上一贴就倒阳了，我们使坏的方法很多，所以离我远一点比较好，不然晚上的时候你不知我做了什么喔。

如果阳举有问题的时候才去开补阳的药，壮阳的药，大家了解我意思吧。

所以说我们有很多壮阳的药，比如说巴戟天啦，肉苁蓉长得就那个样子对不对？

天雄，但是阳不举你用壮阳的药，阳举没有问题，你不要用壮阳的药，用滋阴的药，补精子的药，那就不会影响到阳，这是一些基本的原则。

那天雄呢阳已经不举了，你用天雄也举不起来你也不用举了，就完啦，意思就是草药类里面最强的，当然我们可以用金石类的药，老师金石类的药的硫磺很强，我们先不要用金石类的药，草药类里面最强的就是天雄，我刚刚讲过，名字是天天雄壮威武嘛。

你可以用天雄，那你说老师天雄有毒，当然是有毒啊，炮制的过程也是一样，我们的远志可以解乌头附子天雄的毒，哦远志。

所以说如果我们天雄做成粉剂，或者是做成丸剂，可以使用丸剂，中药很多我们做成丸剂的时候，会放蜂蜜在里面跟它和在一起，为什么用蜂蜜，除了让他粘着以外，蜂蜜可以解毒，所以说像乌头，我们有乌头蜜，那你不会煮菜的人，老师乌头直接煮了放水跟蜂蜜放在一起煮，那乌头怎能拿得出来？拿不出来了，所以先煮乌头了以后，把乌头取出来，只剩水，再去跟蜂蜜和在一起。

你如果不知道，就乌头煮成水，乌头还在里面，把蜂蜜倒进去，跟蜂蜜混在一起，糟糕，拿又拿不出来，那天雄也是这样子处理，也可以不处理没关系，因为天雄没有像乌头这么毒。

一般来说我们直接混合蜂蜜来做成药丸就可以了。

所以说你看，他这个别录呢说关节重，不能步行，骨头之间的痛都可以使用。
