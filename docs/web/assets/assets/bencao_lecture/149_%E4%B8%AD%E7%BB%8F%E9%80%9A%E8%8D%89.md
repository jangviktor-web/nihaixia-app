# 中经·通草

**【本经原文】** 味辛，平，无毒。主去恶虫，除脾胃寒热，通利九窍、血脉、关节，令人不忘。

一名附支。又名白通草。

**【产地】** 产于江南，多生山侧，茎入药。

**【性味】** 味甘淡，性平，无毒。

**【主治】** 通草为利水退热要药，主泄肺热利阴窍，舒胃气，除水肿，治五淋，下乳催生。

【东垣】主利阴窍，治五淋，除水肿癃，泻肺。

【苏颂】解诸毒，虫毒。

【汪机】明目退热，下乳催生。

**【用量】** 普通五分至一钱。

**【禁忌】** 虚脱之人与孕妇禁忌。

**【容川】** 白通草象人身之油膜，故能通达油膜，上可以通乳，下可以通小便。

164 味药，我们叫做通草，我们又有个名字叫白通草，因为拿出来一看的时候你以为是好像是保利绒，很像啊，保利龙啊，就是这个通草，在这他真的很像保利龙，很轻很轻，所以你在开通草的时候，你用五分，五分啊，你一钱的话已经一大票了，你一两的话，老板说我一包整包给你，一大袋。

不要开一两，五钱。

五分就够了，五分就很多了，因为他质很轻嘛。

你撒到空中掉落下来还有一段时间呐，那个质那么轻，那你怎么开那么重，诸位记得一斤棉花跟一斤铁的故事。

这个通草呢，味辛性平，也是列入《神农本草经》，我们在通乳，我在我临床上使用最多的时候，你看他的样子，白色的中间一个洞，所以我们在通乳的时候用的很多，一看那个女人的奶水还不出来，生完小孩说要断奶，喂了八个月十个月，一年哪，要断奶了，好，通草，下去，阳起石，我们有很多草可以把它通下来，炒麦芽，都可以把这个奶水通下来。

**【主治】** 通草是利水退热的要药，所以我们在排水的时候会是使用到，退热，因为他是性寒，味甘淡，甘淡的药呢，统统是渗利，甘淡的药一定能够渗利，所以说排水利湿的时候我们会用到，健脾排水利湿，腹水，积水，水肿都会使用到通草，除水肿，肺热，统统可以用它。

为什么去肺热，诸位记得，你看那个草，颜色是白的嘛，肺，入肺，只要是白色的统统入肺，解毒，虫毒呀，也可以使用。

唐容川，你看，我们的想法都是一样的。

唐容川呢，白通草象人身的油膜，故能通达油膜，上可以通乳，下可以通小便。

所以，白通草我用在通奶，乳房硬块的时候我们用的很多，因为我们的观念里面认为说你乳癌之前是乳房的硬块，乳房的硬块之前是陈旧的奶水累积，对不对，因为陈旧的奶水里面很多钙质，很多钙质你才会累积成硬块，像石头一样嘛，那个在乳腺里面塞住，然后变成奶粉一样，像石头一样很硬，以后越来越严重，那我们要把它通利出来，我们要开很多通利的药，只要能够入三焦淋巴系统的药，统统可以通乳，通奶，胸部的乳腺。

好像黄芪，硫磺，当然可以啊，白通，有没有，那看你要多强嘛，看什么时候。
