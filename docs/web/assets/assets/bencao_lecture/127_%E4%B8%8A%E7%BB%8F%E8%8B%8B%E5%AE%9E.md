# 上经·苋实

**【本经原文】** 味甘寒，主青盲明目，除邪，利大小便，去寒，久服益气力，不饥，轻身。

一三九号，这个苋实。

苋实这个药现在很少使用它，也没有什么人使用苋实这个药，作为参考。

一四O、瓜蒂

**【本经原文】** 味苦寒，主大水。身面四肢浮肿，下水杀虫毒，咳逆上气及食诸果，病在胸腹中，

皆吐下之。即甜瓜之蒂也。

**【产地】** 处处有之，取甜瓜之苦蒂入药。

**【性味】** 味苦，性寒，无毒。

**【主治】** 上焦之实症，以吐取之，浊痰壅塞，全身水肿等实症。

【倪注】主治因上焦不通造成之全身性水肿，专治膈上之疾，中风浊痰不出，无法吞咽。仲景方之瓜蒂散。

**【药征】** 主治胸中有毒，欲吐而不吐也。

**【用量】** 普通一钱至二钱。

**【禁忌】** 凡虚弱之人禁忌之。吐后不止，可服半夏解之。

第一四○，瓜蒂。

瓜蒂就用的多了，我们这里没有瓜蒂，为什么，因为瓜蒂到处都有，你去菜场，买那个香瓜甜瓜，越甜的瓜那个瓜蒂越苦，你不相信你去尝尝看，就是要那个瓜蒂，平常的不要，瓜蒂是中医的吐剂。

病在上，我们要取吐，取吐的时候你灌肥皂粉很难过，瓜蒂，瓜蒂吃下去包你吐，味道苦寒，我告诉你说不要说苦寒，闻到那味道你就恶心，就想吐了。

所以要喝下去的话最好鼻子塞住，然后再喝。

那瓜蒂呢，主大水，身面四肢浮肿。

吐利，这个身面四肢浮肿大水是因为上焦有病，痰涎壅塞到以后，肺里面的水没有办法进入肾脏，肺是肾的母，肺在上面肾脏在下面，你这样子想，肺是翡翠水库（位于台北附近的水库），里面的水就是肺，那个流出来河流里的水就是肾脏。

当你水库里的水堵到的时候，比如说肺的下方痰涎很多堵在这边，这个水没办法下去啊，这个水就开始累积，肺主皮毛，哇全身就发起来了，病人就告诉你，咳，咳，痰咳不出来，然后非常的短气，病人的胸胁苦满非常的痛，这个时候你知道用吐法。

过去有个医生专门用吐法，管他什么病，伤寒，风寒，太阳，少阳，阳明，什么病都用吐法，也不好，那太过了啊。

我们确定你病在上焦，我们用吐的，吐的时候那瓜蒂散一下去那一吐，痰一吐掉那水通通跑出来，就好像，理论就好像你拿一个吸管，在杯子里面有水，你拿吸管吸住，然后你手按着吸管，水就在吸管里面，你把上面一打开水就排掉了，吐法原理就在这里。

我们在主治的上焦的实症以吐取之，我们有全身是水肿，实症，一定要实症。

所谓实症，你听就知道了，这个病人进来还没有看到你，还在外面诊所门口，你还没看到那个病人，就听他讲话很大声，医生在哪里啊？啊这一定是实症。

那个人进来安安静静没有声音，那是虚症啊。

实症嘛，你可以看到，听的到啊，根本还没看到病人，听就知道了，实症。

那这个呢，中风浊痰不出，我们有时候没办法吞咽，我们用吐的方法，瓜蒂下去的话不吐也要吐，他无法忍耐，他一定要吐啊。

你说老师，那个甜瓜蒂，我们有香瓜各种不同的瓜，没关系，那越苦越青绿的，越苦的你把它通通采起来，就是蒂那个头，瓜的头那边的那一节你把他采下来，把它搜集起来晒干了放在那边备用。

越苦越难吃。

后面的禁忌，吃了瓜蒂吐的不止，老师吃了太多不停止怎么办？用半夏，止吐啊。

平常你用一钱，一钱是多少呢你知道嘛，一钱，如果是粉的量，一钱啊，大概就是一个汤匙，拿一个汤匙起来，平常我们喝汤的汤匙，平匙差不多就是一钱，就有那么多啊，一钱。

那如果说你刚好发生在你岳母身上，那你给她吃两钱，那完了，不要混了，所以一钱就够了，那个子很大的，体格很大的用两钱嘛。
