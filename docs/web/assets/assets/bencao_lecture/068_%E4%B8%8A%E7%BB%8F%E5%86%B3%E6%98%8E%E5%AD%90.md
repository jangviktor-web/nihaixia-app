# 上经·决明子

**【本经原文】** 味咸平，主青盲目淫，肤赤白膜，眼赤痛泪出，久服益精光。

**【产地】** 山野自生之草本植物，产陕西山西一带，今处处可移植，与草决明为截然二种。（西充有，而草决明现多用于园艺。）

**【性味】** 味甘苦咸，性平。

**【主治】** 决明子为泻肝明目要药，能补肝虚泻肝经风热，主头风头痛，治一切眼病。

**【别录】** 疗唇口青。

**【甄权】** 治肝热，风泪赤眼，每旦取一匙洗净，空心吞之，百日后夜见物光。

**【日华】** 助肝气益精，以水调末涂肿毒，治太阳穴头痛，又贴胸心止鼻洪，作枕头治头风明目。

【灵胎】明目益精。

**【用量】** 普通一钱至三钱。

**【禁忌】** 恶麻仁，疗目疾外，其他用者鲜，惟外治可以疗蛇伤虫刺。

第67味药，决明子。

这个《神农本草经》是决明子，用途也是很广，我们除了入药以外，这个决明子你把它炒熟，泡茶喝，好像麦茶一样，所以如果眼睛不好的人，你可以炒决明子，炒熟以后呢泡茶一路从台南到台中开车这里来，泡着茶带在身边，一路喝着来，但小心要找厕所小便（众人笑），喝太多了嘛，因为它味道是甘苦咸，咸会有利水的功能，你炒决明子不要放盐巴了，炒完它有点咸味，淡淡的咸味很好喝，象喝麦茶一样，好像是麦的茶。

它主青盲，眼睛方面的问题，现在诸位读到，一个前面是蒺藜子，白蒺藜，眼球变缩小可以让它长大，决明子，也是一味药，可以久服。

那主治，决明子呢，是泻肝明目的要药，肝主眼睛，肝开窍在眼睛，所以眼睛的问题，我们眼科的问题我们会去治疗肝，那决明子就是清肝的，泻肝的，好让眼睛能够亮起来的药，效果很好，我们的明目地黄丸里面就有这个东西，平常你也可以用决明子炒呀，平常泡茶喝也就可以了，泡茶喝，所以如果说你在家里面，除了用茶招待客人，也可以用炒决明子来招待客人，炒好放在那边，也不会坏。

对视力的确是帮助很大。

徐灵胎呢，除了明目以外，可以益精，可以壮精子的，这个决明子外涂也可以，虫蛇咬伤啊，刺虫，刺伤呀，刺伤什么的，虫刺咬伤都可以。
