# 增补·木通

**【产地】** 木通古名通草，多自生山野，庭园亦可栽植，各省有之，茎入药。

**【性味】** 味辛苦（或作辛甘）性平，无毒。

**【主治】** 木通为导湿热，利小便要药，主降心火，清肺热，化津液，止大渴，治淋沥，水肿。

**【别录】** 疗脾疽常欲眠，心烦哕，出音声，治耳聋，散痈肿诸结不消，及金疮恶疮，鼠瘘踒折，

齆鼻息肉，堕胎。

**【甄权】** 治五淋，利小便，开关格，治人多唾，主水肿浮大。

【孟铣】利诸经脉寒热不通之气。

**【士良】** 理风热小便数急痛，小腹虚满，宜煎汤并葱饮有效。

**【大明】** 安心除烦，止渴退热，明耳目，治鼻塞。通小肠下水，破积聚血块，排脓，治疮疖，

止痛推生下胞，女人血闭，月候不匀，天行时疾，头痛目眩；羸劣，乳结，下乳。

【藏器】利大小便，令人心宽下气。

【李珣】主诸痿疮，喉痹咽痛，浓煎含咽。

【冬垣】通经利窍，导小肠火。

**【用量】** 普通七分至二钱。

**【禁忌】** 凡精滑不梦自遗，及阳虚气弱，内无湿热者忌，孕妇禁用。

第22木通。

诸位看这是郁金，这是木通。哦你看这木通象车轮一样，哦车轮一样，郁金和木通。

这个木通呢，过去我们称为通草，它的味道是辛苦性平，木通是导湿热，利小便的药，所以一般来说我们治水肿的时候，我们会使用到木通，木通，那腹水、肝硬化、积水的时候常常会这个木通也会用到，【别录】说专门治疗脾疽常欲眠，心烦哕，那小便不利是最主要的，【甄权】呢你看水肿浮大。

所以木通是利小便的药。

那张仲景呢也有使用到木通，这个【孟铣】呢他说利诸经脉寒热不通之气。

张仲景用做通脉当归四逆汤里面，当归四逆汤里面就是手脚冰冷，加木通的意思就是让它气能够通到所有的经脉上去，木通象车轮一样，所以它能够通关活络效果非常的好，【大明】呢它说安心除烦，止渴退热，最后它写乳结，下乳。

乳房呢奶水硬在那边，堵在那边出不来，乳房有硬块哦，出不来，我们可以用木通，来清它，木通也是很好使用的一个药，那一般来说的话，这个木通质很轻，诸位看它是质很轻的东西啊，一般开二钱，哦二钱都很多了，一钱两钱就够了。
