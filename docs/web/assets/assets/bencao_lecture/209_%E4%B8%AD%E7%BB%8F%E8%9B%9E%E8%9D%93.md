# 中经·蛞蝓

**【本经原文】** 味咸，寒，无毒。治贼风歪僻，轶筋及脱肛，惊痫，挛缩。生池泽及阴地、沙石、

垣下。一名陵蠡。

蛞蝓，你知道什么东西？已经找不到这个东西了。

就是鼻涕虫，下雨天的时候阴沟旁边跑出来，“老师这个的白白一条虫上面两个角，粘答答的，走墙上还可以看见白白的印子”，就是那个东西。

蛞蝓。

这个东西味道是咸的，那有没有吃过？我没有吃过。

没有毒。

治贼风，中风眼，头歪，眼斜，挛缩，睾丸缩起来。

那这种东西生在池泽阴湿的地方。

这种粘巴巴东西用的时候，记得哦一定要制过。

以前收药的，水蛭啊，虻虫啊，蛴螬啊这些药，采药的师傅带着个瓦片，弧形的，那个瓦片下面生火，抓来后在上面“哧”，这样烤一下，炙过，变成黄的。

烤干以后收到袋里面，不会来一条条收进去，回家以后再制啊，当场就制好了。

邙虫啊，抓水蛭的脚放在水里面，那个吸血的水蛭才有用啊，脚放在池塘里面，哇！一票吸上来，一条条抓下来制，然后收起来。

那牺牲一下，脚放下去。

有的采药师傅就拿猪腿，吸了再上来哦。

看你自己做选择，采药师傅啦。

那这个很恶心，这是蛞蝓，就是我们的鼻涕虫哦。

使用，诸位看看就可以了。

那蛞蝓这种东西你还是要知道，为什么？我就讲过，哪天你飞机失事掉到山里面怎么办？很难讲，哦。
