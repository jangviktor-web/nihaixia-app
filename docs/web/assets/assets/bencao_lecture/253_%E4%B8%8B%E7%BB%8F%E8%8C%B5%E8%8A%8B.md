# 下经·茵芋

**【本经原文】** 味苦，温，有毒。治五臓邪气，心腹寒热，羸瘦，如疟状，发作有时，诸关节风湿痹痛，生川谷。

289，这个茵芋，很少用。

二九〇、贯众

**【本经原文】** 一名贯节，一名贯渠，一名百头，一名虎卷，一名扁苻。味苦，微寒，有毒。治腹中邪热气，诸毒，杀三虫。生山谷。

**【产地】** 处处有之，多自生山中溪畔，或森林阴处，根黑褐色。

**【性味】** 味苦，性微寒，有小毒。

**【主治】** 贯众为解毒要药，功能治腹中邪热之毒，软坚破积，及妇科诸血症。

**【别录】** 去寸白[涤虫。]，破症瘕，除头风，止金疮。

【苏颂】为末水服一钱，止鼻血有效。

【灵胎】解毒杀虫。

**【用量】** 普通一钱至二钱。

**【禁忌】** 无。

29 贯众，这个就是贯众，诸位看，这贯众，长得好好看，很漂亮，它有黑的纹路，也很像牛肉干，跟大黄很像哦。

那这个贯众性味：味苦，微寒，一点点的寒，我们使用贯众的时候，就是，打蛔虫，打虫药，病人有肚子里面长虫，我们有很多的处方，贯众是一个很凶悍的一个处方。

那，食物上面，就是，流鼻血，很多，还有，肚子里面有虫。

你看小孩子的肚子这么大，那么圆，山野里面，在这个农村里面或者在山野，小孩子肚子很大很圆，这大部分都有虫在里面，有蛔虫在，那贯众是一个，还有很多，像《本草纲目》里面，像使君子哦，也可以使用，那我们经方呢，我们用乌梅啊，蜀椒啊这些配合，对不对，这些又辛又辣的药，然后贯众也是一种，也是其中会使用的药，你看他主治：解毒的要药，治腹中邪热，这个主要是讲蛔虫，软坚破积，并不是说里面是肿块，而是肚子太大了嘛，里面那个蛔虫太多，那中药，动物可以用哦，如果那狗，狗很多虫子哦，吐、吐、吐，有时会吐出来，大便都是虫，这时候贯众来给他吃了，骗狗说这是牛肉干，不晓得狗会不会上当。

比如说去寸白，寸白是绦虫。

那破症瘕，就是，那这个，一般来说，一钱两钱就够了，如果虫子比较多，三钱。

有虫子最明显的表征就是晚上睡觉的时候肛门会很痒，那个就是肚子里面有虫。
