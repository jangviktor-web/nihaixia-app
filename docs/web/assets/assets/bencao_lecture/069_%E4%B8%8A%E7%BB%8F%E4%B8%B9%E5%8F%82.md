# 上经·丹参

**【本经原文】** 味苦微寒，主心腹邪气，肠鸣幽幽如走水，寒热积聚，破症除瘕，止烦满益气。

**【产地】** 产陕西一带，今各处俱有之，叶对生，作心脏形，根紫赤色，入药。

**【性味】** 味苦性微寒，无毒。

**【主治】** 丹参为通经要药，功能活血调经，治心腹邪气，寒热积聚，宿血恶露。

**【别录】** 养血，去心腹痛疾，结气，腰脊强，脚痹，除风邪留热。

**【弘景】** 清酒饮，疗风痹，足软。

**【大明】** 养神定志，通利关脉，治冷热劳，骨结疼痛。四肢不遂，头痛赤眼，热温狂闷，破宿血，生新血，安生胎，落死胎，止崩带，调月经，血邪心烦，恶疮疥癣瘿赘，一切肿毒。

**【纲目】** 活血通心包络，治疝痛。

【灵胎】养血消瘀。

**【用量】** 普通二钱至三四钱，大剂一两。

**【禁忌】** 孕妇无故忌，畏咸水，反藜芦。

丹参为女子调经良药，故有一味丹参功兼四物之称，产后养血去瘀，能入心养血，故天王补心丹中用此味治劳心过度，神志不宁，烦热健忘，怔忡。又言丹参入心又曰赤参。

第68味药，丹参。

也是比较大的药，丹参，这个丹参呢，味苦，诸位只要记得，微寒的药，象我们平常比较热，通通可以吃，没关系，不一定说一定要生病的时候吃，丹参在过去呢，除了能够活血化瘀，还可以利水，补气，使气非常的顺，同时呢，能够让郁气能够散开来，那丹参在过去使用最多的，就是用在妇科上面。

我们中医有一句话，就是，丹参一味可以抵四物汤，四物汤丹参就可以抵了，又补又攻，又攻泻都在里面，这么多说法，意思就是说，丹参，用途很广，那【别录】

呢，说养血啊，去心腹的疾疼，诸位记得，我们中医的观念里面呢，认为，女人呢，上面是阳，所以女人的奶水排出来是白色的，下体呢，肚脐以下是阴，少腹里边是阴，少腹，那有些寒药或是有些活血化瘀的药，都是阴的药，它能够进去，把里边的瘀血清出来，所以，活血化瘀的药，一般来说少腹，讲的少腹的刺痛，都是有瘀血，瘀血在里面，那活血化瘀就很重要了，唐容川就写一本叫《血证论》，这《血证论》专门讨论活血化瘀，如何使用，他认为百病啊，久病，任何久病，只要是病久了，都有瘀血，意思形容很重要。

我们治疗癌症，治疗肿瘤，到后来也就是活血化瘀嘛，你说子宫肿瘤，卵巢肿瘤呢，我们到头来都是以活血化瘀的，其它都是以寒热的开始，但一般活血化瘀，我们都会加活血化瘀的药进去。

丹参呢，也可以安胎，尤其在妇人产前，老师她出血了，那出血了，老师我们不能开太多活血化瘀的药，开下去她胎儿掉下来怎么办，你开丹参，丹参可以固胎、可以安胎，同时可以把瘀血排掉，应该是很好，这很好用。

> 《本草纲目》说它能够活血，通心包络，能够止疝气的疼，所以说，徐灵胎说养血消瘀，又能够养血，又能够化瘀血，普通剂量，你可以二钱三钱四钱你到一两都没有关系，那丹参本身入心脏，所以，南派很有名的天王补心丹，治疗失眠，治疗心悸怔忡，天王补心丹里边都有丹参，能够入心脏。

那经方，我们在使用张仲景的方子的时候，几乎看不到丹参，我在治疗心脏病也看不到丹参，妇科的时候，张仲景也不用丹参，那我会加一点丹参下去，各人的看法不太一样，但是我一再跟大家强调，你们要以张仲景的《伤寒》《金匮》的条辨里面的方子为主，那再加上需要加增减什么药的时候，从《神农本草经》里面增减，这就永远不会脱离经方的范围，这个做到了很好以后，再去加南派的药进来了，天王补心丹啊，什么，龙胆泻肝汤啊，什么防风通圣散啊（forever），好，附在上面，圣诞树枝很好了嘛，多几个灯啊，多几个腊烛，这样子是对的，如果没有经方做基础，你用南派的话，你空壳子，外面很好，里面空的，没办法治病的，辩证都会有问题，就是因为丹参，它能够入心脏，所以我们也叫它赤参。

这个呢，大家可以看看，前边是续断，后边的就是决明子，可以泡来吃，它是没有毒的，可以吃，丹参呢，长的样子是这样子，有点暗红色的样子，丹参。
