# 上经·桑蜱蛸

**【本经原文】** 味咸平，主伤中，疝瘕阴痿，益精生子，女子血闭，腰痛，通五淋，利小便水道。

今名桑螵蛸。

**【产地】** 处处有之，乃螳螂所作房，着生于桑枝上者，入药。[深秋至翌年春季均可采收，至芒种节后一齐出。]

**【性味】** 味咸甘，性平，无毒。

**【主治】** 桑蜱蛸为固肾益精要药，主遗尿，滑精，治白浊疝瘕，肾衰阴痿，通五淋，疗便浊。

**【别录】** 疗男子虚损，四脏气微，梦寐失精，遗溺，久服益气养神。

**【甄权】** 炮熟空心食之，止小便利。

【吴克潜】桑螵蛸为小儿梦中遗尿要药，得覆盆子菟丝子益智仁补骨脂等甚效，合龙骨疗滑精，著名方剂有桑螵蛸散（盐灸桑螵蛸远志肉龙骨盐炙菖蒲人参茯神醋炙龟板当归）治男子因女劳，小便日数十次，如稠米泔色，心神恍惚，有实效。

【灵胎】养血逐瘀，补肾利水。

**【用量】** 普通一钱至三钱。

**【禁忌】** 凡膀胱有热，小便短数者忌之。

再来呢，一二六，桑螵蛸。

这个桑螵蛸呢，长成这个样子，诸位看看。

陈列一下。

这个桑螵蛸呢，实际上，就是螳螂的幼虫。

那这个桑螵蛸呢，也是益精生子，它能够，这个也是味道比较咸平的。

我们用在滋补的药里面用到很多补肾，补肾益精的药，男女都可以用，那桑螵蛸呢，有固肾的功能，益精又固肾，固精的功能。

那有的人呢，比较早泄啊，早泄的话你开一些比如菟丝子啊，覆盆子啊，这种都是生精子的药，并没有固阳的药，对不对？你要固守嘛，固守的时候，你用到桑螵蛸，可以固守，龙骨，固守它，锁阳，固住它，精就不会出来。

不然的话，你们还没有HAPPY就结束了，那……夫妻感情会不好嘛。

我们中药有固阳的药，这就不容易出来，但是你固阳的药不要加太强哦，太强了不出来了，太过了嘛。

所以这个剂量一定要小心，用的很好。

那桑螵蛸就是固精的药，不单单能够生精，而且有固阳，所以遗精的时候可以用，或者早泄的时候都可以用。

象甄权呢，他说这个桑螵蛸这种药，你烤啊……烤啊，就象烤肉一样，烤肉一样，烤烤就可以吃啦，很好吃啊，很香啊，烤来吃哦。

所以这个就是能够止小便，小便的时候没办法控住，老年人吃了就可以。

那小孩子遗尿啊，尿床都可以。

那你如果说针灸很熟，啊，扎了小朋友那个夜尿点，通一下，通通它，啊，吓死他，晚上都不敢小便了，然后再给他吃点桑螵蛸，烤点桑螵蛸给他吃，晚上看他尿不尿。

就是你现在学到了，《伤寒》《金匮》你学到了，还有很好的处方。

现在你知道，老是单味的在用，单味药的在用嘛。

我还有再补充一点。

因为前几天胃不好，台湾的食物比较有问题。

我们的川芎，单味在用的时候，用的很广。

任何的骨头突出了，比如说，老师，这个太太的脚的大拇趾奇怪咧？哦一个歪一个……大拇趾，本来大拇趾的趾甲是这样子的，这个大拇趾突一段出来，脚掌这个骨头，突出来一段很痛，还有人呢，脚后跟，成这样子，突出来，骨头起来，老师这个突出来骨头很难过，很痛啊，怎么办？那我给西医开刀，开刀以后就长回来，更大，那怎么办呢？川芎。

单味川芎粉，川芎粉拿那个棉布包，放在棉布包里面，然后喷点米酒上去，米酒能够加强……温中嘛，加强药以后，然后晚上可以贴上去，贴到脚上去，贴到骨头肿起来的地方，然后早上起来把它拿掉，每天晚上贴，每天晚上贴。

那你一包可能用一钱粉在里面，这很多了嘛，你用到两三四天以后，味道没有了，代表药力过了，你再拿一包来贴。

手的骨头，有的人是，这个受伤，这个骨头突起来，统统可以用，当然我们用报刺法，伸进去，东南西北，西南东北，各扎一针那种，那也可以，那刺完以后再贴川芎的，都很好，效果都很好。

那老师那个川芎粉呢，还有个，我们还有个蓖麻籽，这个蓖麻籽呢，也是单味药在外用，一般磨过以后变成黑黑粘粘的，那个象膏状一样，拿来贴，脂肪瘤，贴在上面，涂点黑黑的油……磨完以后油油的，就这样涂上去，棉布贴到皮肤上面，然后用OK绷什么的，盖住嘛，每天晚上贴，白天不要贴，一段时间就消掉。

中药很多在外用。

我想到就会告诉你。

所以桑螵蛸呢，徐灵胎用来养血，逐瘀，补肾利水。

你看桑螵蛸黑黑的，都是能够补肾。
