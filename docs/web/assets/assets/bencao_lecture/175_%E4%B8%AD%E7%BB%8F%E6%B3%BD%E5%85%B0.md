# 中经·泽兰

**【本经原文】** 一名龙枣。味苦，微温，无毒。治乳妇衄血，中风余疾，大腹水肿，身面四肢浮肿，骨节中水，金疮，痈肿疮脓。生诸大泽旁。一名虎兰。

**【产地】** 生于溪涧或湿地，叶类薄荷，根紫黑色，叶与子根（地笋）皆入药。

**【性味】** 味苦甘，性微温，无毒。

**【主治】** 泽兰为女科要药，功能行血消水，主养血气，破宿瘀，消症瘕痈肿，胎前产后诸病。

**【甄权】** 产后腹痛，频产血气衰冷，成劳瘦羸，妇人血沥腰痛。

**【大明】** 胎前产后百病，通九窍，利关节，养血气破宿血，消症瘕，通小肠，长肌肉，消扑损瘀血，治鼻血吐血，头风目痛，妇人劳瘦，丈夫面黄。

【灵胎】清湿热，治水肿。

**【用量】** 普通一钱至三钱。

**【禁忌】** 破血通积，大虚不宜。

第一百九十三，泽兰。

当然你可以用在很多地方，最主要我们使用泽兰的时候是妇科，妇科用得最多。

女科里面用得最多，最主要是它能够活血，行血，消水，排水，所以一般来说如果女人有大腹水肿，身面四肢浮肿，女人很多肿哦，水肿很多，那关节骨节里面有水，累积在里面，都可以用泽兰，所以泽兰是最主要是行水，行血，消水的重要的药物。

几乎你看到一个女人，过胖，身上有积水，统统可以使用，泽兰本身没有毒，剂量用大都没有关系。

诸位看，这个是海藻，长这个样子。

这个就是泽兰，那个中药我们有一句话叫做好吃的就是你平时吃的，不好吃的就是生病时候吃的，所以这个是海藻，这是泽兰，你们可以传阅一下。

海藻因为质比较轻，所以一钱两钱就很多了，那泽兰呢，质也比较轻，一钱两钱三钱，你看剂量，如果水肿的很厉害，加重。

泽兰呢，味是苦味的，甘味的混合，苦甘的。

**【药性】** 是温性的药，积水大部分都是寒症的，所以，他能够温水，就是能够让水气化出来。

**【主治】** ，泽兰功能行水，行血，消水，他能够养血气。

胎前产前，妇人在怀孕中间有水肿，经方里面张仲景没有选用泽兰，张仲景用别的药，但泽兰也可以使用没有关系。

**【大明】** 呢，他说妇人劳瘦，最后，丈夫面黄，黄瘦都可以使用。

一般来说我们黄的话，病人有积水，有一种黄疸，有这种积水的时候我们可以看到都可以使用泽兰。

【徐灵胎】你看，治水肿。那么多名家，都讲泽兰能够消水，所以，诸位记得，水肿的时候，泽兰是利尿剂。
