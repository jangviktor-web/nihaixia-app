# 增补·红花

本经无记载

**【产地】** 产我国北地，今处处有之，园圃亦可栽植，为两年生之草本植物，花开色红，故名。

**【性味】** 味辛，性温，无毒。

**【主治】** 红花为活血行瘀要药，主暴吐紫血，（紫则有瘀），产后血晕，痘疮血热有毒，（血行则毒解），治月经不调，腹中结块。

**【开宝】** 主产后血运口噤，腹内恶血不尽，绞痛，胎死腹中，并酒煮服，亦主蛊毒。

**【丹溪】** 多用破血，少用养血。

**【用量】** 普通五分至钱半。

**【禁忌】** 忌沉香麝香，能使红花变色，可下死胎，孕妇忌用，过用红花，能使血行不止而毙。

**【容川】** 色赤自入血分，味苦专能泄血，而花性专主轻扬，上行外走，故能泄肌肤脉络在外在上之血，有谚云：治风先治血，血行风自灭，血足则肝阳不动，而风自熄。观仲景之红蓝花酒，治风气百疾，则知治风先治血的道理。色红能生血，而味苦，又能泻血。

番红花——红花之产于新疆者，味甘性平无毒，主活血开郁，治心忧气闷，惊悸，伤寒发狂今多用为开胃行经之品。

藏红花——红花之产于西藏者，性味同红花，以入滚水内色如血，可冲四次不变色者为真，主活血通经治吐血（各种痞结冲汤服，忌食油荤盐），功用最良。

土红花——红花之产于福建者，根叶入药，味甘，性微寒，无毒，（或作有毒）治劳热瘴疟，骨节疼痛。

再来呢，红花。

这个本草经也没有记载。

在我国北方很多地方都有，那最主要我们有几个红花，诸位看到可以看到后面有番红花，藏红花，土红花，现在市面我最常用的是川红花。

川红花呢，这个花的颜色很红，诸位看红花长的这样子，如果打开来没有味道，淡，没有味道的话就是藏红花。

打开来里面有股臭袜子味道，川红花，比较腥臭川红花。

那川红花价钱差很多，那个藏红花很贵，川红花比较便宜，味辛性温无毒，红花是活血行瘀的药，一般来说大吐、吐血，产后的眩晕，我们都会用红花，为什么，因为血在走的时候，红花能够行血，所以血里面有瘀血块挡住的时候它能够把它清出来，让血变得速度加快不会有瘀血堵在身体里面，那用得多呢，把血会破坏掉，少用呢，能够养血，那一般来说我们五分到一钱，一钱半就很多了，因为红花质很轻。

看那个红花质很轻。

唐容川呢，他对这个红花解释得非常好，你看花性主轻扬，上形外走，他是熟谙我们的中医的话这个专科讲的话，专科医师讲的话，经验，治风我们要先治血，血行风自灭。

我们讲的肝就是风，肝脏就是风脏，治肝就是先治血，血走肝病自然就会好。

血足则肝阳不动，风自熄，风就会停止下来，肝病就会停下来，所以说我们一定要让它行血，所以活血化瘀是我们治疗肝病的大原则，西医不知道啊结果就是血管栓塞，就是找死，这个绝对不可以做，你一栓塞的话，肝阳就受阻，肝阳就进不了血分，药力啊血就没有办法透达，当然我们的药力也就一样没有办法透达。

那藏红花呢，因产在西藏高山的地方，青藏高原上面，它能够通到脑部的血，所以你如果吃藏红花的话，一般这脑部不会缺氧，所以西藏人，很多动物那个羚羊啊在那个五千公尺以上跳得跑得很开心，牦牛那个跑啊跳啊很开心，没事，为什么它们没事我们常人有事，这个红花嘛，没有在那边吃点，那吃冬虫夏草那样的，多好，所以红花呢，在我们使用上我们治疗脑中风、脑瘀血的话我们都会使用红花，如果说你没有藏红花找不到正品藏红花，你用川红花的话，剂量重一点就好了，比如三钱，那你用大剂的时候三钱、四钱很大一包，那你用藏红花可能五分一钱就够了，藏红花的力量是比川红花来得强，但是珍品不好找，这是红花。
