# 上经·白英

**【本经原文】** 味甘寒，主寒热八疽消渴补中益气，久服轻身延年。

**【产地】** 生川泽，为野生蔓草，全草可用。 {西充有}

**【性味】** 根苗叶味甘，性寒。

【效用】白英为解热药，治风疹，丹毒，黄疸及热疟。有补益之效。

**【弘景】** 叶做羹饮，可疗劳。

【藏器】烦热，风疹，丹毒，瘴疟寒热，小儿结热，煮汁饮之。第44味白英，白英呢这种是全草，这种药根苗叶全草都可以用，味甘性寒。我们用的不多，因为它这些味甘寒，主消渴补中益气，我们消渴的药非常的多。所以白英近世用的比较少。可不可以用？可以用。到处都有不一定要到四川，到处都有。但这个药用的不多，它是解热的药。诸位有个概念就可以了。那像风疹，小儿，因为它是味甘嘛，甘味的药性寒，寒能够去所有的热病，小孩子的风热啊，发烧啊、风疹啊，风疹通通是热症，丹毒啊通通可以用。
