# 下经·白头翁

**【本经原文】** 一名野丈人，一名胡王使者．味苦，温，有毒。治温疟，狂易，寒热，症瘕积聚，

瘿气，逐血，止痛，治金疮。生山谷及田野。

**【产地】** 处处有之，生山谷及田野，近根处有白茸，故名。

**【性味】** 味辛苦，性温，无毒（或作小毒）。

**【主治】** 白头翁为治痢要药，功能泄热凉血，治毒痢赤痢[大便时肛门很热，便后又想上厕所。]，下血腹痛，及妇女经闭。

**【别录】** 治鼻衄。

**【甄权】** 赤痢腹痛，齿痛，百节骨痛，项下瘿瘤。

**【弘景】** 止毒痢。

**【容川】** 白头翁一茎直上如柴胡，所以能治下痢后重者，升散郁结也。其无风动摇，有风不动，

色白有毛，凡毛皆得风气，采于秋月，得金木交合之气，故能熄风，从肺金以达风木之气，使木不侮土，故功在升举后重，而止痢疾，又其味苦，是治风热之妙药，仲景治产后中风，及痢疾后重者，走取其熄风火，达肝阳也。

**【药征】** 主治热痢下重也。

**【用量】** 普通钱半至三钱。

**【禁忌】** 滞下胃虚不思食，及完谷不化，泄泻由虚寒寒热而不由湿毒者，均忌，得酒良。

二九八白头翁，诸位看这就是白头翁，长成这个样子。

白头翁经方使用很多。

白头翁，这个白头翁呢，是治疗下痢，张仲景治痢的主要的药。

一般来说是热痢，你们如果没有下痢过，可能不了解那有多痛苦，你如果有下痢一天40次，你想想看怎么过日子？的确就是这样子的啊，我就有这样的病人。

坐到我面前，我们才聊大概是1 分钟15分钟，他要上2次厕所，然后我就问柜台，这个人进来的时候上了没有？哦，上了1次，在等你的时候上了1次。

我们是尽量不让病人等，所以按照他准时到，我准时帮他看病，你看他，才在诊室等一下，从车上下来时上了1次厕所，然后看到我的时候看了一半，上了1次厕所，然后回来再跟我讲完话，他认为讲完了，再去上一次厕所，然后在那边等药，等了之后，回去之前再去上一次厕所，那他怎么过日子？哦，我们痢分2 种，一种是寒痢，一种是热痢，这是热痢。

那热痢呢，那老师你怎么知道是热痢？你去闻就知道了，它是又酸又臭，热，你看到颜色就知道是热。

寒痢就是他吃进去是意苏苏拉出来是意苏苏，哦，吃进去是青钢菜，拉出来的就是青钢菜，哦，那吃什么拉什么，食物都没有消化掉，那是寒痢。

那如果是你岳母得了寒痢，你再给她吃白头翁，那她痢得更厉害，从此你就不用回娘家了，回你岳家去，不要回去，所以说你寒热一定要区分，当你寒热区分的时候，你下重手，一剂下去就回来，那病人好得很快。

这个白头翁，它另外一个名字叫野丈人，丈人就丈人嘛，还野丈人，我不懂它的意思。

那这个味辛、苦，性温，白头翁是治痢的要药，功能是泄热解毒凉血止痢，下血腹痛。

所以说当病人下痢得很厉害的时候，我们经方里有白头翁汤，当然白头翁是主药，主力的药还要配合其它几味药。

这个，到我们介绍到方子的时候再跟诸位讲。

你出方子的时候，如严重的话，我一般来说我们白头翁开3 钱，那个药并不是很重，3钱已经很多了，一般病人吃完第一碗，比如说我们一副药是6 碗水煮成2 碗，或9碗煮成3碗，他吃完第一碗以后，已经好很多了，厉害到这种程度。

还会问你，哦，为什么会好得这么快？为什么好得这么快，你的医生太笨了嘛，前面的医生太笨了嘛，我们这个白头翁汤用了几千年，本来就应该好得很快，对不对？

好了还在问，因为他们病了很久。

我们常常遇到这种下痢的病人，诸位不要以为美国医药很发达哦，那个西医越发达的越贫脊，病人越苦啊，那病人来这边2年，我说你下痢有多久了？2年，天哪！2年，那你吃了什么药？我什么药都吃了，照样痢，对不对？我说那你看过中医没有？

没有，那这就是原因了！这就是拉了2 年的原因，你看你要不要吸取教训，拉肚子拉了2 年，对不对？这个案例太好了，我让他看中医有多厉害，然后我开完处方特地跟他讲，你这个处方以后我可以把它翻译成英文，让你看看1800 多年前，就有这个处方，也就是我们早在1800多年前已经解决了。

哦！中医那么厉害！然后慢慢日积月累，我告诉老外，中国的文化不得了。

然后他吃完，我问他你好不好？我心里知道他会好啊，他说很好啊！我说你看1800 多年前我们就把你治好了，到现在你还治不了，你们还有大堆仪器，我连仪器都不用看，听就知道你要吃什么药。

除了治下痢以外，象咽喉有甲状腺炎，都可以使用，那如果你甲状腺有肿瘤，或者有腮腺炎，同时有下痢，那这个白头翁是太好了，对不对？一药两治，对不对？我们一鱼两吃，一石二鸟，哦，这白头翁很好用。

那这个里疾后重，上完厕所。

下痢很重，肛门还很热，老是还想上厕所，这是白头翁汤症，哦，赤痢。

那唐容川，你看白头翁一茎直上，象柴胡一样，就是因为他一茎往上，所以可以治下痢后重，明白没有？这就后重就是上完厕所还想上，感觉那肛门还没收起来，收不起来，那你还是很想再坐回去那种感觉，这种感觉出现的时候，你就要记得白头翁，它能升散，郁结，你看，无风动摇，有风不动，象我们的荆芥啊，独活，羌活很多都是这样子的哦。

药征：主治热痢下重，下重就是里疾后重，哦，肛门觉得很重，不能收口，我们这样讲完以后，如果你没有经验，不怪你，等你有了经验以后，你死也不能忘了白头翁，哇，真好！真好这个药，到目前我使用白头翁，无往不利，哦，无往不利，没有失掉一个病人。

诸位看哦，白头翁的普通钱半到3 钱，对不对？白头翁的禁忌，如果有带下胃虚，不思食，完谷不化，对不对？那是不是寒症？完谷不化的意思是什么？就是吃意苏苏大便时出来也是意苏苏，泄泻有虚寒这种都不可以吃的。

所以诸位今天已经学到了，诸位知道，老师，他是热痢的话，我们用白头翁，你用黄柏，黄芩啊都可以加进去，你说老师，白术可以收，当然可以啊，再快点，加点猪苓利小便，把水从小便排出来，收得是不是更快？老师，寒痢呢？你不要去想经方哦，寒痢，里边寒嘛，对不对？你就加炮附子，可以啊！白术，可以啊！你帮他加点茯苓，把水利出来，对不对，干姜啊诸如此类的，那大肠炎，涩，那个拉得厉害，血跟水混合的，哦，老师，我们用涩剂，那个大肠炎，哦，比那个赤痢还厉害哦，就是不断地上厕所，不断的下痢，还戴尿布的哦，那吃的时候，我们用涩剂，经常用赤石脂，禹余粮和赤石脂，这种都是涩剂下去收敛它。

那通通不能止的时候，我们再去想办法利尿，把小便利出来，里边没有水啦，自然而然痢就停下来了嘛。

所以你说中医有没有系统？的确有，真的有系统的哦，所以说诸位了解了药性以后，到以后我们介绍经方的时候，你看看他有多细，哦，那因为你了解了以后，中间少掉一个，你会感觉到，哎呀，中间好像少掉一个什么东西，这个时候就你就把它补进去。

以后就要靠诸位，所以药性一定要熟。

那白头翁汤里边有几味药，那白头翁就是主力，主力的药用的量就会比较重，哦，比较重。
