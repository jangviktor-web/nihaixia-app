# 中经·鮀鱼甲

**【本经原文】** 味辛，微温，有毒。治心腹症瘕，伏坚积聚，寒热，女子崩中下血五色，小腹阴中相引痛，疮疥死肌。生南海池泽。

239鮀鱼甲，这个字念tuo。

鮀鱼是鲨鱼的一种，这种现在用的很少。

生南海，取无时。

有毒。

现在用的很少。

二四〇、樗鸡

**【本经原文】** 味苦，平，有小毒。治心腹邪气，阴痿，益精，强志，生子色，补中，轻身。生川谷樗树上。

240是一种鸡，野鸡类的东西，动物性的东西。

生子好颜色啊，补中啊。

一般来说山鸡类的东西呢，都有滋补的功能，诸位看看就好了。

你不要去开樗鸠两只，没有。

药房没有的。

这个可以吃没有关系，入药很难的。
