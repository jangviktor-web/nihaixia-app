# 上经·茜根

**【本经原文】** 味苦寒，主寒湿，风痹，黄疸，补中，现名茜草。

**【产地】** 生山谷中，为多年生蔓草，亦可种植根形如圆柱，色红褐入药。

**【性味】** 味酸咸，性寒无毒。

**【主治】** 茜草为凉血通经要药，主吐血下血，月经不通，月经不止，治骨节风痛，折跌损伤，

凉无病之血，行已伤之血。

**【别录】** 止血内崩，下血，膀胱不足，踒跌，蛊毒，久服益精气，可以染绛，又苗根主痹及热中，伤跌折。

**【甄权】** 治六极伤，心肺吐血，泻血。

**【大明】** 止鼻洪尿血，产后血运，月经不止，带下，扑损瘀血，泄精，痔瘘疮节，排脓，酒煎服。

**【用量】** 普通一钱至二钱。

**【禁忌】** 病人虽见血证，若加泄泻，饮食不进者忌。

茜草一名血见愁，其理血之效可知，俗方用治女子经水不通。以一两煎酒服之。仲醇曰治疸，此治因蓄血而发黄的疸，不专于湿热者也。

黑发方：茜根一斤，生地三斤，加水熬成膏，每日酒服半匙，一月发尽黑。

**【容川】** 色赤味苦，根长，故下行之力必重，专能降泄行血。

第六十九味药，茜根。

这个我们称为茜根，你开处方的时候你可以写茜根，茜草，都可以。

这个药，在《黄帝内经》出现过，那一般来说，如果你状况不明，还出现腹痛得很厉害，你不了解里面什么样的状况，我们就开茜草，这个茜草，活血化瘀的力量很强，它的范围很广，为什么，因为它是味酸主收，而且它是咸味的药，诸位记得咸味的药，主攻坚，它能够攻坚，所以很多硬块呀在里面，肿瘤呀，我们都去开，都可以开茜草，它可以攻坚啊，它除了活血化瘀外，它就是攻坚，能够攻坚，那味道是酸，酸味的，酸味主什么，主收敛嘛，有些病人呢，如果下血，比如说子宫，西医说，啊，你子宫颈癌，病人出血不止，那老是开进去的时候，开处方进去的时候，我又希望止血，又怕止血的话，血无止法，一下止血的话，那血排不出来，那个癌细胞肿得很大，开茜草啊。

茜草本主收敛的，又主攻坚，它一起来的，我们就有这种药，我刚刚讲就这意思。

茜草，那它本身是性寒无毒的，没有毒性的药，跟我们那个什么乌头啊，大热大毒没有关系的，茜草吃不会死人的，你开个五钱八钱一两都没有关系，这凉血通经的要药。

一般来说，我们看女人，看外症，人比较稍为胖一点的，都是热，比较瘦的，都是凉，那茜草呢，药是寒性的，性寒的药，所以如果说稍为胖点的女太太小姐们呢，你用茜草这个寒药，就是很对症的，那一般那个下血下得很多，又可以止血，又可以止血崩，包括女孩子生小孩生完，血崩大量不止，你要去止血它，又要去怕它有瘀血停留里边，没有排尽，那你又要止血，你怎么办呢，那就用茜草。

你看[禁忌]后面，茜草又一个名称叫血见愁，任何的血病，碰到茜草，这个血病都发愁，意思就是茜草效果很好，它凝血的效果，非常的好。

头发变黑的，这是历代的经验方，茜草一斤，生地三斤，你把它加进水熬成膏，每天喝个半勺，一个月头发就变黑了，可以吃没所谓啊，因为，生地是滋补的药，茜草又没有毒，当然没有关系了，可以吃，因为中医的观念里面，认为为什么？中医认为说发为血余，头发，血在滋润它多余的地方就是头发，血之余啊，所以，我们血余炭，你如果把头发烧了以后，就是血余炭，其实血余炭就是比较好听嘛，实际上就是乱发，大家剪一堆头发，剪下来火一烧，血余炭，如果讲这是我头发烧焦给你吃的，怪怪的，（众人笑）血余炭，这很好听。

说说那个黄土不好，灶心土，说是伏龙肝，听起来还不错。

这中医有些，我讲老鼠药，西医也说老鼠药不好听嘛，他说（Coumarin）好听嘛，实际就是老鼠药，中医也有一些，就这样子。

嗯，那你可以做，只要是头发白了，老师我可以吃？当然可以吃啊，滋补的药，谁都可以吃啊，当然可以吃了，吃吃看。
