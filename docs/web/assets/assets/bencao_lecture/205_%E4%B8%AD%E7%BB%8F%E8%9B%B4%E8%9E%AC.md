# 中经·蛴螬

**【本经原文】** 味咸，微温，有毒。治恶血，血瘀，痹气，破折，血在胁下坚满痛，月闭，目中淫肤，青翳，白膜。生平泽及人家积粪草中。一名蟦蛴。

236呢这个药叫蛴螬。

蛴螬呢，在经方里面我们有大黄蟅虫丸。我们在治疗淤血、陈年的老血的时候，会有时候使用到蛴螬，那就那个地方用到蛴螬，张仲景用一次。

蛴螬这个药是金龟子的幼虫，一般来说长在比较脏的地方，有一点毒性的，能够去肝血，淤血块。

像骨折啊，血在胁下坚满，青翳啊，眼睛的青翳白膜。

“那老师你怎么知道他是淤血呢？”我们叫肌肤甲错。

中医很棒呀，所以我说你们学中医走对路了。

什么叫肌肤甲错，皮肤就好像蛇皮一样一块一块的，拍一拍白白的屑就掉下来。

“老师全身？”不是。

只长一段地方，一节地方，从三阴交到蠡沟这一段地方，脚上面这一段。

腿拿起来你这个小腿怎么搞的，肌肤甲错。

里面有陈血，肚子里面有陈血，恶血，很深的地方。

它就会从这个地方表现出来。

这个时候就是大黄蟅虫丸症。

里面就会用到蛴螬这一味药。

大黄蟅虫丸里面有很多的药，有时候不容易找齐，地鳖虫啊不容易找齐，这是张仲景出的方子，我有点怀疑，我们有很多经方不一定要用到动物性的药，我们植物性的药一样可以把它清出来。

突然就蹦一个出来。

问不到张仲景，这个你摆进去的？哦。

因为张仲景处方，经方的时候，我们所谓经典之方，这个处方简单几味药。

像温病派，南派的中医，你去给他说医生我咳嗽，可以开八九十味药，所有《本草纲目》里面能治咳嗽的药统统开在里面，枇杷叶一分五分，然后这个什么药啊杏仁，南杏仁，北杏仁。

南杏仁，北杏仁不一样。

弄一包，咳嗽。

药房拿到这个药单不想做这个生意，太麻烦了嘛，这个两分两片那个几片。

拿到经方家的药很开心，为什么？五味药，七味药，四味药，两味药结束了，一包结束了。

经方就这样子。

因为经典之方嘛，绝对处方。

那这个蛴螬呢以后你们读到金匮就知道，大黄蟅虫丸一票啊！那么多在药里面，不太像张仲景的处方，但是有我们就要讲，不敢乱删。

有的地方太离谱了我把它修正过来了，临床上我修正过来，哎！一剂知二剂已。

我知道我修正的对。

就一个地方用到蛴螬，要找要到粪坑里找，书上这样写的嘛。
