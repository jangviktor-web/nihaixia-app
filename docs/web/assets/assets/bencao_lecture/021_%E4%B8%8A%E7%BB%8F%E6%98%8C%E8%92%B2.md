# 上经·昌蒲

**【本经原文】** 味辛温，主风寒湿痹，咳逆上气，开心孔补五脏，通九窍，明耳目，出声音，主耳聋痈疽，温肠胃，止小便利，久服轻身不忘不迷惑延年，生池泽。

吕氏春秋云冬至后五旬七日昌始生，昌者百草之先，于是始耕，又名兰荪sūn。即今之菖蒲也。

**【产地】** 我国四川，今处处有之，多生水滨，可供盆栽，西洋及日本亦俱产之，根入药，一寸九节者良。

**【性味】** 味辛性温无毒。

**【主治】** 菖蒲为宣窍泄热，健胃行滞要药，主开心孔通九窍，明耳目出声音，治咳嗽上逆，霍乱转筋，健脾胃杀诸虫，疗噤口痢。

**【别录】** 四肢湿痹不得曲伸，小儿温疟，身积热不解，可作浴汤。

**【甄权】** 治耳鸣，头风泪下，鬼气，杀虫，恶疮疥掻。

**【大明】** 除风下气，丈夫水脏女人血海冷败，多忘，除烦闷，止心腹痛，霍乱转筋及耳痛者，

作末炒，趁热裹。

**【好古】** 心积伏梁。

**【时珍】** 解巴豆大戟毒。

【灵胎】下逆开窍。

**【用量】** 普通生用二三钱，干用五分至一钱半。

**【禁忌】** 忌饴糖羊肉铁器。

【吴克潜】菖蒲南人多常用置食水中，或加矾少许，解一切毒，周颠仙曰常食菖蒲饮水，永无腹痛之疾，沈金鳌曰治禁口痢，屡用屡效，道藏经曰能治一切风，手足顽痹瘫痪不遂。正传曰九节菖蒲去毛捣末，入黑猪心一个，批开煮服，之癫痫风疾，著名方剂有菖蒲丸（石菖蒲人参丹参天冬麦冬赤石脂）。治小儿心气不足，不能言语。又醋糊丸棉裹置耳中，治耳内卒痛，聋闭不闻，有菖蒲益智丸（菖蒲远志人参桔梗牛膝附子茯苓桂心)。治健忘恍惚，破积聚止痛，安心定神聪明耳目均效。

【倪注】常用于鼻塞不通，脑部受损。内服外用皆宜。

**【炮制】** 拣去杂质，刷去灰尘，洗净晒干，去灰尘即得。

第十九菖蒲。

菖蒲用途非常的多。

首先我们先确认，市面上有两种，一种石菖蒲，一种是水菖蒲，诸位要拿的是九节石菖蒲，这里讲的是石菖蒲不是水菖蒲。

那真的菖蒲九节，长了九个节，一节一节看起来象竹子一样，你不用真的算是九节，那个最近不是说浙江有菖蒲出来，诸位这个不需要，很多人都想要夸大。

我们一般的菖蒲，用的是石菖蒲。

> 《神农本草经》讲这个菖蒲，你这个样子开，到药房不知道，你真要到药房开的时候，菖蒲要这样写，要草字头：菖蒲，你不能说武昌的昌没有草字头，他说你字写错了，实际上本草经的原文是昌，结果药房以为你这个人书都没读，菖蒲都没有草字头，你写有草字头嘛。

味辛温，辛味的药，辛香的药都是主发散的。

温，药性是温的都可以去寒，所以它主风寒湿痹。

诸位记得，中医很喜欢用这些名词，以后你还会要碰到：风寒湿痹，为什么要讲风寒湿，因为我们有的药是祛风的，有的药是去寒的，有的药是去湿的。

我们辩证说这个人是风寒湿，就是我们处方这三味药要混在一起，混在一个方剂里面，所以会用这个话来讲，本草就这样来写。

菖蒲，主要的功能，宣窍，主辛散，主发散，那你湿如果太盛的时候，痹在里面要靠菖蒲来打散它。

所以说鼻子的病，比如说，“老师我鼻子很严重，每天过敏，鼻涕很浓稠很多”，有人是鼻水很多，基本上都在鼻子这边堵到了，晚上睡觉鼻子都不能开，这个不能呼吸，都用嘴巴呼吸，这样鼻子塞在那边，这个菖蒲进去就能打开来，辛香嘛，辛味的要能够发散。

当然，你说我喷那个黑胡椒，当然也可以了，黑胡椒进去更强，你闻闻就开始打喷嚏了嘛。

所以辛辣的药都是主发散的。

菖蒲，最主要的功能，开心孔补五脏通九窍，明耳目，我们在治疗心脏病的时候常常开到菖蒲，治疗心脏病非常好，通九窍。

**【产地】** ，当然我们中国的四川产的最多。

这种根入药，一般来说是石菖蒲，现在都可以培植的。

**【性味】** 味辛性温无毒。

这些菖蒲，除了内服以外，外用都可以。

内服，比如说我们常常用的，因为他是根茎类，我们切的时候常常用，比如说你的体格，我这种的体格用3钱，你用1钱就可能力量不够，那小朋友1钱嘛，他是介于小朋友和我的中间，那2钱嘛，这个是汤剂里面可以加。

打粉，打汤剂打成粉喷到鼻子里面也可以，但是光喷一个菖蒲还是不够力量，那我常常会加一些辛夷粉，辛夷、菖蒲，辛夷后面会介绍到，也是辛香发散，开窍的力量很强，当然这些，这两味药我们会用，那我真正在诊所里面我是在用麝香、矾石，因为麝香、矾石更快，那用途更广，所以当你们开业当医生的时候，诊所里面用，你有的时候急救，麝香、矾石喷下去，因为是2种的喷剂，菖蒲、辛夷，紧急的时候拿错了，干脆用麝香、矾石。

哪那么麻烦，我就用麝香、矾石来清他，因为他能通窍，麝香这个药无孔不入，你一喷他直接喷到脑部里去了，然后矾石又是收敛，因为酸味能够收敛痰水的药，这两种药非常的好。

当然你说“老师，麝香、矾石，我们再把菖蒲、辛夷加进去”，当然清鼻子的效果会更强。

那这种，这边有个疗噤口痢，噤口痢这个主要的症状是病患，赤痢，大便拉来出来是红的，赤痢带点血，还有痛，大便后肛门口会痛，又吃不下东西的，这个我们称之为噤口痢，口字拿掉也可以，禁口痢。

那这种药，你看旁边象【别录】里说可以做浴汤，菖蒲拿来可以煮水，可以洗汤，可以去皮肤身热不解，湿热，热不解的时候菖蒲可以去热，你洗一下，洗澡的话会冒汗出来。

李时珍是《本草纲目》的作者，他说解巴豆、大戟的毒，我们巴豆中毒，你要去抓菖蒲，不需要，冷开水喝下去就解掉了，很快，冷水就可以了。

当然你可以用菖蒲了，李时珍是比较喜欢小题大做，寡妇床头尘，下次我开处方我说你这个药要去寡妇床头拿那个灰尘，三年以上的灰尘，你要去采，你不是刁难人家么？这个是李时珍干出来的，所以说弄的太复杂。

能够辛香开窍。

那【禁忌】，象饴糖啊这种甜的，你可以看一下，这个【吴克潜】，他是南方人，南方人他很了解他们当地生活的习俗，常常把菖蒲放到喝的饮用水里面，然后加点明矾，因为菖蒲可以解毒。

那个南方，谁知道（是）什么毒，那个蛇，或者是蝎子、虾，那个都有毒的，有毒性的，那可以解毒。

那常常喝菖蒲，用菖蒲来泡水，永远不会腹痛，最主要是它能够解毒。

后面，象菖蒲丸诸位可以作参考，书本上有的基本上我们课堂就不讲了。

这个药（菖蒲），常常并用跟辛夷花，一起并用，处方单上你写辛夷好了，不需要写辛夷花，因为你写辛夷就是花了，当然你也可以把花放上去了。

那菖蒲，比如我们开3钱，菖蒲质比较重，辛夷花2钱，那个花很轻啊。

你说辛夷花要3 钱，那辛夷花一大包，菖蒲一点点，了解我意思吗？稍微减量，但是你有时候可以加量一些，看病人的情形，所以说一般来说我会减量，辛夷花剂量会比较少，毕竟花类的跟菖蒲类又有一点点不同，因为你想想看，一棵树，长长长，长到顶上开花，是不是正好开花在这个地方（鼻尖），你有没有，看鼻子长到这边（头顶）？没有吧，鼻子长到这边，花，不会直着长到头上面，这个花不能用，花都开的垂下来的，那个辛夷花就是垂下来的，刚好在鼻子的位置，如果你鼻子长到这边（头顶），你可能要吃玫瑰，或者是菊花。

所以我们辛夷，象我最常用的治疗就是这两味药加上苍术，因为苍术我们还没有讲到，所以我就先告诉你，3钱，苍术3钱，菖蒲3钱，辛夷2钱，这样的话你光这3味药，鼻窦炎就好了，治好了，这三味药，只去鼻窦炎里面堵到的东西，不管你是寒热，寒热就是说，鼻涕一流出来是浓的就是热，流清涕，只要排一些冷水，排出来都是白白的清的鼻涕都是寒的嘛，不管寒热都用这三味药。

那再去管寒热的话那就要知道，寒热在肺里面，因为肺开窍于鼻嘛，鼻子是肺之窍，这个时候你可以在里面加些干姜，可以去肺的寒这样，如果肺里面太热，你可以加些杏仁，去肺热的药，麦门冬啊诸如此类的。

刚刚我再回头，如果你是心脏问题的时候，我们不会加辛夷，辛夷是治疗鼻子的，我们菖蒲会重用，开心窍，因为开九窍嘛，心窍会打开来，菖蒲非常好用的一个药，所以你看我后面写，我注解在上面有没有：常用于鼻塞不通，脑部受损，内服外用都可以。
