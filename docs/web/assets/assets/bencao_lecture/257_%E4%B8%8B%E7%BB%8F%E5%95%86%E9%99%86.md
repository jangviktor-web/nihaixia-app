# 下经·商陆

**【本经原文】** 味辛，平，有毒。治水胀，疝瘕，痹，熨除痈肿，杀鬼精物。生川谷。一名䓪根。

**【产地】** 处处有之，多生山野阴地，其根有赤白两种，赤者有毒，白者入药。

**【性味】** 味苦（或作辛），性寒，有毒。

**【主治】** 商陆为利水消肿要药，主治水肿，瘕疝，脚气胀满，能疏五臓，散水气，通利大小肠，

并可傅痈疮。

**【别录】** 疗胸邪气，水肿痿痹，腹满洪，直疏五臓，散水气。

**【甄权】** 泻十种水病，喉痹不通，薄切醋炒涂喉外良。

**【大明】** 通大小肠，泻蛊毒，堕胎，熁肿毒，傅恶物。

**【容川】** 商陆用根，取其内透膜膈，以导水下行。一般用苗则升，用根则降。

**【用量】** 普通五分至一钱左右

**【禁忌】** 虚人禁用，赤者有毒伤人，只堪贴脐，商陆入麝香少许，用以利溲水肿。

294页，商陆，对，我们就用到了，哦，诸位看看商陆长的这个样子，很奇怪的样子，这就是商陆。

有一种方式，排水，又不伤正，不管他元气强还是元气弱，就是过去那个商陆，把它打粉以后，放一点点麝香，因为麝香就来至麝的肚脐嘛，无孔不入，混点麝香在里面，然后用棉布包起来，放在病人肚脐上，然后，你如果加温，你可用那个熨斗或什么，现在有个电热毯在上面加热，一放上边，就开始排小便，不用内服，外敷，就开始排小便，因为商陆涤水，我们可以看到，本经的原文：商陆的味道是辛辣的，平，有毒，专门治水胀。

那商陆有两种，一种是赤根的，一种是白的，你们现在看到是白色的，白色的入药，赤色的可以外用，赤色的很毒，不要吃，赤色我们拿来敷肚脐，比白色的好，因为它很强嘛。

那这个你看哦，这个性味：味苦性寒有毒，主治呢，商陆是利水消肿的要药，主治水肿，可不可以内服？当然可以内服。

你看商陆的样子，轻轻的，一般来说你用1钱，大、重剂2钱就可以了。

这个商陆呢，最主要是下焦，脚肿胀满，诸位看这个【甄权】：泄10 种水病，喉痹不通，那个通大小肠，那个【大明】有没有？唐容川呢，说这商陆用根，因为它内透膈膜，导水下行，一般我们用商陆的根。

那这种处方呢，一吃下去，大概2 分钟半个小时最多，就开始有反应了，就开始跑厕所，就这么快。

那禁忌里面最后一段，你看哦，赤色的，赤商陆颜色是红色的根的话只能贴肚脐用的。

这是一个很强的药，张仲景呢，还没有使用到商陆，张仲景只使用到甘遂、芫花，大戟最多，商陆啊，牵牛他很少用。

那临证上面到我们以后会介绍张仲景的排水的药以后，我们会加些商陆，我们看看什么时机，我们提醒诸位怎么用。

一般来说1钱，大、严重的用2钱，诸位一定要记得，要用白色的商陆根，赤色的不可以用，外敷可以用赤色的，敷在肚脐上面。
