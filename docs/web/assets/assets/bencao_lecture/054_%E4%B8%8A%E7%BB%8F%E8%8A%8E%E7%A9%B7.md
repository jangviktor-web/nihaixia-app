# 上经·芎穷

**【本经原文】** 味辛温，主中风入脑，头痛寒痹，筋挛缓急，金疮，妇人血闭无子。一名川芎。

**【产地】** 产四川陜西及江南各地，为多年生草本，或自生或栽种，根为块状结节，味辛烈，入药。

**【性味】** 味辛性温无毒。

**【主治】** 川芎为顺气行血要药，功能行气开郁，入肝理血，上行头目，下行血海，主治头痛及妇女一切气郁血郁，心腹痛，腰脚软，破宿血，养新血，补肝散风。

**【别录】** 除脑中冷痛，面上游风去来，目泪多涕唾，忽忽如醉，诸寒冷气，心腹坚痛，中恶卒急肿痛，胁风痛。

**【甄权】** 脚膝软弱，半身不遂，胞衣不下。

**【大明】** 一切风一切气，一切劳损，一切血，补五劳，壮筋骨，调众脉，破症结宿血，养新血，

吐血，鼻血，溺血，脑瘫，发背，瘰疬瘿赘痔瘘疮疥，长肉排脓，消瘀痰血。

**【好古】** 搜肝风，补肝血，润肝燥，益肝虚。

**【容川】** 川芎之味更辛苦于当归，得木火之性尤烈，苦而兼辛，有生血之功，质不柔润，性专走窜，故专主行心肝之血。苦者火之味也，苦而兼辛，则性温而有生血之功，苦而不辛，则性凉而专主泻血，温者阴中之阳，是风木本气，故入肝经，根又主上升故能至于巅顶，以散风寒，气滞血瘀，寒热身疼，女子经闭不通，当行血中之气。

**【用量】** 普通三分至钱半。

**【禁忌】** 其性疏散，不宜久服，反能损肝，畏黄连，伏雌黄。

那第五十三味就是这个不管是伤寒家、温病派都会使用的，使用到最多的，现在名称叫做川芎，以前呢叫芎穷。

那这个川芎呢，【性味】它是味道是辛，辛温，（味辛性温），我们用到的地方非常的多。

遇到任何的肝病，诸位只要记得，看到肝病，不管你是什么B肝、C肝、肝硬化、肝癌，川芎都要用。

头痛，我们开处方的时候病人只要喊头痛，第一个下去就是川芎了，所以过去中医有说，治头痛不会用川芎的人就不会治头痛的一称，有这句话，有这么个说法。

那川芎呢，也是妇科的良药。

根据临床上就看得出，病人在吃阿司匹林，阿司匹林是酸的，我很多的病人每天…这个西医在叫他每天，就美国人啊，叫他每天吃一颗阿司匹林，吃到后来的时候有天到医院去打点滴说血管都找不到，为什么？酸收嘛，整个血管缩起来。

那血管都找不到啦，在肌肉里面乱戳，病人本来血管要大，那血管怎么那么小，酸收，寒冽，寒气在里面，你刚刚看到，血脉不可以冷，那让血管绷张起来，让血管血液循环回来，让它张开来，我开的大剂的川芎下去，哇，效果就很好，回来得很快，川芎非常好用。

那我宁可你吃川芎，来预防中风跟治疗中风，而不要去吃阿司匹林，讲阿司匹林好的根本是妖魔，怎么会去帮药厂说话呢？美国从来没有个证据说阿司匹林很好，那个说阿司匹林好是医生说的哦，医生要赚钱嘛，药厂叫医生去说的，你问药厂，药厂说没有啊，那脑神经科的，说不能吃阿司匹林，阿司匹林吃了会脑出血，心脏科的说吃阿司匹林可以预防心脏病，那病人夹在中间，你告诉我，我要听谁的？都不要吃就对的。

吃川芎绝对比它好，你们有没有听过一个死亡证明说吃川芎死掉的？没有啊，有没有法医有没有开过这种，那白目的法医，真是哦。

因为它产在四川，芎穷呢产在四川，所以我们叫川芎，中药里面有川字在那边的都是因为它在四川出产，味道非常的辛烈，入药。

所以你看它【主治】，它是顺气行血的要药，因为味辛嘛，辛味的药能够散，功能行气开郁，所以力量很强，辛辣的药能够横行，它所以入肝理血，上到头目，下到血海，血海讲的是子宫胞户、子宫卵巢的地方，治头痛，妇女一切气郁血郁，所以女孩子来只要看病，肝病，女妇人病都开个川芎都没有错，那开三钱、四钱、五钱都没有关系，大剂的用都没有关系，你开得多点，你可以吃到它的辛辣，辛味很强，为了它的味道太强，你就开个三钱、两钱就够了。

那脑中冷痛，你看【别录】，头痛。

那【大明】呢讲得更严重，更过，它一切的风，一切的气，一切的劳损，一切血，那一切一切通通可以用，反正用了它也就不会错。

那【好古】呢，就是对肝病很有研究的，它就开始，所有都是肝，你看看：搜肝风，补肝血，润肝燥，益肝虚。

反正它只要有，对肝的有好，它都开在里面。

这就是我们为什么要去看各个名家的注解，在使用上面，历代的名家的经验嘛，所以中医是一个经验哲学，这认为说历代名家看起来，这个人是看肝病的，它用的川芎很多，那个人专门看头痛的，怎么也是用川芎？这个人专门看妇科的，也是用川芎，那个人的心得都不一样，在临症上它们通通治好，像我们后面的学者就把它通通抓起来，通通把好的东西集中在一起，然后我们就知道什么时候、什么时机、剂量多少，我们可以用川芎。

那你像刚刚【大明】里面，不但一切劳损，还有阴，比如说我们生甲状腺肿瘤啊，喉咙脖子肿啊，都可以用，因为川芎是活血。

那西医常常说，你查那个颈大动脉里面有堵塞，那个都可以用川芎啊，因为川芎是活血行血的药嘛。

那【唐容川】呢，大家都很清楚，他是经方家，他写，这个川芎呢味比当归的更辛更苦，它是得木火之性尤烈，那个四川产的药你要听听唐容川的，唐容川就是四川人啦，当地他就是看那药的成长，药的收成的时节啊，这些，他都非常了解，所以它的性专走窜，因为它的辛，辛苦的要比当归更强，所以专门活心脏肝脏的血，所以他那个川芎用得很多，因为是入肝经呐。

那诸位呢，女人的子宫胞户也有肝经，如果你在治病的时候，平常好像我炖个四物汤，四物汤里也有川芎啊，八珍汤啊，川芎然后去炖鸡，你用个两钱、三钱就可以了，我们治病的时候，你知道他是…治病的时候，你开处方要有个观念，这个开三钱、五钱…剂量上面你要看那个病人嘛，你要是她救命还是要给他省钱，那边，我刚刚讲过，川芎是无毒的药，你吃个一两，一剂一两也不会死人，你要救他，开个一两又SoWhat？那所以过去呢药房是中医在管，为什么？诶，我开处方叫我的药房去抓，我的药房从来不怀疑我的啊，因为我自己药房是我自己训练的，我的处方你拿到…我是传真回台湾，好你去台湾抓，那个药房就说，这个怎么能吃，他的药房不是我的，所以我们诊所出来的药没有问题，为什么？因为里面配药师都是我在训练，看到我开的处方他们照单抓药，从来不怀疑的。

如果说开重剂的时候，他们到药房去抓，药房他不给药，或者说是自己就自动减轻斤两，他不知道病人重到什么程度，所以药房就缺德，然后你为了拿这个药你还跟他争辩一番还在那边吵，然后他又表示自己懂，所以药房很要不得。

**【禁忌】** 呢，它说什么其性疏散，不宜久服，反能损肝，畏黄连，伏雌黄。

这个倒还是没有什么，我们在临床上面，当然你病好了，没事在那边吃干嘛？病好了就好了，平常不用吃。

所有身体里面活血化瘀，不管在肌肉上、在内脏、在骨头、在头上痛，身上有疮，通通可以用川芎，适用的范围非常的广，这是经方里面很重要的药。
