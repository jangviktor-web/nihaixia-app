# 下经·旋复花（旋覆花）

**【本经原文】** 一名筋根花，一名金沸。味甘，温，无毒。主益气，去面黑，色媚好。其根，味辛，治腹中寒热邪气，利小便。久服不饥，轻身。生平泽。

**【产地】** 产原野湿地，各处有之，园圃亦可栽植，亦名金钱花。

**【性味】** 味咸，性温，无毒（或作有小毒）。

**【主治】** 旋覆花为下气祛痰健胃行水要药，主治肺胃气虚，痰水胶结，上气喘急，根能续筋断

[续断更好。]。[

1.旋覆花常与代锗石并用。

2.制胃酸。仅使用在热症。

3.旋覆花、半夏汤止打嗝。]

**【别录】** 消胸上痰结，唾如胶漆，心胸痰水，膀胱留饮，风气湿痹，皮间死肉，利大肠，通血脉，益色泽。

**【甄权】** 主水肿，逐大腹，开胃，止呕逆不下食。

【灵胎】降气消痰。

**【用量】** 普通一钱至二、三钱。

**【禁忌】** 病人涉虚者，忌多服，冷利大肠，虚寒人禁用。

这个二百七十五，我们讲旋复花。

平常我们——过去的古字就是“覆”，现在我们没有加这个“覆”，旋覆花。

这个旋覆花呢，我们常常跟前面的赤色的代赭石，并用。

看看这个旋覆花长的样子，这里，长这个样子。

主要的功能呢，它能够下气，胃气上升能够冲上，打嗝嗝气上来，下气祛痰，能够健胃行水，所以我们能够健胃，胃里面胃气不足，我们可以用旋覆花，我用了很多，行水，还有我们可以制它的酸，这个念“制”，控制的制，制酸，所以我在国外用的很多，来的病人胃酸很多，旋覆花代赭石汤一剂下去，就中了，无一不好，那这个是使用的热症，热症的肠胃。

尤其，因为代赭石本身味道是寒凉的，那旋覆花呢，诸位看，又有一个名字叫“金沸草”，所以你以后看到金沸草就是指旋覆花。

金沸草。

你如果说到药房去，你找金沸草三钱，旋覆花三钱，实际上你拿的会是一样的东西。

有的药房呢只认得旋覆花，不认得金沸草，所以你说金沸草没有，旋覆花有，就会有这种情形出现，那是老师傅没有教好，他的师傅没有把他教好！它的【性味】味咸，性温，无毒。

旋覆花的下气祛痰，主治，肺胃的气虚，这个虚不是那个虚啊，是虚实的虚，痰水胶结，它的根能够续筋，续筋断。

你说旋覆花的根能够续筋，我直接写续断，不是更好吗？旁治，续筋断。

**【别录】** 呢，消胸上痰结，唾如胶漆，痰很胶，如硬块一样，都可以使用它。

这个主呕逆，【甄权】主水肿，逐大腹，腹胀，呕逆不下食。

一般来说，只要是这个肚子恶心，东西吃不下，你都可以使用到旋覆花，因为旋覆花本身是热性的，代赭石是比较寒凉的，如果说，你用半夏来止呕，旋覆花来降气，就可以治疗什么打嗝，哦对症。

如果寒很重，恶心很重，你可以用什么？吴茱萸、干姜之类的东西。

这个旋覆花降气消痰。

处方剂量呢，一般来说两钱、三钱就很多了，因为它是花类的，质很轻，就像我刚才讲的，你只要听了大概胃酸太多，就可以用旋覆花了。

在临床上用的非常的多，非常的广泛。
