# 上经·松脂

**【本经原文】** 味苦温，主疽恶创，头伤白秃，疥搔风气，安五脏，除热，久服轻身不老延年。

**【产地】** 产于松树之脂，处处有之。

**【性味】** 松脂味苦甘，性温。松子味甘，性微温。松花味甘，性温。松节味苦，性温。

**【主治】** 松脂为袪风寒湿，止痛，生肌，杀虫药；治痈疽恶疮，风痹，死肌，疥癣，蛀齿。松子为祛风，滋润强壮药；治骨节风痹，气虚头眩，肺燥咳嗽，及老人虚闭。松花为驱风，镇静药；

治头眩脑肿。松节为驱风，止痛药；治历节风痛，风痹，脚弱。

**【别录】** 松脂除胃中伏热，咽干消渴，风痹死肌，炼之令白，其赤者主恶痹。

**【甄权】** 松脂治骨节风，头眩，去死肌，变白，散水气，润五脏。

**【大明】** 松脂除邪下气，润心肺，治耳聋。

**【弘景】** 松节酿酒，主脚弱骨节风。

【灵胎】除湿火敷疮疡。

**【用量】** 普通一钱至三钱。

**【禁忌】** 燥热症者忌。
