# 上经·橘柚

**【本经原文】** 味辛温，主胸中瘕热逆气，利水谷，久服去臭，下气通神。又名橘皮。今之陈皮。

**【产地】** 产我国广东，即广橘皮，以晒干陈久为良，故名陈皮。

**【性味】** 味苦辛，性温，无毒。

**【主治】** 陈皮为宣通疏利要药，主行气健胃，去湿化痰，能发散清热，消积水气。

**【别录】** 下气止呕咳，治气冲胸中，吐逆霍乱，疗脾不能消谷，止泄，除膀胱留热停水，起淋，

利小便，去寸白虫。

**【甄权】** 清痰涎，治上气咳嗽．开胃主气痢，破症瘕痃癖。

**【药征】** 主治呃逆也，旁治胸痹停痰。

**【用量】** 普通一钱至三钱。

**【禁忌】** 凡中气虚，气不归元者，忌与耗气药同用，胃虚有火呕吐，忌与温热香燥药同用，阴虚咳嗽生痰，忌与半夏南星等同用，疟非寒甚者忌。

成无己曰陈皮和百药，脾为气母，肺为气籥，凡补药涩药必用陈皮以利气，凡用陈皮取其发散皮肤也，故陈皮之用在于行气，气行则领导百药，有痰者因气行而化，有湿者亦因气行而消，其它因食积及饮食之毒亦无不因气行而消解，气虚不能归元，则仅存之气不可再行而耗之，故忌。

**【容川】** 陈皮亦木实也，能治胃，兼治脾，但兼辛香，又能上达于肺。枳壳不辛香，故不走肺，

厚朴辛，而气太沉，故不走肺。因肺通于大肠，故厚朴可泄肺气。其气不轻不重，故可降上焦与中焦之气。

陈皮，橘子的皮，那陈皮，广陈皮，广东，广西这边一带的陈皮，做的比较好。

它能够利水谷，不消化、肠胃不消化的时候可以吃，陈皮，可以下气通神。

我们为什么讲下气？诸位这样想，用观想的方式：到小肠—到大肠，这食物一路下来，从食道下来，它只能下不能往上，大家都知道这个观念，吃东西下去，它只能下不能上。

它如果逆起来就是气往上逆，使用他陈皮能够下气，最终能把肠子食物里的气往下导，让消化的功能恢复过来。

那我们还有一种青皮，这个陈皮，为什么叫陈皮？就是橘子晒干了以后，越陈年是越久越好。

如果这个陈皮是新鲜的可以吃的橘子采下来的，还有青皮，青皮就是橘子还是青色的时候就把它采下来，还没有熟就把它采下来，那青皮跟陈皮两个同样是皮，注意青皮能够入肝脏，舒肝的力量非常强，味，气很厚。

陈皮的功能，那唐容川这个，陈皮也是木的实，木结的果实，这种能够治胃，能够治脾，清香，所以上达于肺，像止咳像枳实，枳实很小，一个个长得很小，你切下来像小拇指一样长，像金桔很小的一个，就是没有壳的，止咳，它不清香不走肺。

那厚朴，味道比较辛辣，比较辛辣，但是厚朴的气太沉，很强啊，味道很强的都往下沉，所以它不走肺，所以陈皮走肺。

所以我们使用的时候，如果说一个人的肠胃，陈皮你要着重在胃的地方。

厚朴在小肠大肠的地方，着重在这个上面。

所以如果逆气在胃里面的时候我们可以用陈皮，那厚朴的味是辛辣，更强，气往下走。

所以，如果一个病人有问题我们会陈皮厚朴一块儿使用。

因为陈皮能够把肠子的蠕动变回原来的样子，变回正常，再加厚朴，小肠大肠的蠕动变回来，我们所谓气入丹田就好了，就变成肠的蠕动，变回正常，能够开胃，那同时也是健脾的药，脾脏管全身的水，管全身的肌肉，所以管少腹肚子这边，这边有积水，肌肉有痿缩的现象，我们都会使用健脾的方式来治疗，这陈皮是健脾的良药。
