# 中经·紫参

**【本经原文】** 味苦，寒，无毒。治心腹积聚，寒热邪气。通九窍，利大小便。治牛病。生山谷。

一名牡蒙。

**【产地】** 珍珠菜之地下茎谓之紫参，多产于深山溪涧之旁，色紫黑。

**【性味】** 味苦，性寒，无毒。

**【主治】** 紫参为破血通经要药，功能治心腹寒热积聚，产后恶露不行。

**【别录】** 疗肠胃大热，唾血衄血，肠中聚血，廱肿诸疮，止渴益精。

**【甄权】** 治心腹坚胀，散瘀血，治妇人血闭不通。

**【好古】** 主狂疟温疟，鼽血，汗出，治血痢。

**【用量】** 普通一钱至三钱。

**【禁忌】** 畏辛夷。

一百八十四，紫参。

张仲景有选用紫参，这个紫参呢，本经原文是治心腹积聚，寒热邪痛。

你说这个老师很多都是心腹拘紧，寒热邪痛。

所以我说，我们要参考这个经方，在金匮里面就可以看到，下利背痛。

病人有下利的时候，背有痛，我们用紫参汤，紫参汤呢，不是单味紫参啊，是以紫参为主，这个药，他是为什么噢，你看，他是破血通经的药。

> 《别录》就讲的很正确的，只要肠胃大热、破血，吐血出来，还有鼻子出血出来，

都可以使用。

那《甄权》呢，治心腹坚涨，善晕眩，这是妇人血闭不通，月经没有来，都可以使用这个紫参。

那咳嗽、咳逆、下利肺痛，肺里面有淤血、有积血，统统可以使用紫参。

紫参呢由于它性是寒凉的性，它不是温热的性，性是寒凉的性，所以说当你使用紫参的时候，要考虑到，病人如果是热症，紫参是完全对症的。

病人如果是寒症，紫参不对症。

所以，我们要知道药性的寒热，目的就在这里，只此而已。
