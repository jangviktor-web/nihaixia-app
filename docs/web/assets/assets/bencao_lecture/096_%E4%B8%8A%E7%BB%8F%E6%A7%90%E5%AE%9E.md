# 上经·槐实

**【本经原文】** 味苦寒，主五内邪气热，止涎唾，补绝伤，五痔，火创，妇人乳瘕，子藏急痛。

**【产地】** 槐树处处有之，其花与实均入药。

**【性味】** 味苦性平，无毒。

**【主治】** 槐花为凉血要药，主五痔肠风，解毒杀虫，凉大肠，润肝燥，治吐衄，崩中，痢疾，

漏下。

**【大明】** 主五痔，心痛，眼赤，杀腹脏虫，及皮肤风热，肠风泻血，赤白痢，并炒研服。

【灵胎】清湿火疗疮痔。

**【用量】** 普通一钱至三钱。

**【禁忌】** 病人虚寒作泄及阴虚血热而非实热者均忌。

**【附录】** 槐角子即槐实，味苦性寒，无毒，主一切热，散一切结，清一切火，治五痔瘘疮（熬膏丸入谷道，日三易），邪热，妇人乳瘕，子脏急痛，补绝伤，疗火疮，阴疮湿痒，大热难产，能明目补脑，除头脑心胸间热，风眩欲倒，心头吐涎如车船上晕者。

第95味药，槐实。

槐实，就是槐树的果实，到处都有。

当我听到一个故事我很难过，我不是跟你讲过嘛，我是五党之大，我的诊所里面共产党、国民党、民进党，我们才几个中国人，还有三个老外，就是共和党、民主党，所以说五党。

共产党那个人跟我讲，啊，讲得我心里很难过，他说文化大革命的时候，因为我们那个时候开槐花，那是治疗痔疮很好的药，他说这个我吃过，我说你吃这个干嘛，他说文革的时候我们没有东西吃啊，那怎么办，还有大跃进的时候也没有东西吃，我那时还小，我们家五个兄弟姐妹，妈妈去槐树采那个槐花，炒来当菜吃。

我说吃了很好，不会得痔疮。

他说对啊，我们这边都没有人得痔疮。

他们也不会得痔疮，他们都没有坐在那里，都在动。

大革命嘛，每天都跑来跑去，那个大跃进每天把家里的铁子拿出去烧，不停动，痔疮是因为长年坐，计程车司机，长途灰狗，美国灰狗bus 的司机，都有痔疮，那那个槐实呢，我们可以熬膏，实，这个实就是种子的子嘛，种子！任何的种子都有仁在里面，花生啊，都有仁在里面，我们柏子仁麻子仁都有油在里面，蓖麻子，很多的油。

只要有仁在里面，你一熬就可以熬成膏。

像这种东西你可以外用，塞在肛门里面，那个塞进去的时候，那个痔哦，有外痔内痔，塞进去好舒服哦。

一塞进去，消炎镇痛的功能就很好，你们是因为没有痛过痔疮，你不晓得，痔疮痛起来是坐立难安，那我们针灸呢，一看，太大了，我们针刺，把它放血，用火罐拔瘀血出来，放血，放血会小掉很多。

这时用槐膏，用槐实熬成的膏塞进去，放在那个肛门的口，都可以治疗。

但治疗要有点commenesense，要手套套起来哈。

那晚上你太太骂死你哈，要带个手套再上去。

那这个槐实是很有名的哈，槐花，槐实，都入药。

到处都有这个槐树，它味苦，性平，没有毒，凉血的，凡是能够凉血的，都有消炎镇痛的功能。

尤其痔疮啊，过去我们学医啊，一招半式走江湖，那有个家族呢，就是他家什么都不会，就是会治痔疮，那老祖宗就告诫说，我告诉你不要传给别人，传给别人的话你就没饭吃，所以他的子孙永远记得这句话，我们永远不讲方子。

不管是内痔外痣，一来就拿槐实膏塞进去，那每个都好了啊，其实就是槐实膏，现在都还有啊，一招半式走江湖，我什么都不治，就是治痔疮，专门治痔疮。

那这个入药也可以，因为它药性是寒凉的，所以干燥的热的，干燥都可以使用。

所以徐灵胎说槐实清脂火疗创伤，火烧到啊，里面有湿热证统统可以用。

那过去我们说痔疮啊，是小肠湿热下注，所以他是湿热的证，槐实呢，可以把这个湿热排掉。

所以它外用内服通通都可以。

老师，你这个熬成膏塞肛门，可不可以内服？当然可以内服啊。

本身没有毒，中药就是这样子，好用，很好用。

那个附录，这个槐实角就是槐实，味苦性寒，主一切热，散一切结，清一切火，痔，专门治疗这个痔疮，熬膏，丸入谷道，谷道就是肛门，因为我们中国人文学造诣比较好，肛门多难听啊。

谷道，哈。

还有日三已，一天换三次。

那妇人，女人呢，胸部，乳房的，有硬块，有破裂，通通可以使用。

阴虱疮痒，这种呢，还有头晕船都可以内服这个槐实。

用途很多。
