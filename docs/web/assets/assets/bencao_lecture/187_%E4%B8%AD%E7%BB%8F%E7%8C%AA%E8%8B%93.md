# 中经·猪苓

**【本经原文】** 味甘，平，无毒。治痎疟，解毒，蛊疰不祥。利水道。久服轻身，耐老。生山谷。

一名猳猪屎。

**【产地】** 产我国四川及其它省山中，多生枫根下，结成块状。

**【性味】** 味甘，性平，无毒。

**【主治】** 猪苓为行水渗湿要药，主肿胀腹满，热渴懊憹，治淋肿，白浊子淋，尿闭，开腠理，

泻膀胱。

**【甄权】** 解伤寒瘟疫大热，发汗，主肿胀满腹急痛。

**【元素】** 治渴除湿，去心中懊憹。

**【好古】** 泻膀胱。

**【药征】** 主治渴而小便不利也。

**【用量】** 普通钱半至三四钱。

**【禁忌】** 猪苓利水之功多，久服必损肾气，昏人目，元素曰，淡渗大燥，能亡津液，无湿者忌之。

216 猪苓，这猪苓长这个样子，当初名字为什么叫猪苓呢，因为猪苓这个药是长在松树下面的根旁边，那长得很像山猪的大便，看上去象猪屎嘛，你不敢摸，怕莫到猪大便，就这样把它定名叫猪苓。

这个猪苓呢在经方里面是个利尿剂。

中药的利尿和西药的利尿不一样，西药在利尿的时候医生会告诉你多喝水，中药的利尿，你不要喝。

消渴，渴得很重的时候你一去利尿吃下去反而渴止掉了，所以消渴口渴不止，用猪苓还可以止渴，消渴的时候我们还可以用猪苓。

中药和西药不一样，中药即使你利尿剂用得比较多点，但是病人绝对不会脱水。

我们除了不小便不利上使用以外，在临症上面的时候，中医会想很多办法。

比如说一个病人，下利，如果用很多涩剂去固他的涩他还照样下利，那还怎么办？

利尿，张仲景讲利尿就讲完了，他后面就没有方子，那你要如何利尿，用猪苓利尿。

那这个猪苓呢，它除了利小便以外，能够渗湿行水，肿胀腹满，肚子肿胀泻膀胱，小便不出来统统可以使用它。

它是性平的，所以它是瘟疫大热发汗伤寒都可以使用，主要是在热证上面的时候使用。

它能够治渴除湿，像腹满腹胀肚子鼓胀，那个湿很盛，脾脏功能不行的时候，脾主湿，我们会用一些利水的药，干淡渗利的药，利湿，把他的水，湿排掉，那猪苓就是很好的药。

药征说，治渴而小便不利，那口渴小便不好都可以使用猪苓。

剂量在用的时候你可以3钱4钱5钱，小便不出来6钱7钱都没有关系，他需要就可以开，以通为补。

第152 页后面这个猪苓的禁忌里面写得很好，猪苓利水的功比较多，久服吃太多了会伤到肾气，小便水利太多了嘛。

刘元素说干淡渗利的药会产生燥，吃太多会大燥，人会亡津液。

所以没有湿症的人不要随便去用它。

那猪苓是很好的利尿剂，在膀胱的结石，肾结石的时候，我们会用一些像猪苓。

比如用滑石，用戎盐，青盐呀，咸能软坚啊。

用猪苓，茯苓，泽泻等，那你说老师这个药下去以后，石头动呀，石头排出来，如果石头很大，石头旁边很利嘛，会把那个尿道割破，割破小便会带血呀，那怎么办？

加点阿胶嘛，唉一看，老师，好像猪苓汤嘛！（笑）以后我们在讲猪苓汤的方子时候你就会看得很清楚。
