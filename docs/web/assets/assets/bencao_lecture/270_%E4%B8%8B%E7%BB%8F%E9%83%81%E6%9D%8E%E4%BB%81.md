# 下经·郁李仁

**【本经原文】** 味酸，平，无毒。治大腹水肿，面目四肢浮肿，利小便水道，根，治齿断肿，龋齿，坚齿。生高山川谷及丘陵。一名爵李。

**【产地】** 产我国陕西甘肃等地，他处亦多有之，其树虽似李树，而结子小若樱桃，核仁入药。

**【性味】** 味酸（或作苦辛），性平，无毒。

**【主治】** 郁李仁为润燥破血，泄气行水要药，主大肠气滞，关格不通，治大腹水肿，四肢浮肿，

破结气，利水道。

【孟铣】破癖气，下四肢水，酒服四十九粒，能泻结气。

**【甄权】** 阳中结气，关格不通。

**【大明】** 泄五脏膀胱急痛，宣腰胯冷脓，消宿食下气。

**【元素】** 破血润燥。

【东垣】专治大肠气滞，燥湿不通。

【宗奭】研和龙脑点赤眼。

**【用量】** 普通一钱至三钱。

**【禁忌】** 性专下降，善导大肠燥结，利周身水气，然下后多令人津液亏损，燥结愈甚，乃治标救急之药，非可常用，津液不足者忌用之。

诸位看这个318 郁李仁，味酸，性平，是没有毒的药，诸位看，本草经的原文呢它专治，治疗大腹水肿、面目四肢浮肿，利小便水道。

郁李，那个李树的根呢，治牙齿断掉，肿起来，牙龈肿都可以。

性味味酸，性平，味道是酸味的，主收敛。

郁李仁呢，是润燥破血，泄气行水的药。

有时你的气，没办法堵在里面，气机不通，这个时候我们用郁李仁把气泄掉，把水排出来，处方的时候你用3 钱、5 钱都可以，那这个产地呢，你看，陕西、甘肃，它树看上去像李树，但结子小，像樱桃一样，核仁入药，你们看到的是仁和核，那【孟铣】呢它直接生用，这个破癖气下四肢水，久服四十九粒，能够泄结气，郁李仁本来一颗一颗的，它说四十九，那真的你也不用去算四十九哦，因为过去很多的医家呢，都以四十九为一个数，为什么？因为七七是四十九，是阳数，所以它用四十九，因为它能够行阳嘛，能够散气，真的说四十八或五十无所谓啊，我不相信会差了一点点。这个主要呢，就是气结在腹中。郁李仁本身没有毒，所以你用大剂也没有关系。你看它这个禁忌，郁李仁，性专下降，非常善于导大肠的燥结，利周身的水气，但是你用多了的话，让病人有脱水的现象，所以使用上面呢要注意一下。一般来说，我们救急的药的时候，在有时机的时候，病人还没元气大虚的时候，我们峻下，大下没有关系。
