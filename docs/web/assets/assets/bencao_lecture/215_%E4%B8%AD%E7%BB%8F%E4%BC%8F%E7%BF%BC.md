# 中经·伏翼

**【本经原文】** 味咸，平，无毒。治目瞑，明目，夜视有精光。久服令人喜乐、媚好、无忧。生川谷及人家屋间。一名蝙蝠，今名夜明砂。

**【产地】** 山洞之中，倒悬于洞顶之上。其屎供药用。

**【性味】** 味辛性寒。

**【主治】** 为散血明目要药，治障翳，青盲，夜盲，头面痈肿，疳积，瘰疬。

【灵胎】养血明日。

**【苏敬】** 烧灰酒服可下死胎。

**【日华】** 炒服治瘰疬。

【宗奭】治疳有效。

**【时珍】** 治目盲障翳。

**【用量】** 一般一钱至二钱。

**【禁忌】** 胃肠寒之人禁忌。

右虫鱼中品十七种，旧十六种，增伏翼于此。

这个就是伏翼。

这个伏翼呢，就是蝙蝠的大便，你不用把袋子打开来闻。

当然不是生用一定是熟用，炙过烧过以后才用的。

> 《神农本草经》的原文呢，蝙蝠的大便又叫夜明砂，治疗眼睛看不到，明目这种功能。

蝙蝠夜袭性的动物，所以你如果眼睛夜盲呀统统可以使用，蝙蝠。

这个大便，中国人很厉害，大便什么味道都知道，我看。

这个蝙蝠呢，味道是辛，辛辣的味道，主发散，药性是寒的，寒凉的，所以一般来说，肠胃比较冷的人都不能吃。

**【主治】** 是散血明目的要药，专门治眼睛有内障，有眼翳，青盲，夜盲，都可以使用。

主要的功能养血明目。

伏翼很多人使用。

如果炒服治瘰疬。

瘰疬是脖子上，还有淋巴结肿大，脖子甲状腺肿大都属于瘰疬一种，最主要会使用它治疗眼睛看不到，治目盲，青盲，还有内障眼睛生翳。

我们到这里呢，诸位可以看到，虫鱼中品，本草中品呢，有十七种。

原旧十六种，增加一个伏翼在这边，和本草经加进去。

诸位记得，凡是遇到虫鱼类的药，都是比较强的，比较逡的，我们用到鱼的话，淡水，都用淡水，没有用到海里的，都是淡水，湖、泽里面的鱼类。

一般来说，都是比较峻的，你才会使用它。
