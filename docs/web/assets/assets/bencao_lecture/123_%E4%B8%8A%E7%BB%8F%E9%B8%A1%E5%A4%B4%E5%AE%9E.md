# 上经·鸡头实

**【本经原文】** 味甘平，主湿痹，腰脊膝痛，补中，除暴疾，益精气强志，令耳目聪明，久服轻身，不饥耐老。今之芡实。

**【产地】** 处处有之，产水泽中，俗名鸡头米。

**【性味】** 味甘淡，性平，无毒。

**【主治】** 芡实为固本益精要药，主泄泻遗精，带下白浊，治湿痹腰脊膝痛。

**【日华】** 开胃助气。

**【容川】** 微甘而涩，能收湿气，故健脾。

【灵胎】补脾益胃。

**【用量】** 普通二至三钱。

**【禁忌】** 生食动冷气，小儿不宜多食，以难化也，故食芡必细嚼，使华液流通，转相灌输，其功胜于乳汁。

那鸡头实呢，一三十五味，鸡头实就是我们的芡实，我们又有个名称称它为鸡头米。

诸位看，这个一三十四味，这是蓬蘽，就是覆盆子长的这个样子，这个鸡头实就是我们芡实，长的这个样子，诸位可以传阅看一下。

那这个芡实呢，你看白色的一粒一粒的，长的象米一样米粒的。

味甘淡，就是甘淡渗利的药，是属于阳药，我们可以平常都可以补中，平常都可以吃的，没事都可以拿来吃的，为固本益精要药。

那腰膝酸痛，平常呢回家你可以煮些汤剂，象四臣汤啊你们可以煮啊，芡实就在这个地方，这是入《神农本草经》的，能够开胃助气。

能收湿气，能够健脾。

所以我们过去只要是健脾，要让脾胃功能很强，我们要靠甘淡渗利的药，象这些药都是甘淡渗利的药。

剂量的话可以开2钱3钱都没有关系。

这些药都是没有毒的，都是平常可以当饮食来吃的。

这个是鸡头实。
