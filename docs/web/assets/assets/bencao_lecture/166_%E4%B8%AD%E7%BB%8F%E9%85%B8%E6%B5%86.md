# 中经·酸浆

**【本经原文】** 味酸，平，无毒。治热，烦满，定志，益气，利水道。产难，吞其实立产。生川泽及人家田园中，一名醋浆。又名洛神珠。灯笼草。

**【产地】** 田园之中。

**【性味】** 其根及苗味苦，性寒。酸浆果味酸，性平。

**【主治】** 其苗，叶，根，茎皆为解热，排水药，治百日咳，黄疸，小便赤涩，果能催生。

**【别录】** 酸浆果主治烦热，定志益气，利水道，难产吞之，立产。

**【弘景】** 酸浆捣汁服，治黄病多效。

**【唐本】** 灯笼草治上气咳嗽，风热，明目，根茎花实并用。

【苏颂】酸浆果食之除热，治黄疸，尤宜小儿。

**【用量】** 一般一钱至四钱。

**【禁忌】** 孕妇禁忌。

第一百八十三，那我们这里没有一百八十三这个药，这个为什么呢，因为一百八十三根据我的想法和考证，就是你们吃的洛神，什么洛神茶，酸酸的那个洛神果，就是它。

到处田园之中都有。

别名又叫洛神珠，也叫做灯笼草，圆圆的一颗。

很甜，你们喝的洛神茶酸酸的，好像酸梅一样，很好吃的。

如果一个法医说吃洛神茶死掉了，这个法医应该被开除，执照被吊销——蠢嘛。

这种本身味酸的东西，都是有收敛的效果。

你看看它的性味，它的根、它的苗是味苦性寒。

酸浆果味酸，性平。

酸味的东西呢，它能够治烦热，定志益气，平常你可以当茶来喝，很好。

主要的呢，我们平常使用的时候，都是，比如说心情烦躁，夏天，你心情烦躁，口渴，都可以是这个洛神，酸浆酸浆果，洛神来泡茶。

这个药呢，一般我们除了汤剂里面放以外，泡茶都可以。

你如果有自己中医诊所，那你在台湾，病人来等，你很忙嘛，煮一点菊花，杭菊。

煮菊花茶放点洛神，酸酸甜甜的噢，甘草在里面，这个远志，一点点远志，因为这个比较苦嘛，病人在那边等就很开心，不会烦躁……等那么久还不来。

很开心，所以可以煮点茶给他吃，洛神吃了很宁心静气。

然后那个病人以后就会产生疑问，为什么每次到你的诊所来心情都很好，就是这个，一直在吃。

当然你可以加点蔗糖，放点蔗糖下去更好。
