# 中经·败酱

**【本经原文】** 一名鹿肠．味苦，平，无毒。治暴热，火疮赤气，疥瘙，疽，痔，马鞍热气。生川谷。

**【产地】** 处处有之，生川谷间。

**【性味】** 味苦（或作咸），性平（或作寒），无毒。

**【主治】** 败酱草主治赤眼，障膜，弩肉，聤耳，痈肿结热，破凝聚血，化脓为水。

**【别录】** 除痈肿，浮肿，结热，风痹不足，产后痛。

**【甄权】** 治毒风瘰痹，破多年凝血，能化脓为水，产后诸病，止腹痛，余疹烦渴。

**【大明】** 治血气心腹痛，破症结，催生落胞，血运鼻衄，吐血，赤白带下，赤眼障膜，弩肉，

聤耳，疮疖疥癣，丹毒，排脓补瘘。

**【用量】** 普通一二钱。

**【禁忌】** 忌葱，性专下泄，无瘀者忌。

下一味药很妙，这味药呢，名称，《本草》呢，叫做败酱，其实就是败酱草。

我有个病人，痛十五年，西医查不出来怎么回事，是英国人。

她先生是做剪头发，那我找他剪头发坐那边，他就跟我抱怨，他在那边讲，我又不能回嘴，万一他卡擦。
