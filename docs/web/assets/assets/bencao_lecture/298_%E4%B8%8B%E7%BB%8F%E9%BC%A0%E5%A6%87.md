# 下经·鼠妇

**【本经原文】** 味酸，温，无毒。治气癃不得小便，妇人月闭，血症，痫，痉，寒热，利水道。

生平谷及人家地上。一名负燔，一名蝛。

这个343，344，345蜣螂，346，蝼蛄，347马陆、地胆、鼠妇，这些药我们临床上使用的时候很少，几乎都没有人使用它，诸位可以看，雀瓮，344 这个还用的比较多，雀瓮就是我们常常解释的蝉蜕，我们前面本草经，我常常之前就跟大家讲过的，有些药它会重复的原因是什么，因为地方的方言说出的不一样，不一样就误解视为两种药，实际上是一种，因为地方方言的关系，那这个雀瓮就是蝉蜕，知了，夏天的时候在叫，味甘，咸寒。

任何的蝉蜕，你看像蛇蜕，蜕皮的东西呢，甲壳类蜕皮的东西，都能够退眼睛的翳，所以治疗眼科的时候我们都会使用它。

诸位看，如果说我们用秦皮，然后呢蝉蜕，就你们现在得到的知识我们来看蛇蜕这几位药，那如果说秦皮我们用三钱，蝉蜕五分，然后一剂三碗水煮一碗，不多啊，然后过滤掉，用这来点眼药水，很好啊，内服都可以，中医中药就有这样的好处，外面去点眼药水，有秦皮在里面，可以止痛止痒眼睛的红肿刺痛，消炎，像那个结膜炎，角膜炎，那去眼翳的障碍，生白内障眼翳的东西，内服也可以，你看这个蝉蜕，跟这个蛇蜕呢，在26页最下方最后面，它的意思是除了眼翳以外还有小孩子哑病，阴囊肿起来都可以使用这个蝉蜕。

当然蛇蜕也可以使用，我们今天介绍到这里。

三五〇、萤火

**【本经原文】** 一名夜光。

味辛，微温，无毒。主明目，小儿火疮，伤热气，蛊毒，鬼疰，通神精。
