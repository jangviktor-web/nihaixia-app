# 增补·鸡子黄

本经无记载。

**【产地】** 处处有之。

**【性味】** 味甘性平。

**【主治】** 镇心安脏，益气补血。清咽开音，散热定惊。止嗽止痢，利产安胎。用醋煮食，治赤白久利。胎衣不下，吞卵黄二三枚，解发刺喉，令吐即下。取蛋壳，细研，调以麻油，擦痘毒神效。

**【用量】** 一般一日二三枚。

**【禁忌】** 多食另人滞闷。[1.升麻、黄连汤，外涂、涮口，可去口舌嘴脓疮。]

那第19鸡子黄，鸡子黄就是鸡蛋黄，那这个怎么找你们自己去找，你到药房说我要一颗鸡蛋黄，人家把你赶出来了。

**【主治】** 呢它能镇心安脏，益气补血，清咽开音，能够清咽开音。

鸡蛋黄其实是一个导引的药，所以我们所谓君臣佐使，这个所谓的，你这个补血的药，要补到心脏里面去，那心中有一滴血，心脏的正中心有一滴血，这一滴血是永远是新鲜的，那新的血去取代旧的血，新的血经过心脏的时候把旧的血踢出来，速度是这样子，一直是新的血去换旧的血，所以是心中一滴血永远是新鲜的，这是正常。

所以要学好医学，你要知道什么叫正常，那有一天呢，突然被惊吓到，或者是一些事情影响到扰心烦心，这滴血瞬间消失掉了，消失掉的话心脏这个血，还是有血通过心脏啊，但是是这样子过去的，那一滴血不见了，那我们大家都知道阿胶能够补血的啊，前面那个阿井的那个水啊，潜在地下的水啊，要煮出来那个驴皮，熬出来驴皮啊，那个补血，那你身上很多地方都补啊，要补的话你怎么知道光阿胶补下去的话，补到肝脏、补到肺脏、补到血管里面去，那有补到心脏那么凑巧，所以我们要有一个药，导引阿胶，来告诉阿胶说，你要在心脏中间制造一滴血出来。
