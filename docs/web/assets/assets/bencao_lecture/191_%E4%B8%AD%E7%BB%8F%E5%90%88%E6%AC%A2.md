# 中经·合欢

**【本经原文】** 味甘，平，无毒。主安五脏，和心志，令人欢乐无忧。久服轻身，明目，得所欲。

生山谷。一名蠲忿，一名夜合。

**【产地】** 山中有之。皮供药用。

**【性味】** 合欢皮味甘，性平。

**【主治】** 为合血，消肿，止痛药，治筋骨折伤及肺痈吐脓。

**【大明】** 煎膏消痈肿，续筋骨。

**【用量】** 一般二至四钱。

**【禁忌】** 无禁忌。

诸位看，这合欢呢就长这个样子。

这个合欢皮味道是甘味的，看它的名字就知道，合欢嘛，令人欢乐无忧，吃下去就会很开心。

西药也有开心的药，中药也有，合欢皮，一名夜合，那这个合欢呢主治活血消肿，止痛的药，一般在筋骨的折伤还有情绪不好的时候我们会加一些合欢下去，让心情变好，张仲景，在肺痈呕吐脓血的时候，会用到合欢。

一般来说消肿还有续筋骨都可以使用合欢，所以合欢的用途蛮多的，它的味甘，甘味的药都有一点滋补的功能在里面。

这个药没什么禁忌。

后面开始呢，是些动物性的药。
