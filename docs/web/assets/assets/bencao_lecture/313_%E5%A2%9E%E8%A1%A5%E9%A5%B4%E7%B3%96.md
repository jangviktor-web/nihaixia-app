# 增补·饴糖

补中益气

**【产地】** 处处有之，乃以米麦制成者。

**【性味】** 味甘，性温，无毒。

**【主治】** 饴糖为滋润肺脾，健胃补中要药，主补虚冷，益气力，治胃气枯燥，脾弱不运。

**【别录】** 主补虚乏，止渴，去血。

【思邈】补虚冷，益气力，止肠鸣咽痛，治唾血，消痰，润肺止嗽。

【孟铣】健脾胃补中，治吐血，打损瘀血者熬焦酒服，能下恶血，又伤寒大毒嗽，于蔓青薤汁中煮一沸，顿服之良。

【宗奭】脾弱不思食人多用，能和胃气，亦用和药。

**【用量】** 普通二钱至三钱。

**【禁忌】** 丹溪曰，饴属土，成于火，大发湿中之热，多食助脾风，能生胃火，此损齿之因，凡中满呕吐，酒病、牙疳，肾病及湿热证，不得轻投。

第八个饴糖就是现在外面卖的麦芽糖，诸位呢如果你跑到夜市去买麦芽糖品质肯定不好，你要跑到中药行去买麦芽糖那个最好，因为那个中药的麦芽糖是品质挑过的，入药的麦芽糖的质最好，那这个麦芽糖呢平常，米麦制成的嘛用米麦慢慢熬出来的，味甘性温。

这个麦芽糖饴糖就是麦芽糖滋润肺脾的药，健胃补中补虚冷，张仲景呢我们常常他在用建中汤里面放些饴糖，讲得就是麦芽糖，这个麦芽糖不是放进去煮。

煮了就没有力量了，它已经熬过十二个小时以上了，有时候一天一夜熬出来，慢慢熬出来那个糖浆，那你是煮完汤药以后事后喝之前呢要加温，要把麦芽糖呢拿一勺进去融化一下，这是饴糖，那能够补虚乏，止渴，去血。

所以一般来说是健脾胃的要药，很好吃很甜，那一般来说胃口如果不开，我们煮药的时候就会放一点饴糖下去，饴糖能够补中益气，当然不一定要建中汤，你平常的汤药里面病人气很虚的时候你都可以加些麦芽糖进去，尤其是小朋友，小朋友喜欢吃甜的啊，苦的中药不要吃，你煮好汤药加点麦芽糖在里面他就很喜欢去喝啊，那这个
