# 上经·蓬蘽

**【本经原文】** 味酸平，安五脏，益精气长阴，令坚强志，倍力有子，久服轻身不老．今名覆盆子。

**【产地】** 处处有之，多生于山野向阳之林木中。

【采集加工】夏初果实由绿变绿黄时采收，除去梗、叶，置沸水中略烫或略蒸，取出，干燥。

**【性味】** 味甘酸，性微温，无毒。

**【主治】** 覆盆子为补涩要药，主益肾脏，缩小便，起阳事，固精液，治遗尿遗精。

【藏器】食之令人好颜色，榨汁涂发不白。

**【甄权】** 主男子肾精虚竭阴痿，能令坚长，女子食之有子。

【宗奭】益肾脏，缩小便，取汁同少蜜煎为稀膏，点服治肺气虚寒。

【括要】补虚续绝，强阴健阳，悦泽肌肤，安和五脏，温中益力，疗劳损风。

**【用量】** 普通一钱至二至三钱。

**【禁忌】** 小便短涩者不宜。（今之前列腺肿大或是癌症均不宜。）

【伏龙山下的人】相关论述1、《本草通玄》：“覆盆子，甘平入肾，起阳治痿，固精摄溺，强肾而无燥热之偏，固精而无疑涩之害，金玉之品也。”2、《本草正义》：“覆盆子为滋养真阴之药，味带微酸，能收摄耗散之阴气而生精液，故寇宗奭谓益肾缩小便，服之当覆其溺器，语虽附会，尚为有理。《本经》主安五脏，脏者阴也。凡子皆坚实，多能补中，况有酸收之力，自能补五脏之阴而益精气。凡子皆重，多能益肾，而此又专入肾阴，能坚肾气，强志倍力有子，皆补益肾阴之效也。《别录》益气轻身，令发不白，仍即《本经》之意。惟此专养阴，非以助阳，> 《本经》、《别录》并未言温，其以为微温微热者，皆后人臆测之辞，一似凡补肾者皆属温药，不知肾阴肾阳，药物各有专主，滋养真阴者，必非温药。”再来呢，第134味药，这个是蓬蘽，蓬蘽那个字念[lěi]，现在我们叫做覆盆子。

三个田，这个念虆[lěi]这是现在所谓的覆盆子。

我们前面跟诸位提过，菟丝子这味药已经被列为保护了，这个植物保护，因为快绝种了，被人家吃太多快绝种了。

大家以后用覆盆子就不用菟丝子，覆盆子就可以了。

籽类的东西都可以强筋健骨，能够补精。

你看看本草经，本经的原文，味酸平，安五脏，益精气长阴，令坚强志，倍力有子。

那这个覆盆子呢，主治是补涩的要药，缩小，你小便太频，老年人小便太频繁，你可以加覆盆子进去。

那阳不举我们可以起阳事，固精液，所以覆盆子非常好用，那【藏器】呢，藏器是陈藏器，一个医生。

食之令人颜色会很好，可以涂发就不会变白。

因为他入肾，肾主头发的品质，头发越黑越亮代表肾气越旺，这个覆盆子是很便宜的药。

那【括要】补虚续绝，所以如果说夫妻两个要生小孩，两个都比较虚寒，里寒的时候都可以加覆盆子，剂量呢1钱2钱3钱看个人的体质，看病人的身体大小。

那禁忌呢，小便短涩者不宜。

这个讲的是里面有炎症，有发炎啊，有热证，那不要用。

一般有肿大有热证的时候，我们用攻坚的药。
