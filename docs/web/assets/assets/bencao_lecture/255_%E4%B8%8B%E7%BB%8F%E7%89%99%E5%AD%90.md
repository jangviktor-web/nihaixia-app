# 下经·牙子

**【本经原文】** 一名狼牙。味苦，寒，有毒。治邪气，热气，疥瘙，恶疡，疮，痔，去白虫。生川谷。

**【产地】** 山中处处有之。

**【性味】** 味苦，性寒，有毒。

**【主治】** 为解毒杀虫要药，治风搔，恶疮，驱寸白条虫。

**【甄权】** 治浮风搔痒，煎汁洗恶疮。

**【大明】** 杀腹臓一切虫，止赤白痢，煎服。

**【禁忌】** 内服须慎重

292味，这叫牙子，牙子是古名的牙子，现在称之为狼牙。

这狼牙呢，经方里面使用，在妇人阴中有疮，阴疮，不能收口，因为阴部里面有津液，是润滑的地方，所以说，有伤口在里面的时候，非常不容易收口，因为他不是干的嘛，是湿的，这个时候，我们用狼牙来治疗，哦，外敷的，你看哦，为解毒杀虫的要药，看到没有，主治：能驱寸白条虫、蛔虫。

一般来说，狼牙，煮过汤以后，用那个棉棒，放到狼牙汤里面泡，泡了这后塞到阴道里面去，能够治得那个疮，一般来说，这个狼牙呢都是外用，很少有内服的。
