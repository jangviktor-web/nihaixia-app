# 下经·葶苈

**【本经原文】** 味辛，寒，无毒。治症瘕，积聚，结气，饮食寒热，破坚，逐邪，通利水道。生平泽及田野。一名大室，一名大适。

**【产地】** 产我国河南陕西河北一带，有甜苦二种，今俱以甜者入药，且多以荠子或折蓂子混充，

苦者绝少。

**【性味】** 味辛苦，性大寒，无毒。

**【主治】** 葶苈子为下气行水要药，功能降肺气，逐痰饮，止喘促，下膀胱水，治面目浮肿。[

1.葶苈子、大枣常配伍。葶苈行气下水很强，加大枣保护胃气。]

**【别录】** 下膀胱水伏留热气，皮间邪水上出面目浮肿，身暴中风，热沸痒，利小便，久服令人虚。

**【甄权】** 疗肺壅土气咳嗽，止喘促，除肺中痰饮。

**【容川】** 葶苈子多油，当能滑利，又有辛味，舆巴豆之辛有油相似，其味苦，与大黄之苦而滑润相似，故葶苈子隐含巴豆舆大黄二者之性，故能大泻肺中之痰饮脓血，性极速降，是猛药类，故仲景配以大枣补之，入药前须要炒过，不炒则不香，不能散。

**【药征】** 主治水病也，旁治肺痈结胸也。

【灵胎】泻肺气，利水道。

**【用量】** 普通八分至二、三钱。

**【禁忌】** 肿满由脾虚不能制水，小便不通，由膀胱虚无气以化者均忌，肺气虚者亦忌，宜大枣为辅、恶僵蚕。

两百七十一，葶苈，葶苈子。

我们遇到在经方里面使用的药，很多的时候，我速度会放慢下来，尽量会讲得很详细。

有的用不到，就跳过去了。

葶苈子，经方里面使用的。

这个葶苈子呢，诸位看，本草经的原文它是味辛寒，性是寒，无毒，也是治肿块啊，利水道，一般来说我们治疗肺癌的时候，会用到葶苈子。

那这个【产地】，在河南陕西河北这一带，有甜苦两种，现在都是以甜的入药了，这是我们现在药房的，多以荠子或者折蓂子来混充，苦味的很少，原来的葶苈子是味苦的。

诸位，这是葶苈子，诸位可以打开来，放一两粒在舌头上尝尝看，是苦味的还是甜味的。

葶苈子呢是排肺水，也是很好使用的一种药。

诸位看【主治】，为下气行水要药，功能降肺气，能够止喘，喘咳一般喘得很厉害，肺气往上逆，气下不下去，我们用葶苈子，为什么会这样子？因为肺是肾脏的妈妈，所以肺是肾水的上源，上源嘛，所以肺法像天幕，好像天上的云一样。

那你这天上的云只在那面，只停在天上不下雨啊，是不是很闷热？你好希望真下雨，那云在上面又不下雨，这个最难过，葶苈子就这样，把云下来变成雨！葶苈子能下肺气，所以说它能够治喘、喘气，非常好用。

由于水在上面，就会有面目浮肿这种现象，脸肿，都可以使用葶苈子。

很多妇人脸肿的原因呢，早上起来脸胖、厚厚的，下面有水一样，老师我为什么早上起来脸肿肿的，那就是葶苈子。

这是肺里面的水。

一般来说我们去水的时候，这个肺里面的水去掉以后，得教妇人——太太多运动，她们有的很少运动，不太出汗嘛，很少运动，所以水停在里面排不出去。

**【甄权】** ，除肺中的痰饮，所以很多药可以治疗肺。

临床上我们有选用，选用的法则呢，我们以经方为主，以张仲景的处方为主，他的条辨、辨证为主。

【唐容川】，他说葶苈子多油，凡是有油脂的你像当归啊、柏子仁、麻子仁、酸枣都有油脂，杏仁都有油脂，都能够滑利。那葶苈子辛辣，葶苈子隐含在—介于巴豆与大黄二者之间的药，也是猛药。一般处方呢，葶苈子用三钱、四钱都在使用，但是我们单用葶苈子是不会这么用的，如果用了葶苈子的时候，我们会用大枣，为什么？因为葶苈子它它下水的力量很强，它会伤到胃气、胃的津液，所以我们要用红枣，比如大枣十枚，十个大枣，来保护他的胃。

**【药征】** ，它是治水病，旁治肺痈结胸，利水道。

一般来说，如果肺里面有积水的时候，病人呢都没有办法平躺，在没有办法平躺的状态之下，在经方里面分好几种处方。

甘遂半夏汤、十枣汤、葶苈大枣泄肺汤，那这些汤剂怎么个使用？我们在介绍金匮、伤寒的时候，再详细给大家讲，务必让你知道何时可以使用。

同样是积水，张仲景的处方不一样，所以我们等到——大家有个概念，有葶苈子在这里排水就可以了。

等到我们讲经方的时候再回头看看，张仲景在想什么，所以就可以把《胎胪药录》原貌还原出来。

张仲景一定有看到有些东西我们没有看到的，不然，哇，怎么那么清楚呢，这个时候用葶苈子，那个时候用甘遂半夏，对不对，这个时候不用半夏了，用十枣汤里面有，甘遂、芫花、大戟啊，为什么舍掉半夏？很厉害啊！【禁忌】：诸位看，肿满由脾虚不能制水，小便不通，由膀胱虚无气以化者都不可使用葶苈大枣，这个上面的“脾虚不能制水”，肝癌、肝硬化的腹水就是这样子，所以不会用葶苈子。

那膀胱虚无气，没有办法气化，水不能出来，我们用炮附子，这种症状，都不会使用到葶苈子。

所以葶苈子呢，肝癌腹水一般不会用到，肺里面有水的时候使用它。

像这种沙子、像一粒粒小种子的，葶苈子小种子嘛，你煮的时候你也可以放到那个那个棉布袋里面包起来，你不包也可以，一煮的话那个到处跑，和旁边的药粘着，只此而已，那你倒出来的时候，再用滤网把它滤掉就可以。
