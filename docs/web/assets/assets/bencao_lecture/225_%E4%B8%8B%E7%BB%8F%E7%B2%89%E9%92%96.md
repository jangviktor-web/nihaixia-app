# 下经·粉钖

【本绖原文】味辛，寒，无毒。治伏尸，毒螫，杀三虫。锡镜鼻，平。治女子血闭，症瘕，伏肠，绝孕。生山谷。一名解锡。

**【产地】** 以醋蒸铅化合而成，日本产此甚多，我国亦有制出，色白，故亦曰白粉，以其为铅所化，故亦曰铅粉。

**【性味】** 味辛，性寒，无毒。

**【主治】** 粉锡为外用要药，作膏药，治溃疡，制妆品，除皮病。

**【别录】** 去鳖瘕。疗恶疮，止小便利，堕胎。

**【甄权】** 治积聚不消，炒焦止小儿疳痢。

**【大明】** 治痈肿瘘烂，呕逆，疗症瘕，小儿疳气。

**【用量】** 普通皆外用，内服甚少，即用，亦宜轻量。

**【禁忌】** 粉钖用以制妆品，久用蚀血，反使面色不华，故妇女常用粉者，去粉则面黄，且少血色。

第258粉锡，是外用的药，不内服的。

粉锡，锡类的，都是外用。

一般来说，毒虫咬伤，虫蛇咬伤，解毒的都可以使用，那产地呢，这个是用醋来蒸铅得到的，我们也叫做铅粉，味辛性寒无毒，这个粉锡呢，是外用药。

大家看[别录]，会用到粉锡的地方就是皮肤的硬块，这个病名叫鳖瘕，就是你皮肤生的硬块，硬的像鳖壳一样，硬壳很硬一块，这个硬疮生在皮肤表面上面，不痛又不痒，这个时候我们会使用到粉锡，这个是治疗皮肤病用的。

这个里面的使用呢，诸位可以参考一下书上面写的。

一般来说，过去的化妆品使用，使用太多反而不好，使用太多会伤到血，一般来说我们对皮肤上的硬疮，就直接撒一点在上面，涂在上面都没有关系，这个外用药。
