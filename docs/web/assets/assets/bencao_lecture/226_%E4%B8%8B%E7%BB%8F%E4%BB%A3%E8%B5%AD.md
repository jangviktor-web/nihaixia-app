**【性味】** 味苦甘，性寒（或作平），无毒。

**【主治】** 代赭石为镇虚祛，养阴血要药，功能避邪毒，治气逆，痰逆，反胃，血中热，血痹，

**【禁忌】** 下部虚寒及阳虚阴痿者忌，胎前慎用，畏天雄附子，凡使，醋淬，研末，水飞用。
