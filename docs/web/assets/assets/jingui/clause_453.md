#### 气利，诃黎勒散主之。

> 气利，诃黎勒散主之。

诃黎勒散方：诃黎勒（煨）十枚。右一味为散，粥饮和，顿服。

**倪海厦解读**：

气利就是屁放得很多，这时候用诃黎勒散，它也能够利小便，专门止气利的。诃黎勒这个药本身是收敛、顾肠的，但是它跟赤石脂、禹余粮不一样，是一种行肠气的药。

病人放一大堆屁出来，结果摸肚子又咕噜咕噜肠鸣得很厉害，拉又没有什么水或大便出来，放出来的全部都是屁，有时屁带一点水这样喷出来，可是里面没有甚多水在里面——这就是诃黎勒散证。

诃黎勒散一定要先把它煨熟，就是先烤黄，烤得很干再打粉。因为诃黎勒也是一个固涩的药剂，你若直接拿生用打成细粉，吞下就会卡在喉咙这里，结果气利还没治好。

这一篇最后，大家看气利：若病人从诊所门口进到办公室，一路放屁过来，已经看完了，你不用讲话，他也不用进来了，马上打电话给药房——诃黎勒，一定要煨过、烤熟以后给他吃，这是散剂，吃下去要用米粥和服，外国人没有吃稀饭，用面汤也可以。

就是小肠里面有宿便，大肠里面没有，可是他又不是小承气汤证。为什么？小承气汤证的话便秘，他没有，他还是会排大便，但是沼气就一直排出来，这时候要加些收敛的药。这个症状用得不多，所以你诃黎勒可以烤一次放在冰箱里等他，平常很少用到。
