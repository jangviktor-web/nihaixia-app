#### 问曰：新产妇人有三病：一者病痉，二者病郁冒，三者大便难，何谓也?

> 问曰：新产妇人有三病：一者病痉，二者病郁冒，三者大便难，何谓也?

**倪海厦解读**：

**新产三病：一者病痉，二者病郁冒，三者大便难**，为什么？

| 三病 | 成因（原文） | 治法 |
|---|---|---|
| **病痉** | 新产血虚，多汗出，喜中风 → 故令病痉 | 柔痉用**栝蒌桂枝汤**；刚痉用**葛根汤** |
| **病郁冒** | 亡血复汗，寒多 → 故令郁冒 | 血不足之虚证：心情忧郁、闷闷不乐、头昏（类产后忧郁） |
| **大便难** | 亡津液、胃燥 → 故大便难 | 用**麻子仁丸**缓润，**不可用承气汤强攻** |

**关键一句**：产妇本就血虚，若用承气大下，本来不虚的都被你弄虚了；麻子仁丸是慢慢润肠，让大便轻松排出，不必用强药攻。

**生活面**：古时坐月子四十天，门窗缝隙都用棉被塞满，就怕产后气血两虚时受风——正对应「喜中风」这一句。
