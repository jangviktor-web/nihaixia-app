#### 气分，心下坚，大如盘，边如旋杯，水饮所作，桂枝去芍药加麻辛附子汤主之。

> 寸口脉迟而涩，迟则为寒，涩为血不足。趺阳脉微而迟，微则为气，迟则为寒。寒气不足，即手足逆冷；手足逆冷，则营卫不利；营卫不利，则腹满胁鸣相逐，气转膀胱，营卫俱劳；阳气不通即身冷，阴气不通即骨疼；阳前通则恶寒，阴前通则痹不仁；阴阳相得，其气乃行，大气一转，其气乃散；实则失气，虚则遗溺，名曰气分。

> 气分，心下坚大如盘，边如旋杯，水饮所作，桂枝去芍药加麻辛附子汤主之。

桂枝去芍药加麻黄细辛附子汤方（又名桂甘姜枣麻辛附子汤、桂姜草枣辛附汤）：桂枝三两（去皮），生姜三两（切），甘草二两（炙），大枣十二枚（擘），麻黄二两（去节），细辛二两，附子一枚（炮，去皮，破八片）。上七味，以水七升，煮麻黄去上沫，内诸药，煮取三升（一本作二升），分温三服。当汗出，如虫行皮中，即愈。

**倪海厦解读**：

这一段在经方史上一直是个谜团，很多经方家来解释。整个讲的是「气分」。

**三证之分：气分 / 水分 / 血分**：
- 阴阳气在转的时候分两证：本条讲的是**气分**
- **水分**是另一证；讲到**血分**就是阴实证——肝硬化、脾脏病、肺癌都归血分

**脉：寸口（阳脉）与趺阳（胃脉）**：
- 寸口脉迟而涩——迟则为寒，涩则为血不足
- 趺阳脉微而迟——微则为气（不足），迟则为寒

**阴阳的走行：一个「8」字**：
- 腹为阴、胸为阳；**肚脐是阴阳的交汇点**
- 阴的走向顺着大肠——升结肠、横结肠、降结肠（顺时针一圈），逆着走就不成阴
- 阴转一圈回来接阳；阳从脐跨上去、到肋间再回头走下来——这就是「大气一转」

**什么叫正常人：上冷下热**：
- 健康标准中医一直没讲清，西医定的标准太低（验血都在指数内，实际脚冷手冷、里有留饮浮饮）
- 阴阳协调时，阳中必有阴、阴中必有阳：头面属阳而摸之是凉的，下肢属阴而实际是温的
- 故**正常人上冷下热**；一变成**上热下冷**就该动手了，别等肿很大

**病机：卫气太寒，水不化气**：
- 卫气太寒、胸腔也寒，上下皆寒
- 饮水入胃不能完全消化——所谓「气分」就是肠胃（气分）的力量不够，喝进去的水**没有办法气化**
- 此时五脏并无重病，只是水化不成气（水比气冷、看得见），入不了肝脾肾，而肺又冷
- 水积在循肋骨一圈，成一个大圆盘 → **心下坚大如盘，边如旋杯**（硬块是寒造成的），肚子变大
- 一句话：**阳不够，阴才会积**，津液累积在此

**症状解释**：
- **手足逆冷**——手脚温度反映肠胃温度；胃经走到脚上，所以胃寒则脚冷
- **营卫不利**——上焦为气、下焦为血；不利则腹满胁鸣（肋骨处有水声）
- **中膈被寒堵住**：阴在下面自己转、阳在上面自己转，整个人身上的「8」被中间隔断
- **阳前通则恶寒**（上寒→自觉身冷）；**阴前通则痹不仁**（下寒→肌肉麻痹不仁，脾主少腹、主肌肉）
- **实则失气，虚则遗溺**——实是寒湿盛、食物堵久生沼气而多屁；虚是里寒、小便不能气化而漏出
- **阴阳相得，其气乃行，大气一转，其气乃散**——阴阳必须互相协调才循环，这也是练功以肚脐为中心旋转的道理

**处方思路：去白芍、重用桂枝、麻辛附**：
- 去白芍——白芍是阴药，本就阴太盛，不可再加阴
- 重用桂枝——要行阳靠桂枝，桂枝能把心火导到小肠
- 麻黄、细辛、附子统统是阳药；这是**少阴证**，专去下焦寒实
- 寒实与阴实不同：实是东西堵到要化解，寒像冰块要溶解——所以用麻黄附子细辛汤这一组

**剂量与煎服**：
- 倪师参考：桂枝三钱、生姜三钱、细辛二钱、麻黄二钱、炮附子一钱；六碗水煮两碗（七碗亦可）
- 麻黄按体格加减：体格大可三钱，小者二钱，小 baby 半钱；心脏受不了就别用四钱
- 先煮麻黄去上沫；麻黄量放小时一次煮完也行

**服后反应**：
- 「当汗出，如虫行皮中」——大气在转、阴阳协调之象；皮肤有阴阳、肌肉有阴阳、连脾脏的膜也各有阴阳，一行阳，各处阳都跟着动
- 倪师：**一剂就知**，水就退掉，阳气很壮
