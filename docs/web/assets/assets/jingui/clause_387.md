#### 趺蹶手指臂肿转筋狐疝蛔虫病脉证治第十九

> 趺fu一声，蹶jue二声。

**倪海厦解读**：

**什么叫趺蹶**：走路的一种病——往前走没问题，但**不能停**，一停就像要摔倒，必须赶紧往前多走几步才稳；要左转时得先在原地转身才能走。脚不能随意转动，就是趺蹶。相书上称「**禹步**」——相传大禹治水长年站在水中，寒湿侵入骨节而致。

**一个实用场景**：太太小姐穿高跟鞋走楼梯摔倒，伤到尾椎骨——若早上受伤下午就来看诊，可见委中与承山之间出现青筋，表示有瘀血堵住。此时**不要扎针，用放血针把青筋表皮刺破、挤点血出来**即可。

**原文**：病趺蹶，其人但能前、不能却，刺腨（小腿肚）入二寸，此太阳经伤也。
