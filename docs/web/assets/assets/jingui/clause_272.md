#### 师曰：寸口脉迟而涩，迟则为寒，涩为血不足;趺阳脉微而迟，微则为气，迟则为寒。寒气不足，即手足逆冷;手足逆冷，则营卫不利;营卫不利，则腹满胁鸣;相逐气转，膀胱营卫俱劳，阳气不通，即身冷，阴气不通，即骨疼。阳前通则恶寒，阴前通则痹不仁。阴阳相得，其气乃行，大气一转，其气乃散，实则矢气，虚则遗溺，名曰气分。

> 师曰：寸口脉迟而涩，迟则为寒，涩为血不足;趺阳脉微而迟，微则为气，迟则为寒。寒气不足，即手足逆冷;手足逆冷，则营卫不利;营卫不利，则腹满胁鸣;相逐气转，膀胱营卫俱劳，阳气不通，即身冷，阴气不通，即骨疼。阳前通则恶寒，阴前通则痹不仁。阴阳相得，其气乃行，大气一转，其气乃散，实则矢气，虚则遗溺，名曰气分。

**倪海厦解读**：

这是「气分」条的脉证部分，与下一条「气分，心下坚大如盘」合看。

**脉**：寸口（阳脉）迟而涩——迟则为寒，涩则为血不足；趺阳（胃脉）微而迟——微则气不足，迟则为寒。

**阴阳的走行是个「8」字**：腹为阴、胸为阳，**肚脐是阴阳交汇点**；阴随大肠（升→横→降）走一圈回来接阳，阳从脐上肋间再回头下行。

**正常人的标准是「上冷下热」**：头面属阳而摸之凉，下肢属阴而反温热。一旦变成上热下冷，就该动手了。

**病机一句话**：卫气太寒、胸腔亦寒 → 水入胃不能气化 → 入不了肝脾肾，积于循肋骨一圈 → **阳不够，阴才会积**。
