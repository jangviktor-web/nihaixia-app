#### 问曰：阴病十八，何谓也?

> 问曰：阴病十八，何谓也?

> 师曰：咳、上气、喘、哕、咽、肠鸣、胀满、心痛、拘急。五藏病各有十八，合为九十病；人又有六微，微有十八病，合为一百八病，五劳、七伤、六极、妇人三十六病，不在其中。

> 这里都不用记，就算考医师执照，也不会考九十病，十八病啊，没有那么无聊。

**倪海厦解读**：

**阴病十八**：咳、上气、喘、哕、咽、肠鸣、胀满、心痛、拘急。（同样是「多数」之意，不必凑数）

**五邪中人，各有法度**——这是本条后半的重点：
- 清邪居上，浊邪居下；大邪中表，小邪中里
- 馨饪之邪（从口入者），宿食也
- 风中于前，寒中于后；湿伤于下，雾伤于上
- 风令脉浮，寒令脉急，雾令皮腠，湿流关节，食伤脾胃
- **极寒伤经，极热伤络**

五邪即风寒暑湿燥热。临证遵循的仍是「阴阳表里虚实寒热」八纲，辨的是**症的变化**，不是病名。
