#### 问曰：病人有气色见于面部，愿问其说?

> 问曰：病人有气色见于面部，愿问其说?

**倪海厦解读**：

张仲景说「鼻头」，就是看**印堂**——相书上印堂叫**疾厄宫**。印堂有横纹，这个人身体里面常常痛（头痛、胃痛之类）；若无痛而有横纹，则多主四十一岁前后事业受阻滞。所以学中医要参考些相书（宫笃相法、神相铁关刀、冰鉴、麻衣相术、柳庄相法），医宗金鉴里的望诊写得并不够细。

**五色主病**：
- 鼻头色**青**——腹中痛；苦冷者死（甚多小孩印堂青青一块，就是肠胃太冷）
- 鼻头色**微黑**——有水气
- 色**黄**——胸上有寒
- 色**白**——亡血
- 微**赤**而非其时者——死
- 目**正圆**者——痉，不治

**印堂青的临床用法**：小孩印堂发青就不吃饭，不是「不好养」，是肠寒——肠胃蠕动太慢，肠子静脉血回流心脏的力量不够。这时用**小建中汤**去肠寒，胃口自然开。
