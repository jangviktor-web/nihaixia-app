#### 二〇三、「阳明病」本自汗出，医更重发汗，病已差，尚微烦不了了者，此必大便硬故也。以亡津液，胃中干燥，故令大便硬。当问其小便日几行。若本小便日三四行，今日再行，故知大便不久出。今为小便数少，以津液当还入胃中，故知不久必大便也。

**倪海厦解读**：

- 二百一十九条，这个很惨这个很惨。本来这个阳明病，本来就自己就流汗出来，肠胃津液都干了，结果，碰到医生，更重发汗。再给他发汗，汗剂下去以后，若这个发汗的话，若他原来还有一点，例如他还有一些，致汗，太阳中风的症状，再给他发汗，病好了。但是，尚微烦不了了者，此大便必硬，大便就开始硬了。那这边意思就是说，医生看他阳明病，这个病的阳明证其实就是有汗的，他一看到，人有汗，桂枝汤，很自动去开桂枝汤。实际上，已经进入阳明了，这个时候，大便，会造成大便更干，为什么，他亡津液。胃，肠胃里面，这里讲肠，里面甚为干燥，所以大便会鞭，大便里面的水分，通通，发表的药，一发汗，大便变的非常硬；这个时候，就问他，你应该问病人，你小便一天几次？若，若本小便日三四行，今日再行；小便并没有改变，所以常常问他小便，你小便当你确定他津液有没有亡失掉的时候，你问他，你小便小便很好，就会知道，你不用担心，人的津液自己会回头，你不需要动他，回头以后，津液回头以后，大便就软掉了，大便自己就会出来。若小便，小便数少，津液当还入胃中，故知不久必大便也，大便，津液回头的意思。
