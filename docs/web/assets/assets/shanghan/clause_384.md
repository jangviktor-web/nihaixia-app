#### 三八四、「伤寒」其脉微涩者，本是「霍乱」，今是「伤寒」，却四五日，至阴经上，转入阴必利；本呕，下利者，不可治也。欲似大便，而反失气，仍不利者，此属「阳明」也，便必硬，十三日愈。所以然者，经尽故也。下利后，当便硬，硬则能食者愈。今反不能食，到后经中，颇能食，复过一经能食，过之一日当愈；不愈者，不属「阳明」也。

> 「伤寒」其脉微涩者，本是「霍乱」，今是「伤寒」，却四五日，至阴经上，转入阴必利；本呕，下利者，不可治也。欲似大便，而反失气，仍不利者，此属「阳明」也，便必硬，十三日愈。所以然者，经尽故也。下利后，当便硬，硬则能食者愈。今反不能食，到后经中，颇能食，复过一经能食，过之一日当愈；不愈者，不属「阳明」也。

**倪海厦解读**：

- 伤寒，其脉微涩，本是霍乱，今是伤寒，却四五日至阴经，阳转入阴，必利，本呕下利者，不可治也。欲似大便而反矢气，仍不利者，此属阳明也，便必鞭，十三日愈。所以然者，经尽故也。下利后，当便鞭，鞭则能食者愈。今反不能食，到后经中颇能食，复过一经能食，过之一日当愈。不愈者，不属阳明也。
- *校注：「便必鞭」之「鞭」，钱超尘考证当作「鞕」（读 ying，隋朝本）。*
- 这一段呢再下一个条辩的时候，他说：「伤寒其脉微涩者，本是霍乱，今是伤寒，却四五日至阴经，阳转入阴，必利，本呕下利者，不可治也。欲似大便而反失气，仍不利者，此属阳明也，便必鞭，十三日愈。所以然者，经尽故也」。
- 中医的文词就是这样，甚多的这个文言文。当在看这个文言文的时候，诸位有个观念：基本上，伤寒，脉一定是浮、紧的脉。所以你摸脉变浮紧的脉，（就是）
- 伤寒，伤寒开麻黄汤。若表寒、里寒，开小青龙汤。表寒里热，开大青龙汤，看他舌头是黄的，口渴，大青龙汤。这就是去伤寒的方式。
- 那若说，现在脉呢是微涩，这个脉变得很小，很细小，那看起来是恶寒，这个，本是霍乱，本来病人有吐利，现在看到有伤寒的症状，那若过了一段时间以后，这个四五日有一个期，过了这个周期以后。若阳转入阴，必利。就是病往深入，在往身体里面走的时候，这个病人会有下利的现象。这是病由表进入里的一种症候。
- 一般而言，若病人出现下利跟呕吐的时候，在过去的中医来说，因为病人呕吐下利，病还在肠胃里面，在肠胃里面，则不要去治他，让他自己恢复。
- 们临床上，（若）有个病人来，你不治他，不可能的（病人要投诉的）。一定要治。
- （这句话）意思是说，若不治他，让他胃气自己恢复的时候，他也会好。
- 那怎么样知道他的胃气自己恢复？病人自己会恢复，就是，病人感觉到好像要大便，没有大便，一直在排气，放屁。所以中医讲的排气，是大肠小肠蠕动开始，蠕动以后，结果食物还堵在小肠里面，还没有出来，但是病人先开始放屁。因为大肠里面这时还没有食物，食物在小肠里面。那蠕动回来的时候代表人的胃气慢慢恢复起来，因为你不是真正的病，是从外面得到的病。身体自己会有机会，自己痊愈。就好像你今天吃坏东西了，吃了不正当的便当，或吃了坏的食物，一般人都可以恢复。重症的人，吃了坏的食物，真的是头痛，一条命都没有了。像你遇到肝癌，或者是遇到什么癌症，那是一吃到坏的食物真的是救都来不及救。
- 像这种情形，他本身就是体格很好，可是，他吃坏东西或是怎么样的，或是当地的湿热很盛造成这样子。那若说排气出来，但是大便还是没有出来的时候：就是阳明症。阳明症出来的时候，大便又会鞭。诸位介绍过，阳明症有两种情形：大肠的、你把它剖面看的时候，若大便的硬块，一块一块的硬块，是围在周围，就中间这一小块，可以通，食物的残渣可以通过，这个时候排出来的时候，便像鞭一样。
- 还有一种，这是第一种情形。第二种情形，也是大承气汤症，阳明症。结果大便整个堵到，很大一块堵到，就是旁边一些小小的缝隙可以通过，小小的缝隙的时候食物的残渣通不过，只有水可以通过。这时病人来就诊的时候也是大便便秘。结果病人说：医生，是下利，你一查，你的下利是便秘引起的下利。？可不可以查到？很简单。
- 舌头伸出来看看，一看，舌根是黄色的，一摸脉，脉一定是数，非常数的，实的，非常有力的脉，同时，小便一定是黄色，深黄色。都是实热症，又实又热。那你说，再确定一下，让病人躺在床上，压压肚脐旁边的天枢穴，一压就痛。你压的时候他拒按。「，医生不可按，按得好难过」，拒按。拒按就是承气汤症。所以们能够辨症的方式甚多，诸位绝对不会弄错，放心好了。
- 那有的人下利甚多，你一按他肚子的时候，「，医生好舒服，你按得好舒服」，喜按。他里面是虚，里面没有东西，这时候你大承气汤下去，是鸡同鸭讲，就会害到病人。那，因为十三日，刚好是两个礼拜，是阳明经尽，所以这个是他自己会恢复的时候。若病在阳明。诸位只要记得，病，进入阳明的时候，不会有死症，不会有死症的[古医家常说阳明无死症]。最初的阳明，就是葛芩连汤症，葛根、黄芩、黄连。
- 这时候病人没有便秘，可能有少许下利少许肚子痛，病在阳明。若便秘以后，开始转成承气汤症。那还有一种，就是刚才讲的承气汤，或者是葛芩连汤，都是腑病，病在腑上面。有种是病在经上面，阳明经上面也是阳明，则是所谓的白虎（汤证）。就是的石膏，会用到（石膏），经病出现的时候，一定是病人有燥热，有口渴，有胃口非常地强大，这种就会是阳明的经病。在阳明症的时候，只看到热症，完全看不到寒症。就当诸位伤寒很熟，法就开始不一样了。这个病人下利以后，当便鞭，鞭则能食者愈。就是，便是结实的，变得硬了，变硬了以后，就会（知道病会传尽）阳明，那就知道他自己会全愈。
- 若说，本来应该是可以吃东西的，阳明症会吃，白虎汤症就是胃口很大的，现在反而不能食。「到后经中颇能食，复过一经能食，过之一日当愈，不愈者，不属阳明也。」这个后面讲的，看起来很复杂，实际上就是告诉诸位，病有没有在阳明。他这个观念就是，若阳明症，就一定可以吃东西的。刚刚介绍到，白虎汤症的时候，病人的胃口很强大，很强大，他吃得很凶，那，这个若不能吃东西，大便又属于鞭的时候，这时候就要小心了，这个病就不是在阳明上面。
