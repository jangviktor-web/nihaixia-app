#### 一一六、微数之脉，慎不可灸。因火为邪，则为烦逆，追虚逐实，血散脉中，火气虽微，内攻有力，焦骨伤筋，血难复也。脉浮，宜以汗解。用火灸之，邪无从出，因火而盛，病从腰以下必重而痹，名火逆也。欲自解者，必当先烦，烦乃有汗而解。何以知之？脉浮，故知汗出解。

> 微数之脉，慎不可灸。因火为邪，则为烦逆，追虚逐实，血散脉中，火气虽微，内攻有力，焦骨伤筋，血难复也。脉浮，宜以汗解。用火灸之，邪无从出，因火而盛，病从腰以下必重而痹，名火逆也。欲自解者，必当先烦，烦乃有汗而解。何以知之？脉浮，故知汗出解。

**倪海厦解读**：

- 微代表是虚，但跳的是数脉，数代表的是热
- 所以微数之脉就是病人是虚热的体质

**实热vs虚热**：

- 白虎汤证是讲阳明热，热在经脉里面，就是白虎汤
- 如果是阳明热，热在大肠、小肠、膀胱
- 热在消化系统里面，就是承气汤
- 白虎汤和承气汤都是热的范围，脉都是很数
- 但是脉会洪大，不会微细

**实热与虚热的治疗差异**：

- 实热要攻实，把去实和去热的药加在一起，就可以攻了
- 虚热要把去热的药加在里面，还要把补虚的药加在里面
- 像吃六味地黄丸，六味地黄丸有什么补
- 桂枝八味丸里面的肉桂和附子下去会很热
- 像虚热的人吃桂附八味丸，虚热会更热，会嘴巴皲裂
- 桂附八味丸来是为了补虚的，以虚热的桂附八味丸要加去热的药在里面
- 可以加黄连、黄芩在里面

**虚热禁灸**：

- 虚热的病人不要灸，要寒湿或纯虚的病人才灸
- 因为火是邪的不是正的，会造成病人虚热而生烦逆
- 追虚逐实，血散脉中
- 并不是虚热的人灸了，血就离开脉了
- 而是血里面有热的人，本来是虚热的人，血里面很热
- 血的热就要往外跑，血里本来是虚热的人，血已经不足了
- 肝里面很热，血的热就要往外跑，血难复也
