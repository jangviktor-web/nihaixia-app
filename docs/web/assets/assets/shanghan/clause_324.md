#### 三二四、「少阴病」饮食入口则吐，心中温温欲吐，复不能吐，始得之，手足寒，脉弦迟者，此胸中实，不可下也，当吐之。若膈上有寒饮，干呕者，不可吐也，当温之，宜四逆汤。

> 「少阴病」饮食入口则吐，心中温温欲吐，复不能吐，始得之，手足寒，脉弦迟者，此胸中实，不可下也，当吐之。若膈上有寒饮，干呕者，不可吐也，当温之，宜四逆汤。

**倪海厦解读**：

- 心中就是讲胃伤寒论你要看懂的话，不能当作心脏，这是胃，胃里面，这个……，胃里面怪怪的很难过，想吐又不能吐，刚开始得到的时候，手脚是冷的，这个是手足冷，跟四逆不一样，这是手脚是冰冷的，脉弦迟者，此胸中饮实，不可下也，当吐之；这个意思是说，你，可见起来很像少阴症，实际上他吃的东西梗到了，或者是鱼，那个鸡骨头，或者什么，或者小孩子，有个铜板，梗到里面，梗到在里面，胸中有饮实，梗到这个地方，要吐它，这个是手足寒，并不是四逆，了解的意思。不是四逆，这是吃东西梗到在食道里面，要吐他，若膈上有寒，胸膈上面有寒，干呕者，就是什么东西都没有，只是恶心不可吐也，急温之，宜四逆（汤），这个就是让你去辨，寒，真正有寒实，或者是，里面有东西堵到了，让你去分辨，这很好分辨，你只要看，你一看那个人的气血，那个急的脸上猪肝色一样，那个都是梗到了，这个是饮实，吃东西吃到，梗到了，；那可见这个人，很虚弱，人脸色苍白一副阴寒的样子，然后干呕，就是恶心，干呕，打嗝，那个都是寒证，一看就知道，所以诸位看伤寒论，不要说，老师，会弄错，不会弄错的！你的，真正在临床上，眼睛一看就知道，不会错的。
