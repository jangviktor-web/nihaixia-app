#### 三〇二、「少阴病」得之二三日，「麻黄附子甘草汤」微发汗，以二三日无证，故微发汗也。

> 「少阴病」得之二三日，「麻黄附子甘草汤」微发汗，以二三日无证，故微发汗也。

**倪海厦解读**：

- 麻黄附子甘草汤麻黄二两去节，甘草二两炙，附子一枚（炮、去皮）。
- 右三味，以水七升，先煮麻黄一二沸，去上沫，纳诸药，煮取三升，去滓，温服一升，日三服。
- 阴病得之2、3 日，麻黄附子甘草汤，微发其汗也，2、3 日，无里症，故微发汗，是，本来少阴症是不发汗的，不发汗，这个为什么可以微发起来，因为你刚开始得到少阴症的时候里寒还没有结很实。这个时候，你稍微发一点汗没有关系，这个时候们可以把细辛换成甘草，甘草能够润肠，你发少许汗没有关系，这是有少阴症的现象，就是但欲寐，脉弦细，但是，要才刚得到，才刚得到，即可一点汗没有关系，那一样，可见看，是这个比例，比例是这样子，只要用到麻黄，先把麻黄滚一下，把泡沫去掉，去掉麻黄里面的麻黄素，安非他命之类的，想是这样子，当时他们、汉朝他们就知道了。
