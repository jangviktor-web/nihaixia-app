#### 三八二、问曰：病有「霍乱」者何？答曰：呕吐而利，此名「霍乱」。

> 问曰：病有「霍乱」者何？答曰：呕吐而利，此名「霍乱」。

**倪海厦解读**：

- 问曰：病有霍乱者何？答曰：呕吐而利，是名霍乱。
- 一开始介绍的：有霍乱者，呕吐而利，是名霍乱。这个霍乱，跟现在的霍乱，要不要放在一起比？诸位不要去想现在的病名，你只要看到呕吐，下利，能够又吐又利的，在中医里就叫霍乱。那若说现在西医讲的霍乱也是呕吐下利，是西医拿中医的名词去（用）的，不是中医拿西医的名词去（用）的。
- 最早的霍乱，这个名词出现在《汉书严助传》里。其实在《黄帝内经》素问里，就有介绍，叫做六元正纪论。它说太阴所至，中满霍乱，太阴脾脏，中满。若病在这边的时候，霍乱，吐下，是因为湿太盛，这个素问也讲到，霍乱。那在《灵枢》也介绍到霍乱。《灵枢》经上面对霍乱的定义，也是太阴，厥气上逆。这也称为霍乱。
- 基本上霍乱是什么观念？在中国的北方，很少看到霍乱，大部份都是南方才有。这个病，出现在春分到秋分之间。也就是说，冬天看不到这种病，是在春分开始以后。按照这个六气，介绍了，天地之间的气，称为少阳，为。.....对不起，少阳是相火，少阴呢是君火。在学针灸的时候，手少阴心经是属于火、手少阳三焦经，它是相火。从夏至到冬至之间，两个火配合，再到太阴的湿。也就是火，就是热啦，和湿夹杂在一起。
- 例如，这是地球，地中有火。这是外面的太阳，也是火，所以，照到地面上的时候，在地上面。下面的热往上升，上面的热往下降，中间，土又很湿，那你人站在这个地方，上面又热，下面又湿，两个交杂在一起。处在这种环境之下的时候，产生了霍乱，这是霍乱的来因。
- 所以他霍乱一定有它当地的节气，还有当地的湿度才会造成的。那北方不会呀，北方冷呀，就不会有这种霍乱的情形。当知道他的病因了以后，就知道霍乱要去湿去热。同时，知道了这个霍乱是什么？
