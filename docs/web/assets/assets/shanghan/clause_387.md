#### 三八七、吐利止而身痛不休者，当消息和解其外，宜「桂枝汤」小和之。

> 吐利止而身痛不休者，当消息和解其外，宜「桂枝汤」小和之。

**倪海厦解读**：

- 吐利止而身痛不休者，当消息和解其外，宜桂枝汤小和之。
- 若病人，可见，「吐利止」，就是霍乱吐利止，「而身痛不休者」，身体还是很疼痛，「当消息和解其外，这时候桂枝汤小和之」，像一般而言，病人进来时只要说身痛，就会问他：请问你，你是痛在皮肤、痛在肌肉、还是痛在骨头？病人讲痛在肌肉，桂枝汤就跳出来了；痛在骨头关节，附子汤就跳出来；上身不痛，只膝盖痛，桂枝汤、知母汤就出来了。速度会甚快，临床上变化就这么多而已。老师：都痛在皮肤上面，麻黄汤症，麻黄汤症痛在皮肤上面，表甚为表，你要靠麻黄，把那个寒去掉才行。像它这个的身痛不休者，一定是痛在肌肉上面。会用桂枝汤，病人一定是痛在肌肉上面，同时一定微微有汗，只要有汗，又痛在肌肉上面，就是桂枝汤症。
- 若说。老师：在神农本草经里面用玉竹，玉竹这个药，可以治肌肉里面的痛，甚佳用。那即可在桂枝汤里加一味单味的药玉竹，这是用的甚多，在美国叫（一名英语）现在台湾什么肌纤维痛症，翻译成肌纤维痛症，总之名词甚多，管它什么痛症，看到开就桂枝汤加玉竹，一下就好了。
