- 那你已经利到后来没有东西利了，脉又微掉了，心脏力量不够了。代表心脏摩擦力不够，那火就弱了，病人当然会感觉身体冷。那为什么常常说，在看病人的时候，你的脚是热的，还是冷的？因为人的心脏，刚好设计好，就是达到最弱的时候，脚趾头是末梢，手指头还不是末梢，脚趾头更远一点。所以若说，你的脚趾头末梢是冷的，就已经知道，你的心脏的摩擦力不够。所以为什么要用桂附，就是让它的摩擦力加强。介绍处方的时候，再把它分开来，这两个药性不太一样。那，那若说老师，的脚趾头旁边都很热，则是正常的心脏，本来心脏就是设计成这个样子的。那你心脏力量不够的时候，脚，开始就会冷。那冷到极限会什么，病人会冷到膝盖，就是极限。

- 所以那是骨的最末的地方，也是人体最末的地方。若四肢冷起来的时候，从脚旁边冷，你说，老师，脚底冷，小腿不冷不感觉到冷，还好，没有关系。那你若冷到膝盖来，已经到极限了，不会再冷上来了。这就所谓的四逆汤症。
- 时候，诸位考虑到，恶寒，是因为心脏力量不够，而不是因为有表症。有表症的恶寒的话，脉一定是什么？浮，而且是紧的，病人会生痛，肌肉痛，回忆一下，伤寒论里面的麻黄汤。这个病人，是因为表寒，表受到风寒以后，毛孔悬浮，整个封闭起来，汗没办法透发，那汗要出来，出不来就停在肌肉里边。这个汗，肌肉里边的水呢应该是循环的，可是这样子水不能够循环，停在肌肉里边，堵塞在里边，则会痛。所以痛来自压力，因为新的水没办法去换旧的水，那旧的水停在那边，新的水不断要进去推它，所以这就产生了压力，所以痛是来自压力，而不是发炎。那病人这个时候产生的脉就一定是浮脉，浮而且紧，那脉是微，代表心脏力量不够，恶寒？这个观念就是，所以你要这样子想，你就不会这个时候开出的是麻黄汤，而开出的是四逆汤。
