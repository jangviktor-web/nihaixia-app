#### 一九三、「阳明病」欲解时，从申至戌上。

> 「阳明病」欲解时，从申至戌上。

**倪海厦解读**：

- 二百零九条，阳明病欲解时，从申时到戍时，就是一开始讲伤寒论的时候，已经讲了，酉，卯和酉就是阳明的时候，若阳明病，便秘好了，或者是燥热好了。阳明病好了的时候，一定是在这段时间，所以，反过来，就是阳明病还在的时候，这段时间一定特别难过，这段时候刚好黄昏的时候，因为燥热，烦热都发生在这段时间，所以如果病人跟你说，奇怪了，什么时候，一天都很好，就是每天黄昏的时候，在夕阳西下的时候，跟着的情人在散步的时候，一阵热上来，这就是阳明热，就已经告诉你是阳明证了。那你就问他，会不会，大便，不好，阳明证，还有一种是，大便很口渴也是属于阳明证，这两种都是阳明证。
