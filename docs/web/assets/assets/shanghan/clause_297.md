#### 二九七、「少阴病」下利止而头眩，时时自冒者，死。

> 「少阴病」下利止而头眩，时时自冒者，死。

**倪海厦解读**：

- 少阴病，下利止，而头眩时时自冒者，死。
- 311，少阴病，下利止，而头眩时时自冒者，也是死，在治疗尿毒、肾脏病的时候，有两个最明显的症状，病人晕眩，还有呕吐，东西吃下去就吐，在西医来说，毒，尿毒跑到、顺着血液跑到心脏里面去了，中医少阴症的时候张仲景说，头昏眩，时时自冒者，这都是死症。今天若没有经方，都是一般的中医在看，那如果西医这个时候介入的时候，洗肾可以让他不死，洗肾也至少可以活命，至少可以活命。那头昏眩，头晕的，因为，刚刚跟诸位解释过，若小肠的火很热，小肠的热和心脏的热火是相同的温度的时候，肾脏里面的水会第一次会蒸溜，这个水气甚佳，从督脉一直会进入到脑部去，这个时候水会去滋润脑部，那你肾脏功能衰弱下去了，病人在下利了，津液往下走，然后又没有…你这个脑部会缺水缺这个，缺好的蒸气，好的气化上来的。所以缺东西的时候，会有，缺营养这个时候会头昏，头昏，那进入少阴症的时候，因为影响到心脏脾脏。
- 一般而言，只要进入阴症的时候，造血功能就不行了，所以你会相对，一定会看到贫血的情形。那在治他的时候当把小肠的温度恢复的时候，肾脏的功能，肾脏里面有阳，命门里面都有阳，这个阳气很盛的时候，这个水从督脉进入脑部了以后，水气化上来的时候，到了脖子，因为水很热，太热的水跑到脑部去也不行，脑部会烧坏掉，所以有脖子，脖子好像冷却管一样，把水稍微冷一下，很好的温度能够进去。头部，那，这个当肾脏的水再次回到头部去的时候，头的昏眩的现象就没有了，所以可以从病人恶不恶心，若病人本来就是少阴症，有吐利了，然后又加上头昏的话，那你吃了你的药头昏没有去掉，吐利加重，这就代表说病情越来越坏了，可能会死。若真的没有能力，没关系，洗肾，即使洗肾比死掉还好，要这样子想，可不可以治，可以治的，可以治的，待会儿少阴篇完的时候，后面有几个处方，来加减给诸位看。
