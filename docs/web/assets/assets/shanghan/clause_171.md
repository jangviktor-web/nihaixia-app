> 「太阳」「少阳」并病，心下硬，颈项强而眩者，当刺大椎、肺俞、肝俞，慎勿下之。

**倪海厦解读**：

- 一百八十六，太阳少阳合病并病，若遇到心下鞭，胃的地方硬块，项强而头昏的，当刺大椎、肺俞、肝俞，慎勿下之。不要攻下，代表这个人有表证嘛有表证。当然这个针灸呢可以这样做，那这个你若说用处方当然也可以，也可以用处方，只要是项强出现的时候，就可以使用到葛根汤，葛根汤。那若有少阳病出现的时候，恶心，晕眩，心下鞭，可以用葛根汤跟柴胡汤的复方都可以使用他。所以可见他的症状，所以伤寒论归伤寒论，条辩归条辩，你在临证的时候甚为灵活，甚为灵活不可死板板的，一定要这样子做。
