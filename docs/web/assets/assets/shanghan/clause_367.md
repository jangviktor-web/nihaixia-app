#### 三六七、下利，脉数而渴者，今自愈。设不差，必清脓血，以有热故也。

> 下利，脉数而渴者，今自愈。设不差，必清脓血，以有热故也。

**倪海厦解读**：

- 下利，脉数而渴者，令自愈，设不差，必圊脓血，以有热故也。
- **脉数而渴 = 胃气回头**：脉数代表阳气来复，口渴代表津液回头想喝水。这种可以让他自己好。
- **若不好，必圊脓血**：热盛伤了大肠津液，肠中发炎，血与大便混杂而下。

**便血三型先分清**（问诊关键，只说「大便带血」无法辨证）：

- **近血**：先出血、再排便——出血位低（如痔疮）
- **远血**：先排便、后有血——肠胃里面出血
- **脓血混杂**：血与大便混在一起——即本条所论，大肠发炎

**用方层次**：

- 一般**热利** → 葛根黄芩黄连汤
- 已成脓血、血便混杂 → **葛芩连汤一点用都没有**，要用后面的方（白头翁汤一类）
- **误治警示**：素体肠胃不好的人，感冒又吃抗生素，好菌被杀光、肠胃更差，表邪陷下去就成了肠病毒——同样的病毒在表是感冒，入肠就是肠病毒。身体差、每次感冒必中的人，平日可吃**桂枝汤**调阴阳。

##### 补录（原 clause_361）

- 下利，脉数而渴者，令自愈；如果不好，大便就会脓血，数而渴代表里面有热，照理说热证的话应该让他自己好，若没有好的话，这个热就会从大便排出来，这种讲的这种下利呢都是在厥阴证上面，寒热都会有的。简单讲就是手脚都是冰冷的，他现在有热证。
