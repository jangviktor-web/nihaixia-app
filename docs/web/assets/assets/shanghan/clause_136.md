#### 一三六、「伤寒」十余日，热结在里，复往来寒热者，与「大柴胡汤」；但「结胸」，无大热者，此为水结在胸胁也，但头微汗出者，「大陷胸汤」主之。

> 「伤寒」十余日，热结在里，复往来寒热者，与「大柴胡汤」；但「结胸」，无大热者，此为水结在胸胁也，但头微汗出者，「大陷胸汤」主之。

**倪海厦解读**：

- 那若说这个人没有大热了，那代表表邪完全下陷在里面了，水结在胸膈，一般水若结在胸腔这边的时候，都会胀满，痛……心下会痛，压到这这个都会痛，有时不会按都会痛，拒按的时候。那喜按，比较小陷胸，比较轻微，按下去比较舒服。
- 有的时候……像这种是水结在这边，会用到大陷胸汤的时候，都是拒按，就是你病人这里很痛，你一按……不要不要压……按到会更痛。拒按为实，拒按呢为实证，就好像一个太太怀孕了，怀孕的时候，那个里面是实，小孩子在里面，你还给她按来按去。那你这个这个……小朋友会有抗议的，那流产那——拒按。拒按就是实，实就是有东西在里面，那虚实的时候去按他，就可以知道。那虚证，里面没有东西，虚证的时候喜按，就好像腹满，有个人肚子胀满了，好，现在你今天已经学到的，肚子胀满了，你压他，「~~, 好舒服，医生多压一下……」谁有时间给你们多压，病人甚多那你腹部压，腹诊找到需要的症状就好了。结果他说：「诶，医生多按一点」，就知道，这个是喜按。那腹胀喜按厚朴生姜半夏人参甘草汤证。那若一压……「啊啊啊医生不可按，好痛……」这大便堵到，里面有东西堵在里面所以腹诊的时候，拒按跟喜按，很明显，甚为明显。
- 无太热者，此与水结在胸胁也，但头微汗出者，「大陷胸汤」主之。
- 伤寒十余曰，本来有表证，麻黄汤就好了，结果热结在里，若热结在里，大便没有了，热结到了，所以这是阳明证，便秘了，复往来寒热者，就是少阳证，阳明和少阳兼有，所以是大柴胡汤。小柴胡是介乎少阳和太阳之间。大柴胡汤下去的时候，表里双解，因为大柴胡汤里面有枳实、大黄。但结胸无大热者，此与水结在胸胁也，但头微汗出者，「大陷胸汤」主之。这热和水结在胸腔里面，若热结在里，就是结在大肠里面，结在下焦，就是大柴胡汤证；但结胸无大热者，就是结在上焦，胸口就是大陷胸汤证。
