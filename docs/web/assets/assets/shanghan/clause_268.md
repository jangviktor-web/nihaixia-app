#### 二六八、「三阳合病」脉浮大，上关上，但欲眠睡，目合则汗。

> 「三阳合病」脉浮大，上关上，但欲眠睡，目合则汗。

**倪海厦解读**：

- 「三阳合病」，脉浮大，上关上，但欲眠睡，目合则汗。
- 二百八十二条，三阳合病，脉浮大，上关上，但欲眠睡。目合则汗，不是说眼睛关上就流汗，这个三阳合病的时候诸位记得，只要太阳，阳明，少阳同时出现的时候，一定是小柴胡汤来解它，三阳合病，是和解，少阳。这个条辩就是告诉诸位，这个人，睡在那边，躺在那边不动，眼睛闭上去都会流汗，就是表证还有，们平常人，你坐在那边不动，你不会有汗的，不动也流汗，就是表症还是有的意思，只此而已，那你这个脉浮大，上关上，又是这个，所以，他说这个，三阳并病，太阳，少阳，阳明病证统统都有，不动都有汗，里面太热了，处方，小柴胡汤。
