#### 三八八、吐利，汗出，发热，恶寒，四肢拘急，手足厥冷者，「四逆汤」主之。

> 吐利，汗出，发热，恶寒，四肢拘急，手足厥冷者，「四逆汤」主之。

**倪海厦解读**：

- 吐利汗出，发热恶寒，四肢拘急，手足厥冷者，四逆汤主之。
- 病人吐利又有汗出，发热恶寒，四肢拘急，手足厥冷，四逆汤主之。可见，上吐下利，津液已经丧失甚多，又流汗甚多，津液丧失掉了，里面津液不够了。病人发热恶寒，什么意思？当津液不够的时候，常人，心脏搏动产生的热，中医，把它定名为火。肺呢法像天，所以肺是很寒冷的，色白，白色的。这两个平衡的时候，你不会感到怕冷怕热，就是常温。若说，当你津液不够时，肺的津液丧失掉了，因为出汗，皮毛，肺的津液也不够了。这个时候病人为什么发热，心脏的火往上走了（注：也是往外走了），制衡心脏的热呢（注：肺寒反制衡心火使之不太过）已经没了，所以为什么叫火克金，火金互相一定要有相生相克的情形，就是说这两个脏腑、五脏之间一定要有制衡的力量，不单单相生，之外还要互相制衡，才能很和谐在身体里，能够帮助们运转。
- 那你若津液不够了，肺津液没有了，心脏的心火往外走，往外走病人出现发热现象，身体感觉冷。正常人心火往下走，进入小肠里面，所以小肠跟心脏都是属于火，火要往下走，才能走到四肢末梢去，心脏的火走到手指头尖，小肠的火走到脚趾头间。但小肠的火也是来自于心脏的火，现在心脏的热往上走，因为津液没了，病人的手脚四肢会发冷，四肢上面要有温度，有温度的时候，心脏才会产生速度，所以可见一锅水在里面，若没有加热是冷的，水不会动，不会动就痛。所以你若火在下面加热，水开始煮滚了以后，转了以后，中医就称为：，老师这就叫做气。当有气在运转的时候，就很正常。当你变成冷水停在里面不动的时候，津液又不够，因为津液发汗流掉了，津液不够了，就会抽筋，拘挛起来。所以寒则拘急，所以寒则拘急，寒症拘挛热则纵。所以中风有两种，一种是手脚绷起来，一种是纵在外面，一种热还有一种寒，手脚都是厥冷逆冷，用四逆汤。
- 四逆，当时取的名字很好，就是告诉你四逆嘛四肢厥逆，这样想反应的甚快。
- 因为当初设计处方名称的时候很有意思，经方当名称在这边时，你一看这个病，已经名称就对上去了，即可节省甚多思考的时间，这样的话救病人来的及，比较来的及。
