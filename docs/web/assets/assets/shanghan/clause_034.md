#### 三四、「太阳病」桂枝证，医反下之，利遂不止，脉促者，表未解也；喘而汗出者，「葛根黄芩黄连汤」主之。

> 「太阳病」桂枝证，医反下之，利遂不止，脉促者，表未解也；喘而汗出者，「葛根黄芩黄连汤」主之。

**倪海厦解读**：

- 原本有桂枝表证，被医生攻下，或不小心吃坏肚子造成下利
- 结果利下不止，脉促，喘而汗出者，表未解也
- 病人被攻下，血都往下跑，血往下力量很强，脉会跳得很快稍微停一下
- 这时葛根汤没用，要用「葛根黄芩黄连汤」
- 有表证，误下，造成表邪
- 病毒渗透到汗腺里，进入肠子，血往下走，病毒跟着下来
- 像阿米巴痢疾，可以用「葛根黄芩黄连汤」

**葛根黄芩黄连汤方**：

- 葛根半斤，甘草二两炙，黄芩三两，黄连三两
- 右四味，以水八升，先煮葛根，减二升，内诸药，煮取二升，去滓，分温再服

**药性解析**：

- 黄芩、黄连是非常寒凉的药，能去热
- 热就是炎，所以也是消炎的药
- 黄芩、黄连不仅可以内服，还可以外敷
- 如果皮肤破，可用黄芩黄连；如果化脓，可以加去湿的药
- 黄芩杀菌的力量很强
- 阿米巴痢疾的时候，大肠的壁都破洞了，下利都是血
- 下利久了人会脱水，所以用葛根升水，用炙甘草，把肠子的津液补足，用黄芩、黄连解毒

**表邪未陷 vs 已陷里热**：

- 表邪未陷者，重于解表
- 已陷而成为里热者，重于清里
- 本来是桂枝汤证，结果下利，这时候要重于清里，改成「葛芩连汤」

**虚寒 vs 实热辨证**：

- **虚寒者**：脉微无力，舌苔淡白，下利不热，色黄淡，肛门没有灼热的感觉
- **实热者**：脉数有力，舌红苔黄，黄的再进就红，再进就黑了，就是壮热
- 实热者下利热灼，色黄赤而臭热，肛门有灼热的感觉
- **临床案例**：西医所谓的肠病毒的案例，其实就是表邪下陷，到了肠子变成热利
- 病人喝到葛芩连汤，病人觉得不苦，反而觉得很甜很好喝

**针灸治疗热利**：

- 针「曲池」、「合谷」、「天枢」、「关元」、「三阴交」
