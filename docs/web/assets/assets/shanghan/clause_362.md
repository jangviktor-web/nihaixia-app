#### 三六二、下利，手足厥冷，无脉者，灸之。不温。若脉不还，反微喘者，死。「少阴」负趺阳者，为顺也。

> 下利，手足厥冷，无脉者，灸之。不温。若脉不还，反微喘者，死。「少阴」负趺阳者，为顺也。

**倪海厦解读**：

- 下利，手足厥冷，无脉者，灸之不温，若脉不还，反微喘者，死。
- 下利、手脚冰冷、**脉没了**——这是死证之候。

**处理与判断**：

- 灸**关元、中极、中脘**（温复元阳、接续胃气）
- 灸了手脚仍不温、脉仍不回，反而出现微微喘 → 只剩一点残阳浮在上，**死证**
- **接续看下一条**：单看「无脉」还不够，还要看「少阴负趺阳」——尺脉（少阴／肾）弱于关脉（趺阳／胃气），说明胃气尚存，虽下利亦不至于危，此为**顺**。

##### 补录（原 clause_352）

- 「少阴」负「趺阳」者，为顺也。
- 「少阴负趺阳者，为顺也」——**少阴是尺脉，趺阳是关脉（胃脉）**，此处「负」是尺脉比关脉小。
- **正常脉形**：寸 > 关 > 尺，三部逐部斜降（关脉比尺脉大一点，寸脉比关脉大一点）。反过来，**寸脉变小、尺脉浮起**，阴阳倒置，身体已经出问题了。
- **为顺的意思**：胃气（趺阳）还在，后天之本未绝，虽下利也不会出大问题——这是从脉证判顺逆。

**脉不可凭时怎么办**（如手部受伤无脉可摸）：

- 改**望闻**：听声音有没有元气、看面色有没有血色
- 看**手指末梢**血色——末梢血都没了，就知道贫血严重
- 下利的人若还声音洪亮、气色不坏，就是顺

##### 补录（原 clause_353）

- 少阳负趺阳者，趺阳脉是胃脉，少阴脉是肾脉，少阴脉在太溪这个地方，所以太溪脉比胃所在的冲阳脉小，冲阳脉比较大，太溪脉比较小这是正常，太溪脉本来就是阴，在里边胃气比较大在外面，所以你若摸病人脚的脉冲阳脉比较大，太溪脉比较小是正常。
