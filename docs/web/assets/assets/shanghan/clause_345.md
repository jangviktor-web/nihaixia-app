#### 三四五、「伤寒」发热，下利至甚，厥不止者，死。

> 「伤寒」发热，下利至甚，厥不止者，死。

**倪海厦解读**：

- 「伤寒」，发热，下利至甚，厥不止者，死。三六一条，伤寒发热同样是伤寒发热，下利至甚，厥不止者，死。
- 越来越冷手脚越来越冷，那个病人冰到什么程度哈，腹水的病人呢你摸上去，那个腿肿的又大，整个像寒冰一样，冰块一样。甚为冰冷，厥不止，越来越冷，寒气一直往身上走，这种都是死证。
- 照理说下利是越利越寒，体能都没有了，手脚冰冷了，若病人发热，代表肠胃功能回来了，利应该会自止，现在发热，下利至甚。厥不止者，这时候下利不止反发热，手脚一直冰冷，没有办法热起来的这都是死证。除了癌证的末期、肝病的末期。还有霍乱痢疾的上吐下泻，好的津液都吐光了，下泻又把肠胃的津液泻掉了，就会有这种现象。
