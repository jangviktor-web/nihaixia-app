#### 一五四、心下痞，按之濡，其脉关上浮者，「大黄黄连泻心汤」主之。

> 心下痞，按之濡，其脉关上浮者，「大黄黄连泻心汤」主之。

**倪海厦解读**：

- 大黄黄连泻心汤方：大黄二两，黄连一两。右二味，以麻沸汤二升渍之，须臾，绞去渣，分温服。
- 心下痞，就是满而不痛，心下满，摸、压下去，胀胀的，但是压着不痛，按之软绵绵的，其脉关上浮者，「大黄黄连泻心汤」主之。这个条辨是从脉诊上面来判断：关骨这个地方，寸、关、尺，关是中膈中间，就是胃的位置，寸是胸阳的位置。这里关上脉浮，关脉和寸脉的浮脉，意思就是说上焦比较热一点，只此而已。
- 诸位看这个处方，大黄黄连泻心汤，其实这个「心」就是胃啦。读《伤寒论》的时候，心要把它当成胃，心下就是胃下；说胃，就把它当成肠。大黄二钱、黄连一钱，不可真的拿二两，那不得了了。这两味药「麻沸汤二升渍之，须臾」，怎么弄它你们知道？不是煮的喔，要取它的药气，就好像泡茶，把大黄跟黄连丢到杯子里面，热水冲下去就可以了。不可真的像它，拿一个棉布把它包进去，然后滚水放进去烫一烫，再碾它的汁出来，那你的手就被烫伤了；你就直接把它当茶泡，不煮它。当你不去煮它的时候，是取它的药的气；若去煮它，就取它的药的味。大黄跟黄连味都很厚，所以要它进入血分的时候才煮；在这里不是，这里是泡茶一样泡一下，只是取它的气。因为他的胃中有热，简单讲，舌苔是黄的，脉浮上来，就可以用。
- 临床上用的地方甚多。例如有一个人跑来：「老师，奇怪，坐在那边看电视，怎么无缘无故突然眼睛就『嘣』，那个血块就嘣出来，眼白的血管就破裂掉了？」或者突然流鼻血，牙齿流血，上焦牙龈出血，或者眼睛里面出血，统统可以使用这个处方，因为取它的气，它能够降热，把它降下来。所以说上焦的热，统统可以用这个药把它清出来。简单的看，就是流血、失血、出血，病人会有出血的现象。
- 这种泡的药，「老师，这个黄连很苦？」——是很苦，可他有那个证，他喝的时候不苦，还有病人跟你说这个药很好喝。但是你这个药若煮过就没有用了，煮过大黄跟黄连就往下走了，要泡，「麻沸汤」就是滚水。所以五官无缘无故出血的时候，就知道是上热，胃中太热，胃热上浮、上升，冲上去，就用这个药。
- 临床上伤科出血的时候统统可以使用它。这个药若打作粉剂，收敛伤口用：大黄、黄连做粉是去热的；粉里面加点白术，就是祛湿的；加点没药、乳香，是收敛伤口、排脓的；加三七，化脓、活血化瘀，瘀血在里面。这些药加在一起，伤科的皮肤化脓没有办法收口，外敷一点粉就可以收口。中药的好处在这里，既可以内服，又可以外敷。
- 抽烟的人，舌头伸出来都是黄的，每天早上起来燥热，嘴巴干，痰咳出来都是黄的、胶痰，怎么把这个痰清掉？一样。用皂荚，皂荚是碱性的，一定要用红枣，红枣跟十枣汤的意思一样，能够把胃的胃液阻绝开来，否则皂荚下去，碱跟酸一中和，胃就很难过；这就叫秤不离砣，从古到今不分开来。用这个来清肺，把肺里面清得很干净。
- 痰甚多，有天南星，祛痰的；口不渴用半夏，口渴不用半夏，以渴和不渴来决定。戒烟以后容易胃口大开，人会胖，十个戒烟九个胖，一个不胖（倪师自指）。用石膏看他多大，这个人胃太大了，石膏五两，那个老外三四百磅的八两。石膏能去胃热，因为是寒凉的药，一下去胃的蠕动就减缓，胃热下降，胃口就下来了；再加知母，知母能去湿，把肺里面的湿收敛起来，配合祛痰的药，就能把烟戒掉。
- 老烟枪抽得晚上睡不着觉，加些柴胡下去，里面有黄芩，加点黄芩，加点疏肝的药，例如郁金：柴胡三钱、黄芩三钱、皂荚三钱、南星三钱、知母五钱、郁金五钱。柴胡、郁金能够疏肝气，肝脏功能起来帮助解毒，抽烟的欲望就没有了。若不开柴胡、黄芩、郁金这些清肝的药，光上面的药会把肺里的烟痰、烟油清得干干净净，胶痰都清掉，可他还是会想抽烟；加了这些下去，就不想抽烟了。按这个方法不但很容易戒掉，而且还会瘦掉。
- 这是大黄黄连泻心汤。所以大黄你若炮制的，泡过水出来，不会清肠、不会清大便，是去胃家的热、往上冲的热。
