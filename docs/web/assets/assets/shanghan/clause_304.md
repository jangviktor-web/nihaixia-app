#### 三〇四、「少阴病」得之一二日，口中和，其背恶寒者，当灸之，「附子汤」主之。

> 「少阴病」得之一二日，口中和，其背恶寒者，当灸之，「附子汤」主之。

**倪海厦解读**：

- 「少阴病」得之一二日，口中和，其背微恶寒者，当灸之。
318．少阴病，得之一二日，口中和，而背微恶寒者，当灸之。这个意思，就不是说背很冷，例如你冷，有人冷在命门，有人冷在那个膏盲，有人冷在肾俞，津门，哪里冷，你就灸哪里就好了，所以少阴病，只要是没有口渴，没有津液不够，津液没有问题，即可用灸的方式来把寒湿去掉你怎么知道灸哪里，寒湿在哪里，哪里就冷的意思，看他部位，即可灸，所以，少阴症的时候，阴症的时候，灸很好。
