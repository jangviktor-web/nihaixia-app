#### 一八七、「伤寒」脉浮而缓，手足自温者，是为系在「太阴」。「太阴」者，身当发黄，若小便自利者，不能发黄；至七八日，大便硬者，为「阳明病」也。

> 「伤寒」脉浮而缓，手足自温者，是为系在「太阴」。「太阴」者，身当发黄，若小便自利者，不能发黄；至七八日，大便硬者，为「阳明病」也。

**倪海厦解读**：

- 伤寒，脉浮而缓，照理说，应该是伤寒是脉浮而且紧，现在是缓脉，手脚自温，缓脉是胃的脉，脾胃的脉是缓脉，代表。手脚，四肢末稍，手脚的温度，也是脾。
- 胃气在管。手脚自温，这是系在太阴，太阴者，身当发黄，若病进入太阴，还没有介绍，病人会看到发黄，身黄的现象，若小便自利者，不能发黄，这个七八日，大便鞭者，为阳明病，为什么会有这种现象？就是有中湿之人。湿，湿很盛的人，你一看，这个，发表，一发表下去的时候，这个湿很盛呐，没有排湿药在里面，没有加在里面，你就直接发表，就，表汗透出来了，里面湿还有，还停在身体里面。那如果这个湿，那太阴，是主在腹部，主腹，应该是发黄，为什么是发黄，身上的汗液，从胃到肠子里面，肠胃津液，往四散，经过三焦，三焦，上中下三焦，三焦是油网，三焦的油网，再到皮肤表面，再到皮肤毛孔，汗就排出来，所以汗的源头，是从肠胃的津液，经过三焦以后到皮肤毛孔，排出去，那你若平常中焦就有湿热的人，湿很盛的人，你湿跟水不一样湿很粘稠，一般而言，去湿的方法没有湿的用发汗的方法，一般都是利尿，就是前面介绍的，风湿关节炎，怎么治，痛风怎么治你们有没有看到痛风的时候，他用发表的药，没有，用桂枝附子汤，甘草附子汤，诸如此类的，不会用麻黄，它没有，所以这个湿在身上的时候，你发汗的时候，湿并没有办法把它发掉，所以身上的水份，是经过三焦的网跑到皮肤上面去。
- 三焦的网，三焦里面是油，这个油是黄油，你会看到身上是鲜黄的，鲜黄的颜色，因为三焦，一直在管你，所有内脏之间的往来，脏腑之间的往来，的食物吃进去，脾胃的消化系统，的能量，三焦是一个传达的一个系统，所以三焦是无所不在，那你若津液，正常的津液，三焦里面一定要有点油，所以水在跑的时候，地上有油跑得甚快，地上没有油，跑不动所以三焦会有油网在里面。上一堂课，跟诸位介绍，人在快要走之前的时候，不单单是汗出，是油跑出来，三焦的油跑出来，一摸，粘嗒嗒的，完了！就知道是约了。若汗发掉的时候，湿还在里面的时候，没有汗了，三焦的油就会跑到皮肤表面上，这个时候，身会发黄，若小便自利者，不能发黄，什么叫小便自利？小便自利就是说，他小便还很好，汗解，你发汗的时候并没有伤到他的津液，他的津液自己会回流。
- 所以常常看，这个发汗，老师，这个人吃的麻黄汤，不晓得他的汗有发的有没有过，问他，你打电话问他，你小便，「小便不好，不利」，口渴不渴，「喝那汗出来一直不能止啊」，小便又不利，哇，津液伤到了，他说，那你吃点人参，甘草，生姜大枣，补补津液，若整个人有气无力地讲不出话来，即可开茯苓四逆汤有甚多四逆汤这样子。一般不会到这个阶段的，发个汗就这样子，太差了，身体也太差了，真是病夫。小便自利者不会发黄，因为津液会回头，所以看不到鲜黄的三焦的津液，三焦的油脂。七八日，大便鞭，为阳明，鞭就是硬，大便排出来很硬，不可把它想成鞭，鞭就是硬的。排出来，的病人形容给听？他排出来大便就像棒球一样，「嘭」掉到马桶里还有声音「扑通」，还有石头撞击的声音一样，然后，冲水冲不下去，拿棍子去戳。可见硬到这种程度，他在形容的时候，他为什么的女儿的大便是这样子，就在心里想大承气汤，他在讲的时候，就在想这是什么了，不会想如此恶心，他在跟，给女儿大承气，他不知道跟给女儿大承气，听了就是大承气。
- 大便鞭，甚为硬。
