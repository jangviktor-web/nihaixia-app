#### 一二三、「太阳病」过经十余日，心下温温欲吐，而胸中痛，大便反溏，腹微满，郁郁微烦，先此时自极吐下者，与「调胃承气汤」。若不尔者，不可与。但欲呕，胸中痛，微溏者，此非「柴胡汤」证，以呕，故知极吐下也。

> 「太阳病」过经十余日，心下温温欲吐，而胸中痛，大便反溏，腹微满，郁郁微烦，先此时自极吐下者，与「调胃承气汤」。若不尔者，不可与。但欲呕，胸中痛，微溏者，此非「柴胡汤」证，以呕，故知极吐下也。

**倪海厦解读**：

- 调胃承气汤方：大黄四两（去皮，清酒洗），甘草二两（炙），芒硝半升。上三味，以水三升，煮取一升，去滓，内芒硝，更上火微煮令沸，少少温服之。
- （讲稿第137条）本条辨「曾极吐下」后的胃气不和，与柴胡证相鉴别。
- **心下温温欲吐、胸中痛、大便反溏、腹微满、郁郁微烦**：一组胃中不和、余热未清的见证。
- **关键在「先此时自极吐下」**：病人此前自己大吐大下过，胃气被扰，故与调胃承气汤微和胃气。
- **若不尔者，不可与**：未曾极吐下者，不可轻用。
- **此非柴胡汤证**：但欲呕、胸中痛、微溏，看似柴胡，实因极吐下所致，故不可作柴胡证治。
- **临证体会**：倪师说这种「想吐又吐不出来、胃里很难过」的情况，调胃承气汤下去即解；胃肠为诸病之门户，胃肠治不好，肝病肾病亦难治。
