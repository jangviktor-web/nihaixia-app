- 二百零五，阳明中风，口苦，咽干，腹满，微喘，发热，恶寒，脉浮而紧，若下之，胃中空虚，客气动膈。这里是什么意思，就是甚多人，他不晓得，张仲景，在阳明篇的时候，张仲景一再要强调要攻下的时候，一定要确诊他是纯阳明证，你一定要看清楚他是纯阳明，遇到他是纯阳明实证的时候你再攻下，若他有其它的证状，像你口苦是少阳证，少阳证那个胆胆汁往上逆，是少阳证。
- 小柴胡汤里有口苦，有口苦的症状，胸胁苦满，这个，这个腹满，看起来咽干，看起来好像是阳明的证状，因为腹满，其实腹满有虚证，像厚朴生姜半夏人参甘草汤证是，腹满也会有，里面一肚子气在里面，排气的。微喘，看起来好像是阳明证，发热，病人有恶寒，所以说你不能确认它是正阳明证的时候，千万不要去攻下，一定要确定他是有阳明证的时候，你若攻下，你不知道还有一些是表证，结果你攻下，胃中空虚，这个胃不单单是个胃，指的是小肠大肠肠子，小肠中间空虚掉了，这个客气动膈，一攻下以后，里虚掉了，里虚掉以后，你的那个下焦，刚刚才跟各位介绍了，心肺，是阳，以身体来说，横膈到肚脐，横膈到肚脐，是中焦，下面呢是下焦，若说，上面心肺是阳，若把中间，分成一半，分成一半，上半身呢是阳，下半身就是阴，中焦呢是半阴半阳的中间，当你把下焦一攻下以后，一攻下，阴气往下走，这个阳气往下陷，阳气往下陷的时候，这个阳气不应该呆在这边，就要回头，就会在这边振动，造成病人会有喘满的现象，这就叫做客气动膈，动在这个膈的地方。所以说，你没有确定他有。虽然这人有便秘，或者怎么样子？但还有一些伤寒表证或者中风表证的时候，那这就是阳明中风，你就不要攻下，一定要先把表先去掉，确定他里面是实热的时候，这个时候，再攻下。
