- 临床上阴骨怎么解释？若光看这个不晓得他是做什么？
- 曾经在治疗血癌的时候，小朋友原来做了化疗，做了骨髓移植，结果呢骨髓移植以后又做化疗，西医宣布无治。无治以后，给中医看了，来找了。结果吃中药，两个礼拜以后，小孩子胃口也开了，元气也恢复了。再回去一查的时候，没有血癌。
