#### 九八、得病六七日，脉迟浮弱，恶风寒，手足温，医二三下之，不能食而胁下满痛，面目及身黄，颈项强，小便难者，与「柴胡汤」，后必下重。本渴饮水而呕者，柴胡不中与也，食谷者哕。

> 得病六七日，脉迟浮弱，恶风寒，手足温，医二三下之，不能食而胁下满痛，面目及身黄，颈项强，小便难者，与「柴胡汤」，后必下重。本渴饮水而呕者，柴胡不中与也，食谷者哕。

**倪海厦解读**：

- 此条辨是说，医生看错了
- 病人得病一段时间以后，医生以为病人已经进入阳明证了
- 脉迟浮弱是说病人的脉浮、弱、迟的迟，就是一息二下很迟
- 病人本来就是身体虚的，阳明证的时候，手掌与脚是热的
- 医生看病人手足温，就以为病人是阳明证而攻
- 医二三下之，攻下了以后，病人本来身体就虚掉了
- 攻下的药都是寒凉的，造成胃里面更寒
- 胃里面没有蠕动，食物都吃不下了，所以胁下满痛
- 造成脸孔和身体都发黄了

**黄疸的辨证**：

- 【内经】讲五脏的正色：肝是青色，心是赤色，脾是黄色，肺是白色，肾是黑色
- 当病人脸整个是黑的，就是肾，很多人脸色发青黄就是肝
- 但是这些颜色都是枯燥干干的
- 一看到肝病到了后来，整个脸色都发青，就是肝脏的原色，就很危险
- 同理寒的病人身体脸色也是黄，因为被攻了
- 所以面目身黄，就是脾的颜色
- 因为脾主运化，是食物进来消化了以后产生血的地方
- 结果脾脏受到伤害，病人面目身黄
- 病人气血两虚的时候，因为造血功能失调了，津液也不够
- 这时候病人身上的黄，是透过皮肤看过去的血的颜色
- 病人身体很虚的黄，看到皮肤上的黄，实际上是血的颜色
- 如果是胆有问题的黄，发出来是鲜黄的，流出来的汗液都是黄的

**小便难的机理**：

- 病人小便难者，这时候脾就不能运化了，水从大便被攻掉了

**柴胡汤的误用**：

- 如果在这种状况下，再开柴胡汤给病人
- 结果柴胡汤吃下去后，柴胡汤里面有黄芩，黄芩是去热寒凉的药
- 还有半夏去水，病人已经津液了
- 下重就是脱肛的现象
- 大便便后，肛门收不起来了
- 下重不渴而饮水呕者，不渴，病人会渴，喝了水又吐
- 因为胃的火已经没有了，胃已经寒凉了
- 喝了水，根本不能化为气进入肺滋润到四肢
- 所以饮水会吐出来
- 柴胡汤不中与也，食谷者哕
- 哕就是打嗝，有哕证的时候，就代表胃气已绝
- 遇到这种情形的时候用「茯苓四逆汤」
