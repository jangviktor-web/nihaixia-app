#### 八〇、「伤寒」医以丸药大下之，身热不去，微烦者，「栀子干姜汤」主之。

> 「伤寒」医以丸药大下之，身热不去，微烦者，「栀子干姜汤」主之。

**倪海厦解读**：

- 栀子干姜汤方：栀子十四个（擘），干姜二两。上二味，以水三升半，煮取一升半，去滓，分二服，温进一服（得吐者，止后服）。
- *原典补录：《伤寒论·辨太阳病脉证并治中》第 80 条原文（**两味**：栀子、干姜）。*
- *倪师讲稿第 88 条所讲为「栀子干姜**豉**汤」（多香豉四合，三味），属另一首方，讲解见「栀子干姜豉汤」条。两方勿混。*

##### 补录（原 clause_093）

- 这是治疗虚证，病后虚烦主要的处方
- 医生一定是看到病人有承气汤证，譬如午后潮热或大便不通的情形，才会用攻下的药
- 攻下了以后，把大便都清掉，病人的身热并没有完全去掉
- 反而造成微烦，代表里面虚掉了
- 通大便的药都是寒凉的药，寒凉的药一下去，身热还没有去
- 代表里面寒很盛，本来就是寒，再用寒药下去，虚寒就更严重了
- 这寒一定在肠子里面，所以在病后要让他恢复加干姜就好了
- 干姜这药完全是「温中」的，「中」就是肠胃消化系统
- 干姜的温就是让肠胃的热度恢复，所以肠胃的蠕动功能恢复就是靠干姜
- 生姜是散寒，把寒散掉，但是没有温的力量
- 干姜的热力比生姜大很多

**如何判断寒湿**：

- 开这处方的时候，病人的舌苔一定是很薄白
- 平常摸不管是浮中沉，摸到跳一息四至的时候代表是胃的脉
- 结果摸虽然是四至，但是脉形很细，很弱，弹起来没有力量
- 就知道胃寒很盛了，这时候知道寒在胃上面，单纯是胃寒而己
- 所以加干姜在里面

**三焦寒热分布**：

- 当上焦与中焦有虚寒的时候，我们会用到干姜
- 如果是下焦虚寒，就会用到附子

**栀子干姜豉汤方**：

- 栀子十四枚劈，干姜二两，香豉四合
- 右三味，以水三升，煮取一升半，去滓，分二服

**干姜入肺、入胃（上焦＋中焦）**：

- 用到干姜，就代表病人「虚」了，而且是寒虚；部位是中焦、上焦（胃、肺）
- 干姜色白、味辛，辛入肺 → 能除肺里的寒；胃里有寒，同样是干姜
- 干姜管中焦、上焦，**不管下焦**；下焦寒要用（炮）附子——所以干姜附子汤用的是炮附子

**「寒」的定义**：

- 一息四至（呼吸一次脉跳四下）是胃气，属正常蠕动
- 蠕动速度变慢（呼吸一次只跳两下），中医就把这个不正常的速度定义为「寒」

**干姜 vs 生姜怎么选（本条辨证眼目）**：

- 本条只讲「微烦」，**没有讲恶心** → 用**干姜**温中
- 若兼**恶心** → 改用**生姜**去散寒（生姜能散寒，但没有干姜那种温中的力量）

**倪师口述参考剂量**：

- 栀子四钱、干姜四钱、香豉二钱（原文作栀子十四枚、干姜二两、香豉四合）
- 「伤寒」，医以丸药大下之，身热不去，微烦者，「栀子干姜豉汤」主之。
