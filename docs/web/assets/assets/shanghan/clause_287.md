#### 二八七、「少阴病」脉紧，至七八日，自下利，脉暴微，手足反温，脉紧反去者，为欲解也，虽烦下利，必自愈。

> 「少阴病」脉紧，至七八日，自下利，脉暴微，手足反温，脉紧反去者，为欲解也，虽烦下利，必自愈。

**倪海厦解读**：

- 那少阴病，301条，脉若紧的话，7、8天以后，自然，自已会下利，胸，突然暴烦，这个胸就是，胃，哦胃是这样，那手脚反温，脉紧反去者，为欲解也，虽反下利，必自愈，自己会好的，那这个为什么会这样子，就是刚才讲的，中间的寒湿，脾肺中间的寒湿到心和肾中间的时候，肾正在下方，中间寒湿梗到这边的时候，瞬间寒湿去掉，去掉的时候他会自下利，自下利，那，寒湿去掉，那病人，突然会感觉到，瞬间感觉到胸会暴烦，手足反温。
- 临床上看的时候，在治疗一个病人，心脏痛，心脏病，他这个心脏病很奇怪，这个，到医院去查，查不出来心脏病，然后自己失眠，一直睡不好，然后，查他，这个，他的脉也不是少阴病的脉，但是，就是凭他的失眠，凭他的失眠看，他是少阴症里面的黄连阿胶汤症，会介绍到，结果，用黄连阿胶汤加减，你知道他什么叫胸暴烦，真的领悟到了所谓心暴烦，因为他的脉证甚快速，人没有力，就跟他讲，你这个人虚数的脉，你，他，他说医生可见底怎么回事了，为什么大家都不知道，你的心脏就好像引擎在空转，心脏在跳，但是你觉得跟身体是分离的，没有感觉到心脏在帮助到你，他说，对，就是这样的感觉！好，你听着药一吃下去，中医治，就把中医炫耀一下，不是炫耀很厉害，在美国，经常说，是最烂的，你们碰到就倒霉，这药吃下去，你心脏突然感觉到引擎的力量爆发出来，好了车子会跑了，原来是空档在那边踩着油门，引擎会上档就跑。
- 结果，一个礼拜后回来，他说，吃了你的药第三天，在开会的时候，突然，中午的时候，哇，胸口很疼，一痛，好像那个引擎转到那个带子上去，突然那个带子上去了，哇，那个引擎那个动力回来了，就感觉突然一阵痛，很强烈的痛，一痛时候，手脚就开始热，哇，马上那个时候精神就来了，当天晚上就可以睡觉了，这就叫做暴烦，他的感觉就是这样子，所有的症通通去，全部去，全部去掉了，就那一剂，他现在把当神，他说，什么都要找你，所以你说现在生意，他说，这个中医居然连这个都知道，他们仪器都查不到，对，就开伤寒论的方子，所以中医绝对是对的，这个胸暴烦，就这样子，瞬间痛一下，痛一下过去了就好，痛完以后，手脚马上开始，哇，很明显，因为常常问病人，手脚是热是冷的呀，有的还说，不知道，笨蛋，还要把脚翘过来给摸，谁爱摸你的脚，晚上睡觉就知道是热是冷的，甚多人没有CommonSense，手脚热的冷的不知道，所以的病人被训练得很好，你知道，跟他说，你只要手脚是热的，就不会死，他就会永远记得。
