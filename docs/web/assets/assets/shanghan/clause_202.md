#### 二〇二、「阳明病」口燥，但欲漱水，不欲咽者，此必衄。

> 「阳明病」口燥，但欲漱水，不欲咽者，此必衄。

**倪海厦解读**：

- 在经方里面讲，口渴，嘴巴里面口渴，想去喝水，但是不想吞下去，嘴巴漱漱就吐出来，只要看到这种现象，统统是有淤血。那的唐容川讲的血症论讲了甚多，只要是口渴，不欲饮，只要有口渴，不想喝水，嘴巴很口渴，喝了水不想吞下去，你说这个人找麻烦，不是，他是有淤血。意思就是说，他的燥热上去的时候到鼻子，鼻子的血管很小，所以他的血一冲上去的时候，到鼻粘膜这边的时候，通不过去，因为血量太大，鼻血管太小。就是堵在这边的时候，血管还没有破的时候，他就会有这种现象，等于是有淤血。所以血管一破裂，流鼻血一出来的时候，高热也退掉了，同时，这个，这个口渴的现象也会去掉。淤血自己就会通。
