#### 一七二、「太阳」与「少阳」合病，自下利者，与「黄芩汤」；若呕者，「黄芩加半夏生姜汤」主之。

> 「太阳」与「少阳」合病，自下利者，与「黄芩汤」；若呕者，「黄芩加半夏生姜汤」主之。

**倪海厦解读**：

- 那一八七条，它这也是讲太阳少阳合病，自下利者，有拉肚子了，与黄芩汤。若呕者，黄芩加半夏生姜汤，阳明若，不要讲少阳，光是太阳有下利的时候，会使用葛芩连汤。若他讲太阳少阳合病，意思就是告诉你这个病人是有下利，但是兼有太阳证。太阳证的话，恶风有汗，身体肌肉酸痛，同时间往来寒热，恶心，有点恶心。就知道，啊这个病人是由太阳证进入少阳证，又出现下利。这个时候最好的选择是黄芩汤。所以纯太阳的下利，是葛芩连汤。现在是黄芩汤，那看看黄芩汤是什么东西。
- 黄芩汤方黄芩三两，甘草二两炙，芍药二两，大枣十二枚（劈）。此四味，以水一斗煮取三升，去滓，温服一升，日再服，夜一服。
- 黄芩汤，四味药，诸位看，甘草（灸甘草）、红枣和芍药加上黄芩，这四味药，来十碗水去煮成三碗，把渣丢掉，日再服，晚上再吃一次，半夜再吃一次。肠胃方面的都会这样子做，芍药出现了。大家记得，在你读伤寒的时候，仲景先师他会用到芍药，除了补阴不足，第一个目的是补阴不足，第二个，用到芍药就是有痛，腹痛。这个芍药跟枳实这两味药，张仲景在有胸满的症状的时候，他一定会加重枳实下去。把他写整齐一点，枳实。有腹痛的时候，肚子有痛的时候，一定会重用芍药。如果你弄错了，有胸满的时候你重用芍药他会更满，胸部更涨，所以治疗心脏病，几乎不用到白芍，胸满气喘也用不到白芍。那治疗肚子有痛的时候，腹痛的时候，用不到枳实，但是胸满的时候一定会用到枳实，这在念伤寒论越到后来你会看得很清楚。所以这从那个虽然那个药典胎胪药录丢了，但是凭张仲景的处方里面可以了解到，当时那个本草里面怎么注解的。黄芩这个是肠胃炎的时候一定会使用到的，如果是在胃里面，张仲景用大黄、黄连，若在到了肠子里面去用黄芩。看到了没有，这就是大黄、黄芩、黄连不同的使用。「老师若肠胃通通出问题？」大黄、黄芩、黄连。
- 你这样了解了三黄泻心汤。
- 若他的胃没问题，是在肠子里面，下利跟胃没有关系，跟肠子有关系，应该用黄芩，黄芩汤。那病人下利的时候用炙甘草，因为炙甘草入小肠，小肠跟心脏是表里。所以当会用到甘草的时候，若生甘草，多数在胃里面，肠子里面用的这个炙甘草。所以白芍能够去腹痛，去腹痛的原因是什么？是因为腹部有非常多的静脉在里面，所以白芍下去的时候，可以把静脉收起来。还有就是下利，白芍能够滋阴，同时可以生成甚多的在肠壁上腹部上面产生甚多的这个滋润的功能。白芍芍药是滋阴的药。所以你们若说一般在市面上看到市面上的四物汤里面有白芍，芍药所以实际上芍药是止腹痛的，同时可以滋阴的。那你知道这药性以后，可见若同样是四物汤，一般比例是二三三二当归、川芎、芍药、熟地这个二三三二。那老师这个月经痛，白芍一两，同样处方但是白芍加重。一看岳母说。还要年青点，生地加重点，生地滋补的药，对岳母好点，加重年青美丽。诸如此类的，所以但是你那个四物汤不可身体很健康的时候吃所以平时没事，今天有事没事你吃点桂枝汤，把肌肉不舒服的地方解掉，那你身体常年是好的，可以滋补滋补很好，因为中药本来就是食物。
- 黄芩加半夏生姜汤方黄芩三两，芍药二两，甘草二两炙，大枣十二枚（劈），半夏半升生姜一两半（一本作三两）。此六味，以水一斗，煮取三升，去滓，温服一升，日再服，夜一服。
- 那他说若恶心的，你治下利恶心的怎么办？同样是黄芩，黄芩加半夏生姜，如果说，单味是生半夏和生姜，这两个药放在一起的时候，有个特别的名字叫小半夏汤，小半夏汤。小半夏汤专门止呕，去恶心。那你若生半夏，平常半夏制过，半夏怎么制？半夏跟生姜煮在一起，生姜可以解半夏的毒，半夏有毒，解掉以后就切片晒干，烘干以后切片，叫制半夏。所以制半夏实际就是半夏跟生姜混合的东西。但是你炮制过的以后跟生用的，例如说现在要止呕，老师没有生半夏，那你去那制半夏，制半夏的话你就不用加生姜了，你加生姜是外行，因为制半夏本来就是用生姜炮制过的。那你若说真正在使用的时候，你有生半夏，拿生半夏再加生姜下去，当然生姜是解它的毒，可是你是生用直接入汤剂的话，一剂下去呕就去掉了，那比你用制半夏止恶心的力量来的强的非常多强非常多。
- 诸位看黄芩加半夏生姜，这个黄芩、芍药、炙甘草、红枣再加上半夏，他里面这个人参，没有放人参，因为他津液没有伤到，所以说这个处方呢是肚子下利、肠利，治下利，是这个热利，但是是腹痛肚子会痛的热利同时有恶心，一般小孩子肠胃炎吃坏肚子，处方都在这里面。所以说你什么时候用黄芩汤，什么时候用黄芩加生姜半夏汤，就是看恶不恶心。这两个处方都有腹痛，葛芩连汤没有腹痛的就是下利。所以说病人进来，老师那个热利怎么知道什么时候用葛芩连汤，什么时候用黄芩汤下利热利大便很臭，肚子痛不痛？痛，黄芩汤，结束了。恶心，黄芩汤加上生姜半夏。都不痛，葛芩连汤从痛就可以确诊，确实的它不会错。那止利效果甚为好，过去霍乱啊都会用到这些处方。以前抗战的时候，的老师就是抗战的时候遇霍乱疟疾那长江黄河一带，那个蒋介石政府就把他们招来，那时候没有西医，把中医抓来当军医，所以的老师军医出身，他是中医，以后不会有了，当时他们那一批是这样子过来的。疟疾霍乱的时候，下利的时候用这种，所以诸位要看病速度甚快，就是按照的方法，你只要懂方义就好了，懂方义。
