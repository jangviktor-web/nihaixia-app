#### 三六、「太阳」与「阳明」合病，喘而胸满者，不可下，宜「麻黄汤」。

> 「太阳」与「阳明」合病，喘而胸满者，不可下，宜「麻黄汤」。

**倪海厦解读**：

- 太阳有病，代表有表证，有寒束在身上
- 阳明有病，就是热发散不出来，集中在胸，往上冲，冲到肺上，而肺又被束到
- 所以喘而胸满者，不可下，绝对不可以攻里
- 如果「麻黄汤证」，表寒很厉害、怕冷，病人陈述很冷、全身骨节酸痛、没有汗
- 如果攻下就会结胸，要确定病人没表证，才可以攻里
- 如果感冒、有汗，往「桂枝汤」、「葛根汤」去想
- 如果感冒、无汗，就要想到「麻黄汤」，怕冷、关节酸痛，就是「麻黄汤」了
- 因为，「麻黄汤」很强，所以特别要注意病人可不可以开「麻黄汤」

**表寒里寒 vs 表寒里热**：

- 小青龙汤：表寒里寒
- 大青龙汤：表寒里热
- 麻黄汤：表寒
