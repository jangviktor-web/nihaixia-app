#### 一八四、问曰：恶寒何故自罢？答曰：「阳明」居中，主土也，万物所归，无所复传，始虽恶寒，二日自止，此为「阳明病」也。

**倪海厦解读**：

- 一百九十九条，恶寒何故自罢，为什么，本来是有表证一进阳明以后，表证就没了，它回答，阳明，是居中土也，万物所归，无所复传，始虽恶寒，二日自止，两周以后自止，此为阳明病也，阳明病，可见无所复传，因为万物所归，所以的脾土，脾胃的土，肠胃的功能甚为强大，它能够消化任何的东西，就好像大自然界的脾土一样，土一样，土能够承载万物，你有没有听过土在那边抱怨，没有，它是不断地默默承担人类的垃圾。它是，万物所归，所以说，到这边，无所复传。这个条辨，大家可以了解到，病到阳明，就停住了。停住，不代表说，不可去治疗它。希望诸位在有便秘的时候，就去治疗它。你若有便秘的时候治疗它，你就不需要什么SKⅡ了，面膜都不需要，因为大便很好，皮肤会甚为润泽，你皮肤黑色会出来，就是大便都不好，肠胃不好，所以脸上的阳明经，承泣，四白，巨髎，眼睛下方，头维，下关，颊车，承泣四白巨髎，眼颊的部分是属于阳明，所以你阳明经若很好的话，脸上的皮肤就很好，所以可见看脸上皮肤的话，就知道这个人是便秘，还是下利，还是很正常。到这里可见，不会传经的。
