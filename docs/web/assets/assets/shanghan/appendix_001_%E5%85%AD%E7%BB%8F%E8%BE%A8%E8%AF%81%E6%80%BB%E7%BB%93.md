#### 附录一：六经辨证总结

**六经用药总结**（113 方一以贯之）：

- 太阳用麻黄、少阳用柴胡、阳明用葛根（葛芩连汤）、少阴用细辛——**统统是辛散**
- **非寒不泄**：不用寒药无法宣泄——石膏、大黄、黄芩、黄连
- **非温不补**：药性不温则补不到里面去——吴茱萸、干姜、附子、蜀椒
- 张仲景的补法不是开四物汤，而是**以温药作补**
- **上工治未病**：不单是知道肝病会传脾，而是**在还没发病时就知道肝有问题**，不靠检验指数。
- 肝主丑时（01–03 点）：此时不能睡，就要注意肝
- 肝有两个宣泄口：**胆（排胆汁）与大肠**（肝下方有血管通大肠）——所以治肝要治大肠、保持大便通畅
- 早期征兆：小便偏黄、饭前不饿没胃口、手掌由粉红转深红→暗红
- 实脾的目的：把病截止在肝，不再传

**肾病治心**（以此类推：见肾之病，知肾传心，当先实心）：

- 肾水本应生木，肾一坏水不生木、直入心 → 水克火
- 掌心（劳宫、少府）发黑发青 = 肾的问题；掌红 = 肝的问题
- 苦味入心 → 用**黄连**解肾毒（尿毒入血）
- 危候二征：**呕吐不止**、**头晕昏眩**（毒气上冲）
- 好转指标：呕止、眩停、小便恢复便意（日 2000–3000cc）、掌黑退去——不必拘于尿毒指数
