#### 九六、「伤寒」五六日，「中风」，往来寒热，胸胁苦满，嘿嘿不欲饮食，心烦喜呕。或胸中烦而不呕，或渴，或腹中痛，或胁下痞硬，或心下悸、小便不利，或不渴、身有微热，或咳者，「小柴胡汤」主之。

> 「伤寒」五六日，「中风」，往来寒热，胸胁苦满，嘿嘿不欲饮食，心烦喜呕。或胸中烦而不呕，或渴，或腹中痛，或胁下痞硬，或心下悸、小便不利，或不渴、身有微热，或咳者，「小柴胡汤」主之。

**倪海厦解读**：

**少阳证的起因**：

- 此条辨，太阳证也有，少阳证也有，起因是表证没有好
- 一〇五条简单的讲了一下少阳证
- 伤寒五六日，如果得到感冒一段时间后

**少阳证四大主证**：

- 「或」是副证，参考就可以了，主证有四个：
- 一、往来寒热
- 二、胸胁苦满
- 三、默默不欲食
- 四、心烦喜呕

**病在何处**：

- 病在表有太阳、少阳、阳明
- 如果是病在太阳和少阳中间的时候，就是小柴胡汤
- 如果太阳进入阳明，比较偏重阳明的时候，就是承气汤
- 如果是在少阳和阳明中间，就是大柴胡汤

**小柴胡汤的临床场景**：

- 例：小孩感冒发烧，西医开退烧药，又开很强的镇静剂给小孩睡觉
- 一个星期后，这小孩的淋巴结整个肿起来，又感觉往来寒热
- 就是一天来好几次的忽冷忽热，跟「疟」不一样
- 疟有隔日疟，或间日疟，有时间性的
- 中医的少阳就是淋巴系统
- 太阳表证在人的皮肤表面，进入皮肤的时候，就是桂枝汤证
- 没有治疗好，就进入半表半里，就是淋巴系统上
- 淋巴系统也是人的防卫系统

**如何知道进入淋巴系统**：

- 中医的辨证论治，第一往来寒热，第二胸胁苦满
- 胸胁的地方，纵膈膜、横膈膜、胸腔里面都是水，严重的还有水声，很胀满，肋骨会痛
- 第三默默不欲食，人的五脏六腑外面都有淋巴和神经，自然肠胃的蠕动会受到影响
- 第四心烦喜呕，为什么喜呕？
- 第一食物没有完全消化掉，第二淋巴系统里面有很多水份
- 淋巴系统里面的水和血常常在互换，就是内分泌系统
- 病邪进入的时候，水隔在中间
- 胸胁苦满，纵膈膜、横膈膜、胸腔里面都是淋巴包到
- 水太重的时候，通通便在这
- 这水又不在胃里面，而在淋巴系统里面
- 所以中医讲半表半里，没有进入内脏，全部进到里面就是阳明

**柴胡的药性**：

- 柴胡，长在地上的时候，一半在上面，一半在下面
- 柴胡拉起来，根和身体是一样高，所以一半在表，一半在里
- 所以甲状腺亢进，内分泌系统的问题，都用柴胡
- 内分泌全部包括在少阳里面
- 只要不入脏的，脑部、淋巴结、大脖子都算在内
- 柴胡是主要的药，所以叫柴胡汤

**小柴胡汤七味药的原理**：

- 大柴胡汤就是病邪进入少阳和阳明之间用的
- 太阳刚刚好进入少阳的时候，因为胸胁苦满，所以一定开半夏
- 本身呕，就是一定是柴胡证
- 如果是呕，就代表少阳证，少阳证的主证是呕
- 如果是渴就是阳明证
- 为什么往来寒热？因为是淋巴系统的时候已经不在表了
- 这时候人的免疫系统出来抗，打赢的时候就是热，打输的时候就是冷
- 所以一来一往，因为近距离交战，这样一天好几次，没有限定时间的即是柴胡证
- 所以有热的现象就黄芩在里面，因为黄芩能够去热
- 因为默默不欲食，就是小柴胡汤，七味药就是小柴胡汤
- 北派用人参的时候，专门治心下满，就是胃不好的时后吃人参
- 所以泻心汤中有人参就是专治肠胃的
- 柴胡把黄芩带到半表半里，就是淋巴系统里面
- 人参、生姜、甘草、大枣，进入体内以后肠胃一样吸收，免疫系统增强
- 所以小柴胡汤也会有流汗的现象，汗一出来也解掉了

**误治的后果**：

- 但是如果小柴胡汤证，开的是表药桂枝汤、麻黄汤、葛根汤
- 就是开成太阳证的药，就进入纯少阳了
- 把阳发挥后，少阳马上转阳明
- 因为一发表的时候，津液会伤得更多
- 津液伤了却没有把病毒清掉，反而把正常的体液丧失掉了
- 结果转移到体内，就会有肠胃炎下利的现象

**三阳并病的处理**：

- 如果三阳并病，项强、头痛、中风、太阳证
- 还有恶心、胃口不开、口渴
- 三阳并病的时候，中医叫「担法」
- 不要柴胡桂枝开在一起

**小柴胡汤的药理解释**：

- 「柴胡」苦辛，专疏泄淋巴管，解三焦之壅，开胸膈之塞，退寒热
- 解烦渴，「小柴胡汤」以之为君
- 「黄芩」苦寒，清火郁
- 「姜」「夏」辛温，降水逆
- 「参」「草」「枣」则为补助津液，以为佐耳

**小柴胡汤方**：

- 柴胡半斤，黄芩三两，人参二两（倪师讲课版源1505；宋本三两），甘草三两
- 半夏半升洗，生姜三两切，大枣十二枚劈
- 右七味，以水一斗二升，煮取六升，去滓，再煎，取三升，温服一升，日三服

**剂量应用**：

- 柴胡，胖子用五六钱就可以了，平常人三钱，小孩一钱半二钱
- 黄芩、人参、甘草、生姜各三钱（彼此等量，柴胡重用为君——临床柴胡五钱>其余各三钱，源1509）
- 因为黄芩比较寒凉，要同时理中，让中焦恢复，同时把病毒排出去
- 半夏重用，柴胡用三钱，半夏就少于三钱
- 大枣无所谓多少
- 平常六碗水熬成两碗，空肚桂枝汤喝完要吃点稀饭，让药发散一下
- 其余的汤剂不用

**小柴胡汤加减法**：

- 原本伤寒论里面，张仲景没有加减法，加减法是后人加进去的
- 若胸中烦而不呕，去半夏、人参，加栝蒌实一枚
- 若渴者，去半夏，加人参合前成四两半，栝蒌四两
- 若腹中痛者，去黄芩，加芍药三两
- 若胁下痞鞭，去大枣，加牡蛎四两
- 若心下悸，小便不利者，去黄芩，加茯苓四两
- 若不渴外有微热者，去人参，加桂枝三两，温覆取微汗愈
- 若咳者，去人参、大枣、生姜，加五味子半升，干姜三两

**加减法详解**：

- 若胸中烦而不呕代表胃里面没有停水了，这时候加栝蒌实
- 为什么加栝蒌实？胃的下方的结实
- 平常胃的下方随时保持着两公升的食物在里面
- 永远有东西停在里面，新的食物就把旧的推出去
- 所以有时候吃了三四小时后，还会恶出食物的味道
- 这一段东西坏掉的时候，会心烦，不是心情不好
- 而是胃里面不通，胀闷胀满的感觉，不会恶心呕吐
- 这段坏掉的时候，用栝蒌实
- 用的大黄芒硝，会直接下去，不会停留在胃下方
- 调胃承气汤里面，是在十二指肠的地方
- 若渴，去半夏，加人参合前成四两半，栝蒌四两
- 这里的栝蒌是栝蒌根，栝蒌根可以生津止渴的
- 临床上，栝蒌根可以降血糖，有种种病
- 角弓反张，脑膜炎，就是用栝蒌根
- 若腹中痛者，去黄芩，加芍药
- 为什么肚子痛？寒湿跑到下焦去了
- 张仲景对腹痛一定会重用芍药
- 凡胸满者，一定去芍药
- 一般不通代表肝气不足，没有办法舒松开来
- 因为少阳讲的就是胆
- 消化这时候用重牡蛎，牡蛎可以平肝气
- 而且咸能软坚，能够去除硬块
- 不只是在胁下，喉咙的硬块、腋下淋巴的肿块，都可以用牡蛎
- 心下悸，心下悸即水在中焦，才会令小便不利，所以用茯苓
- 一般来说有咳嗽的时候，药常常把红枣拿掉
- 红枣何时加何时去看病情
- 如果病人湿热很盛的，还有酒客，因为红枣太甜，属甘味，吃了会增腻
- 舌苔黄、抽烟多的，就把红枣拿掉
- 五味子没有寒热，只针对咳嗽，有润肺的功能
- 五味子加二三钱就够了，咳得重的加点重

**小柴胡汤治肝炎**：

- 小柴胡汤治疗西医说的肝炎，由中医来看，就是有湿热
- 小便黄兼往来寒热、胸胁苦满、默默不欲食、心烦喜呕等等
- 西医只知道这是肝肿起来，顶到胃了，病人没有胃口
- 我们加上茯苓、白术，茯苓稍微比白术多一点，以去湿来改善胃口
- 然后加上郁金来行肝气
- 病人如果全身黄疸，病人的精神还好，用茵陈蒿
- 虚烦不得眠，加栀子

**如何判断肝病好转**：

- 怎么知道病人好？
- 晚上一点到三点能睡了、一觉到天亮胃口好、小便颜色正常
- 体力恢复，双脚温热起来，就代表病好了
- 西医以为肝癌是无形的杀手，那代表西医不能预先诊断出肝癌
- 其实正统中医两年前就能知道
- 我们可以在发生肝癌在肝脏之前
- 每天晚上上一点到三点不能睡，就要赶快治疗了

**郁金与疏肝**：

- 这些种树的技巧以领悟治肝的方法
- 郁金用来疏散郁气，半夏去多余的水等等
- 都是与肝木喜疏达的特性有关

**小柴胡汤为预防肝病第一方**：

- 小柴胡汤可以是预防肝病的第一方
- 淋巴结、淋巴肿块，这是结实在三焦
- 我们用黄色去实的药，用小柴胡汤加石硫磺
- 当脑部有积水时，用小柴胡汤加重半夏去至高之积水
- 乳癌的药方，其实也是小柴胡汤的加减
- 遇到经期来的时候，乳癌的药方中需加桂枝
- 利用桂枝降冲逆的特性，把水导入子宫里

**小柴胡汤的广泛应用**：

- 临床上只要看到小柴胡汤的主证，就可以用小柴胡汤
- 我们不管西医的病名是肾脏病或是经期生理痛等其它病名
- 还有，当女性在经期得到感冒，一律使用小柴胡汤来和解
- 女性经期腹痛用小柴胡汤加白芍，需要的时候白芍可以加重使用

**古今医统**：

- 【古今医统】曰：「小柴胡汤」治瘰疬，乳毒，便毒，下疳
- 及肝经之一切疮疡，发热，潮热，或不思饮食
- 小柴胡汤进入三焦，所有的淋巴系统、腺体
- 手少阳三焦经、足少阳胆经、肝，是人身上最主要最大的腺体

**正体类要**：

- 【正体类要】曰：小柴胡汤治一切扑伤等证
- 打架，身体表面很好，可是气血而又没有瘀血
- 所以他是伤在半表半中间
- 大便如果是黑色的，就是有内出血
- 小便不通了，代表血堵在膀胱了
- 一般性伤科是小柴胡汤证
- 但是小柴胡汤下去只能清热消炎，打架不能把瘀清出来
- 所以用桃仁，不一定是桃子的仁，杏子的仁也可以
- 桃仁这专门攻破瘀血

**伤科用小柴胡汤加桃仁**：

- 胃的血已经离开血管，跑到淋巴系统里面去了
- 在三焦油网中间，经过十几年后
- 西医打开来看胃有没有问题，但是胃壁和淋巴结成一块
- 纠结得拿不掉，所以西医叫淋巴癌
- 在伤的时候，就用小柴胡汤加桃仁
- 如何查有瘀血，看舌头，舌头上有一块青一块黑的，旁边有齿痕
- 他可能没有感觉，这时候用小柴胡汤加桃仁
- 桃仁加一钱半，胖子用五六钱都可以
- 包括女孩子的妇科也可以用，子宫在半表半中间
- 子宫是腺体，所以子宫拿掉，内分泌不平衡，内分泌系统全部属于半表半里

**脑受伤瘀血的处理**：

- 脑受伤瘀血，在脚上「然谷」放血
- 下针「涌泉」「人中」「百会」
- 处方「小柴胡汤」的加减，加些破瘀的桃仁、红花
- 三焦、血脉、神经、脑细胞都属于少阳
- 所以眼睛、鼻子、耳朵、头部都是属于少阳

**保命集**：

- 【保命集】曰：产后日久，虽日久而脉浮疾者，宜服「二元汤」
- 即本方合「四物汤」（又名柴胡四物汤）
- 就是小柴胡汤里面加四物汤

**四物汤方**：

- 当归、川芎、白芍、生地
- 真正滋补的时候用生地不是熟地，而且大剂的用
- 瘦子当归用五钱生地用一两
- 当归和生地专门补血的，补到脊椎骨上面去
- 脊椎骨生血的力量很强
- 熟地就是生地炒熟就熟地，炒过炮制的比较热
- 虚热的人补药下去会更热，用生地嘴会破，用生地就不会了

**四物汤的临床应用**：

- 女孩子月经子痛，白芍专门止腹痛，能破瘀
- 所以产后或流产过，肚子会痛可以用芍药甘草汤
- 一两，平常二三钱就很强了
- 让血流回心脏比较强就可以了
- 如果是静脉瘤那二三钱就不够了，一定比例
- 如果要让怀孕很好的话，一定加重川芎
- 如果是月经来的时候吃的，可使她的子宫排干净，把瘀血清出来
- 西医之子宫内膜异位，一定会加重川芎
- 如果眼睛黑黑的，舌头胖胖的，生地可以重用到二三两都可以

**乳房硬块的治疗**：

- 乳房硬块，小柴胡汤可以去掉胸胁苦满
- 如果硬块比较严重的时候，同样是小柴胡汤就要加一些减一些
- 如果要让胸部的满去掉，桃仁是很好的破瘀的药
- 也可以加牡蛎，牡蛎也是攻坚的
- 牡蛎的攻坚和芒硝不一样
- 中药里面有很多攻坚的药，桃仁、附子也是攻坚的药
- 什么时候用到附子？只有在腹膜炎的时候才用附子
- 已经发热了，非用附子把它清出来
- 这时候附子就不是补阳的药而是攻坚的药

**炙甘草与胸阳**：

- 要让胸阳旺起来，重用炙甘草
- 炙甘草平常用一二钱是对肠胃的
- 加重到五钱一两的时候，上焦热就热起来
- 所以后面有炙甘草汤，炙甘草用到四五钱以上，马上热在胸阳
- 所以一救逆的汤方「甘草干姜汤」，炙甘草用到四、干姜用二
- 炙甘草加重，让胸阳热起来，才有血在上焦

**乳癌的经验方**：

- 治疗乳癌的经验方：
- 第一方是治乳癌或是乳房中有硬块，尚未溃烂破出时使用：
- 柴胡三钱、黄芩三钱、瓦楞子五钱、川芎三钱、丹皮三钱
- 三七三钱、续断三钱、炮附子五钱、阳起石三钱、白芍五钱
- 枳实三钱、乳香三钱、炒麦芽五钱、玉金五钱、当归二钱
- 牡蛎一两、龙胆草三钱
- 体力差足冷，加熟地三钱；经期加桂枝三钱
- 九碗水煮成三碗，早晚餐前各一碗
- 第二方是治疗乳癌已经溃决破口，有恶臭，出黑臭水时使用：
- 柴胡三钱、紫根五钱、龙骨五钱、牡蛎一两、白术五钱
- 炮附子五钱、黄芩三钱、黄连三钱
- 九碗水煮成三碗，早晚餐前各一碗
- 以上方为主力处方来做加减
- 当病人进入乳癌末期气血两虚时
- 可以用八珍汤来做加减
- 主要观念在行气，破瘀，用咸味攻坚，开气去郁
- 令三焦气机流畅
- 同时必须以强固胃气，增加命门火维持生命的延伸为主

- 触之有一种抵抗物、同时觉压痛者是
- 则之随脑、咽喉、气管、支气管、肺、肋膜、心脏、胃、肠、肝、脾、胰、肾、子宫等病证之治愈
- 而此抵抗物亦渐次消缩
- 是故余谓胸胁苦满之腹证，概不外前胸壁里面所有淋巴腺之肿胀硬结也
- 师之创立「小柴胡汤」，即欲此续发的淋巴腺之肿胀硬结与其应用主目的者
- 又以此淋巴腺之肿胀硬结为其应用主目的者
- 夫亦以其续发的病变不仅易于触知，且确定不变也
