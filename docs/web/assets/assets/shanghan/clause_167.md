#### 一六七、病胁下素有痞，连在脐旁，痛引少腹，入阴筋者，此名「藏结」，死。

> 病胁下素有痞，连在脐旁，痛引少腹，入阴筋者，此名「藏结」，死。

**倪海厦解读**：

- 一百八十二条，这个条辩可以看到，当年在汉朝那个时候，之前他们那个医学技术不发达，像这种病不该死的死掉了。病，胁下，素有痞，硬块，痛，连在脐旁，肚脐旁边痛，痛引到少腹，入阴经者，用来说的话就是到睾丸里面去了，此为藏结，死。张仲景说死。这个呢根据解读想的原因，它疝气或者是肠炎或是那个腹膜破掉在里面。那当时发炎，没有那种好的医生，好的技术，所以，一看到这种病就死掉了一看到这种病就死掉了。也可能是盲肠炎或者怎么样的就死掉了。
- 看过这种病人，有个病人，这个病人是女孩子，女的没有睾丸，没有关系她就是痛在这块儿。强痛，痛了多久？十五年。英国的女人。那你去医院看，有没有跟你说是盲肠炎或腹膜炎。「没有，都说很好，说这里（指大脑）有问题」。这个十五年，这个太太十五年就呆在家里面不能出门。一按，哇！拒按！然后再一压她的足三里下一寸，阑尾点，压痛。更好玩的是在哪里，这个人的手掌，这个已经拍照拍下来。所以那个相机很方便。她的手掌，这是指头，这样画，这个指头上去，大指在这边，生命线在这边，简单画一下，在生命线的中间如此大一块，褐色的，褐灰色的那个圆圆的一块，这样的，在手掌，左手掌上。这是大肠，正好在合谷、大肠交界的地方。常常看大家的手掌，中医看手掌不是帮你算命，因为每个人看手掌都是帮人算命，不是，看你的肝脏，看你的身体。那病人就有这个现象。处方的时候，用经方的大黄牡丹皮汤还是用金匮的方子攻它，她已转成腹膜炎，腹膜炎的时候已经破裂掉了，认为她是肠子破裂掉了。她大便甚为不好，所以用薏米附子败酱散跟大黄牡丹汤给她吃。刚开始吃粉剂不是吃汤剂，后来改成粉剂。天哪，这个人呢连续吃六个月。
- 诸位以为说，那六个月不是下利，利死人。你错了。用汤剂给她，前三个月的时候，给她还是一天一次，不给她吃的话，她一个礼拜上一次厕所，少许出来。越吃她就越来越收，然后现在这个这个褐斑嘛完全褪掉了，正常了。但是她还有，因为她大便好甚多了，所以就改粉剂给她吃，装在胶囊里面，不用如此痛苦。然后这个女的她才给，十五年了她没有办法出门，痛，痛，然后现在可以出来了。可以出来走动，可以出来听听音乐、看看电影啊什么的。以前就呆在家里，你说她先生痛不痛苦。
- 所以你以为腹膜炎或是盲肠炎，美国医生可以查到，告诉你照样查不到。可是病人骗你干，说痛得要死，她为什么骗你痛，医生给她给她的结果就是说她神经有问题，然后验血，他说她没有发炎，都没有都好的，实际上就是藏结，就是堵在这个地方，连在阴茎上了。那当年写死，实际上这个证应该不会死的，也有可能是大肠癌或者怎么样子，或者是睾丸癌。
- 脏结专论：「脏结」为邪结在脏，与阴相结。邪结在胸，与阳相结为「结胸」。「脏结」证见白滑舌苔者，难治。无阳证，不往来寒热，其人反静，舌苔滑者，不可攻。病者若胁下素有「痞」，连在脐旁，痛引少腹，入阴筋者，死。「结胸」证，脉浮大者，下则死。「结胸」证悉具，烦躁者死。病名曰「结」，脏器有硬变，或内部肿瘤所致，古称「症瘕积聚」故预后不良，或为癌瘤，则死期可待。
- 「脏结」就是脏腑之间联络的网络，被「寒」与「湿」固结了，结果「腑」里面吸收的营养没有办法给「脏」，「脏」没有营养，「脏」的功能逐渐衰弱，所以「脏结」的病人，舌苔都白白的，很厚很滑，皮肤很黄，暗暗黑黑的，没有什么精神，不爱讲话，静静的。刚开始西医检查都正常的，等到检查出来的时候，已经尿毒了，肝硬化了，中医治疗三天舌苔就变回来，中医为什么看舌苔？就是看看病人有没有胃气，「脏结」的人舌苔白掉了，吃东西淡而无味，食同嚼蜡，搞不好四五十岁还在生青春痘，因为在三焦油网上，所以一定要大剂的用「柴胡」，利用柴胡把药导到三焦油网上面，因为是全身性的寒且湿，去湿靠白术，可以用五钱，这是胖子用量，湿要有出路，靠茯苓，由小便导出来，去寒靠炮附，用三钱，加些生姜在胃里面和，最重要的是「生附」，生附一枚，炮附把里阳壮起来，裹寒去掉了，肌肉上和三焦油网上的寒，全部靠生附去掉，生附下去，病人除了小便量增加以外，大便出来溏的，大便稀稀的，吃了三付后，舌苔就变回来，胃口大开，临床上尿毒的病人，吃一剂，尿毒指数从二百八降到一百三了，炮附温中，生附温经，血脉、神经都温到，这是主方，临床上看病人还有何症状作加减，若胃口不好常常恶心就加半夏，依此类推。有些久病的病人，在吃药去除寒湿以后，因为脏与腑开始可以沟通了，会有吐「白津」或大便溏的现象，这种情形在病人开始出现口渴的时候就会好转。
- 脏结汤方柴胡五钱、白术五钱、茯苓五钱、炮附三钱、生附一枚主方在此，其余需临证视情况而定。
