#### 三六一、下利脉数，有微热汗出，今自愈。设复紧，为未解。

> 下利脉数，有微热汗出，今自愈。设复紧，为未解。

**倪海厦解读**：

- 下利，脉缓，有微热，汗出，令自愈，设复紧，为未解。
- **向愈之征**：脉缓（邪退）、有微热（胃阳来复）、汗出（郁热外透）、胃口开能喝水 → 今自愈。
- **未解之征**：脉**复紧**——紧主寒、主痛，代表寒没排干净，还有寒在里面。
- **处理**：这种不要去治他，让他多吃点稀饭，慢慢等胃气恢复。

**倪师养生三档**：

- 常态吃**七分饱**；病态吃**五分饱**；（玩笑话）「虐待人」吃一分饱
- 常保五分、七分，胃一直蠕动，胃气长存；**胃气存则手脚温热，主长寿**
- 吃太饱是口腹之欲，伤胃耗气，反而折寿

##### 补录（原 clause_349）

- 如果说这个病人呢也是下利啊，但是脉缓，有微热，汗出，令自愈，如果又紧，为未解。就是说本来应该是自己会痊愈，为什么？有微热，热回来，胃口也开了，能够喝点水，结果摸他的脉，脉又是沉紧的，代表说还没有完全排掉，还有寒在里面。像这种，不要去治它，让他多吃点稀饭，慢慢慢慢胃气恢复，常常跟病家说，包括自己养生之道，要吃七分饱，平常常态的时候吃七分饱，病态的时候吃五分饱，当你生病的时候吃五分饱，虐待人的时候吃一分饱。所以五分饱是治病的，七分饱是正常的，吃太饱口福之余这个不好，对身体不好，短命的，那若常常保持这样子。那你的胃把它保存五分。五分饱没有全饱的时候。胃会一直蠕动，胃气一直在那边，那只要你胃气常存，手脚温热，这种都是长寿。
- **宋本异文**：宋本第361条作「下利脉数，有微热汗出，今自愈。设复紧，为未解」；本库从倪师讲稿作「脉缓……令自愈」。
