#### 一一一、「太阳病」「中风」，以火劫发汗，邪风被火热，血气流溢，失其常度。两阳相熏灼，其身发黄。阳盛则欲衄，阴虚小便难。阴阳俱虚竭，身体则枯燥，但头汗出，剂颈而还，腹满，微喘，口干咽烂，或不大便，久则谵语，甚者至哕，手足躁扰，捻衣摸床，小便利者，其人可治。

> 「太阳病」「中风」，以火劫发汗，邪风被火热，血气流溢，失其常度。两阳相熏灼，其身发黄。阳盛则欲衄，阴虚小便难。阴阳俱虚竭，身体则枯燥，但头汗出，剂颈而还，腹满，微喘，口干咽烂，或不大便，久则谵语，甚者至哕，手足躁扰，捻衣摸床，小便利者，其人可治。

**倪海厦解读**：

- 已经有感冒的热在身体里面，然后又有火气进来了
- 用火熏他，这是两个阳热在互相熏灼
- 结果造成病人津液丧失过多，其身发黄
- 血里面百分之六十的水，水份丧失很多的时候
- 从皮肤上看到血的颜色是黄色的，实在是血的原色，其实是液不足了
- 这时候吃水果最好

**阳盛vs阴虚**：

- 阳盛则欲衄，阳气是往上走的
- 如果病人会流鼻血，血里面的热就会散出来，就好了
- 如果病人阴虚小便难，因为津液不够了

**阴阳俱虚竭**：

- 阴阳俱虚竭，身体则枯燥，就好
- 如果病人阴阳两虚，身体就枯燥了，瘦干干的
- 但头汗出，为什么有这现象？身上一点汗都没有，但是满头大汗，就是头汗
- 中医叫浮阳，浮阳就是免疫系统，就是肠胃的功能
- 肠胃的热气，正常时阴阳是相交的
- 为什么阳热能停在中焦不会散出去？因为人有阴，有津液，按一定比率存在
- 所以可以停在中焦

**浮阳与牡蛎**：

- 有一天如果津液少了，津液少的原因，可能被攻下，可能被火烤
- 津液一少，胃里面的阳热就冲到头上去了
- 中药里面能把浮阳降下来，最好的就是牡蛎的壳，牡蛎会收浮阳
- 相书上学牡蛎人只能干校宫干不了将官，因这人太急躁了
- 一上蒸笼头这种人只能干校官，不适合带兵
- 所以牡蛎是收浮阳，与这里的「但头汗出」不同
- 这里是阴阳都虚掉才会头汗出

**津液伤极的症状**：

- 腹满，里面的大便都干掉了，微喘，口干、咽烂，喉咙都烂掉了
- 或不大便，久则谵语，甚至至「哕」
- 严重到打嗝的时候更虚，有打嗝现象就是胃气绝了
- 如果再进去手足躁扰，捻衣摸床

**小便利者其人可治**：

- 小便还通利，代表他元阳还有
- 因为小便是气化出来的，代表津液还有
- 如果小便都没有了，就真的很危险了

**小儿感冒误治案例**：

- 例：小孩感冒，麻黄汤证，一剂下去小孩发汗太过，烧退了就转白虎汤证了
- 结果误诊，看他还发烧给大青龙汤，小孩一直在发汗
- 原来是太阳表证，立刻转成阳明燥证，就捻衣摸床
- 这代表津竭了，而阳明燥热证
- 对小孩摸脉不浮，因为小孩的脉，正常时都跳得很快
- 摸肚子拒按，表示大便堵在里面
- 阳明证应该考虑大承气汤或白虎汤？
- 结果因按而用大承气汤，大承气汤一下去，烧就退了
- 还有，这小孩从小就黄疸，大便不好，常常阳明燥热
- 常常口渴，常常便秘，脑子反应慢
- 大承气汤一攻都好了

**孙斋氏曰**：

- 孙斋氏曰：本条直对证药：
- 「黄疸病」用茵陈蒿汤
- 腹满而喘、谵语、下大便用「承气汤」
- 独躁扰循摸一症为神经濒绝之现象，法在不治
- 这现象用「大承气汤」
- 如果白虎汤证造成的壮热，用犀角地黄汤可能会好
- 大便不通的，就不会好
