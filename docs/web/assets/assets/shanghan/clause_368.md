#### 三六八、下利后脉绝，手足厥冷，晬时脉还，手足温者生，脉不还者死。

> 下利后脉绝，手足厥冷，晬时脉还，手足温者生，脉不还者死。

**倪海厦解读**：

- 下利后，脉绝，手足厥冷，睟时脉还，手足温者生，脉不还者死。
- **手足厥冷之辨**：平常人的手脚凉还算是「温」；这里讲的冰冷是**摸上去像冰块**一样，是真寒之厥。

**晬时 = 周时，一昼夜（约 24 小时）**：

- 若脉回来、手脚转温 → **生**
- 脉不回来 → **死**

**不可坐等**（倪师强调的重点）：

- 摸到脉没了，不能只是等——**通脉四逆汤**（生附子、干姜、炙甘草）先把脉弄回来
- 煮药时手也不要闲：同时灸**关元、中脘**，帮胃气恢复
- **与三七七条分工**：三七七重在「灸之不温、脉不还、反微喘」判死；本条重在给阳气一个昼夜的观察窗，同时主动救逆，而非消极等待。

##### 补录（原 clause_363）

- 下利以后，脉绝，脉没有了，手脚冰冷，过一段时间呢，脉又慢慢回来，睟时呢约一天24小时，手足温者生，脉不还者死。手足温代表胃气回来，诸位在阳明篇大承气汤证的时候大承气汤病人很热的时候，手脚多汗。这里手脚温代表胃气回来，所以这个最主要看病人虚冷下去不好，人虚脱下去了，脉很少，看他会不会活回来，就看他手足温。手脚是温的胃气慢慢回来就不会死。若一天以后回不来就会很危险。
