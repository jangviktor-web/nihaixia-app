# 第六章·灵龟八法

今天进入理论部分的最后阶段。 第一个是介绍子午流注，还有一个灵龟八法。是耳针、 回阳九针、 十三鬼穴。 这是比较特殊的治症，针灸基础要很好，基础不好的话，知道穴道也没有效果， 先介绍灵龟八法。

过去中国人，不管在哲学、 军事、 医学，都脱离不了易经八卦的范围。 易经八卦有先天卦 、后天卦， 易经八卦有： 干三连，坤六断，震仰盂， 艮覆碗，离中虚，坎中满，兑上缺，巽下断。 实际上， 先天卦就是一个四度空间，本身是静止的状态， 当把它变成后天卦的时候，就可以用它。 用的都是后天卦， 临床上不管是算命、看风水 、命理、看病 、针灸上，通通都是用后天卦，有个方法， 当书上讲的很复杂， 怎样去计算时间， 会弄个大半天。 但实际上， 有这个盘可用， 不用去算如此复杂的过程。

灵龟八法跟子午流注，有一个特性， 是在什么时机用它。 一般用在急救、 急诊上，平常当然也可以用， 但怕你学了以后， 例如学了灵龟八法，其他治疗法都忘了，都用灵龟法。 若姓陈， 以后就叫陈灵龟了。 例如子午流注， 你姓孙， 以后叫孙子午， 正常的经络都忘了， 前面讲的都是主流， 下面介绍的就是给你翅膀，你是只老虎， 给你翅膀，增加你的功力。 耳针、 回阳针、 十三鬼穴， 会一一跟诸位介绍。
