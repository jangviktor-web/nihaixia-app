# 第六章·回阳九针

诸位看卷四，八十六页、八十七页的回阳九针。 这个回阳九针歌， “ 哑门劳宫三阴交， 涌泉太溪中脘接， 环跳三里合谷并。 此是回阳九针穴 ”。

中脘是胃的募穴，这个回阳针是用在过去病人虽死掉， 但心口还有温度， 回阳针就可把人从阴间拉回阳间。 下针按照过去的说法，下针后会醒过来，醒过来就活的好好的，但有时候下针回来只能多活半个小时，这半个小时，就是过去说的回光返照，让他把遗言交待一下。

下回阳九针时，过去的老师有用过，在美国怎么会有机会用到。病人都送到太平间，还没有让他回阳，他就已经归阴了，都来不及回阳，所以碰不到使用的机会。

的老师曾告诉，在大陆作战的时候，在部队里面有这种情形，下针的时候，病人断气了，但家属没到，病人眼睛张开，死不瞑目，要等家属到了再看一眼， 等家属到了，病人已经不会讲话，的老师就下回阳针， 下针后病人醒过来， 开始讲话。 一般而言，不用下到第九针， 大约第六针，病人就开始呼吸可以讲话，那下完九针以后，老师的经验约有半个小时，让他把所有事情谈一谈，遗言交待一下。

这是用在最后一步， 已经没有可以用的方法了，就用回阳九针。 穴道要下的准， 不要足三里下到足二里， 三阴交下到二阴交。 要练到一看就要知道穴道在哪，这是经验，诸位要到这个阶段才行。 这是的九个位置，记得就好， 会不会用到， 很难讲， 可能一辈子用不到， 没用过， 看你个人会不会用到。

孙真人针十三鬼穴歌百邪颠狂所为病，针有十三穴须认， 凡针之体先鬼宫， 次针鬼信无不应，一一从头逐一求， 男从左起女从右。 一针人中鬼宫停， 左边下针右出针； 第二手大指甲下，名鬼信刺三分深； 三针足大趾甲下，名曰鬼垒入二分； 四针掌上大陵穴， 入针五分为鬼心； 五针申脉为鬼路， 火针三分七锃锃； 第六却寻大椎上， 入发一寸名鬼枕； 七刺耳垂下八分，名曰鬼床针要温； 八针承浆名鬼市，从左出右君须记； 九针劳宫为鬼窟； 十针上星名鬼堂； 十一阴下缝三壮， 女玉门头为鬼藏； 十二曲池名鬼腿， 火针仍要七锃锃； 十三舌头当舌中， 此穴须名是鬼封。 手足两边相对刺， 若逢孤穴只单通， 此是先师真妙诀，狂猖恶鬼走无踪。
