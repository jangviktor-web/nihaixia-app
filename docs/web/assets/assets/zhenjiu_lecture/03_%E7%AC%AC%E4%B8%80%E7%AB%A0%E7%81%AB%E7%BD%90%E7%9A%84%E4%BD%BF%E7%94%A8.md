# 第一章·火罐的使用

用真空的拔火罐， 火罐有不同的 size， 用真空的来吸。 在介绍火罐， 并没有介绍哪个厂商。 火罐用的时候就要拿火罐枪将空气吸出来， 拿的时候后面的尾巴一拔， 气就放出来了。

你们命很好，在学针灸时，是用点火的。 当时， 曾有个过于。不小心头发烧了一个大洞。

火罐除了可以吸脓，还有瘀血，在活血化瘀的时候， 例如膝盖扭伤，会在痛点放血， 用火罐放血的时候看颜色， 由黑变淡，就起罐。 被竹子刺到或海胆刺到，都可以用火罐抽出来。

有些地方不能拔火罐， 例如乳中，否则乳头会流黄水出来。 多汗的地方不上火罐，头部也不用火罐。在外科急性扭伤的时候用的甚多，受伤时马上在扭到的地方上火罐。还有痔疮，现在是用放血针，刺完以后，就用火罐把它吸出来。 西医的放血针做得很好，针尖呈三角形， 很锐利，放完后就可以直接丢掉。 下文介绍针时，再跟各位讲。 这是笫一章的基本概念，
