# 第六章·血痢。痔疮。肠漏与大肠癌

那若痔疮，还有一种是血痢。 这两个有很特殊的手法。 在讲针灸的时候，痔疮时。 如是外痔就放血， 用火罐去吸， 用枯痔散，让痔脱落下来。 有一种很特殊的灸法， 可以治疗下血， 例如内痔， 有大量的血排出来。

叫肠风下血。 大肠发炎的时候，大便会跟血混在一起，下利甚多。 要怎么灸？教你怎么灸，这是背后，尾椎骨在这，腰椎第十四椎，肚脐正对面， 可以从膀胱经最低的地方肾俞开始。

从第十四椎开始， 从尾椎骨往上走， 用手指头去按， 按照过去的说法是一寸，这是同身寸。 你一路往上按，每一个关节都会有一个痛点，最常见的是三个椎，压了好痛，遇到痛就放个生姜灸。

肠风下血， 中医讲的是症。那病， 可能是内痔或大肠炎， 而且是鲜血。在这个背后连续痛点灸，第二天会消甚多。 灸到没有血流出就可以了。 因每个人都不一样，要灸到什么时候，不要问，要灸到症都好了，这基本常识。 这是很特殊治下血的方法。

临床上，还有一个叫肠漏，叫肠漏。 因为病人开过刀，开完刀后伤口又没好，产生瘘管。 由于那个地方每天都要用，伤口怎么会收口？所以敌人痔疮，你们开刀。 治疗肠漏， 开完刀没好，产生瘘管时， 用灸的，效果很好， 收口力量甚大，速度比针还好。在尾椎骨 、腰椎灸。 用隔着生姜灸，效果真的是甚佳，这是传承千年的手法。 治痔疮， 下承山 、孔最、 长强都可以， 天应放血也都很好。

若碰到大肠癌， 中医是辨证论治， 大肠癌，大便不出来，针灸要怎么做。 想尽办法大便还是不出来，则是大肠癌了。 下痞根、 消积， 因有肿块在里面。 有一个症是大肠排不出来，一般有癌症的病人， 脚一定是冷的。 因为脚冷的原因是这样，小肠是属火。 心脏的火移热到小肠里面来， 成为小肠的火，小肠就是热的， 脚是温热的。

现在有一个肿块， 不管是摄护腺癌 、子宫肿瘤 、卵巢癌， 不管什么癌， 只要有癌产生时，都会把阳阻隔掉。 热没办法下来，脚就是冰的。 所以， 可见摄护腺肥大，脚都是冰的。 所以说， 怎么知道他有没摄护腺肥大， 当脚是冰的， 因为癌细胞肿块，会把阳隔绝掉。 阳没办法下去了，但身上还有阳热，就会找个地方散掉。 不然就太热，若热没办法下去， 回逆心脏，而心脏管两个手，就会到劳宫穴、少府， 所以手掌会非常干。像干的面包，男人一握手，就知道这个人有没有摄护腺癌。 一握，手太干了，就讲完了。不用摸脉就已经知道了， 大肠癌也是一样，女人的子宫肿瘤也是一样，脚都是冰的，手脚皮都退掉了。 ？ 因为下焦堵到，整个下焦堵到， 阳会回逆心脏， 心脏会心悸，冲到手上， 手上会很干，就是这样的原因造成的。
