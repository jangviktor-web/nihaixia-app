# 第三章·与四季的关系

井穴主冬天，脏主冬，冬天的时候刺井穴。 井荣俞经合五穴，都在手肘以下或膝盖以下。 若今天扎针， 你又怕出事，在手脚上扎针就不会有事。 若能一针把人扎死，那还真是天才，拜你为师。 刀子刺下去都能救回来，何况扎在脚上怎么会死，很安全的。

下面介绍的时间，若出问题时是夏天，一样取他的俞穴。 声音主长夏，对长夏的定义， 中医，依中国易经，在春三月的时候，这三个月，其实不是一月到三月，而走到了第三个月的最后两周， 即将要转换为夏天的时候。 夏天三个月，第一个月最早的两周。 也就是说，春和夏交接的前后两个礼拜，春天取两个礼拜，夏天取两个礼拜，把它合并成一个月， 叫长夏。 春夏交接一个月、夏秋交接一个月，秋冬交接又一个月，冬天和春天交接又一个月，这是长夏的位置。 真正对长夏的定义，是节气在转换或季节的交换。 这长夏不是说夏天很长， 夏天都一样的。

至于合穴，《针灸甲乙经》指出， 味主秋， 常有人味道有问题，包括嗅觉，还有人嘴巴发出金属的味道。 如嘴巴如此甜，嘴巴如此苦。 只要有味道的问题治在合穴， 主秋，秋天。

那要去春夏秋冬， 中医的观念，春夏养阳、秋冬这个季节是养阴， 阴阳的定义，过去甚多人说， 阳！ 阴！ 指的是男人的生殖器及女人的生殖器。 他以为他讲的很妙。 讲人纪至简，给你们一个观念，看的手臂， 看得到的都是阴， 阴就是有形的。 力量有多大，则是阳。 比方说， 可以握，肝病的不可以握，握的力量有多大，肌肉的力量有多大，这些无形的就是阳。 能握，肝脏好才能握，肝病的人不能握，那握的力量有多大，这是阳。 看到皮肤、肌肉、血管， 这些都是阴，这是阴阳的观念。 所谓春天夏天要养阳，秋冬主收敛要养阴。圣人 、智者告诉，要随着节气定，春夏要多运动， 不是秋冬不用运动， 而是要收敛， 包括房事要节制。

针灸的穴道是可以用在保养的，会教你们如何美颜，下次回来！ 不要说，老师！你怎么变了， 你是老师的儿子？

若按照节气走，不违逆节气， 寿命会延长，就不会生病。 生病的人是反着走的。
