## 🏗️ 技术架构

```
lib/
├── engine/                          # 诊断引擎
│   ├── diagnostic_engine.dart       #   六经辨证状态机
│   └── diagnostic_rules.dart        #   诊断规则（合病·鉴别·加减）
├── models/                          # 数据模型
│   ├── diagnosis.dart               #   诊断结果 + 处方 + 加减
│   ├── formula.dart                 #   方剂模型
│   └── herb.dart                    #   药物模型
├── data/                            # 数据层
│   ├── formula_repository.dart      #   方剂仓库（4级匹配策略）
│   ├── herb_repository.dart         #   药物仓库
│   └── database_helper.dart         #   SQLite 持久化
├── screens/                         # UI 界面
│   ├── chat_screen.dart             #   对话式诊断
│   ├── knowledge_screen.dart        #   方剂/药物速查
│   ├── diagnosis_history_screen.dart#   诊断历史趋势
│   └── tools_screen.dart            #   实用工具集
└── assets/data/                     # 离线数据
    ├── formulas.json                #   322首方剂
    ├── herbs.json                   #   448味药物（《神农本草经》全量）
    ├── acupoints.json               #   408穴（十四经脉 + 经外奇穴）
    └── acupuncture.json             #   穴位处方（14类257条 + 透针31）
```

<details>
<summary><b>📐 诊断引擎设计</b></summary>

**4级方剂匹配策略：**
1. 精确匹配 `name`
2. 别名匹配 `alias`
3. 斜杠分割匹配（如"小柴胡汤/大柴胡汤"取第一个）
4. 子串匹配（如"桂枝加厚朴杏仁汤"匹配"桂枝汤"）

**合病检测：** 6经评分 → 精确条件匹配 → 方剂覆盖
**鉴别诊断：** 经 + 证型关键词 + 问诊答案 → 26对鉴别

</details>

## 📖 六经辨证体系

<div align="center">

| 经 | 主证 | 主方 | 要点 |
|:---:|:---|:---|:---|
| ☀️ **太阳** | 脉浮、头项强痛、恶寒 | 桂枝汤 / 麻黄汤 | 表证第一关 |
| 🔥 **阳明** | 但热不寒、胃家实 | 白虎汤 / 承气汤 | 阳明无死证 |
| 🌅 **少阳** | 口苦咽干目眩、往来寒热 | 小柴胡汤 | 半表半里，但见一证便是 |
| 🌙 **太阴** | 腹满吐利、食不下 | 理中汤 / 四逆汤 | 脾虚寒湿 |
| 🌑 **少阴** | 脉微细、但欲寐 | 四逆汤 / 真武汤 | 心肾阳虚，急温之 |
| ☯️ **厥阴** | 消渴、气上撞心、寒热错杂 | 乌梅丸 / 当归四逆汤 | 阴之尽，寒热并结 |

</div>

## 📝 更新日志

### 🎯 v1.10.1 (2026-08-16) — 针灸穴位板块「全量体检 + 手术级修复」

> 针灸穴位，曾是汉唐中医最容易被「点开放空」的角落：有的穴位没有归属经脉，有的介绍只有一句话，有的处方明明写着「配某穴」，点了却跳不过去。这一次，我们不靠猜、不凭印象，拿倪师《人纪·针灸》逐字逐穴做了一场**实证审计**。

**一、审计怎么做的（达尔文纪律）**
- 把权威文档下载到本地（8029 行、41.7 万字，十四经脉逐穴讲授），脚本实抽 + 源码二次核验
- 每一处「缺失 / 变薄 / 关联断裂」都标注了出处——能断言的就断言，吃不准的显式标注「待文档段落确认」
- 全程人在回路：先出报告，用户确认「全量修复」，再动手

**二、三类问题，逐项动刀**

| 维度 | 修复前 | 修复后 | 关键动作 |
|:---|:---|:---|:---|
| 穴位总数 | 379，且声明 366（元数据自相矛盾） | **408** | 补督脉 8、任脉 7、肝经 4、胆经 4、经外奇穴 6，十四经脉全部达标 |
| 归属经脉 | 16 条穴位「查无经脉」 | **0** | 中风八大穴→经外奇穴、五里穴→足厥阴肝经、八髎→膀胱、渊腋→胆经、膏肓/瘛脉/禾髎…逐一归位 |
| 穴位↔处方关联 | 90%，24 处点不动 | **100%** | 缺穴补齐 + 处方错别字归一，点击即达 |
| 针刺/灸法/禁忌 | 87%~100% 空字段 | 文档讲了就回填（针刺 55% / 灸法 51% / 禁忌 32%） | 没讲的如实留空，**绝不编造** |
| 处方错别字 | 17 类 | **0** | 见下方清单 |

**三、那些被写走样的名方（现已全部修正）**
处方文件里，古人名方一个个被「写错字」，一个错别字就是一处跳不过去的死链：

> 大杼→**大抒** · 膻中→**塹堂 / 膳中** · 蠡沟→**蛧沟** · 郄门→**郙门** · 巨阙→**巨阶** · 脾俞/肺俞/肾俞→**脿/肺/肾俭** · 大陵→**大敛** · 中渚→**中渺** · 十宣→**十宠** · 翳风→**翨风** · 肩髃→**肩廓** · 肩井→**肩醹** · 中阳→**中脘**……

**四、详情页「关联打通」（最值得体验的升级）**
穴位，不再是一座座孤岛。点开任意穴位，现在能看到：
- **倪师处方公式** — 自动解析临床心悟里的 `**XX方**：A + B + C`。比如三毛穴：「**暖宫方**：三毛 + 关元 + 气海 + 三阴交，治宫寒不孕、痛经」，组成穴可逐个点开
- **关联穴位处方** — 反向告诉你「哪些处方用到了这个穴」，一键直达
- **关联透针透穴** — 中府透云门这类透针组合，也能跳

**五、应用体验增强**
- 📝 「关于」页终于有了**更新日志**（内置 `changelog.json`，含历史版本）
- 🎉 装完新版，**自动弹出「本次更新了什么」**——再也不会装了不知道改了啥
- 🔢 版本号对外改为 `1.10.1 / 1.10.2 / 1.10.3` 递增格式，一眼看出是第几版

**六、验证（不是嘴上说）**
- `flutter analyze`：**0 错误**
- `flutter test`：**174 / 174 全过**
- `flutter build apk --release` 成功，aapt2 校验 `versionCode=8 / versionName=1.10.1`

### 🚀 v1.6.0 – v1.10.0 累计重大更新

> 这五个版本，是汉唐中医从「能用」走向「可信」的一段路。我们把之前埋下的每一处「差不多」，都翻出来逐一较真。完整逐版本记录见项目根目录 [`CHANGELOG.md`](CHANGELOG.md)。

- **🧠 七步问诊引擎重构**：以六经为纲，叠加《金匮》19 证候族鉴别树，双轨并行。实测 237 首用户方剂覆盖 **97.9%**，224/224 界面可达、0 误判；诊断引擎全量 **226/226（100%）** 可达——意味着没有任何一首方剂藏在 App 里却点不出来。
- **🌿 神农本草经板块修复**：方剂里的组成药名五花八门（朱砂 / 丹砂、栝蒌实 / 栝楼实、炮附子 / 附子……），导致「含此药的方剂」大量点不动。做了一套别名归一，组成名可解析率 **67% → 91%**；又补建了 8 味《本经》漏载的药（狗脊、玄参、磁石、肉苁蓉…），全量 **440 → 448 味**。
- **🔍 倪海厦关联核查（三轮）**：顺着倪师「病证 → 方」的讲法，修正了 5 处错配——狐惑主方应为甘草泻心汤、杏子汤实为麻黄杏仁甘草汤、桃红四物汤应归桂枝茯苓丸、牡蛎汤标签纠正等。
- **⌨️ 按键与可达性审计**：七步问诊每一个选项按钮实测，修掉 16 处标注 / 引擎错误——你按下的每一个键，都真的会带你到对的地方。
