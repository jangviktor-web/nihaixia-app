# 汉唐中医 v1.11.25 发布说明

> 发布日期：2026-10-10
> 内部版本：1.11.25+4024（Android versionCode=4024）

## 一句话
本版三线并进：**易经 64 卦新增传统卦象典故插画**、**「中医时辰开穴综合计算器」扩为四法并排（纳子 / 纳甲 / 灵龟八法 / 飞腾八法）**、**五运六气新增三张可视化图并入库《内经》运气文献**。

---

## 🌟 一、易经 64 卦 · 卦象典故插画

- 每卦详情页在卦名（上卦／下卦说明）下方显示该卦的传统典故版画（如 **乾为天 = 云中取鹿**、**地天泰 = 梯上取鹿**），共 **64 张，全覆盖**。
- 插画文件名与 `yijing_data.dart` 的卦名**一一对应**（双向对账 64/64，无缺无多）；异体字归一（**天山遯 → 天山遁**）。
- `errorBuilder` 兜底：某图缺失时**静默收起**，不影响页面其它内容。
- 零新增依赖，包体积仅增约 **1.1 MB**。

## 🌟 二、中医时辰开穴综合计算器 · 四法并排

- 纳子法 / 纳甲法 / 灵龟八法 / 飞腾八法四个 Tab，选中即给出当日 **日干支、时干支** 与开穴。
  - **纳甲正开**：如 太渊（肺经 · 输穴），并给出「返本还原」原穴（输穴返本还原取原穴·神门）。
  - **飞腾八法**：按时干直接查卦取单穴（如时干辛 → 后溪）。
  - **灵龟八法**：日干支与时干支基数相加，阳日 +9 / 阴日 +6 取余数定卦穴（主穴 **照海** + 配穴 **列缺**），并列出推算步骤。
- 附天干歌 / 地支歌（天干 → 脏腑、时辰 → 经络）与各法说明，口径与参考站逐项对拍一致（198 日 × 12 时辰 = 19008 项零差异）。

## 🌟 三、五运六气 · 三张可视化图 + 文献入库

- 新增三图（Tab 切换，随所选日期重绘、当前步高亮）：
  - **运气五行图** —— 十字五宫夹中央，司天／在泉与五行圆形联动。
  - **五运图** —— 单环十扇区，主运／客运分色，标出各步界日期（大寒 / 春分 / 芒种 / 处暑 / 立冬系）。
  - **六气图** —— 双环，主气与客气逐步对应。
- 日期可任选（如生日），结果含：岁运（中运）病候、司天／在泉病候、运年干支与六十甲子序号、客气加临。
- **文献数据入库**：新增《内经》运气七篇大论原文（60 条）、三纪／太过不及／胜复郁（15 条）、六气胜复（6 条）、司天在泉病候 + 治则（12 条），App 内可直接查阅原文与治则。
- 零新增依赖；算法口径未改（与既有对拍夹具一致）。
