> 发布日期：2026-09-03 · 离线优先 · 完全免费 · Apache 2.0

## ✨ 这一版带来了什么

中药的世界里，同一味药往往身兼数名——茈胡即柴胡，橘皮即陈皮。名不正则言不顺，检索便会迷路。这一版为药库做了一次「正名」：**异名归一，旧名不废**——按任何一个旧名检索，都能找到它的正名条目。同时，民俗参考侧落地了三盘合参与八字补全。

### 1. 同药异名合并 —— 药库归一，正本清源

18 组「异名同种」的药材条目合并为一条正名条目（479→461 条），并在 `herb_repository` 登记 103 条「异名→正名」映射（如 `茈胡→柴胡`、`橘皮→陈皮`）。

- 数据更干净：同名异写的重复条目不再各说各话。
- 名称与别名统一经归一（`canonicalOf`）处理，为后续索引能力打地基。

### 2. 异名检索修复 —— 按旧名，也能找到它

合并之后曾出现 74 个异名在药库页搜不到的回归（按「茈胡」检索命中不了「柴胡」）。本版把散落三处的检索逻辑收敛到唯一入口 `matchesQuery`，全量异名与正名均可命中，并以 `tool/audit_alias_search.dart` 作为可执行的回归审计基线——「用户能不能搜到」从此有了机械化判据。

### 3. 三盘合参 B 方案 —— 紫微 + 八字 + 命卦同源合参

三盘同参落地；晚子时归次日改为**可开关**（默认按当日早子时处理），尊重不同流派的排盘习惯。

### 4. 八字补全 —— 十神 · 旬空 · 刑冲 · 长生

- 十神逐柱 + 旬空（空亡）标注；
- 刑冲合害 / 合会关系检测；
- 长生十二神双口径（火土同宫 / 水土同宫）用户自选。

### 5. UI 统一状态组件 StateView

新增 `StateView`（loading / empty / error），10 处加载与空状态统一、3 处静默加载接入错误重试；设计 Token 体系（间距 / 圆角 / 字号）落地，消除硬编码色值。
