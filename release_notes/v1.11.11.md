# 汉唐中医 v1.11.11 发布说明

> 🌿 同药异名合并 · 异名检索修复 · 三盘合参与八字补全
> 发布日期：2026-09-03 · 离线优先 · 完全免费 · Apache 2.0

---

## ✨ 这一版带来了什么

### 1. 同药异名合并 —— 药库归一，检索不迷路

18 组「异名同种」的药材条目合并为一条正名条目（479→461 条），并在 `herb_repository` 登记 103 条「异名→正名」映射（如 `茈胡→柴胡`、`橘皮→陈皮`）。

**重要修复**：合并后曾出现 74 个异名在药库页搜不到的回归（按「茈胡」检索命中不了「柴胡」）。本版把检索逻辑收敛到唯一入口 `matchesQuery`，全量异名与正名均可命中，并以 `tool/audit_alias_search.dart` 作为可执行的回归审计基线。

### 2. 三盘合参 B 方案

紫微 + 八字 + 命卦同源合参落地；晚子时归次日改为**可开关**（默认按当日早子时处理）。

### 3. 八字补全

- 十神逐柱 + 旬空（空亡）
- 刑冲合害/合会关系检测
- 长生十二神双口径（火土同宫 / 水土同宫）用户自选

### 4. UI 统一状态组件

新增 `StateView`（loading/empty/error），10 处加载与空状态统一、3 处静默加载接入错误重试；设计 Token 体系（间距/圆角/字号）落地，消除硬编码色值。
