# 汉唐中医 v1.11.26 发布说明

> 本次为 GitHub 首发版本（上一 GitHub 发行版为 v1.11.25）。本版起新增内容此前仅经钉钉群内测，现统一公开发布。
> 版本号规则：对外展示 `1.11.26`，内部 `build` 号 `+4029` 作为 Android `versionCode` 单调递增。

---

## ✨ 主要新增

### 十四经循行穴位图（十二正经 + 任督二脉）
- 针灸页「穴位讲解」新增「经络图」按钮，内置 14 张循行穴位图（手太阴肺经 → 足厥阴肝经 + 任脉 + 督脉）。
- 支持双指放大到 6 倍看清图中细小穴名标注；选中具体经络时直接打开该经图，选「全部」则在对话框内自由切换经络。
- 新增 `assets/images/meridians/`：14 张 WebP，683×1024，合计 536KB；文件名与经穴库 `meridian` 字段字面一致，运行时无需名称映射表。

### 耳穴国标定位图直接嵌包（GB/T 13734-2008 附录 A 正/背面）
- 耳穴地图 Dialog 内嵌国标附录 A 标准图（图 A.15 正面 84 穴 / 图 A.16 背面 9 穴），取代原自绘坐标点图。
- Dialog 改为「正面 84 穴 / 背面 9 穴」两 tab + InteractiveViewer 可双指放大细看穴名；去除水平镜像、按原始朝向展示（镜像会让图内穴名文字反读）。
- 图内保留「定位依据 GB/T 13734-2008，仅供学习参考」标注。

### 耳穴国标库（GB/T 13734-2008，93 穴）
- 新增 `assets/data/ear_points.json`：全 93 穴结构化数据（穴名 / 拼音 / 代码 / 分区 / 定位 / 主治），10 个耳区。
- 针灸页新增第 4 个「耳穴」tab：分区筛选 + 穴名 / 拼音 / 代码搜索 + 卡片展开查看定位与主治，页内标注定位依据 GB/T 13734-2008。
- 处方中的「耳穴:XXX」支持一键跳转到对应穴道并自动展开该穴卡片；旧称 / 俗称自动归并为国标名（下脚端→交感、降压沟→耳背沟 等 18 条别名）。

### 合并倪师 BBXX 配穴（针灸数据扩容至 384 条）
- 将倪师软件 BBXX 表的病症→配穴合并进 App 针灸数据，条目由 257 扩至 384（+127 新建 / 34 富化），14 类目不变；独立 QA 四轮复验全过。
- 新增 127 条倪师临床配穴（妇科 / 泌尿 / 眼科 / 口腔肠胃 / 神经精神 / 关节骨科 / 皮肤等病症）；34 条 App 既有病症补充倪师配穴，0 伪匹配。
- 剔除伪富化、解析泄漏清零、穴名错字归一（廖→髎 全系、悬钟 / 肩髃 / 次髎 / 攒竹 / 听宫 等）、病名糠尿病→糖尿病。

## 🐛 修复

### 五运六气三图排版修复（真机截图反馈）
- 六气图「外环客气 / 内环主气 / 步名」三层文字在 3 点与 9 点方向相互叠压：文字改为沿扇区切线方向排布（随角度旋转），各层只按半径分离，物理上不再可能叠压。
