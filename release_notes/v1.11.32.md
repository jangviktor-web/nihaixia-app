## ✨ 一、问倪师AI：让倪师讲义由你自己选的模型来答

一句话：**先把讲义里的原话检索出来，再交给模型组织成人话**——模型不自由发挥，讲不出就明说讲义里没有。

### 🧠 本地检索 → 模型作答

- 提问先在**离线讲义库**里检索：伤寒论 394 条、金匮要略、针灸讲稿 72 篇、本草讲稿 335 篇、医案 1257 例、古今病名对照 48 条、穴位 408 穴、方剂 314 首。
- 命中的原文片段连同**出处**一起喂给模型；persona 硬约束「只依据片段作答，讲不出就说讲义里没有涉及」，禁止编造条文号与方剂。
- 三路召回：关键词 → 病名古名/方名优先 → 医案反推方剂回讲稿（「二跳」）→ 症状反推穴位再反推医案（「三跳」）。
- 全程离线检索，不上传病史、不依赖云端知识库。

### 🔌 端点由你自己配

- 设置 →「AI 讲义问答」：OpenAI 兼容地址 / API Key / 模型名，支持一键拉取模型列表。
- **默认关闭**。关闭时应用不发出任何网络请求；开启后也只发往你自己填的地址。
- Key 只存本机 SQLite，不写入日志、不上传；卸载即删。

### 💬 对话可续接 + 多会话

- 轮次落本地 SQLite（DB v6：`llm_sessions` + `llm_turns`），**退出页面、杀进程后重开都在**。
- 右上角时钟图标 → 历史会话抽屉，按「今天 / 昨天 / 7 天内 / 更早」分组，支持**切换、重命名、删除**。
- 「新对话」清空当前视图但不删旧会话，可随时切回。
- 单会话保留最近 50 轮（给模型只带最近 3 轮，存更多无意义）；失败轮不落库。

### 🔍 出处审计

- 回答里出现**讲义片段与医案都没有的方名**时，回答下方标注「N 处方名未在讲义片段中出现」，展开列出并提示「可能是模型自身知识补充，涉及用药以讲义原文为准」。
- 不改写、不拦截回答，只交底——让你自己判断哪句是倪师原话、哪句是模型自带知识。
- 已知边界：只能识别方剂库内 314 首方名，库外或自造方名抽不出（漏报但不误报）。

### 🧾 类方禁忌进上下文

- 检索天然只召回「这个方治什么」（正向适应证），而辨证难点在排除。现在把方剂库的 `contraindication` 与 `explanation`（314 首方全有）一并送入上下文。
- 例：问「我怕冷、无汗、身痛，喝桂枝汤行吗」——模型能看到桂枝汤禁忌「脉浮紧，发热，**汗不出者不可与**」，以及麻黄汤要点「**无汗用麻黄，有汗用桂枝**」。
- **诚实性约束**：块标题写死「非讲稿原文」，persona 规定凡称「倪师讲 / 原文说 / 讲稿里」的必须来自讲义片段，不得把整理数据说成倪师原话。

## ✨ 二、症状自查：辨证 Tab 一页勾选

原「辨证」Tab 是逐题翻屏的聊天式问诊（十一问要点十一屏）。新增一页式自查，与聊天页**共用同一套引擎与规则数据**，只是交互不同——适合「我已经知道自己哪儿不舒服、只想快速对一下方证」。

- **第一步·寒热总纲（必选）**：只怕冷 / 只发热 / 发热怕冷 / 一阵冷一阵热 / 上热下寒 / 发热而渴不恶寒 —— 决定六经方向。
- **第二步·进阶线索（选填多选）**：面红如妆、口渴欲冷饮、小便清长、大便稀溏无灼热等寒热真假八维线索。
- **十一问**：体温 / 脉 / 渴 / 汗 / 痛 / 二便 / 胃口 / 睡眠 / 精神（chip 单选）。
- 选满 **3 项**即可辨证；结果弹层给出六经 / 证型 / 置信度 / 命中症状 / 判断依据，**方剂名可继续点进详情页**。
- **六条健康基线全过时直接给正面反馈**（「你是个正常人」+ 六条要点），不会硬凑一个方证。
- 结论定位为**快速初筛**；症状复杂时仍建议用聊天式问诊逐项确认。

## ✨ 三、回答内跳转（问答页与讲义阅读页共用一套）

- 回答里的**方剂名 / 药材名 / 穴位名**自动变可点链接：分别跳方剂 / 药材 / 穴位详情页。
- 三类共用一份候选索引：最长优先（「桂枝汤」不会被拆成「桂枝」）、方剂优先、穴位带排除名单（避免「太阳」「光明」这类短名误配）。
- 回答下方「参考 N 条本地讲义片段」的**每一条都可点开原文**——用来核对回答到底有没有照讲义讲。
- 未做行内「宋本176」链接：实测模型基本不输出条号，且形态不稳（第176条 / 一七六 / 宋本176），正则放宽会误伤普通数字；片段可点已满足核对需求。

## 🐛 四、修复

- **穴位库「消渴穴」与病名「消渴」撞词**：奇穴「消渴穴」去「穴」字后与病名「消渴」同名，问「消渴怎么辨证」会被误判成针灸提问，3 条针灸讲稿抢占上下文槽位、厥阴篇条文被挤出去。已复用既有短名撞词机制修复；全库审计确认仅此一例。
- **方剂「见于经典」书名号拆词漏挂**：宋本 175 原文写作「甘草『附子汤』主之」，书名号插在方名中间导致「甘草附子汤」漏挂、「附子汤」误挂。判定前统一剥离 `「」『』` 后一次修对三处：175 甘草附子汤、177 炙甘草汤、112 逆汤。
