## ✨ 这一版带来了什么

中医的世界里，一味药常常散落在医案的病机里、闭门课的原文中、方剂的组成间。这一版做的，就是把「药」的索引彻底打通：**无论在哪里读到药名，轻轻一点，就能走进它的详情页**。同时，药物详情页做了一次瘦身——相关内容不再一页堆叠，而是按「入口 → 列表 → 详情」逐层展开。

### 1. 药库列表 / 搜索全部可点击 —— 任意药名，一键进详情

移除了「有详情才可点」的门控：本草列表与搜索结果的**每一行**，现在都能直达药物详情页。曾经「药名点了没反应」的困惑，这一版彻底根治。

### 2. 医案 / 闭门课正文药名可点 —— 读到哪里，点到哪里

- 医案详情的自由文本字段（病机、治法、倪师观点等）里，药材名与方剂名直接可点——读医案时顺手查药，不必再切回药库搜索。
- 闭门课正文的药材名渲染为链接，并自动做异名归一：按「橘皮」点进去是「陈皮」；方剂名整体识别，绝不会把「小柴胡汤」误拆成药材「柴胡」。

### 3. 药物详情页三级结构 —— 页面清爽，按需展开

详情页只保留三个入口按钮：**关联医案 / 关联闭门课 / 含此药方剂**，各带数量徽标。点击进入仅标题的简洁列表页，再点条目查看完整内容。

以生附子为例：过去一页要堆下 145 条医案，现在首页清清爽爽，列表与详情各自按需加载，层级独立、互不拖累。

- **收藏态崩溃隐患修复**：药物 / 方剂详情页的收藏异步回调补齐 `mounted` 守卫，消除快速返回上一页时「setState after dispose」的闪退风险。
- **测试**：全量 `flutter test` 333/333 通过；`flutter analyze` 0 error / 0 warning。
- **出包门禁**：异名检索功能级审计 PASS；aapt2 校验四包 `1.11.12（versionCode 4）` 一致；签名指纹与线上已装版相同。
