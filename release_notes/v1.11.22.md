## 🌟 v1.11.20 · 工具箱三大民俗命理功能

- **袁天罡称骨算命**（`lib/screens/chenggu_bone_screen.dart` + `lib/data/chenggu_data.dart`）：按出生年/月/日/时对照称骨歌诀累计骨重，查表得命格批语，零新增依赖。
- **受生债查询**（`lib/screens/shousheng_debt_screen.dart` + `lib/data/shousheng_data.dart`）：按出生年天干 + 生肖查表得受生债库官、数目与纳音，附民俗文化背景。
- **轩辕黄帝四季歌**（`lib/screens/huangdi_siji_screen.dart` + `lib/data/huangdi_siji_data.dart`）：四季养生歌诀浏览 + 按节气/季节检索；配图由 1600×1520 裁剪去水印图换为 983×983 无水印原图（381KB → 175KB）。
- 三项功能均内置免责声明卡，标注「民俗文化参考，不构成医学诊断或治疗建议」，与医疗诊断工具分区明确。

## 🛠️ v1.11.21 · 工具箱分区 + 中文日期选择器修复

- **工具箱分区**：18 项按主题拆分为「中医区(6) / 玄学区(11) / 通用区(1=设置)」三块带配色分区头。
  - 新增 `ZoneSection` 组件（`enum Zone{general,tcm,metaphysics}`）：彩色标题 + 着色背景（暖褐=中医 / 冷紫=玄学 / primary=通用），分区边界清晰。
  - `AppColors` 新增 `tcmZone` / `metaphysicsZone` 双主题色 token（`lib/theme/app_colors.dart`，light/dark/copyWith/lerp 全补）。
  - 18 张 `_ToolCard` 原样保留，扁平 `ListView` 重构为 3 个 `ZoneSection`，零引擎/路由改动。
- **中文日期选择器修复**：`MaterialApp` 此前缺 `localizationsDelegates` / `supportedLocales` / `locale` 且 `pubspec.yaml` 缺 `flutter_localizations`，导致 8 处 `showDatePicker` 回退英文；现强制 `locale=zh_CN` 并补依赖，年月日与按钮全中文。

## 🎏 v1.11.22 · 黄历神诞检索 + 记梦 / 身兆记录

- **每日黄历神诞检索入口**：黄历右上角新增 🎏 入口，进入「农历节日·神诞」表（`lib/screens/festival_lookup_screen.dart`），合并玉匣记神仙圣诞 + 潮汕节俗 + 斋期共 **219 条**，支持关键词搜索、农历/公历双显，零新依赖零新资产。
- **周公解梦 · 记梦**：周公解梦右上角 📝 入口新增「记梦」面板，写入 `Bookmark(category:'记梦', source:'周公解梦·记梦')`，关键词/梦境描述可选。
- **玉匣灵兆 · 身兆记录**：玉匣灵兆右上角 ⚠️ 入口新增「记录身体征兆」面板，写入 `Bookmark(category:'身兆记录', source:'玉匣灵兆·{时辰}')`，source 自动带当前时辰。
- **复用 Bookmark 体系**：记梦/身兆记录直接复用既有 `Bookmark` 模型 + `bookmarks` 表，无新表、无数据库迁移；`insertBookmark` 触发 `bookmarkVersion.value++`，收藏页按 `category` 自动归类显示。
