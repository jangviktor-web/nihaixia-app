# 汉唐中医 v1.11.27 发布说明

> 发布日期：2026-10-19
> 内部版本：1.11.27+4032（Android versionCode=4032）

## 一句话

民俗文化参考层一次补齐三个术数小模块（**三山国王灵签 92 签 / 小六壬双口径 / 梅花易数**），四个排盘结果页支持**一键存图与分享长图**，梅花易数新增**摇一摇起卦**。

## ✨ 新增（Added）

- **三山国王灵签**：收录广东揭西三山国王祖庙传承 92 签，每签含签号 / 签题 / 签诗原文 / 吉凶等级四字段。「求签」页签默念所问之事后摇取签文；「签谱」页签支持按吉凶（上 42 / 中 31 / 下 17 / 无事 2）筛选 + 签题与签诗全文检索。
- **小六壬**：时间起课，月 / 日 / 时三宫顺数，六宫（大安 / 留连 / 速喜 / 赤口 / 小吉 / 空亡）配主事六神与歌诀。术内对「月初一落宫」本有口径分歧，故**「通行掌诀」与《多能鄙事》双口径并列**由使用者自选，页面同时展示推算过程便于自核。
- **梅花易数**：时间 / 数字 / 随机三种起卦，输出主卦、互卦、变卦三卦与动爻爻辞；以动爻定体用，按《体用总诀》五关系断吉凶，结合月建旺相休囚死修正力度；互卦遵循「乾坤无互，互其变卦」特例。**零新建卦数据**，直接复用易经库，与易经模块同源。
- **排盘结果存图 / 分享长图**：八字排盘、紫微斗数、五运六气、梅花易数四个结果页 AppBar 新增图片入口，进入长图预览页（可滚动查看），提供「保存图片」（存本机，无需存储权限）与「分享长图」（系统分享面板，可转存相册 / 文件 / 微信）两个出口；导出内容与各页结果区同源，统一附带免责脚注。
- **梅花易数「摇一摇起卦」**：输入区新增「摇一摇随机起卦」开关（默认开启，可随时关闭）。摇动手机即自动切到随机起卦并重摇一卦（不动已输入的时间 / 数字），触觉反馈确认；一次摇动只出一卦，缓慢倾斜不误判。

## 🔧 改进（Changed）

- 长图预览页底部按钮带漏出内容：供截图的底层全量布局副本溢出部分会画到底栏上，卡片标题从半透明按钮后漏出、被实心按钮截断。现将溢出裁在视口内并给底栏加不透明背景。
- 小六壬双口径不冒充唯一正解：页面并列呈现，口径出处随结果展示。

## ⚠️ 边界（Known Issues）

- 三个术数模块均属**民俗文化参考**，页内固定免责声明，与经方医疗模块在界面与文案上清晰分隔，不构成任何吉凶指令或医疗建议。
- 小六壬不署作者名（「李淳风」署名无可靠版本学证据）。
- 灵签数据未收录「典故 / 现代解读」层（参考开源项目命语自带的该层为现代 AI 生成内容，未采用）。

## 📜 数据与实现

- 签谱正文整理参考开源项目**命语**（`github.com/Brhiza/mingyu`，AGPL-3.0）的 `ssgw-data`，仅取祖庙签谱的传统文本字段，其自带的现代解读内容一律未采用；全部代码与数据层为本项目自行撰写（Apache-2.0），生成脚本 `tool/gen_sanshan_lingqian_data.py` 可完整复现。
- 本版新增依赖 `sensors_plus`（加速度计，Android / iOS 均无需传感器权限）；存图功能零新增依赖（复用已有 `path_provider` + `share_plus`）。
