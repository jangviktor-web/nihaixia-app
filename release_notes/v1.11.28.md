# 汉唐中医 v1.11.28 发布说明

> 发布日期：2026-10-30
> 内部版本：1.11.28+8037（Android versionCode=8037）

## 一句话

字号上限提到 **200%** 并全 App 生效；古籍原文库收录《灵枢》《针灸大成》并打通经典全文搜索；修掉浅色模式下搜索页文字过浅；切 tab 与滚动做了两项性能优化。

## ✨ 新增（Added）

- **字号上限 150% → 200%**：设置里的字体大小滑块改为 0.8 ~ 2.0（每档 5%，共 24 档）。
- **字号全 App 生效**：原先字号只作用于首页四个 tab，设置页、方剂 / 医案详情与各类弹窗都不跟随；现已覆盖全部页面。
- **古籍原文书库**：收录《灵枢》82 章、《针灸大成》339 章，按「书 → 章节目录（可按章名与正文搜索）→ 章节阅读」三级组织，正文中的方剂名 / 药材名可点开详情。入口：工具 → 中医区「古籍原文」、内经速查页右上角、伤寒金匮页第三张卡。
- **全局搜索「经典」分组**：索引覆盖伤寒 380 条 + 金匮 453 条 + 内经 73 篇讲稿 + 421 古文章节（共 1327 条），标题命中优先，带来源标签与关键词上下文摘要，点击直达篇章。

## 🔧 变更（Changed）

- **古籍库换书**：《神农本草经》《道德经》移出古书库（本草模块 465 味药与本草页不受影响），新增明·杨继洲《针灸大成》。
- 伤寒论 / 金匮要略 / 内经三个讲稿阅读库新增库内搜索框。

## 🐛 修复（Fixed）

- **浅色模式下搜索页结果标题几乎看不清**：关键词高亮使用 `RichText` 渲染，未命中片段没有显式颜色，而 `RichText` 不继承默认文字样式，浅色下回退成接近白色。现统一显式指定基础色，关键词仍以强调色加粗，浅色 / 深色均达 WCAG AA（≥ 4.5:1）。
- 八字盘 / 关煞 / 紫微盘的同类 `RichText` 补基础色兜底；古籍书库、讲稿阅读库的小字副标题与免责脚注换成对比度更高的颜色。

## ⚡ 性能（Performance）

- **切 tab 不再重建整页**：知识库 7 个 tab、针灸 4 个子 tab、内经 3 个子 tab 加保活，切回不重建首屏长列表，筛选与滚动位置保留。
- **过滤结果缓存**：方剂 257、本草 465、穴位 408、医案 1257 的过滤结果按筛选条件缓存，仅在条件变化时重算。

- 古籍原文与讲稿存在主题重叠（素问 / 伤寒 / 金匮原文未收，只收 App 内原本没有的《灵枢》《针灸大成》）。
