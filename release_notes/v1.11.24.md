# 汉唐中医 v1.11.24 发布说明

> 发布日期：2026-10-03
> 内部版本：1.11.24+19（Android versionCode=19）

## 一句话
穴位讲解的经络筛选分组新增**六奇经**（冲脉 / 带脉 / 阴维脉 / 阳维脉 / 阴跷脉 / 阳跷脉），57 条交会穴补齐所属经脉标注，多脉穴**忠实出现在所有所属脉分组**——奇经视角的取穴入口就此补齐。同时随版带出穴位「国标穴序」排序、同名并列次键修复与「子宫」禁链等一批穴位模块精修。

---

## 🌟 本版主打：六奇经筛选分组

### 1. 经络筛选从 15 组扩到 21 组

- 穴位讲解页的经络筛选序列更新为：十二正经 → 督脉 → 任脉 → **冲脉 / 带脉 / 阴维脉 / 阳维脉 / 阴跷脉 / 阳跷脉** → 经外奇穴，共 **21 条**。
- 六奇经在经络学说里**不单独设穴**（无本经穴位），但冲脉并少阴上行、带脉束腰、阴维阳维维系一身之阴阳、阴阳跷跷分主一身左右之阴阳——它们的交会穴散在十二经与督任之间。此前这些穴只能按十二经 / 督任查到，奇经视角缺位。

### 2. 57 条交会穴补齐次键标注

- `assets/data/acupoints.json` 为 57 条交会穴补 `meridians` 次键列表，标注其所属**全部**经脉（含六奇经），总穴数 408 不变。
- **多脉穴绝不压缩成单脉**：如 **公孙**（足太阴脾经 + 冲脉）同时出现在「脾经」与「冲脉」两个分组；**内关**（手厥阴心包经 + 阴维脉）、**照海**（足少阴肾经 + 阴跷脉）、**外关**（手少阳三焦经 + 阳维脉）、**带脉穴**（足少阳胆经 + 带脉）同理。各穴在主脉下的内容原样保留。
- 数据分布：阳维脉 17 穴次、冲脉 15、阳跷脉 13、阴维脉 9、带脉 4、阴跷脉 3（多脉穴在多脉下分别计）。

### 3. 检索同步升级

- **按脉筛选**：同时匹配主键 `meridian` 与次键 `meridians`，切到「冲脉」即列出全部冲脉交会穴。
- **全文搜索**：支持次键模糊匹配，搜「冲脉」「带脉」等可直接命中其交会穴。

### 4. 随版带出：穴位模块精修（v1.11.23 后累积落地）

- **国标穴序**：十二正经组内按国标穴序排列（如肺经 中府→云门→……→少商），督脉 / 任脉同样按国标序；异名归槽（人中→水沟、顖会→囟会、通谷→足通谷等）。
- **同名并列次键**：同长度穴位名并列时按名称字典序稳定取舍（督脉「腰阳关」与胆经「阳关穴」不再抢位误链）。
- **「子宫」禁链**：解剖语境的「子宫」不再被误链到经外奇穴（正当引用写作「子宫穴」仍可命中）。
- **数据错字修正**：三焦经「瘛脉穴」→「瘈脉穴」。
