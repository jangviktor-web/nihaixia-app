## ✨ 新增（Added）

- **《黄帝内经》结构化条目检索**：「黄帝内经·速查」页新增入口，内置 `lib/data/neijing_entries.dart` 共 52 条 `NeijingEntry`、10 个维度（`kNeijingDimensions`）。
  - 维度覆盖：脏象 / 望诊 / 脉诊 / 病因病机 / 经络循行 / 气血津液 / 辨证体系（八纲·六经·脏腑）/ 治则方药 / 病证举例 / 误治宜忌。
  - **每条强制四字段分离**——`original`（《内经》原文引文）/ `source`（篇·节，可核查）/ `vernacular`（白话译解）/ `nishi`（倪师视角，非原文直引处一律标【推断】），一眼可分「经典原文 vs 解读」，解决「原文出处不清」。
  - 检索页 `lib/screens/neijing_entries_screen.dart`：支持六字段搜索（标题 / 原文 / 出处 / 白话 / 倪师 / 标签，词间「与」）、**按篇名检索**（如「热论」「灵枢」）、维度筛选、标签交叉「或」检索；卡片展开分字段显示，【推断】以 error 色高亮。
  - 全部颜色走 `ColorScheme`，深色模式无硬编码，与原脏象/望诊/脉诊三 Tab 共存（原三 Tab 未动）。
  - 新增 `test/neijing_entries_screen_test.dart`（21 例：过滤逻辑 / 标签排序 / 高亮 / 页面交互 / 深色模式），21/21 通过。

## 🐛 修复（Fixed）

- **深色模式正文不可读**（+11）：`MarkdownStyleSheet.fromTheme()` 把引用块底色硬编码为 `Colors.blue.shade100`（#BBDEFB），深色模式下白字压浅蓝底对比度仅 **1.09:1**。闭门课正文通篇引用块，整页几乎看不清。
  - 引用块底色 → `surfaceContainerHighest`（深色 #3D332D），文字显式 `onSurface`，对比度升至 **9.50:1**，蓝色块移除、改用 `primary` 左侧竖线标识引用。
  - 行内代码/代码块底色统一为 `surfaceContainerHighest`；链接与四级小标题用 `primary`，其余统一 `onSurface`，表格边框用 `outlineVariant`。
  - 列表页细节（闭门课 chevron、`ActionChip` 文字）补全主题色。
  - 新增 `test/markdown_doc_contrast_test.dart`（WCAG 2.1 对比度断言），5/5 通过。
- **早晚子时 × 真太阳时下的农历与干支**（+12）：
  - 早子时（00:00–01:00）八字/关煞屏农历落后一天：现农历基准日随早子时同步 +1 天。
  - 判定顺序颠倒：原用未校正原始小时判早/晚子时，校正在引擎内部后执行导致日柱差一天、时柱落亥时；现改为先取校正后时刻再判定。
  - 晚子时时柱错误：改为取「校正后次日子时」重排。
  - 新增 `test/zishi_solar_lunar_test.dart`（15 例），15/15 通过。
