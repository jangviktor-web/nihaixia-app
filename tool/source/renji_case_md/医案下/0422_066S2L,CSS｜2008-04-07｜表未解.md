# 066S2 L,CSS｜2008-04-07｜表未解

## 性别

女

## 年龄及体型

36岁，中等

## 来诊原因

七年前开始右脸三叉神经痛，刺痛，吹风则加重
服药后

## 问诊

右脸仍有痛
无汗出玄府不开，汗透发不出累积产生压力，故仍痛。
风吹难过稍好些仍须发表
右边鼻子一直不通

## 脉诊

浮弦细发表用麻黄(除非体内津液不足或值经期)

## 中药处方

葛根四钱  麻黄三钱  桂枝四钱  白芍四钱  生姜二片  大枣十枚  炙甘
草三钱葛根汤
白附子三钱  僵蚕三钱去风痛，用于风吹了就会头痛
勾陈三钱可穿透神经末梢
川芎三钱各种头痛要药
7碗水煮成2碗  早晚饭前各喝一碗
2. HTS25(止痛) 早碗饭后各40颗

## 针灸处方

左合谷面口合谷收，可发汗
右迎香通鼻窍
左侠溪、解溪胆经、胃经母穴，久痛为虚，补其母
左外关可发汗
右下关、地仓、太阳、头维近取穴
左眉棱点附近痛左阴陵泉下面的压痛点，此乃奇穴，专治眉棱骨痛
