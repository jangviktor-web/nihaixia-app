# 238 T, L｜2008-05-28

## 性别

男

## 年龄及体型

41，瘦

## 来诊原因

肾结石（一年前也有过肾结石，吃中药排出来了）。
上周六，右肾很痛。
触诊：
1、身体：压右足肾石点，无压痛
腹诊：
耳诊：右耳肾点有压痛

## 中药处方

HTS26   6两  40X2 早晚餐前

## 解说

有些人对痛不敏感。故此人虽有肾结石，但在肾石点并没有反应出来。但是在耳朵的肾点有反应。

## 针灸处方

右耳肾点埋耳针
