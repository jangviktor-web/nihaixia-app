# 053S6 J,D｜2008-04-16

## 性别

男

## 年龄及体型

71y/o 高壮

## 来诊原因

2006中风后左侧麻痹 回诊
问诊：
稳定进步中，可以正确读出字母，但无法理解意思。
难以入睡，走路回复情况较慢，但跑步恢复很好。
