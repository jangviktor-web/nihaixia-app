# 081S2 M,G｜2008-03-06

女

眼睛流泪全天发病改善为仅晚上发病。眼泪服药后由油状改善成清水状油为气
左腋下淋巴腺稍肿(在心包经上)
背部痛大幅好转。
咳已好，但仍感觉喉痒及有痰。
记忆不好
不易入眠
体力很好
