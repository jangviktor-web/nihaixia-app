# 192 H, J｜2008-03-11｜中焦湿热 (C 肝)

## 性别

男

## 来诊原因

睡眠有6周不好﹐因为西医告诉他有C 肝﹐

## 问诊

1、睡眠：不好
2、大便：正常：
3、胃口﹕好
4、口渴：有﹐饮室温的水
5、小便：中黄到深黄
6、手足温度：双足中温

## 脉诊

洪缓

## 望诊

眼诊：肝区有洞﹑亁﹑松﹐ 心包有痰﹑

## 中药处方

柴胡3钱﹑黄芩3钱﹑玉金5钱﹑龙胆草3钱﹑茵陈3钱﹑茜草3钱﹑白芍5钱﹑川芎3钱﹑栀子3钱﹑丹皮3钱﹑黄柏3钱﹑补骨脂2钱﹑白朮3钱﹑茯苓4钱﹑泽泻5钱﹑生姜2钱﹑炙甘草3钱﹑大枣10枚
5付 93碗﹐ 早餐﹑晚饭前喝
柴胡3钱﹑玉金5钱、黄芩3钱﹑龙胆草3钱疏肝解郁
茵陈3钱﹑栀子3钱清肝中湿热
茜草3﹑白芍5钱﹑川芎3钱﹑丹皮3钱入肝活血化瘀
白朮3钱﹑茯苓4钱﹑泽泻5钱使湿热从小便去, 治肝先实脾
生姜2钱﹑炙甘草3钱﹑大枣10枚生肠胃津液﹐治肝先实脾
黄柏3钱清下焦湿热(补北)
补骨脂2钱补肾(补北)
