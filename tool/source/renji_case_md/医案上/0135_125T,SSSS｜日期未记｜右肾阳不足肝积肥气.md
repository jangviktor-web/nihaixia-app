# 125 T,SSSS｜日期未记｜右肾阳不足 肝积肥气

## 来诊原因

2、胃口：好
3、大便：日行一次 自觉不尽感
4、小便：淡黄
5、口渴：尚可 喜温饮
6、手足温度：双足稍冷
7、掌额温度：
8、问汗：手脚有汗，身体不大有汗
9、体力：尚好
10、头身：
11、生理期：
12、其他：

## 脉诊

沉细 (春逢冬脉)相生脉为吉

舌诊：淡白干
眼诊：右瞳孔收缩迟缓肾阳不足
两眼肝区有圈纹
