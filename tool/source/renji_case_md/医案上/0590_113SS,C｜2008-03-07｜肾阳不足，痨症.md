# 113 SS,C｜2008-03-07｜肾阳不足，痨症

## 性别

男

## 年龄及体型

32岁，削瘦

## 来诊原因

自觉肾有问题，易倦怠。
左腰膀胱经久痛。

## 问诊

病史：没开过刀。
瘦多久了：一直如此，大学时胖一点。
如何知道肾有问题：验尿中含糖高。
倦怠多久了：大学毕业后。
早上起床后精神：差早上起床后精神好表示肾功能佳。
大便：不定时，有时不成形肾主二便，肾衰竭时无便意。
小便：尚好。
胃口：不太好，易生口疮。
手足温度：手脚凉，额头热。
口渴：尚好，喝室温水，不喜冰饮。
时咳白痰出可用桔梗

## 望诊

人消瘦，手臂血管粗大脉大为劳，劳证，劳证者易倦怠
眼诊：瞳孔反应差肾阳不足。瞳孔大肾虚
舌诊：黄湿。
触诊：左腰膀胱经久痛故查左踝肾石点，有压痛肾结石。

## 中药处方

桂枝四钱 白芍三钱 麻黄二钱 白朮二钱 炮附子二钱 甘草三钱 防风四钱 知母五钱桂枝芍药知母汤
桔梗三钱去白痰
泽泻三钱 补骨脂三钱 阳起石三钱补肾
侧柏叶三钱 当归二钱生发
黄芩三钱 黄连二钱 黄柏三钱舌苔黄湿厚
十付
93碗
早餐前及晚餐前各一碗

## 解说

有结石时暂时不要喝豆浆。
痨症病因为大汗后遇冷，汗发不透，日复一日而得，乃湿在血脉中。

## 针灸处方

右阴谷 右委中 左踝天应。
